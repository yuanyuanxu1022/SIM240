# 阶段三修订方案：SIM-EC1XT240 局部显式压印

## 范围与固定几何

全部后续实现限定在 OpenLB。局部单胞为 `Lx=240 nm`：`x∈[0,60) nm` 为左半凸台、`x∈[60,180) nm` 为凹槽、`x∈[180,240) nm` 为右半凸台。x 两侧周期连接后，两半凸台组成宽 120 nm 的完整凸台；中央凹槽宽120 nm、深 `d_g=100 nm`。基底表面 `z=0`，凸台底面 `z=h`，槽顶 `z=h+100 nm`。y 暂取 `Ly=240 nm` 周期，仅是无限长直条的局部测试选择，不是液滴布局周期。

`h` 必须保留为运行参数。宏观模型的 `h0=1000 nm`、`hf=65 nm`、位移 `−935 nm` 均是待确认映射。本轮 `h=65 nm` 只用于清楚检查材料布局，不是确认的终态，也未放入液滴或流体。

## S3-A：静态几何（本轮完成）

- 使用单元中心材料标记和 VTI CellData；材料0为z向外部padding，1为内部可用空间，2为固定基底，3为带槽压头。
- x/y物理域不放实体墙，均声明周期；z非周期。导出的物理单胞不复制周期ghost或overlap。
- 默认 `dx=5 nm`，所有界面落在体素面上。记录名义尺寸、离散单元数、单元中心公式、有效壁面位置、padding和未来OpenLB overlap。
- 编译和运行只生成材料数组与文件；程序没有 lattice、碰撞、迁移、液滴或运动压头代码。

## S3-B：真实动态几何（下一阶段）

目标是在真实 OpenLB `SuperGeometry`/`SuperLattice` 上把静态材料函数提升为 `h(t)` 驱动的压头，而不是再做独立数组原型。

实施要求：

1. 复用现有 M1 五次平滑轨迹形式，但 `h0/hf/Tmove` 使用经确认的局部工况；M3字段级转换/回滚原型保留为算法参考，明确它尚非真实lattice接入。
2. 每一材料变化必须同步更新边界动力学、分布函数、FreeSurface字段、邻域标志和overlap；周期缝两端同步处理。
3. 新覆盖液体的质量去向和新释放单元的初始化都进入全局守恒账本；失败时原子回滚。
4. 验收包括：轨迹/几何误差、逐步材料计数、周期缝一致性、无孤立可用单元、无NaN/Inf、静止压头零转换对照，以及多MPI分块时与单rank一致。

## S3-C：液体受压（S3-B通过后）

1. 只使用经确认的初始液体体积与形状；不得把原OpenFOAM中半径52 µm的宏观供液滴缩成纳米液滴后称为同一工况。
2. 基底/压头接触角、表面张力和实际树脂物性须有来源；缺项继续标为待确认。
3. 第一基线可选择固定参考气压FreeSurface，但必须标明忽略气体动力学且周期域没有真实排气出口；需要预测困气压力时另建显式气体/压力耦合方案。
4. 验收记录液体与界面质量、累计转换通量、界面连通与碎裂、最大速度、壁法向渗漏、凹槽填充率及凸台下横向通量。不能直接套用阶段二连续墙的 `Bxx=0`，因为 `h>0` 时凸台下方横向连通。

## 正式压印前仍待确认

- `h0`、`hf`、`Tmove` 及65 nm的局部映射；
- 初始液体体积、形状和局部供液边界；
- 两种接触角与气体处理层级。
