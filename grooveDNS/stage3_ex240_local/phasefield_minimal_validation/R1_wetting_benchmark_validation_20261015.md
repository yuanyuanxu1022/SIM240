### 6.1 "末5次"的采样口径（须在后续协议中注明，避免误读）

源码 `phasefield_minimal_validation.cpp:314`：`recentAngles` / `recentDp` **仅在 `step % vtkInterval == 0` 时入栈**。故 §2 表中"末5次"= **末 5 个 VTK 采样**，而非末 5 个连续时步：

- contact（vtkInterval=500）：采样步 = 4000 / 4500 / 5000 / 5500 / 6000（跨 2000 步）；
- laplace（vtkInterval=400）：采样步 = 2400 / 2800 / 3200 / 3600 / 4000（跨 1600 步）。

三种算法在同一份 `history.csv` 上的独立重算（全部精确复现 `result.txt`）：

| 量 | 程序口径（VTK 末5采样 ÷ 末态实测值） | 同数据 ÷ 解析预期值 | 末 5 个连续时步 |
|---|---|---|---|
| contact Δp 稳定性 | **3.342%** | **3.048%** | 0.0017% |
| laplace Δp 稳定性 | **2.943%** | **2.597%** | 0.0047% |
| contact 末5次角度范围 | **1.6220°** | — | 0.0025° |

**三种口径均远低于门槛（≤5% / ≤2°），R1 判定不受影响。** 但"末5次"字面容易被读成"末5个时步"（后者小三个数量级），建议后续协议明确写成"末 5 个 VTK 采样"。

### 6.2 残余长程漂移（对 R2 预算的提示）

复核发现 contact 的漂移**不是收敛到常数**，而是单调缓慢爬升，每 1000 步增量按 ≈0.782 的比值几何衰减：

| 区间 | 增量 |
|---|---|
| 1000→2000 | +1.910×10⁻⁴ |
| 2000→3000 | +1.460×10⁻⁴（比值 0.765） |
| 3000→4000 | +1.136×10⁻⁴（0.778） |
| 4000→5000 | +8.877×10⁻⁵（0.781） |
| 5000→6000 | +6.994×10⁻⁵（0.788） |

按该衰减率外推（**推测，非实测**）：**渐近漂移 ≈ 9.81×10⁻⁴ = 1e-3 门槛的 98.1%**（余量仅 1.9×10⁻⁵）；对应时标约在 1 万步量级。laplace 案例则相反：漂移自 step≈50 的谷底（−2.45×10⁻⁴）单调**回复向 0**（step 4000 时 −5.2×10⁻⁵），无触顶风险。

**含义**：接触线仍在缓慢弛豫（末 5 个 VTK 采样间角度范围仍有 1.622°，与漂移同源——**推测**）。R2-XY 含带图案的模具壁面与更长的接触线，若正式 run 显著长于 6000 步，"全程最大漂移 ≤1e-3"余量极小，须在 R2 协议中事先写明漂移预算与判读窗口政策。
