## 2. 测试A：固定开放边界基线

命令：

```text
./moving_punch_open_drain baseline
```

程序在第一次 `collideAndStream` 之前、配置y端 `LocalPressure` 时由OpenLB抛出：

```text
Uncaught exception: Could not set Boundary.
```

进程收到SIGABRT，完成步数为0。因此没有可报告的密度、速度、质量漂移或通量结果，不能把生成中的空/不完整CSV当作验证数据。失败记录保存在 `output/open_drain_fixed_h75_20260907/failure_record.txt`。

根因是y压力面与带槽压头/固定基底在边、角处相交。当前材料划分令固体优先，压力材料只覆盖剩余开口，但OpenLB `LocalPressure3D` 只接受可识别的平面离散法向；在该截断压力面边缘，通用 `boundary::set` 无法为所有节点构造合法边界类型，因而拒绝设置。不能忽略这些节点，也不能在同一节点叠加压力和固壁边界。
