# 显式压头 75→65 nm 功能测试冻结协议

本文件在移动运行前建立；不得在结果出现后放宽阈值。

- converter：dx=5 nm，dt=1e-11 s，tau=1.7。
- 运动：1000步，即 T=1e-8 s；随后保持1000步。五次平滑轨迹最大速度为 `1.875 m/s`，最大格子壁速 `0.00375`，按格子声速归一为 `0.00650`。最大单步位移18.75 pm，即0.00375 dx。
- 选择依据：单步远小于0.25dx、壁速Mach远小于0.1，同时总步数有限。本T仅为数值功能测试，不对应实验1秒。
- 前置固定基线：100步；要求2400个压力节点法向全正确、零/冲突/遗漏为0，材料不变，有限，maxU<=1e-14 m/s，质量相对变化及收支残差<=1e-13。
- 移动位置：最终目标/解析实际h误差<=1e-12 nm；累计转换节点恰为 `48×48×2=4608`；最终离散体积减少量等于4608 dx³；每步q均为-1（无效）或[0,1]，非法链接和压力/固体冲突均为0。
- 稳定性：无NaN/Inf；0.8<=rho<=1.2；流体max Mach<=0.05。
- 质量收支：`R=M(t)-M(0)+累计向外净质量`，全过程及最终 `|R|/M0<=1e-3`。
- 排液证据：最终累计向外质量>0，且相对连续排开质量 `rho*Lx*Ly*10nm` 的差异<=5%。
- 转换账本：covered节点的物理离散分布（stored f_i+w_i）全部局部转移；转移前后质量差相对被转换质量<=1e-12。禁止密度归一化或全域质量强制修正。
