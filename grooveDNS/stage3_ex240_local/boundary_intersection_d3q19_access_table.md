# 移动 Bouzidi—LocalPressure 交线 D3Q19 访问表

## 版本与口径

本表对应本机 OpenLB `5953d8a-dirty`、Git commit
`882924a9cfc8dcdf82909e39530789cb6f5ebcc4`。方向与 opposite 直接来自
`/home/dell/openlb/src/descriptor/definition/common.h`，不是按其他版本推测。
`cell[i]` 是 OpenLB 的 shifted population；直接矩必须使用
`rho=1+sum_i(cell[i])`。

低 y LocalPressure 的法向模板为 `direction=1, orientation=-1`。其 momenta/stress
读取 `cy=0` 与 `cy=-1` 的 population，即
`{0,1,2,3,4,6,7,8,9,10,12,14,15,16}`；
`CombinedRLBdynamics::collide` 随后重构并写全部 19 个 population。
streaming 对全部 19 个 population 执行；目标 cell 的 `f_i` 来自 `p-c_i`，
而该 cell 原有 `f_i` 传播到 `p+c_i`。Bouzidi 在 PostStream 对每个有效 q
读取 `x_b[i]`、固体侧 `x_s[i]` 及流体侧 `x_f[opp(i)]`，最终写
`x_b[opp(i)]`。
