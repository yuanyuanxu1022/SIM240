# OpenLB FreeSurface 最小验证报告

## 总判定

**当前 FreeSurface 配置尚未证明满足纳米压印填充需求，综合判定 FAIL。** 两个与目标图形无关的最小工况已按冻结顺序完成：静态液滴在 step 1711 出现液相体积分数上越界；简单矩形槽虽稳定跑满 4000 步，但没有形成可分辨的毛细上升或润湿填充响应。两组的液体质量漂移、rho、Mach、材料场和非有限值检查均良好，因此失败集中在界面转换带和润湿物理响应，而不是整体流场爆炸。

本轮没有修改 STEP 6-A～6-D、OpenLB、物性或既有历史结果；没有使用目标图形、动态压头、扩大区域或参数扫描。

## 实际实现与本机 API 核对

- OpenLB：`5953d8a-dirty`；真实 `SuperGeometry` / `SuperLattice`。
- descriptor：带 FreeSurface 所需字段的 D3Q27。
- 初始化和推进：`FreeSurface3DSetup::addPostProcessor()`、`FreeSurface::initialize()`、`collideAndStream()`。
- 物理映射：`dx=5 nm`、`dt=1 ps`、`rho=1000 kg/m3`、`nu=1e-6 m2/s`、`tau=0.62`、`sigma=0.0309 N/m`、零体力。
- 表面张力格子值按本机实现所用换算 `dt² sigma/(rho dx³)`，本例为 `2.472e-4`。
- FreeSurface 转换阈值为 `1e-3`，冻结 epsilon 审计范围为 `[-0.00100001, 1.00100001]`。
- 本机官方 FreeSurface README 明确将固壁 `EPSILON=1`描述为润湿壁倾向，但该路径没有可直接指定并校准数值接触角的接口。因此矩形槽测试只能检查**定性润湿响应**，不能声称使用了某个给定角度。
- 气相是 FreeSurface 固定参考压力状态，不解析气体动力学或困气压力。

## 1. 静态液滴表面张力测试

### 工况

240 nm 三周期立方域，中心为半径 60 nm 的球形液滴；初始速度和体力均为零。液体体积分数使用每个格点 `8³` 子采样初始化。正式目标为 2000 步，VTK 每 200 步。

### 结果

|指标|结果|冻结要求|判定|
|---|---:|---:|---|
|完成步数|1711/2000|2000|FAIL|
|最大液体质量相对漂移|`1.78403e-4`|`<=5e-3`|PASS|
|rho范围|`[0.999929927, 1.000800023]`|`[0.8,1.2]`|PASS|
|最大Mach|`3.52580e-4`|`<=0.05`|PASS|
|epsilon范围|`[-9.87882e-4, 1.001043276]`|`[-0.00100001,1.00100001]`|FAIL|
|等效半径最大相对漂移|`6.64902e-5`|`<=5e-3`|PASS|
|液滴中心最大漂移|`4.42e-12 nm`|`<=5 nm`|PASS|
|包围盒最大轴向差|`0 nm`|`<=10 nm`|PASS|
|NaN/Inf；材料漂移|0；0|0；0|PASS|

首次且唯一的停止原因是 step 1711 的 `epsilon_max=1.001043276`，比冻结上限高 `4.32663e-5`。此时 FreeSurface cell 类型由 6096/2360/102136 变为 6104/2360/102128（fluid/interface/gas），但几何 material 未改变。界面没有表现出形状破坏或高 Mach；因此这是一次小幅但真实的 FreeSurface 转换带越界，不能因为其他量良好而忽略。

表面张力确实产生了 Laplace 尺度的压力响应。理论 `2 sigma/R=1.030 MPa`；去除三层 overlap 后，bulk-liquid 平均表压在 step 1600 为 `1.03919 MPa`（相对差 `+0.892%`），step 1711 为 `1.01154 MPa`（`-1.792%`）。step 200 尚有 `+44.8%` 初始压力过冲，随后衰减。气相 VTK pressure 只作可视化，不能解释为已解析的真实气体压力。

结论：表面张力压力尺度、质量和球形保持均得到支持，但在冻结时长内 epsilon 严格稳定性未通过，不能将其归档为稳定静态液滴基准。

## 2. 简单矩形槽毛细填充测试

### 工况

计算域为 `200×40×165 nm`，y 周期，x/z 固壁。两片 10 nm 厚竖直墙位于 x=`60–70 nm` 和 `130–140 nm`、z=`60–160 nm`，形成宽 60 nm、高 100 nm 的矩形毛细槽；槽下方与液池连通。初始液面为 z=`62.5 nm` 的一层界面，槽名义体积为 `2.4e-22 m3`。固壁使用 `EPSILON=1` 润湿倾向。正式运行 4000 步，VTK 每 400 步。

### 结果

|指标|结果|冻结要求|判定|
|---|---:|---:|---|
|完成步数|4000/4000|4000|PASS|
|最大液体质量相对漂移|`7.40881e-5`|`<=5e-3`|PASS|
|rho范围|`[0.998783015, 1.000554197]`|`[0.8,1.2]`|PASS|
|最大Mach|`1.49142e-3`|`<=0.05`|PASS|
|epsilon范围|`[0,1.000611490]`|冻结转换带|PASS|
|最大单步填充率变化|`4.27045e-6`|`<=0.02`|PASS|
|NaN/Inf；材料漂移|0；0|0；0|PASS|
|槽填充率|`0.0250000 → 0.0216573`|至少增加0.01|FAIL|
|槽内相对外液池界面上升|`0 nm`|至少5 nm|FAIL|

填充率最大值为 `0.02504025`（step 43），最小值为 `0.02163571`（step 3758），末态比初态降低 `0.00334275`，相对初始值下降约 `13.37%`。逐步增量有 559 次符号反转，但单步幅度很小；这表示存在低幅数值摆动，并未形成持续毛细填充。槽内和外部界面最高点始终同为 `62.5 nm`。

结论：该工况证明 FreeSurface 在带固定固壁的简单槽内可以稳定推进并保持质量，但没有证明当前 `solid EPSILON=1` 设置能给出纳米槽所需的接触角/毛细响应。由于本轮禁止参数扫描，不能从单一结果区分“4000步观察时间不足”“润湿边界表达不足”或“初始化/分辨率限制”；这些均保留为限制，不能把无上升解释成已验证的物理接触角。

## 对五项检查的回答

1. **液相体积分数范围**：矩形槽通过；液滴在 step 1711 以 `4.33e-5` 超出冻结上限，失败。
2. **界面振荡**：液滴球形、中心和等效半径稳定，但发生 epsilon 转换带越界；矩形槽填充率存在小幅反复且没有净上升。
3. **质量守恒**：两组最大相对漂移分别为 `1.784e-4` 和 `7.409e-5`，均通过本轮 `5e-3` 门槛。
4. **填充率变化**：矩形槽由 `0.0250` 降至 `0.0216573`，未观察到毛细填充。
5. **接触角边界响应**：只实现并测试了本版本文档支持的 `solid EPSILON=1` 定性润湿倾向；未观察到可分辨毛细上升，且没有数值角度接口，所以接触角响应未验证。

## 停止结论

本轮最小流程已经将问题拆开：表面张力具有合理的 Laplace 压力尺度，基础推进和液体质量统计可用；但严格界面稳定性与润湿毛细响应至少各有一项未通过。因此**当前 OpenLB FreeSurface 设置尚不能作为纳米压印填充的已验证基础**。本轮到此停止，不返回目标结构、不加入动态压头，也不扩大区域。
