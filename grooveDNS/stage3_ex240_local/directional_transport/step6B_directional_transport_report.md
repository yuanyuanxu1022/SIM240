# SIM-EC1XT240 STEP 6-B 旋转角/方向性输运报告

## 结论

**STEP 6-B 固定间隙方向性输运基准：PASS。** 0°、45°、90°结构分别完成X/Y体力驱动的六组真实OpenLB稳态计算，全部达到预先冻结的1000步收敛窗口并以退出码0结束。无NaN/Inf，material场不变，质量、密度、Mach及同方向两截面通量一致性均满足冻结标准。

结果给出预期且可量化的各向异性：0°时槽轴沿+y，Y向输运系数约为X向的2.545倍；旋转90°后两主项交换；45°时出现大小相近的`Kxy`和`Kyx`，且互易相对差为`7.66e-10`。这建立了h=65 nm、dx=5 nm下的首个旋转角输运数据库，但不是网格无关结果，也不含动态压头、自由表面、润湿、液滴或空气。

## 1. 冻结模型与角度定义

- 模型：固定SIM-EC1XT240显式直槽，凸台间隙`h=65 nm`、槽深`100 nm`；单相全充液。
- 角度相对原槽轴定义：0°沿+y，45°沿+x+y，90°沿+x。
- OpenLB D3Q19 ForcedBGK；`dx=5 nm`、`dt=1e-11 s`、`tau=1.7`、`rho=1000 kg/m3`、`nu=1e-6 m2/s`。
- x/y双周期，z方向固定halfway bounce-back；压头固定。
- 驱动加速度`a=1e5 m/s2`，X/Y工况分别只有对应单一分量非零。
- 0°/90°使用48×48核心节点、`240×240 nm`周期单胞，不存重复周期端点。
- 45°为保证笛卡尔格点上的严格双周期拼接，使用68×68核心节点、`340×340 nm`周期超胞；有效法向周期`240.4163 nm`，槽宽及总凸台宽各`120.2082 nm`。相对目标240 nm的偏差为`0.17346%`，且斜壁存在dx=5 nm阶梯化。

程序复用已通过的固定间隙单相框架；与基线的物理差异仅为结构方向和与其相容的周期超胞。源程序、冻结协议和所有运行输出均位于本报告同目录，历史STEP 5代码与结果未修改。

## 2. 输运和阻力定义

对每个驱动方向`j`，按实际周期核心域直接积分：

```text
J_i  = (1/A_plan) integral_V(u_i dV)                  [m2/s]
K_ij = mu J_i/(rho a_j)                               [m3]
Q_j  = J_j L_perpendicular                            [m3/s]
R_j  = rho a_j L_j / Q_j                              [Pa s/m3]
```

`K`的列对应驱动方向X/Y，行对应响应X/Y。这里的`Q_j`是周期超胞按主方向平均长度得到的等效流率，`R_j`是均匀体力梯度下的方向阻力。由于x/y均为周期边界，域内没有入口—出口总压降；`pmax-pmin`只表示局部周期压力扰动，不能替代上述阻力定义。

## 3. 完整平面输运张量

单位均为`m3`：

```text
angle 0 deg:  K = [[ 3.2231601750e-23, -3.3476394225e-34],
                   [ 1.2952885697e-34,  8.2042000655e-23]]

angle 45 deg: K = [[ 5.7219000552e-23,  2.5036827786e-23],
                   [ 2.5036827805e-23,  5.7219000560e-23]]

angle 90 deg: K = [[ 8.2042000650e-23, -1.3195553460e-34],
                   [-1.4221057856e-33,  3.2231601755e-23]]
```

0°的主值为`K_parallel=8.2042000655e-23 m3`和`K_perp=3.2231601750e-23 m3`，各向异性比为`2.54539012`。90°主项与0°互换到浮点/收敛精度内。

由0°张量作理想45°旋转，预期对角项为`5.7136801203e-23 m3`、交叉项为`2.4905199453e-23 m3`。实际45°对应偏差分别为`+0.1439%`和`+0.5285%`；实际主值相对0°主值为`+0.2606%`和`-0.1534%`。该小差异与45°超胞的有效周期偏差及阶梯化一致，但在没有45°网格收敛试验前不能完全归因或视为物理角度效应。

## 7. 结论范围与停止点

本数据库验证了SIM-EC1XT240显式直槽在`h=65 nm`、`dx=5 nm`、单相全充液、固定压头、双周期体力驱动下的0°/45°/90°方向性输运。主值交换、45°交叉响应和近似互易性共同支持张量化描述。

限制包括：只有一个间隙和一个网格；45°使用近似相容超胞且有阶梯误差；体力驱动是线性稳态基准而非真实压印压力历史。因此结果不能代表液滴供液、接触角、填槽、困气或动态压头过程，也不应直接宣称为宏观模型的网格无关闭合参数。

**本轮在固定间隙单相方向性基准完成后停止；未加入FreeSurface、接触角、液滴、空气或动态压头。**

Historical internal directory names such as `stage3_ex240_local` are retained for reproducibility. The correct physical/model designation is **SIM-EC1XT240**.
