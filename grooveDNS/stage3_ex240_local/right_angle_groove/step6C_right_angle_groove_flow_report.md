# SIM-EC1XT240 STEP 6-C 直角沟槽固定间隙单相流动报告

## 判定

**STEP 6-C 正交交汇沟槽固定间隙基准：PASS。** `h=75 nm`和`h=65 nm`分别完成X/Y体力驱动的四组真实OpenLB稳态DNS。全部达到预先冻结的1000步收敛窗口并以退出码0结束；无NaN/Inf，material场不变，双周期边界下的两截面流量一致，质量、密度和Mach均满足冻结标准。

本轮采用“两个120 nm宽沟槽正交交汇”的直角结构定义。它对应现有路线报告允许的“正交交汇”基准，不代表尚未通过OAS局部映射确认的某个特定90°弯头。

## 1. 几何和离散定义

平面周期单胞为`240×240 nm`，核心节点为`48×48`，不存重复周期端点。沟槽平面区域定义为：

```text
60 nm <= x < 180 nm  OR  60 nm <= y < 180 nm
```

因此两个120 nm宽的中心沟槽正交交汇，四角各保留一个`60×60 nm`凸台；沟槽深度为`100 nm`。基底位于`z=0`，凸台底面位于`z=h`，槽顶位于`z=h+100 nm`。x/y两方向的材料图在周期拼接处完全一致。

沟槽平面面积为`43,200 nm2`，占单胞平面的75%。这与单一直槽的50%沟槽面积不同，因此本基准用于建立交汇结构自身的流动数据，不能把它与STEP 6-A直槽的差值完全解释成“仅有转角”效应。若后续需要隔离转角影响，应另建固体面积分数相同并经OAS确认的90°弯头。

## 2. 数值模型和边界

- OpenLB `5953d8a-dirty`，commit `882924a9cfc8dcdf82909e39530789cb6f5ebcc4`；
- D3Q19 ForcedBGK，`dx=5 nm`、`dt=1e-11 s`、`tau=1.7`；
- `rho=1000 kg/m3`、`nu=1e-6 m2/s`；
- x/y双周期，z方向基底及固定带槽压头均为无滑移bounce-back；
- X/Y工况分别仅施加对应方向的`a=1e5 m/s2`，等效均匀压力梯度`rho*a=1e8 Pa/m`；
- 单相全充液，初始速度为零，压头固定。

本轮没有使用动态压头、FreeSurface、接触角、液滴或空气模型。

## 3. 稳态流量、阻力和压力

定义沿用固定间隙基线：

```text
J_i = (1/A_plan) integral_V(u_i dV)                  [m2/s]
K_ii = mu J_i/(rho a_i)                              [m3]
Q_i = J_i L_perpendicular                            [m3/s]
R_i = rho a_i/J_i                                    [Pa s/m3]
```

周期域的总驱动压力梯度由体力明确给定为`1e8 Pa/m`。对单胞内局部周期压力扰动做简单最小二乘拟合所得斜率约为`1.70e7–1.77e7 Pa/m`，它只是局部扰动的描述量，不是入口—出口压降，也不能替代施加的等效压力梯度。VTI压力极差同样只用于比较局部压力重排。

## 7. 结论范围与停止点

本轮完成的是单个`240×240 nm`周期单胞中的正交交汇沟槽、两个固定间隙、单相全充液稳态DNS。它证明该显式几何在当前功能网格和低Mach驱动下稳定，并建立了流量、阻力、压力与槽内速度基准。

局限包括：尚未做网格收敛；正交交汇的沟槽面积分数与直槽不同；角点在5 nm笛卡尔网格上离散；没有OAS局部转弯映射、动态压印、供液界面、润湿或困气。因此不能把本结果称为真实液滴压印或完整SIM-EC1XT240版图结果。

**STEP 6-C在固定间隙单相基准完成后停止；未扩大区域，未进入两相或动态压头。**

Historical internal directory names such as `stage3_ex240_local` are retained for reproducibility. The correct physical/model designation is **SIM-EC1XT240**.
