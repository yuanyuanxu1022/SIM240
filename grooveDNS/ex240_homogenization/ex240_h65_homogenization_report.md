# EX240 局部 h=65 nm 固定间隙 DNS 等效化报告

## 结论

新压头几何下的首个固定间隙功能网格结果已完成。真实 OpenLB 单相 DNS 在 `h=65 nm`、`dx=5 nm`、x/y 双周期和固定无滑移压头/基底下，分别完成 X、Y 体力驱动。两组均由预先规定的完整 1000 步窗口判据自动结束，并通过质量、密度、Mach、截面一致性、非有限值及材料不变检查。

本结果是单个固定间隙、单个功能网格的等效化采样点，不是网格无关值，不证明 65 nm 是实际最终残余膜厚，也不是动态压印、液滴填充、自由表面或困气结果。

## 等效参数定义

平面面积为

`A_plan = Lx Ly = 240 nm × 240 nm`。

主输出采用流体域深度积分通量

`J_i = (1/A_plan) integral_Omega_f u_i dV`，单位 m²/s。

对仅含第 j 方向加速度 `a_j` 的工况，定义

`K_ij = mu J_i/(rho a_j)`，单位 m³。

本报告另给出 `B_ij=K_ij/H_ref`。这里明确选择

`H_ref = V_nominal/A_plan = h + (120/240)×100 nm = 115 nm`，

即名义平面平均流体厚度。它不是凸台间隙 `h=65 nm`，也不是槽内总高度 `165 nm`。B 只是基于这一明确参考厚度的换写；不能在未建立尺度匹配和宏观闭合关系前直接当作宏观阻力倒数。K 为本轮主结果。

## 几何、离散域与积分

- `Lx=Ly=240 nm`；x/y 均为真实 OpenLB 周期方向。
- 左半凸台 `x=0–60 nm`，槽 `x=60–180 nm`，右半凸台 `x=180–240 nm`。
- 基底有效 halfway bounce-back 壁面为 `z=0`；凸台底面为 `z=65 nm`；槽顶为 `z=165 nm`。
- cell-centred 节点间距 5 nm；每周期实际存储 48×48 个核心平面节点，不另存重复周期端点。
- 统计只遍历 `forCoreSpatialLocations` 的材料 1；overlap=3 和 padding 不计入积分。
- 每个节点统一使用 `dx³` 体积权重，`A_plan` 使用同一非重复的 `240×240 nm²` 周期面积。

名义流体体积为

`V = 240×240×65 + 120×240×100 = 6.624e-21 m³`。

实际流体核心节点为 52992，对应离散体积 `6.623999999996066e-21 m³`。与名义值约 `3.93e-33 m³` 的差异来自浮点累加舍入；几何层数为凸台下13层、中央槽附加20层，因此本 dx 恰好整除全部名义尺寸。有效壁面位于相邻流体/固体节点中心的中点，而不是固体节点中心。

## 物性、converter 与驱动选择

- `rho=1000 kg/m³`，`nu=1e-6 m²/s`，`mu=1e-3 Pa·s`。
- `dt=1e-11 s`，实际 `tau=1.7`。
- 最终采用 `a=1e5 m/s²`；X 为 `(a,0,0)`，Y 为 `(0,a,0)`。
- 对应格子 FORCE 分量为 `2e-9`，其余分量严格为零。

最初预案使用 `a=1e8 m/s²`。首个 X 短测虽有限且几何正确，但启动瞬态 `max|rho-1|=9.91e-5`，超过已冻结的短测阈值 `1e-7`，因此按失败保留在 `output/ex240_h65_dx5_short-x_20260907/`，没有放宽阈值或追认通过。随后仅将驱动力降至 `1e5 m/s²`，建立独立冻结协议和 run-id；其余阈值不变。低驱动用于保持线性、低 Mach 响应，并未改变 K 的定义。

## 预先冻结的稳态与验收标准

正式上限为30000步；完整最近1000步不裁剪初始瞬态。主 J 同时要求 `std/abs(mean)<=1e-6` 和 `(max-min)/abs(mean)<=5e-6`。交叉 J 使用窗口最大绝对值 `<=1e-12 m²/s`，不除近零均值。

正式验收另要求：无 NaN/Inf；全过程流体质量最大绝对相对漂移 `<=1e-10`；最大密度偏差 `<=1e-6`；实际最大速度计算的 Mach `<=0.05`；两个同方向截面通量相对差 `<=1e-5`；材料场完全不变。完整冻结文本见 `frozen_protocol.md` 与 `frozen_protocol_a1e5.md`。

## 响应张量解释

按“行是响应 i、列是驱动 j”，本功能网格的 K 为

`[[3.22316018e-23, -3.34763942e-34], [1.29528857e-34, 8.20420007e-23]] m³`。

交叉项极小且符号随数值残差变化，因此只作为绝对残差报告，不计算相对误差或标准差/近零均值。主项显示该固定带槽空间沿 y 的深度积分输运响应高于 x；这与旧阶段二连续墙封闭直槽并非同一几何，既没有预设 `Bxx=0`，也没有要求复现旧阶段一 `Byy=97.6164 nm²`。

## 限制与停止点

这里只完成 `h=65 nm, dx=5 nm` 单点功能网格。没有进行网格、间隙或驱动力线性扫描，因而没有离散不确定度和间隙依赖；也尚未证明 K/B 可直接写入具体宏观模型。没有运行移动压头、FreeSurface、液滴、接触角、空气、困气或1×1 mm模型。按本轮要求，X/Y 完成后已停止，未启动任何追加计算。
