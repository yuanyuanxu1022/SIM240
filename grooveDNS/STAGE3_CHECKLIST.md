# 阶段三方案与运行注意事项清单

每次修改、编译或运行阶段三前，逐项检查并记录结果；任何一项不确定都先暂停，不猜测、不掩盖。

## 一、范围与文件保护

- [ ] 只在当前阶段三独立目录操作。
- [ ] 未修改阶段一、阶段二、自由球基准、README 或 `../tmp/`。
- [ ] 使用新的 run-id，不覆盖旧输出。
- [ ] 运行前后检查 `git diff` 和关键文件哈希。

## 二、几何与网格

- [ ] 明确计算域尺寸、坐标原点和单位（m/nm/µm）。
- [ ] 核对 dx、网格点数、实体 padding 和周期端点是否重复计数。
- [ ] 检查压头位置、位移方向和最小间隙是否与目标一致。
- [ ] 不把局部纳米单元误写成完整 1×1 mm 纳米解析域。

## 三、边界与物理模型

- [ ] 分别列出 x/y/z 六个面实际边界。
- [ ] periodic 不得解释为空气出口；symmetry 不得解释为周期。
- [ ] 明确模型是单相、FreeSurface、VOF、相场还是显式液气两相。
- [ ] 若声称空气排出，必须有空气相和真实出口/排气通道。

## 四、单位与参数映射

- [ ] 统一 B（m²）、Darcy 阻力（m⁻²）、压力梯度（Pa/m）、速度（m/s）和黏度单位。
- [ ] 核对物理 dt、tau、Mach、Re 和 sigma_lattice。
- [ ] 不把 Bxx/Byy 直接当作 Darcy 系数；记录转换公式和有效截面积。
- [ ] 任何参数改变都使用独立 run-id，并说明改变的是物理量还是数值量。

## 五、FreeSurface 与守恒

- [ ] MASS、EPSILON、CELL_TYPE、CELL_FLAGS、HAS_INTERFACE_NBRS、PREVIOUS_VELOCITY 均已初始化。
- [ ] `EPSILON` 始终满足 `[0,1]`，禁止截断掩盖错误。
- [ ] 报告解析体积、离散 EPSILON 体积和初始误差。
- [ ] 分别检查液体体积漂移和 MASS 漂移。
- [ ] 检查 Interface 连通分量、液滴是否消失或碎裂。
- [ ] 动态节点转换若无安全质量重分配，必须拒绝转换并停止。

## 六、移动压头

- [ ] 同步更新压头几何位置、壁面速度、固流节点和边界链接。
- [ ] 不得只给固定 BounceBack 设置速度来伪装移动压头。
- [ ] 每次转换记录源节点、接收节点、质量账本和回滚状态。
- [ ] 容量不足、字段不同步或邻域非法时原子性回滚。

## 七、运行与输出

- [ ] 先编译，再运行短测试；异常时立即停止。
- [ ] 检查 rho、速度、MASS、EPSILON、分布函数是否 NaN/Inf。
- [ ] 确认统计和 VTK 写入正确的独立输出目录。
- [ ] 记录首次异常 step、字段、坐标、数值范围和邻域状态。
- [ ] 不运行未经批准的更细网格、长时间、移动压头或 1 mm 模型。

## 八、论文表述

- [ ] 区分“已确认”“由代码推导”“估算”“存在歧义”“未实现”。
- [ ] 不把最细网格结果写成严格网格无关真值，除非有 GCI/Richardson 或解析基准。
- [ ] 不把静态 FreeSurface 写成真实压印、空气排出或 trapped-air 结果。
- [ ] 明确说明宏观等效模型没有逐个解析全部纳米沟槽。

## 九、最终检查

- [ ] 结论是否有对应文件路径、字段或输出证据？
- [ ] 是否误把原型测试写成真实 lattice 功能？
- [ ] 是否保留失败日志和旧结果？
- [ ] 是否在报告中写明本次是否运行仿真、修改了哪些文件？
