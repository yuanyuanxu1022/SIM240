## 4. h25/d100 横槽的未通过项（需裁定，本文不改判）

| dx (nm) | K (m³) | 截面通量极差 % | 截面/体积分差 % | 功率差 % | 中→细变化 % |
|---|---|---|---|---|---|
| 5.0 | 2.077039494131e-24 | **0.012942** ✗ | 0.001366 ✓ | 1.2e-12 ✓ | — |
| 2.5 | 2.071883486974e-24 | 0.001815 ✓ | 0.000285 ✓ | 3.2e-12 ✓ | 0.2482 ✓ |
| 1.25 | 2.069465766270e-24 | 0.000090 ✓ | 0.000010 ✓ | 1.6e-11 ✓ | 0.1167 ✓ |

事实：唯一未通过项是 **5 nm 档的截面通量极差 0.0129%**，超出 0.01% 门槛 0.0029 个百分点。2.5 nm 与 1.25 nm 两档全部合格，中→细变化 0.1167% 远低于 0.5%。

该量随网格一阶收敛（0.0129 → 0.0018 → 0.00009），符合"粗网格离散误差"而非"解算错误"的特征。物理上它衡量不同 x 位置截面流量是否相等，稳态不可压缩流动应当相等；P2/P1 只保证弱不压缩，粗网格上必然有残差。5 nm 网格在 25 nm 缝隙上只有 5 层单元。

**一处实现与协议文字不一致，需明确记录**：`PROTOCOL.md` 第 4 节写的是"横槽 **fine**：至少 9 个非壁面截面的通量极差 ≤0.01%"，而 `verify_results.py` 对**所有档位**施加了该门槛。按协议文字，本算例的 fine 档合格；按现行代码，整体判 FAIL。

本文不裁定、不改代码、不改门槛：
- 若维持实现从严，h25/d100 T 记为 `PILOT_CHECKS_FAIL`，横槽覆盖 3/4。
- 若按协议文字只对 fine 判定，属"修正实现回协议"而非"放宽门槛"，须单独留痕并说明理由，不能作为让 FAIL 变 PASS 的通道。

### 5.3 可以说的与不能说的

可以说：
- 两个独立实现（LBM/OpenLB 与 FEM）对**沿槽**的互相一致性明显好于**横槽**，横槽差异在 2% 一致性线之外，且方向为 OpenLB 偏大。
- "原公式在全部主方向高估导度"这一结论，在换成 FEM 作参考后**仍然成立且符号一致**：沿槽 17/17、横槽 3/3 全为正。
- 沿槽偏差幅度与缝隙厚度相关：h=25 组（+22.6% 至 +140.5%）明显大于 h=125 组（+10.9% 至 +109.8%），与"局部立方律在薄隙最失效"的既有描述一致。

不能说：
- 不能说"FEM 证明了 OpenLB 错了"。两套方法都是离散近似，横槽差异的归属未定；本文只报差异，不裁决谁更接近连续解。
- 不能说这些数字可以替换 36 条主统计，或据此重算 MAE、各向异性比、张量角差。
- 不能把横槽差异写成"LBM 高估阻力"之类的物理结论。该差异是两套数值方法之间的差异，不是物理机制。
- 不能用 h25/d25 的 2.23% 推断"薄隙物理不重要"或"OpenLB 全体不可用"。
