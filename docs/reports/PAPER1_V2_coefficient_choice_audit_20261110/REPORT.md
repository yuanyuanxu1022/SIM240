## 2. h25不能从已知失败变成“没有验证过”

旧拟合脚本`CASE/D_series/D2_groove_error_map/analysis_fit_v2.py`的声明校准集合为h50/75/125与d25/50/100的9几何；h25不在该系数拟合集合。**不在系数拟合中，不等于不在模型选择时可见，也不等于没有被评价。** 当前正式稿已将h25包含在18几何36条主比较中，保留了最坏点及参考网格敏感性，并明确V2回顾性身份。

已有表S7支持的是(h,d)=(25,100)nm**横槽**在5/2.5nm两参考下残差−18.7051%/−14.9362%。不能扩写为整个h25档、所有槽深和方向均有双网格证据。原36条中该档三个沿槽残差为+5.52%、+7.21%、+3.39%；横槽为−7.10%、−10.32%、−18.71%。这也直接否定“该档两方向一律过冲”的读法。

## 3. 对重拟合表的条件性解释

|转述中的判断|本轮裁定|

|6参数拟合36点本身就经不起审阅|参数数目与点数比不能单独决定有效性；还要看结构、约束、几何分组、优化和评价过程。不能以“敢不敢用六个参数”代替审查|
|留一几何发现(25,100)不好，所以边缘问题只能补算|留一个(h,d)并同时扣P/T，仍保留另外两个h25几何；不等于留出整档h。边缘位置会增加风险，但不能据此证明任何公式都解决不了，更不能直接推出必须新增OpenLB长算|

若新拟合记录找回，至少需要系数/约束、训练几何清单、损失定义（方向分别还是联合minimax）、优化状态和逐折被留出的预测才能复核。模型族或h项若在同批数据/同批CV结果上选择，普通CV结果仍不能直接当成完全独立的性能认证。此处的方法依据为[Cawley与Talbot 2010](https://www.jmlr.org/papers/v11/cawley10a.html)，只支持模型选择与评价要分开的原则，不证明本次未取得记录的拟合究竟发生了何种泄漏。

## 4. d/h不塌缩能说明到哪一步

在同为d/h=1的已有几何中，使LC恰好等于离散K所需的F=K_LB/K_LCL如下：

|h,d (nm)|沿槽所需F|横槽所需F|
|---|---:|---:|
|25,25|0.833842|0.925003|
|50,50|0.653041|0.789337|
|75,75|0.524946|0.711753|

所以在这组离散结果上，一个仅依赖d/h的单值因子不能**逐点精确**复现这些F。几何中还保留固定w及不同h/w、d/w，这一差别有明确来源。但它不证明所有单变量近似都无用、不规定必须达到何种误差，也不证明引入两变量必须重推整套理论或补一批新算例。先声明目标与误差口径，再判断简化能否接受；本轮不另拟模型。
