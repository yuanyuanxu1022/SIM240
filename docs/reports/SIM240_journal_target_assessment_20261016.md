## 判断与边界

用户明确采用**中科院分区**。本轮评估对象是当前范围v2.0及§12：固定间隙、全充液、连续介质牛顿无滑移、周期矩形槽，OpenLB计算沿/横槽输运，与Jain/局部立方律比较；h/d各三个水平、九个几何、十八个主方向工况，另有网格复核。角度、机制、修正均按证据决定，不扩展两相或下压。

**导师判断而非录用概率预测：完成当前主线后，以三区应用期刊为主要目标；只有在新增知识和机制证据确实成立时，才考虑二区流体力学期刊。当前没有把一区作为主要目标的证据。** 如果最后只有九点K表、常规验证与已有闭合差异，三区也可能以创新不足拒稿。尚未完成的计划不能当作已完成稿的水平。

分区不是按算例数、机时或使用何种求解器换算。九个几何的两个方向不等于十八个独立几何；敏感性、归一化、等体积效率若只是同一批数值的重画，也不自动形成新的物理贡献。单相数值研究可以发表高水平论文，关键在新知识与可信证据，而非堆叠两相复杂度。

本轮仅核对现有方案和在线期刊政策，未重新验收D2、未检查运行状态、未运行仿真，既有PASS/FAIL不变。

## 为什么暂不优先Engineering with Computers

虽然新下载Part I/II发表于该刊，当前本项目不是相同类型的贡献。该刊[官方范围](https://link.springer.com/journal/366/aims-and-scope)强调有广泛影响的新研究与算法软件开发，明确不鼓励只应用已有方法、算法和工作流程的稿件。当前方案主要是已有OpenLB方法的物理应用和闭合校核，并未提出新的数值算法或通用软件能力。因此不因两篇参考论文用OpenLB就把此刊列为首选，也不为选刊强行改造求解器。

补强方向建议：

1. **先验收，再选刊。** 当前§6仍把整套D2矩阵列为待独立验收，本轮不将批次运行或部分PASS提升为完整证据。
2. **查新要改变研究问题而不只改变措辞。** [Dewangan与Datta2020原文](https://www.cambridge.org/core/journals/journal-of-fluid-mechanics/article/effective-permeability-tensor-of-confined-flows-with-wall-grooves-of-arbitrary-shape/089D6608B5CF065BAC9B1C4F7D42FBCF)已包含沟槽渗透率理论与显式数值对比。需要逐项说明当前矩形台阶/基线/结果给出了此前未解决的什么，不能将宽泛DNS对比当首次。
3. **优先提高一条核心结论的强度。** 例如说明局部立方律偏差何时超过已知数值误差、受哪些几何量控制，并用受力/流场证据解释。区间敏感性和等体积参照服务于该结论，不另包装成两项独立创新。
4. **若拟修正模型，留出几何。** 首轮九点上拟合再在同九点上比较，不是泛化验证；P/T互换也不是独立几何。是否需要额外点或不同求解途径按现有证据决定，本轮不自动增加计算。
5. **守住第一篇单相范围。** 不为冲区临时加入两相、下压、润湿；也不把材料经验律未经证实地搬到UV胶。
