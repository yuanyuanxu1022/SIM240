# 二维 FEM 定点试点最终数值报告

日期：2026-11-13。状态：五个计划算例的独立数值检查全部通过；论文正式参考资格未授予，投稿就绪状态不变。

## 1. 已完成范围与未改变事项

按固定顺序完成平板 P/T、h75/d100 P/T 和 h50/d120 T，各三档网格（5、2.5、1.25 nm）。沿槽使用二维标量 Poisson 方程，横槽使用 P2/P1 Taylor–Hood Stokes 离散和稀疏直接求解。未增加 h125、h25、h100 或 19P+4T 算例，未重拟合 V2，未改论文母稿、36 条主统计、46 条记录组成、历史 FAIL 或既有 FVM 资格。

FEM 与 FVM 都是同一连续 Stokes 模型的数值解。本试点增强指定点的独立数值核验，不是实验验证，不证明 OpenLB 软件普遍准确，也不建立严格误差界。

## 2. 加强后的独立复核

`verify_results.py` 从保存的网格和场重新计算 K、黏性功率、几何面积、壁面无滑移、速度/压力周期性、压力均值、横槽截面通量，并重新装配离散方程计算相对残差；不以求解器 JSON 自报指标替代验收。横槽截面由复核器在三角形内重建垂直截线并积分。

旧场未保存压力均值约束的单个拉氏乘子，复核器从保存场的连续性方程恢复该标量后检查全部动量、连续性和压力均值方程。P2/P1 只保证弱形式不可压缩，逐单元散度 L2 量保留为诊断，不设逐点散度为零的一票否决门槛。

复核过程中修正了三个复核器实现问题：积分阶次须与求解器一致；方程约化必须传入周期自由度而非面编号；压力周期配对必须通过边界面选取，以包含槽肩 `z=d` 的端点。最终五例均为 `PILOT_NUMERICAL_CHECKS_PASS`，问题列表均为空。

## 3. 数值结果

### 3.1 平板解析验证

平板 P/T 的 fine 导度均回到解析值 \(K=h^3/12=3.515625\times10^{-23}\) m³；相对解析误差约 \(1.1\times10^{-10}\%\)（P）和 \(1.2\times10^{-10}\%\)（T），远低于 0.1% 门槛。平板剖面、功率、周期和残差检查同时通过。

### 3.2 h75/d100 与既有合格 FVM 对照

| 方向 | FEM fine K (m³) | mid→fine K 变化 | 与合格 FVM 差 |
|---|---:|---:|---:|
| P | 9.752454669277113e-23 | 0.02429933% | 0.03247359% |
| T | 4.339824820208931e-23 | 0.07015789% | 0.00499633% |

两方向均满足 coarse→mid≤1%、mid→fine≤0.5% 和 fine 与 FVM 差≤0.5%。横槽 fine 的独立截面通量极差为 0.0000039632%，截面均值与体积分通量差为 0.0000005109%，功率差为 1.27e-10%。

### 3.3 h50/d120 T 候选参考

三档 K 依次为 1.4173892956798913e-23、1.4146661602543869e-23、1.4133804082943873e-23 m³。coarse→mid 变化 0.19212332%，mid→fine 变化 0.09088731%；fine 功率差 5.81e-11%，截面通量极差 0.0000149528%，截面/体积分差 0.0000015610%。重组离散方程相对残差 4.13e-12，低于 1e-10。

因此 h50/d120 T 可作为**通过内部数值检查的 FEM 试点候选值**，但不是已获正式资格的论文参考。

## 4. 候选第二组成对证据

- 原局部立方律 \(A_{LC}=10.33236067576\)，方向比高估 113.54543119%，重建流向角差 −6.14921116°。
- OpenLB 相对候选参考：P +0.69147857%（2% 一致性 PASS），T +3.64516481%（FAIL）。该 T 差异必须保留，不能因 V2 改善而改写。
- 原公式 P/T 偏差为 +206.95773437%/+43.74352692%；V2 为 +10.87510723%/−3.52783428%。在这一个候选点上，V2 的绝对偏差明显小于原公式。

这支持“原公式的双向不等幅偏差可显著扭曲各向异性与重建流向，V2 有回顾性改善”这一限定主张。它不把 35/36、MAE 或最大残差改写成 FEM/FVM 统计，也不证明全参数域。
