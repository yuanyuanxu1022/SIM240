# 论文核心结论—现有 FVM 证据对照及定点 FEM 试点决定

日期：2026-11-13。范围：只整理现行六条结论与已保存 FVM 资格证据，并在关键横槽无法按现冻结协议新增合规结果的前提下启动最小 FEM 试点。本文不是论文母稿，不修改36条主统计、46条记录组成、历史FAIL、现有FVM资格或项目级三项false。

## 1. 总结判断

现有 FVM 对论文最重要的支撑不是“证明 OpenLB 软件普遍准确”，而是：

1. 在基准几何 h75/d100 的双向及另外两个沿槽点上，**原公式大幅正偏差不再只依赖 OpenLB 5 nm 参考**。
2. 在基准几何，独立 FVM 成对主值仍给出明显的方向比失真：Aref=2.2478177463、ALC=3.6956052262，方向比高估64.408579%，重建角差−8.841962°。它们不替换原 OpenLB 的约67%和9.20°，但支持同一 qualitative 结论。
3. 四个合格方向上，V2 的绝对误差都明显小于原公式；但35/36、MAE和最大残差仍只属于 OpenLB 5 nm 主集合，不能改写成FVM统计。
4. OpenLB 数值一致性必须逐点说：h75P、h50P、h125P分别为+0.804185%、+0.691479%、+0.629506%，均通过2%；h75T为+2.511044%，仍为FAIL。h25T与h125T无合格参考，不赋delta。

逐条完整映射见 `CONCLUSION_FVM_MAP.csv`。其中C5的h100/d100新增间隙对照没有合格FVM双向参考；C6的连续上界和S14机制诊断不能借FVM结果变成已证明的因果或离散误差结论。

## 2. 当前最关键的缺口

**首选缺口是 h50/d120 横槽，而不是继续围绕已有基准点反复计算。** 理由：

- h50/d120 沿槽 FVM 已合格；补横槽后可形成第二组成对主值，用于检验基准点之外的各向异性结论。
- 该点是老师确认稿中允许代表点缩减时的优先补点。
- h125/d120 虽有合格沿槽参考，但不能替代h50T；其横槽数值已显示一致，却因回执、跨机拼接和tight未运行而未取得资格。
- h100/d100需要同时补P和T，超出“最小试点”；h25/d100涉及薄隙功率诊断和另一个科学问题，不宜与首个FEM试点混合。

第二对参考仍只是代表点证据，不自动证明整个参数域。是否最终采用19P+4T或缩减点集仍由老师确认。

## 3. 为什么触发 FEM 试点

最新启动审查记录表明：现冻结FVM发布在本机因libc/libm指纹漂移而无法新增合规运行，服务器外部指纹不符；重冻结会使既有回执与当前发布摘要不一致，需另建发布谱系和重验。h125T还受fine/tight墙钟与未完成tight约束。**这些是执行与证据链阻塞，不是FVM科学失效，也不改变既有合格结果。**

因此满足用户给定的条件：“关键横槽参考仍无法合规取得，则启动定点FEM试点”。本试点不宣称FEM比FVM更准确，不替代既有FVM，不追溯修改任何FAIL。

## 4. 最小 FEM 试点职责与停止边界

试点依次进行：

1. 平板P/T解析基准：验证驱动、单位、深度积分K、周期与壁面实现。
2. h75/d100 P+T：与现有合格FVM成对结果对照，检验新实现的几何、归一化和通量/功率账。
3. 只有前两级通过后，运行 **h50/d120 T**，形成候选第二组成对参考。

h125/d120 T不自动进入本轮；若以后需要压力测试或第三方法对照，另行授权。h25、h100及19P+4T均不在本试点范围。

每级必须保存方程/边界说明、网格身份、程序与依赖版本、线性系统求解信息、K、截面通量差、功率收支和独立后处理结果。任何一级未通过即停止，不为接近OpenLB或FVM而调参。

## 5. 不能越过的论文口径

- FEM与FVM都是同一连续Stokes模型的数值方法；二者一致增强数值核验，不是实验验证。
- 新方法的结果无论更接近或更远离OpenLB，都须保留并分析，不能按预期选择参考。
- h75T的+2.511044%一致性FAIL、S4等历史FAIL和V2薄隙限制均保留。
- 新FEM结果在完成自身网格与收支验收前只称“试点输出”，不称合格独立参考。

## 6. 试点完成后的状态更新

五个计划算例已通过加强后的独立数值复核，最终数值和边界见 `FEM_PILOT_FINAL_REPORT.md`。h75/d100 P/T 的 FEM fine 与既有合格 FVM 分别相差 0.03247359% 和 0.00499633%；h50/d120 T 的 FEM fine 候选值为 1.4133804082943873e-23 m³，mid→fine 变化 0.09088731%。

候选第二对（合格 FVM P＋FEM 试点 T）给出 Aref=4.83848360425，原公式方向比高估 113.54543119%、重建角差 −6.14921116°；OpenLB T 偏差 +3.64516481%，仍为 FAIL。新结果未获论文正式参考资格，不改变36条统计或任何历史FAIL，也不自动扩展覆盖点。
