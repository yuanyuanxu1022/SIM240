## 4. 最少验证的分步停点

### V0：当前主张的只读收口，零新增求解

交付：C01—C06与正文位置对应、原式/参数/锁一致、30条标定角色与留组分母明确、P/T/A和阻力口径一致、完整报告负结果与适用条件。本轮完成主张清单和资料绑定；不冒称已逐份重验全部原始流场或重做旧120条预测。

若论文只把G4作为有限证据下的经验候选与探索性补充，**无须为这种表述预先完成所有18项矩形基准及所有预测计算**。但原主体结果的数值可信度、图文与来源仍须按第一篇总清单闭合；这不等于宣布整篇可投稿。

### V1：先决定合格数值参考，当前主要卡点

保留旧窄槽1%/0.5%敏感性目标FAIL与当前10/12开发加密验收，不直接换2.5nm/1.25nm、替换原5nm主评分或拟合一个统一网格修正。先形成版本化参考合同，明确适用几何、P/T/A误差证据和失败停点。旧审查提出的参考≤0.5%、停止≤0.05%等仍是未批准建议，本轮不启用，也不把它们当误差定理。

已有窄槽三格可复用为风险定位证据，不要求无条件重跑它们。缺少的宽细2项也不能因“只差两项”就绕过窄槽失败停点。后续是否必须补、用何种方法及数量，由新参考合同的证据缺口决定，不能现在虚报精确最小算例数。

如选择新增有限元参考：当前N8仅代数/记录链验收，下一可先审保存场的解析误差、通量积分和能量提取能否只读实现；本轮不执行提取。矩形基准的最少方法证据应覆盖实际将用到的标量沿槽与速度压力横槽路径、解析平板、制造解误差/细化趋势、代数/积分敏感性和映射/规范。18项是既有待审方案，不自动全部获准；如缩减/替代，须在新结果出现前逐项写明等价证据和删减理由，不能冒称完整18项已通过。矩形方法资格之后仍需真实沟槽的角点/边界/参考精度证据。

此处不指定某个“最坏点”代表所有情况；原有窄/宽、浅/深及薄间隙风险要与最终保留结论关联。选择代表点应在新结果出现前按几何/方法风险记录，不按公式误差最小来挑点。若要求连续精度界，离散敏感性/条件GCI不能自动当严格界。

### V2：在V1与原前置条件满足后，检验冻结的新几何预测

原G4 v1合同保持16主方向+4细格参考，P/T各8项、A8项，三模型预测表共60行不是60次流动求解。4细格不混入16主方向平均。没有本轮授权的求解、读取保留组结果或run_id。

若未来继续这个原测试合同：先核生成时间与接触记录，再逐项独立验收来源/退出/数值/几何/保存输出，最后算六条件。不能以“本AI未读过”宣称整个团队从未看过。缺项为INCOMPLETE_OR_REFERENCE_INVALID；任一正式目标失败保留FAIL。即使通过，措辞也限于指定8几何/数值参考，不升级为整个0.8—3.2、1/3—1.6比例域统一保证。

如主数值参考改变、训练数据改变或需重拟合，必须保留v1并另立协议/模型版本，在保留结果出现或接触之前冻结。不得将改参考后的分数覆盖原评分，已知数据不再命名为新盲测。

### V3：按结果决定论文措辞，停止无关扩张

若V2成功且参考证据合格，只升级C03所限测试集的表述；连续模型精度只能按实际参考误差证据附条件说明。若A或其他条件失败，保留各方向结果和失败，G4继续为有局限候选；不因失败临时混合方向、换G6或新增参数后沿用同一测试PASS。若需要新模型，再另立v2与新的未见验证方案。

不纳入本篇最少清单：任意占比、接触极限精确化、无限深槽全域精度、两相润湿、气体、动态压头、全尺寸压印和真实胶工艺验证。要声称主导耗散机制或真实材料准确性，则需另一组证据，不能由G4拟合系数直接解释。
