# 一个补强问题及最小证据约定

2026-11-10，作者内部AI辅助裁定。用户授权“继续加强论文，先裁定一个值得补强的科学问题及其最小证据，不先增加算例”。沿用A：公布V2四参数与已知反例保留。本文是分析范围约定，不是新仿真协议、盲测预注册、作者最终采用或投稿许可。

## 1. 选定问题

固定间隙、槽深及槽占比，仅改变真实横向宽度时，局部立方律的偏差能否由两方向共用的整体倍率解释？若不能，方向比失真如何随已测宽度改变，又与既有归一化梯度差额的方向差异怎样对应？

对象限一平壁、一矩形槽壁、全充液、静止无滑移、牛顿常黏度、周期直槽的既有低惯性计算。选用已知D4开发组h=75 nm、d=120 nm、槽/凸台等宽，w=60和240 nm，真实周期P=120和480 nm。Ly随P变化，但两者均为槽向周期、既有场核查在保存精度下槽向均匀；采用单位投影面积的深度积分J与K，不能拿未经面积归一的Q或总功率相减。

这是利用已知结果提出的回顾性问题，不把后写的约定包装为看数前预测。核心不是首次发现宽度效应或各向异性；拟补强的是同一组几何上“模型所见的开度分布不变—双向修正不等—方向比失真—梯度差额结构”的闭合论证。

## 2. 竞争解释与判别量

局部立方律在固定h、d、槽占比时不含w，两个宽度得到同一对K_i^LC。以指定网格结果K_i^Δ为比较对象，令

F_i=K_i^Δ/K_i^LC，a_i=1/F_i，r_i=a_i−1，A_Δ=K_P^Δ/K_T^Δ，A_LC=K_P^LC/K_T^LC。

主要判别量B=A_LC/A_Δ=a_P/a_T=(1+r_P)/(1+r_T)。

- 整体倍率解释：同一几何存在c>0使两方向同时精确，即F_P=F_T，B=1。允许每种几何有自己的c，不要求跨宽度共用一个c。
- 方向性失真：F_P≠F_T，B≠1。任何共同c都不能改变A_LC；改动总尺度不可能精确修复方向比。
- 宽度关联：报告两宽度B的差异及其在5/2.5 nm上的变化，不由两个宽度推出全域单调性、临界值或渐近指数。

辅助量为“允许每种几何使用最佳共同倍率后，至少一个主方向仍留下的最小相对偏差”：

E_* = min_(c>0) max(|c a_P−1|, |c a_T−1|)
    = |a_P−a_T|/(a_P+a_T) = |B−1|/(B+1)，c_*=2/(a_P+a_T)。

这是正数两端相对误差的代数极小极大关系，最优点两方向残差等幅反号；不运行拟合/优化。它依赖已知参考值，是事后诊断，不是新预测公式，不等于h³/12物理下界、不适用于具有不同方向因子的V2，也不声称行业只采用共同倍率。若不需要这项读数，B及两个F本身已经能判别。

1. 两宽度×P/T=4条既有5 nm导度是基本反例；再用相同四条的2.5 nm结果检查已观测离散敏感性，共8条已有方向记录、2种物理几何。读取scalar_records.csv列出的明确路径，不遍历保留预测目录。
2. 核8条result、manifest、独立exit与原审查来源绑定；核h/d/占比/物性/驱动/边界/停止协议和binary相同，保留Ly=P与面积定义。只重算K=νJ/a与上述标量，不重验时间轨迹或物理Gate。
3. 复用这8份末态已经完成的positive_excess_diagnostic.csv，不重新读取/解码流场或求导。保留两种导数模板与各方向原分组，使用除以各自R_i^LC的绝对贡献s_ij，不用单个百分比份额比较两方向阻力。
4. 记S_i=Σ_j s_ij、b_i=r_i−S_i，则B=(1+S_P+b_P)/(1+S_T+b_T)。保留b_i，不按比例抹平。仅用S重建的B_diag=(1+S_P)/(1+S_T)及其与标量B的差，用于暴露离散账差，不称独立验证。两方向分组不同且受约束，不能把项逐一配对相减解释成独立物理原因。

## 4. 失败、降级与停止规则

- 若源绑定不一致、两方向错配或关键设置不一致，停止该配对的物理解释，先报告来源缺口。
- 若B在所查网格上接近1、方向差不稳定或宽度顺序反转，就不把它写成有稳健支持的方向性失真。保留结果，不选择性换几何或加宽度追逐显著性。
- 若梯度账差不能对上既有S14账差，先定位既有后处理来源；不得归一成强制闭合。标量差仍可报告，机制层降为待核。
- 即使全部对应，也只得到指定离散参考和指定分解下的证据；窄槽既有网格FAIL、宽槽仅两档、reference_qualified=false均保持。观察到两档变化小于两宽差，不构成连续误差界。
- 若文献已有同条件同口径的同一评价与解释，则收窄增量，不能用本项目新命名的B/E_*掩盖重复。当前未取得最近完整方法在这两几何下的匹配数值预测，不排名其精度、不宣布不可适用。
