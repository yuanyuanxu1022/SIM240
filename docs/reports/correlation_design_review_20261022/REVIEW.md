## 2. 公式与尺度关系的核准

本研究的K=μJ/G单位m³，J=(1/A_plan)∫u dV，G=ρa。对线性Stokes、同一无滑移边界与充分充液几何族，以h作长度、Gh²/μ作速度尺度，可得

\[
K_i=h^3\mathcal K_i(w/h,d/h;\varphi),\qquad
K_i=K_i^{LC}F_i(w/h,d/h;\varphi),\quad R_i=\mu/K_i.
\]

其中K_parallel^LC=[(1−φ)h³+φ(h+d)³]/12，K_perp^LC=1/{12[(1−φ)/h³+φ/(h+d)³]}。阻力修正系数为1/F_i，不是F_i。

推导依据：Stokes式−∇p+μ∇²u+G e_i=0，令x=h x*、u=Gh²u*/μ、p=Gh p*，无量纲边界形状只剩w/h、d/h、φ。体积积分除以平面面积多给一个长度h，故J∝Gh³/μ。同比缩放全部长度λ倍后K'=λ³K。这是明确条件下的尺度结论，不是F具体形式的第一性原理推导。有限惯性、滑移等额外物理长度或非牛顿本构会改变这些前提，不纳入本阶段。

因此，固定w的现有数据已包含两个独立几何比例，并非对所有其他槽宽一概毫无信息；它们能通过上述尺度假设映射相似几何。另一方面，单纯同比放大的新点也不能当新比例或新机制。候选8个预测几何经过精确有理数检查，均不与23种建模几何同属一个(w/h,d/h)点；它们都在候选建模几何的**对数无量纲坐标凸包**内，避免将明显外推混成内插预测。此为几何覆盖检查，不是精度或物理验证。

原C4是已公布的固定历史基线，不因新方案重新挑点而改写旧成绩。新模型如继续用C4形式，应在获准后只用23种开发几何重新估参或另行修改物理限制；在取得预测组结果前，冻结形式、全部系数、选择规则和预测输出哈希。旧18点产生的公式、参数、误差与本方案开发集必须分列。

## 4. 如何执行与如何判断（尚未冻结的方案）

顺序建议：老师确认范围 → 新目录实现可变w/P与完整输出 → 编译/静态/零推进几何预查 → 平板和历史基准回归 → 最大新几何驱动线性与代表网格核对 → 开发组 → 冻结模型与新几何预测 → 用户另行启动预测组及其数值参考。每阶段分别授权/验收，不自动串联长算。

沿用当前牛顿物性ρ1000kg/m³、ν1e−6m²/s（μ1mPa·s），τ1、主驱动a1e5m/s²，x/y周期及原边界。矩阵时间步按dt=(τ−0.5)dx²/(3ν)算出；不是把dt当可自由调节的拟合参数。小Mach不代替驱动线性或空间精度。

旧D2源码w/P/areaPlan为常量，命令行没有w/P接口，caseId还会将dx取整。**现有可执行文件不能直接运行本矩阵。** 后续只在新实现目录改几何、体积、wrapX、转换器参考尺度、预查及身份记录，不覆盖旧D2、原结果、旧冻结协议和历史FAIL。本轮没有实施这些源码修改或编译。

数值验收以届时单独冻结的新协议执行。原质量/Mach/密度/截面/q/fallback门槛保留，不因新增范围调宽。特别需要审查60000步上限与1000步统计窗：细化后dt变小，不能把相同步数当相同物理观察时间；需在运行前统一物理收敛/采样尺度，并保留稳态证据。三层网格仍须检查实际序列、非单调/舍入及是否可作Richardson/GCI，不能仅因有三个目录就称网格独立。

模型报告P/T分别列平均绝对、均方根、最坏及有符号误差，逐点保留。可提交老师讨论的性能目标为平均绝对误差≤5%、最坏≤10%；关键参考网格变化以1%作为拟议精度目标。它们是**待确认的新设计目标，不是已通过的结果、官方标准或旧门槛**。缺少应用容许误差依据，需老师在查看新结果之前确认/改定，不能事后按成绩移动。网格变化<1%本身也不是连续解误差上界。
