# 逐句候选拼接稿（用于对比，不是推荐定稿）

纳米压印流动的降阶模型常用局部立方律估计图案化表面的等效导度，但其对沿槽与横槽输运的描述需要分别检验。

本文采用格子玻尔兹曼方法，计算平面基底与周期矩形沟槽之间的沿槽、横槽稳态导度；取固定间隙、全充液牛顿流体和无滑移壁面，沟槽周期为240 nm，槽与凸台等宽。

主比较以18种几何在5 nm网格上得到的36个主方向导度结果为离散参考，每种几何分别包含沿槽和横槽结果；另以2.5 nm网格加密其中4种几何，检查网格敏感性。

相对于5 nm离散参考，局部立方律在全部36个主方向结果上均高估导度，沿槽与横槽的最大相对偏差分别为+204.85%和+54.19%；其中，沿槽最大偏差对应的公式值约为参考值的3.05倍。

在基准几何（h=75 nm、d=100 nm）下，局部立方律与5 nm离散参考的各向异性比分别为3.70和2.21；以同一线性张量关系重建相对槽轴45°驱动下的平均通量方向，两组结果相差9.20°。

相对于同一组5 nm离散参考，既定经验修正（V2）在回顾性评价中减小了36条主方向结果中35条的相对偏差绝对值，但一个薄隙横槽点的改善判断随参考网格改变。在新增间隙h=100 nm下保持修正系数不变，两方向的相对偏差绝对值也减小；该比较限于这一几何及5 nm参考。

理论推导表明，在本文所述固定壁面、全充液、无滑移的周期Stokes模型中，局部立方律分别给出沿槽与横槽连续导度的上界；该界不确定偏差幅度，也不保证V2的准确度。

上述定量结果限于采样几何与指定离散参考，尚未建立连续参数范围或实际压印过程的精度保证；结果提示，评价此类降阶模型时，应同时考察两主导度、其比值和参考敏感性。
