## 3. 参考资格仍缺什么

### 3.1 只有两级，不能定观测阶、GCI或连续误差界

K2.5/K5−1=−4.4307318765%。在本次D2指定目录/既有表S2中仅两档；没有为该几何找到第三档1.25nm记录，检索范围仅这些指定资料，不声称全机/外部从未计算。两级可报告局部敏感性，不能独立给观测阶、Richardson外推或严格误差界。h75历史三格、h30/d80当前补证均是不同几何，不替代h25/d100。

固定tau下dt随dx²变化；两档又采用固定1000样本窗，物理窗长不同。因此4.43%不能被唯一归因为纯空间误差，数值停止指标本身也不是稳态真误差界。

附加只读诊断：取与粗格末窗相同的4.1625ns时长，细格需3997样本。现存细格末3997样本的std≈0.00929063、span≈0.103612；该长窗包含较早启动过程。**这是事后等时长诊断，不是原冻结检查，不能追改细格PASS，也不能把10.36%解释为末态误差。** 它说明现有记录不支持把粗细的同1000样本口径直接称“相同物理统计窗的稳定比较”。详见equal_physical_window_diagnostic.json。未来若采用统一无量纲物理窗，应先写协议，不能把新规则追溯到旧记录或自动加时。

### 3.2 同一二进制身份不等于完整历史构建

两档4份manifest均未直接保存source_sha256、generated_source_sha256、openlb_commit、compiler、compile_flags。现存D2 ELF匹配是重要可复用事实，不是源码/依赖/实际编译命令的历史绑定。当前源码/.d/Makefile是线索，不能由时间接近或同名回填字段。

2026-10-28已有历史构建裁决和最小接收合同：完整历史来源须将匹配ELF与实际应用源码、OpenLB/实际链接库内容、编译器/宏/编译链接命令关联到同一构建。该裁决原文保留，本轮未发现能关闭这条来源链的新增直接档案，也不声称它永不可恢复。

### 3.3 已知数据角色不会因重算而变成未见

h25数据在模型形式选择时已知。新算同一h25/d100可以改善参考精度，但不把该几何重新变成V2或新候选的未见测试。真正独立预测还需冻结模型/适用域/逐点预测及使用历史，并用未参与选择的条件检验。原5nm反例和2.5nm对照永久并列。

### B. 若要建立h25/d100横槽的严格新参考

1. **先做零求解来源接收**：针对57611b21…组，只收能形成直接关联的历史构建资料；同时写清新参考要满足什么资格、采用哪套停止/质量/场证据口径。旧D2和新URV规则不自动混用。

3. **若历史来源无法收口，建议新的完整来源下建立5/2.5/1.25nm三条T网格族**，旧两档作为回归/敏感性旁证，保留原字节。新的共同物理统计窗、时间上限、质量观测、场保存、验收规则及资源须运行前冻结；三条只是网格分支，不是完整资格总数的承诺。
4. **平板、驱动力、阶段前置及来源汇总单列**：哪些旧控制可以复用、是否需h25专用平板/线性控制，须按新参考资格协议逐项审定，不能借h30或h75的通过自动填真，也不在本轮随意给新增控制数量。新网格/软件接入、原生审计、性能与正式执行分别准备/授权。
5. **模型开发另一路**：参考合格后才能可靠评价候选。若希望G4/G6正式覆盖h25，应新版本扩域、先冻结评估目标，保留已知h25为开发/补充，另设真正未见条件。当前V2的URV未见数据若用于新模型选择，应重新定义该版本测试集，不得双重使用。
