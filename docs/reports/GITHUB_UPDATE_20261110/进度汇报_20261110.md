## 二、论文现在能说什么（六条结论的要点）

1. **定位与规模**：固定全充液矩形槽族，18 种几何 × 两个主方向 = 36 条 5 nm 主结果。
2. **偏差量与方向**：相对指定离散参考，局部立方律**36/36 全部高估**——沿槽
   +10.30%～+204.85%，横槽 +8.11%～+54.19%。
3. **后果**：各向异性被抬高。基准几何各向异性比由 2.21 升到 3.70（相对高估约 67%），
   45° 流向重建方向差 9.20°。
4. **有限修正**：公布的四参数修正 V2 使 35/36 条改善，平均绝对偏差沿槽 88.85%→6.40%、
   横槽 30.63%→4.42%；**保留唯一变差点**（薄隙 + 横槽，−18.71%）。
5. **可信度支撑**：新增间隙对照与静态接入，两者都**不构成**独立验证。
6. **理论约束与机制**：连续 Stokes 上下界成立（全部记录 0 违反），但只给方向、
   不给幅度；机制诊断单列两宽度组，明确其分母与适用范围。
