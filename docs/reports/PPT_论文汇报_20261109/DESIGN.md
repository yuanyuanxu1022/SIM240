# DESIGN.md — 论文汇报 PPT 视觉设计

## 定位
学术风（蓝白克制、证据驱动）。场景：向导师汇报第一篇论文的内容与结论。

## 画布与母版
- 画布 1280×720；左右安全边距 40。
- 页眉模式 A3：深蓝顶条（主蓝 #1E4FA8）+ 低透明线稿，内容页默认。
- 页脚 D：左单位 14px 灰，右页码 16px 深蓝。

## 配色（≤4 主色 + 少量强调）
| 角色 | hex | 用途 |
|---|---|---|
| 主蓝 | #1E4FA8 | 顶条、编号、标题 |
| 藏蓝 | #0E3F8C | 深底、重点 |
| 浅蓝 | #E8EFF8 / #F0F5FC | 卡片底、表头浅底 |

配色比：蓝族 35–55%，白底 30–55%，浅蓝 0–35%，红 ≤5%，金 = 0。

## 字体
- 思源黑体为主（正文/标题）；封面英文长标题可用思源宋/Times。
- 标题 32–40 Bold 深蓝；卡内标题 24–30；正文 22–28；表格 18–22；注解 14–16。
