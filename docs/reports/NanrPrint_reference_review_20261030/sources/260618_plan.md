# 260618 液滴位置贝叶斯优化方案

## Summary

- 基于 `git_template_3r5cBoard_350_multiRegionPermeationV9_zero` 作为基准模板，基准液滴数 `N0=135`，优化允许液滴数 `N in [122,148]`。
- 优化对象为 imprint 初始液滴中心坐标 `(x_um, y_um)`，液滴半径沿用当前 `52 um`，最小中心距 `280 um`。
- 坐标输出采用平板物理坐标系：`x in [0,5250] um`、`y in [0,3000] um`，再自动转换成 OpenFOAM `setFieldsDict` 里的 `e-6` 单位。
- 填充率目标为 16 个 zone 统一目标填充率 `0.95`，其中 `channel` 纳入评分并单独作为一组。

## Key Changes

- 原始 case 不直接覆盖，优化工具放在 `260618_optimization/`。
- 区域评价使用 `system/imprint/topoSetDict` 中 16 个 zone，`channel` 单独一组，其余区域按 y 方向分 3 组、每组 5 个：
  - `channel`
  - `K400/K350/K300/K280/K240`
  - `EC1XT400/EC1XT350/EC1XT300/EC1XT280/EC1XT240`
  - `R123/HOAS1/R113/HOAS2/R15`
- 每次候选设计生成：
  - `droplets.csv`：`droplet_id,x_um,y_um,radius_um`
  - `system/imprint/setFieldsDict`：由 CSV 自动生成 `cylinderToCell`
  - `metrics.csv`：每个 zone 的最终填充率、组平均、最差欠填充、过填充惩罚
  - `summary.json`：液滴数、最小间距、目标函数值、仿真状态
- 目标函数采用约束惩罚形式：
  - 主项：16 个 zone 最终填充率相对 `0.95` 的均方误差
  - 欠填充权重 `2.0`、过填充权重 `1.0`
  - 组均匀性惩罚：4 组组内方差和组间方差，其中 `channel` 为独立组
  - 硬约束：液滴数范围、最小间距、坐标边界；违反时不运行 OpenFOAM，直接给大惩罚

## Optimization Method

- 采用贝叶斯代理优化，适配 OpenFOAM 单次仿真成本较高的情况。
- 初始样本：
  - 保留当前矩形 350 um 排布作为 baseline。
  - 加入当前 triangle350 排布作为对照样本。
  - 再生成 Latin hypercube / Poisson-disk 随机样本，保证最小间距 280 um。
- 代理模型：
  - 输入不直接用 148个任意点的高维坐标，而用布局特征降维，包括液滴数、各 zone 液滴数量密度、质心、最小间距等。
  - 若环境存在 `scikit-learn`，使用 Gaussian Process + Expected Improvement with Constraints。
  - 若环境缺少 `scikit-learn`，退化为几何先验筛选，仍保持同一候选输出接口。
- 迭代流程：
  1. 生成候选液滴布局。
  2. 复制基准 case 到独立 run 目录。
  3. 写入新的 `setFieldsDict`。
  4. 运行当前无渗透配置，只评价 imprint 层液体流动。
  5. 读取最终时刻 `imprint/alpha.liquid`，按 zone 计算填充率。
  6. 更新代理模型并选择下一批候选。
- 默认预算：先做 `20` 个初始样本，再做 `40` 次贝叶斯迭代；如果仿真很慢，可降为 `10 + 20`。

## Test Plan

- 静态检查：
  - 从两个 case 读取液滴数，确认 `git_template...V9_zero` 为 135、`triangle...zero` 为 145。
  - 校验所有输出 CSV 坐标在 `0 <= x <= 5250`、`0 <= y <= 3000`。
  - 校验最小液滴中心距 `>= 280 um`。
- OpenFOAM 检查：
  - 用 baseline 生成一次 `setFieldsDict`，与当前 V9 初始液滴集合一致。
  - 单独运行 `setFields -region imprint`，确认 `alpha.liquid` 初始化成功。
  - 对一个已完成时间步计算 16 个 zone 的填充率，确认 channel 进入目标函数且分组为独立 `channel` 组。
- 优化验收：
  - 最优解输出 `best_droplets.csv`、`best_setFieldsDict`、`best_metrics.csv`、`best_layout.svg`。
  - 报告 baseline、triangle、best 三者的 16-zone 填充率对比和目标函数对比。

## Assumptions

- 不启用渗透模型，只优化 imprint 层液体流动；原始 case 不被覆盖。
- 液滴半径保持当前 `52 um`，除非后续明确要求同时优化半径。
- channel 纳入填充率评分，并单独设为一组；默认候选点允许进入 channel，以服务 channel 填充率目标。
- 最终计划文件名采用 `260618_plan.md`。
