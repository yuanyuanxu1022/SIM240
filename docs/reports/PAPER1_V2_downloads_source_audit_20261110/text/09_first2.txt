第一篇论文方向确认

1. 论文定位
本文面向纳米压印局部微结构填充问题，建立一种基于 OpenLB 全解析 DNS 对标的 B_eff
等效导流张量建模方法，并将其用于 mixture model 宏观预测。

论文重点不是证明 VOF-Darcy 方法本身，而是通过 DNS 对标、RVE
等效和宏观预测之间的连接，验证局部微结构对导流能力和填充行为的影响能否被等效参数准确描述。



2. 研究对象
本文不直接使用真实完整工业版图，而是使用抽象化后的代表性微结构进行研究。

代表性结构包括：

 • 平板；
 • 直沟槽 / 长条结构；
 • 旋转沟槽；
 • 方块阵列；
 • 回字形结构；
 • 矩形阵列。

这些结构可以参考现有 OAS 版图的几何特征进行抽象，但论文展示和计算对象应经过简化与保密处理。



3. 核心科学问题
本文希望回答的问题是：

如何用等效导流张量 B_eff 描述局部微结构对液体流动方向性和宏观填充行为的影响？

具体包括：

1. 局部微结构能否通过 RVE 方法提取为等效导流张量；

2. B_eff 是否能够反映不同方向上的导流能力差异；

3. 旋转结构是否会产生合理的非对角张量分量；

4. 基于 B_eff 的宏观 mixture model 预测是否能够接近 OpenLB DNS 结果。



4. 方法路线
本文采用以下技术路线：



                                                        1
 抽象化微结构
 → OpenLB 全解析 DNS
 → RVE 提取 B_eff

其中：

 • OpenLB DNS 用作定量对标；
 • RVE 用于提取局部结构的等效导流能力；
 • B_eff 表示不同方向上的等效导流能力；
 • mixture model 用于宏观预测；
 • DNS 与宏观预测之间的误差用于评价等效模型的有效性。


5. 拟定创新点

5.1 通量型 B_eff 等效导流张量
建立适用于纳米压印微结构问题的通量型等效导流张量 B_eff，并区分其与 K、d 的关系：

 K：速度型渗透率
 d：Darcy 阻力
 B_eff：液膜 / 通量型等效导流能力


5.2 DNS 定量对标
使用 OpenLB 对抽象化小版图进行全解析 DNS 计算，将 DNS 结果作为参考标准，用于检验
RVE-B_eff 方法和宏观 mixture model 的合理性。


5.3 旋转结构与非对角张量
设计旋转沟槽或旋转结构算例，验证 B_eff 的张量特征，说明其不仅包含
Bxx、Byy，还可以表达结构方向变化产生的非对角项。


5.4 Mixture Model 宏观预测
将 RVE 提取的 B_eff 接入 mixture model，用于宏观尺度预测，并与 DNS 结果进行定量对比。


5.5 抽象化结构与保密处理
不直接展示真实完整工业图案，而是从实际版图中抽象出代表性结构，在保证科学问题成立的同时降低
保密风险。
