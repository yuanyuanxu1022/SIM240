# 审查授权与工具字段解释

用户对自有稿件明确请求当前限定稿的核心结论与数值参考充分性终审；继承本对话的AI辅助授权。open指作者可见的内部协作，不是期刊公开审稿。venue_policy.checked只表示已核AGENTS.md及本次范围，没有声明任何期刊政策已核验或适用。本轮不是编辑委托，目标期刊政策不作为本次内部科学分析的前置。human_accountable表示作者保留科学责任，不表示已经人工签字。

external_processing_authorized仅限用户请求的本次助手协作；local_only与external_service_use=false指CLI/稿件文件操作均在本机且未向额外服务发送稿件/数据，不冒充本对话使用离线模型。公开网页访问仅为公开文献元数据/方法内容，范围见REVIEW.md。retain_per_venue_policy在本作者自审中按项目AGENTS.md留存研究证据解释，不伪造期刊留存许可。

受控CLI无“不适用/作者项目协议”的专用枚举，以上字段解释与JSON一起使用；校验只核声明完整性，不验证科学主张、真实模型身份、作者采用或期刊合规。无已识别利益冲突；本轮AI参与此前稿件协作，不能称外部独立审稿人。严格数值误差界不在已获证明范围。
