## 2. 参考方法与协议的裁定

审阅[原方法草案](../D4_reference_protocol_draft_20261025/REFERENCE_METHOD_DRAFT.md)、[压力/预算修订审查](../D4_reference_protocol_review_20261025/REPORT.md)、[18项最小范围](../D4_reference_protocol_review_20261025/MINIMUM_SCOPE.md)及B中`method_contract.json`、`symbolic_forms.py`、`entry.py`。

1. **保留方法骨架。** 物理压力强式`−Δu+∇π=f`及弱式`[K,−Bᵀ;−B,0]`一致；只施加一次驱动；周期速度含P2边中点，壁面交点速度优先；约化压力常数向量将约束从自由度位置置零，测试左右零空间及右端相容，再作压力面积去均值。实际装配的正确性目前有旧预检证据，真实解精度仍未验。
2. **保持单位和对象边界。** 平板`K=h³ Ĵ`、`J=a h³ Ĵ/ν`、`R=ρa/J`；制造解源项不是均匀体力，其`Ĵ=1/6`用于检验积分，不能当物理迁移率。首批18项只有矩形，不能证明沟槽角点误差、Stokes对NS偏差或LBM停止误差。
3. **草案预算不是精度证书。** 0.12%空间、0.01%代数、0.01%积分、0.05%模型、0.05%停止的分配尚未建立相应误差界。原0.482365598%是有条件的比较因子传播预算，不是G4误差或旧LBM总误差。本轮不启用新容差、不改旧网格FAIL。
4. **全套验收前还要消除判据歧义。** 原草案第53行同时要求强散度比值和截面偏差≤1e−6，而P2/P1方程只对离散压力测试空间满足弱连续方程；由当前弱式不能推出粗MMS也达到该强散度门槛。必须在未来正式18项协议中逐项规定适用网格、积分/截面采样、归一化及失败解释。不能先看试跑结果再降低原标准。N8试跑只报告这些量，不声称通过最细MMS、观测阶或完整物理验收。
5. **分开两类合同。** 可先新立仅用于诊断的运行/记录合同，明确不产生参考PASS；以后完整18项的数值验收合同仍须独立冻结。无需把全部沟槽研究当作单项诊断的前置条件。

## 5. 最小许可路径与停止点

具体候选范围、参数、停止规则见[有限诊断条件](PILOT_CONDITIONS.md)。建议先只考虑`B0MIN_MMS_mixed_N8`一项：非零压力能暴露压力符号/规范及周期问题，规模也小。成功并完成独立读回后，才另审一个粗平板横向问题；禁止自动跑剩余16项、自动重试或改预条件器继续。

本轮不是批准这个诊断合同。最小闭合顺序：**只修B1–B3并准备独立读回 → 保留无求解控制流/失败/资源夹具证据 → 核对修订版与诊断合同 → 用户另行明确授权启动第一项 → 试跑后独立检查。** 真实路径没运行是预期未知，不能把“先证明真实求解成功”当成准许第一次诊断的循环前提。

当前`NUMERICAL_GATE=NOT_EVALUATED`、`RESULT_PASS=false`、`geometry_PASS=null`；参考正式采用和预测均HOLD，G4 v1及历史FAIL保持。本轮无真实run_id、启动命令或新增计算结果。此前D4开发数据、网格通过/失败的范围沿用各自独立验收，本轮未重复验收流场。
