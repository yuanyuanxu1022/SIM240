# 下午请导师裁定：原公式与 V2 的适用范围

本次目标：两套公式都看，形成适用/失效范围的候选研究方案。先确定目标和证据强度，再决定补算位置；目前未冻结容限、参数域或计算方案，没有新仿真。

开口可以这样说：

> 老师，我希望把这篇工作集中到原公式与 V2 的适用范围：在什么间隙、槽深和方向下，导度偏差能控制在可接受水平。我想先请您确定允许偏差和需要的验证程度，再决定在哪些边界条件补算，而不是先把所有点都继续加细。

## 优先问四个问题

1. **允许多大公式偏差？**
   “老师，导度公式相对合格数值参考的可接受偏差，按5%、10%还是其他水平更合适？应该根据什么用途来定？”
   作用：确定什么叫适用。5/10/20%只是讨论示例，不能因为看完数据某档好看就宣称其为预先验证标准。它与原1%网格门槛分别定义。

2. **两个方向是否分别给范围？**
   “沿槽和横槽的偏差差别很大，是否分别给原公式与V2的适用范围？几何用h/w、d/w表示，槽宽占比w/P先固定在1/2，可以吗？”
   作用：避免用横槽的良好表现替沿槽背书。现有数据也没有验证任意槽宽、周期或槽宽占比。

3. **论文需要证明到什么程度？**
   “先报告现有样本中的回顾性适用候选，还是必须把公式和范围固定后，再用未参与选择的新条件检验？哪种定位能支撑这篇论文的核心贡献？”
   作用：决定证据责任和工作量。有限样点的通过不代表样点之间整个连续区域都可靠；独立预测需真正未参与选择的条件和合格参考，还需判断新颖性和投稿定位。

4. **下一批计算优先放在哪里？**
   “为了找清范围边界，应该优先补接近容限的几何、更浅槽/更大间隙、薄间隙反例，还是先完成h30/d80的0.625nm横槽补证？”
   作用：把计算花在所主张的边界上。0.625目前属于h30/d80严格参考支线；主地图是另外18种几何，不能用一个点给全域背书。各候选须先做范围和资源准备，不自动启动。

如果时间只够问两个：先问第1和第3；分别确定“算多准”和“证明到哪一步”。
