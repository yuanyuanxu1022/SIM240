# 定量机制诊断候选文字（未合入正式稿）

作者内部候选，2026-11-09。仅在接受本轮分解定义与数值限制后使用，不作为最终理论/机制冻结。

为区分方向性闭合偏差中的梯度与剖面贡献，另对已知开发组h=75nm、d=120nm、槽/凸台等宽、w=60和240nm的两方向末态作离线诊断。采用单位平面面积功率除以深度积分通量平方的归一化，使不同宽度的结果对应相同通量；理想局部平板阻力用作共同基线。速度梯度计算采用内部中心差分及真实半格壁处的二阶单边公式，并以另一种半格壁延拓方式检查后处理敏感性。该补充组与原18种几何36条5nm主结果分别报告。

固定通量下，沿槽梯度能量相对局部平板基线的差额可分为横向速度梯度项与局部平板速度剖面偏离项，后者同时包括截面通量分配变化。在2.5nm诊断中，窄槽两项在正项和中分别约41.94%与58.06%，宽槽约73.19%与26.81%。宽槽横向项的相对份额较高，但其以局部平板阻力归一化的绝对贡献由约1.775降至0.532，因此不能将份额增加解释为变宽增加横向阻力。横槽分解利用常截面流量，主速度剖面偏离项在窄、宽两槽中分别约90.17%与64.04%；垂直速度梯度组约7.10%与25.07%，其余为主速度沿程梯度。上述百分数以已列正项之和为分母，不是独立因果份额。

主要份额在已检查网格和两种壁面导数方法下保留，但连续恒等式与离散求积仍有余额；宽槽仅有两档网格，窄槽历史网格目标未通过。区域分区还表明角点邻域的总耗散比例明显依赖所选半径，不能据单张高值图或某一分区比例认定尖角为唯一或主导原因。因此，本诊断支持所测几何中方向与宽度相关的速度耦合/剖面偏离结构，不提供整个参数域的机制份额、连续精度或实际压印过程验证。
