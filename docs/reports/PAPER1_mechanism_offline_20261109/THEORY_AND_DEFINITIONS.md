# 定量诊断定义与正差额恒等式

2026-11-09。作者内部分析说明；不是已合入论文的定理、首创声明或最终公式冻结。沿用当前附录E的连续理想Stokes/无滑移/周期/全充液条件，槽沿y，截面Ω位于xz平面。μ常数，G=ρa。

## 1. 功率和阻力的正确比较量

深度积分通量J为m²/s，平面面积A=P Ly。驱动输入功为

\[
P_{in}=GJA,\quad R_{drive}=G/J=\mu/K.
\]

固定G时，K下降意味着J下降，也使总输入功下降；故不能拿同驱动力下的总耗散大小直接排阻力。采用

\[
R_{diag}=\frac{P_{diag}}{A J^2},\quad R_{LC}=\mu/K_{LC}.
\]

此量等价于对各场作线性重缩放到同一J之后比较单位平面面积功率。跨宽度不能忽略A变化，也不能随意拿不同域的P/Q²直接比较；当前所有表报告R/RLC。

物理黏性耗散密度为Φ=2μD:D，D=(∇u+∇uᵀ)/2。三个法向项为2μ(∂i ui)²；三个剪切项为μ(∂j ui+∂i uj)²，六项非负相加。对沿y不变的场，沿槽主项为μ(∂x uy)²与μ(∂z uy)²；横槽则为2μ(∂x ux)²、2μ(∂z uz)²及μ(∂z ux+∂x uz)²。法向/剪切分量的名称是坐标应变描述，不是空间区域或独立因果机制的标签。

连续积分中，固壁零迹、周期匹配和不可压缩给出∫2D:D=∫|∇u|²。它不逐点成立。当前后处理分别保留两种积分和差额，不能用梯度平方的某分量冒充同名局部应变耗散。

## 2. 固定J的理想平板基线

令V=u/J，单位m⁻¹。P=2w且φ=.5；

\[
K_p^{LC}=\langle H^3\rangle/12,\quad
K_t^{LC}=1/(12\langle H^{-3}\rangle).
\]

沿槽基线B_y=z(H−z)/(2KpLC)，使P⁻¹∫Ω B_y dA=1；它允许各x的截面流量按H³分配。横槽基线B_x=6z(H−z)/H³，每个x的截面积分为1。基线在台阶处不保证x方向连续，不能当成完整Stokes可容许试探场；下述推导仅对其逐列z导数作平方展开，不使用∂xB或其H¹可容许性。

## 3. 沿槽正差额分解

设充分发展的连续场只有V_y=V，固壁零迹，P⁻¹∫V=1。对几乎每个x沿z积分分部：−∂zz B=1/KpLC，边界交叉项为零，因此

\[
\int_\Omega (\partial_zB)^2 dA=P/K_p^{LC},\quad
\int_\Omega \partial_zV\,\partial_zB\,dA=P/K_p^{LC}.
\]

平方展开给出

\[
R_{grad}-R_p^{LC}
=\frac\mu P\int_\Omega\big[(\partial_xV)^2+
     (\partial_z(V-B))^2\big]dA.
\]

两项是横向梯度和相对局部平板基线的剖面偏离。后一项包括截面通量分配的变化，不是只度量形状变化。对所述连续沿槽解Rgrad=Rdrive。恒等式说明额外阻力可以作上述非负数学分解；不说明两个项是可独立操纵的物理原因，也不将∂xV项等同于某个“竖壁带”的功率。

## 4. 横槽正差额分解

令V=(U,W)为xz平面场，q(x)=∫U dz=1。由−∂zzB=12/H³，可得逐列交叉积∫∂zU∂zB dz=12/H³，故

\[
R_{grad}-R_t^{LC}=\frac\mu P\int_\Omega[
 (\partial_z(U-B))^2+(\partial_xU)^2+
 (\partial_xW)^2+(\partial_zW)^2]dA.
\]

它将主速度的抛物线偏离、主速度沿程变化、垂直速度梯度分开。此处“垂直速度梯度项”并非对称应变张量中可独立命名的“垂直耗散”；它属于全域梯度能量的正项。主速度/垂直速度间在真实局部剪切Φ中存在交叉项，只有全域条件成立才可用上述积分关系。

台阶跳点是有限个x位置，逐列z分部积分对几乎处处成立；真实场仍须满足竖壁零迹。弱解框架不要求角点经典二阶可导。该论证沿用附录E有限能量与常通量框架，不因台阶跳点忽略其全局流动影响。

## 5. 离散核验与限制

上述为连续积分恒等式。本轮CSV节点梯度、半格壁处理、节点求积及非零离散散度不保证它逐字成立，因此表中同时列出正项和、直接驱动差额以及梯度积分差额，保留余额，不把正项和重标定到恰好等于驱动值。

份额分母为已列正项之和，不能把它直接说成驱动差额的精确百分比分配。横槽q/J本轮逐列核实范围另列field_checks；有限差分散度只是该诊断的残差，不可改写原质量守恒验收。

这些分量只用于已知h75/d120两宽和已算网格的机制诊断，不能外推到全部主图或连续参数域。最终稿如使用此推导与数字，仍需作者科学审定和独立理论复核；不能声称机制首创、物理验证或所有参考已经合格。
