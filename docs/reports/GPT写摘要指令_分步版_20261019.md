# 让 GPT 写摘要的指令（一步一步来 · 中英双语 · EJMB 版）

2026-10-19 · 配套文件：`SIM240_EJMB_英文整合工作稿_20261019.md`

> **用法**：每块代码框**单独复制一次**发给 GPT，等它回一段，再发下一块。
> **不要一次把六块全贴过去** —— 那样它会把六件事揉成一段，又回到你现在摘要的老毛病。
> 每步拿到结果后，先自己看一眼，再给我核。核完再进行下一步。
>
> 指令是中文的，**每一步都要中英文各一版**：英文用于投稿，中文用于导师/组会/你自己核对。
> **中文不是翻译稿，是同一份论证的第二语言版本**——两者必须同一批数字、同一套术语、同样的边界。
> 共 6 步，约 50 分钟。

---

## 开始前：三件事

1. **新建一个对话**。不要用之前做审查的那个会话（那个是"挑刺"人设，让它写东西会推脱）。
2. **先让它只读文件、不许写**（第 0 步就是干这个）。写作任务先读齐材料，比先动笔重要得多。
3. **每步只要它输出一小段（中英各一版）**。摘要写成一段，但**思考要拆成六步**——这是整份指令的核心设计。
4. **固定术语只定一次**（第 0 步的表）。后面中英文都从这张表取词，否则两个版本会出现两套说法。

## 第 0 步：让它读材料并把数字列成清单（不写摘要）

```
这是一个写作任务，不是审查任务。你要为下面这篇论文重写摘要，**中英文各一版**。
现在先不要动笔，只做三件事。

【读这些文件】
1. docs/reports/SIM240_EJMB_英文整合工作稿_20261019.md
   —— 重点读 Abstract（第 17 行）、I. INTRODUCTION 末尾三条结论（第 69–95 行）、
      IV. E 小结（第 467–475 行）、V. C 末尾（第 542–545 行）、VI. CONCLUSIONS（第 547–549 行）
2. docs/reports/SIM240_投稿目标决定与写作入口_20261019.md
   —— 了解目标期刊与"当前仍不能称投稿完成"的清单

【第一件：用中文复述】
用 5 句话告诉我：这篇论文要证明什么、靠什么证据、边界在哪。
不要用"本文研究了……"这种没有信息的句式，要写出"和什么比、差多少、所以什么"。

【第二件：把数字列成表】
把下面这些量在原文中的**确切数值**抄出来，做成一张表（中文说明 + 原值）：
- 闭合式沿槽高估范围
- 闭合式跨槽高估范围
- 参考几何 (h=75, d=100) 下，闭合式与精确解的各向异性比
- 45° 驱动下的流向角（精确解 / 闭合式 / 差值）
- V2 修正在 18 个沿槽样点上的最大绝对残差
- V2 修正在跨槽样点（h≥50 nm）上的最大绝对残差及样点数
- h=25、d=100 跨槽点，5 nm 与 2.5 nm 两个网格上的残差
- 几何数、主方向工况数、正式运行总数

要求：只抄原文，不要自己算、不要四舍五入、不要补单位。找不到的写"原文未给"。

【第三件：定术语表】
把摘要里必须反复出现的术语列成一张两列对照表（中文 | 英文），只列 6–10 个，
例如"深度积分输运系数""算术–调和平均""局部立方律""各向异性比""残余间隙""经验修正"等。
说明：这张表一旦定下，后面中英文两版必须一律照用，不许中途换说法。
```

**为什么要这一步**：你的摘要之所以数字堆成山，是因为写的时候在"边写边找数"。先把数字钉在表上，后面每一步都从表里挑，就不会再冒出第十一个数字。**术语表则是为了中英两版不打架**——同一个量在两版里换名字，导师对照读时第一个发现的就会是这个。

**拿到结果后**：把它复述的五句话、数字表、术语表贴给我。我核完再往下。

## 第 1 步：只写"一句主张"

```
现在只写一句话，不要写摘要。

这句话是全文的主张，要满足三个条件：
1. 它必须是可被反驳的 —— 如果有人不同意，他能指出"哪张图能推翻它"；
2. 它必须包含"和什么比、差多少、所以什么"三件事；
3. 它不能出现具体百分数（那是证据，不是主张）。

参考句式（不要照抄，用你自己的话）：
"某类模型在某条件下系统性地偏大，而且两个方向的偏大程度不同，因此标量式的修正在原理上就不成立。"

限制：
- 不超过 40 个中文字 / 或 30 个英文词；
- 不要写 "we investigate" "this paper studies" 这种空头动词；
- 不要写 "novel" "first" "unprecedented"。

只输出这一句，中文和英文各一版。
```

**这一步是本轮最重要的**。主张定不下来，后面五步全是白改。写完后你贴给我，我们一起选一版——**这一步值得多来回两轮**。

## 第 2 步：只写"缺口"（1–2 句）

```
现在只写摘要里的"缺口"部分，1–2 句。**先写英文，再把同一句写成中文**，中文不是逐字直译，是同一意思的自然中文表达，但信息量必须一样。

要回答的问题：别人已经做到哪一步了，还差什么？

必须体现这三层（每层一句，可以合并）：
1. 把沟槽图案等效成各向异性渗透率张量，是唯一可行的降阶路线，已被压印建模广泛采用；
2. 这条路线依赖的算术–调和平均（局部立方律）闭合式，在"尖锐直角沟槽 + 有限间隙"这个组合上，
   没有被逐方向地定量检验过 —— 已有的对比要么针对光滑剖面，要么只给力/总流量而不给两个主系数；
3. 所以缺的不是"闭合式会不会错"，而是"两个主方向各自错多少、这个差异会不会改变流向"。

硬性禁止：
- 不许写"文献中尚无研究"（检索不完整，这是不实陈述）；
- 不许贬低前人工作（"however, they failed to..."这种句式不要用）；
- 不许出现任何数字；
- 不许出现 "to the best of our knowledge"（除非你确实做了系统检索，本文没有）。

只输出这 1–2 句，格式：
英文：…
中文：…
```

## 第 3 步：只写"做了什么"（2–3 句）

```
现在只写摘要里的"做了什么"部分，2–3 句。**先英文，后中文**。中文里所有数值、单位、几何量必须与英文完全相同（240 nm、120 nm、25–125 nm、25–120 nm、18 个几何、36 个工况），不许出现"约"“左右”这类模糊化处理。

必须包含（这些是读者判断可信度的最低信息量）：
- 方法：格子 Boltzmann 方法（OpenLB），在显式解析的周期矩形沟槽几何中直接求解；
- 状态：稳态、完全充满、单相牛顿流体、无自由面（一句话讲清，不要展开）；
- 参数：周期 240 nm、槽宽 120 nm、间隙 25–125 nm、槽深 25–120 nm；
- 规模：18 个几何、36 个主方向工况（**注意：18 是几何数，36 是工况数，不许混**）；
- 对照对象：算术–调和局部立方律闭合式，逐点比较两个主方向的深度积分输运系数。

硬性禁止：
- 不许写网格尺寸、时间步、松弛时间、雷诺数、马赫数（这些属于方法章）；
- 不许写"高精度""可靠""严格验证"这类形容词；
- 不许写代码版本号或提交哈希。

只输出这 2–3 句，格式：
英文：…
中文：…
```

## 第 4 步：只写"结果"（3 句，只要 4 个数字）

```
现在只写摘要里的"结果"部分，最多 3 句。**先英文，后中文**。

规则：只准用下面这四个数字，**一个都不许多、一个都不许改**（数值直接从第 0 步的表里抄）：
1. 沿槽高估范围（百分比区间）
2. 跨槽高估范围（百分比区间）
3. 45° 驱动下流向角偏差（度）
4. V2 修正在沿槽 / 跨槽（h≥50 nm）两组样点上的最大绝对残差

三个句子分别承担：
- 第 1 句：两个方向都高估，但幅度不同（给出数字 1 和 2）；
- 第 2 句：因为不同，所以各向异性比和斜向流向都被带偏（给出数字 3）；
- 第 3 句：按方向分别做经验修正后残差降到什么水平（给出数字 4）。

硬性禁止：
- 不许再引入各向异性比 3.70 / 2.21（留给正文）；
- 不许引入 h=25 nm 的双网格残差（留给讨论与结论）；
- 不许说"误差来源于尖角/侧壁/台阶"（机制只是候选解释，摘要里一个字都不提）；
- 不许说"修正后可推广""可用于任意几何"；
- 每个数字后面必须跟一句"所以呢"——没有含义的数字不要放进来；
- **中文版里每个数字必须与英文版逐位一致**（含正负号、小数位、区间方向），不许把"10.5%"写成"约一成"。

只输出这 3 句，格式：
英文：…
中文：…
```

**为什么只给 4 个数字**：摘要的功能是让读者决定"要不要读正文"，不是把结论复述一遍。你现在摘要里有 10 个数字，读者读完一个都记不住。

## 第 5 步：只写"边界"（2 句）

```
现在只写摘要末尾的"边界"部分，最多 2 句。**先英文，后中文**。

必须讲清三件事（可以压进两句）：
1. 误差是相对于离散数值参考解而言的，全参数域的不确定度界没有建立；
2. 修正式是"数据知情、回顾性评价"，不是独立预测检验；
3. 结论限于单相、固定几何、完全充满，不涉及动态充填、自由面、润湿或真实光刻胶流变。

硬性禁止：
- 不许把这部分写成免责声明清单（最多两句，超过就是自我否定）；
- 不许用 "however" "nevertheless" "it should be noted that"（这些词会让读者以为你在撤回前面的结论）；
- 不许出现 "limitation" 这个词（用 "restricted to" "does not establish" 这种直接说法）；
- 不许重复第 4 步已经说过的数字；
- 中文版不许用"不足之处在于""有待进一步完善"这类套话，直接说"本文不涉及……""上述结论不适用于……"。

只输出这 2 句，格式：
英文：…
中文：…
```

## 第 6 步：拼装 + 自检（这一步才让它写"摘要"）

```
现在把前五步的结果拼成两段完整摘要（一段英文、一段中文），并做自检。

【拼装规则】
- 顺序固定：缺口 → 做了什么 → 结果 → 边界。不要改顺序，不要加过渡句。
- 英文：单段，150–200 词（目标 170）。
- 中文：单段，250–320 字（目标 280）。**不是英文的逐句直译**，要符合中文科技论文语序，
  但四个成分、四个数字、三处边界必须一一对应，不许增、不许减、不许换位置。
- 不加 "Abstract" 标题，不加"以下是摘要"之类的前言。
- 前四步的句子可以润色衔接，但不许新增任何事实、数字或限定。
- 两段之间空一行，英文在前、中文在后。

【自检表：逐条回答"是/否"，不要跳过】
1. 英文段一共出现了几个数字？（应为 4 个；超过就删）
2. 中文段一共出现了几个数字？（应与英文完全同数、同值、同符号）
3. 每个数字都能在第 0 步的表里找到原值吗？
4. 有没有出现 "novel / first / unprecedented / for the first time"，或中文的"首次""创新性地"？
5. 有没有出现 "prove / validate / demonstrate that ... mechanism"，或中文的"证明了""揭示了……机理"？
6. 有没有把 18 个几何和 36 个工况混用？（中英两版都查）
7. 有没有说修正可以外推、可以预测未见几何？（中英两版都查）
8. 有没有提到本文没做的工作（实验、两相、移动边界）？
9. 英文段是否在 150–200 词之间？中文段是否在 250–320 字之间？
10. 有没有超过 45 词的英文长句？（有就拆）
11. 第一句读完，读者知道"这篇在跟什么较劲"吗？
12. 中英两版有没有对同一个量用了两个不同说法？（对照第 0 步的术语表逐条查）

【输出格式】
第一段：英文摘要正文（最终要放进稿子的那段）。
第二段：中文摘要正文（给导师/组会用）。
第三段：中文标题「自检」下面列出上面 12 条的一行答案。
第四段：中文标题「数字出处」下面，逐个数字给出它在整合稿中的行号。
第五段：中文标题「中英对照核查」下面列出：同一术语在两版中各自的写法，有没有不一致。
```

## 拿到结果之后：给我核这五件事

把第 6 步的五段原样贴回来，我按下面五项核，核完给你一份对照表：

| 核什么 | 怎么核 |
|---|---|
| 数字真伪 | 逐个回到 `SIM240_EJMB_英文整合工作稿_20261019.md` 对应行，是否逐字一致（不看它的"出处"自述，只认原文） |
| 越界表述 | 扫 "prove / validate / universal / general / any geometry / converged" 等词，以及中文的"证明/揭示/普适/任意几何/已收敛" |
| 数量口径 | 18 几何 / 36 工况 / 52 次运行三者有没有混；V2 的 18 与 15 两个样点数对不对 |
| **中英一致** | 逐句对齐：英文 10 句 ↔ 中文 10 句，数字逐位相同，术语与第 0 步表一致；中文不许比英文多说或少说一件事 |
| 语言 | 英文句子长度、时态（方法和结果用过去时，普遍结论用现在时）、中式英语；中文有没有翻译腔（"被进行""对于……而言"这类） |

**核完再改稿**。不要拿到摘要就直接往稿子里贴——它是"写作助手"，不是"证据来源"。

## 三条提醒

1. **第 1 步（一句主张）值得到回三轮。** 六步里其他五步都是技术活，只有这一步是判断。这一步含糊，整篇摘要就会回到"我们做了 A、B、C"的清单模式。

2. **如果 GPT 在第 4 步擅自多加数字，不要自己删——让它删。** 你要看它是否理解"为什么不能多"。它如果辩解"这个数字很重要"，说明它把你的稿子当成了素材库而不是论证。

3. **写完摘要不要接着写结论。** 结论的约束比摘要更严（要重复边界、要给出下一步），另开一轮，用单独的指令。

## 附：当前摘要的问题（对照用）

现有摘要（第 17 行，225 词）的结构是对的，问题在两处：

- **数字太密**：10.30–204.85%、8.11–54.19%、9.20°、3.70/2.21、10.5%、6.9%、−18.7%/−14.9%，一段里七个量。读者读完只记得"数字很多"。

中文版按同样比例写，约 280 字。**中文不要写成英文的镜像**——中文读者更习惯"先讲对象、再讲做法、最后讲结论"的语序，可以调整句内结构，但每句承担的功能必须与英文一致。

## 中文版单独三条要求（避免翻译腔）

| 常见写法 | 改成 |
|---|---|
| 本文对……进行了研究 | 本文检验了…… / 我们测算了…… |
| 结果表明，……被高估了 | 闭合式在两个方向上都偏大：沿槽 …、跨槽 … |
| 对于……而言，…… | ……的误差是…（去掉"对于…而言"） |
| 由于……的原因 | 因为……（或直接删掉） |
| 具有一定的意义 | 删掉。有意义就说出是什么意义 |
| 不足之处在于 | 本文不涉及…… |

**判断标准**：把中文摘要读出声。如果读起来像翻译软件念英文，就重写；如果像一个同行在会议上跟你讲这三件事，就对了。
