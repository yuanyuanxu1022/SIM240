# 分区公式：变量与区间可行性评估

日期：2026-10-22。用户转述老师要求“分区间具体出来一个公式”，并明确尚未指定分区变量，授权先判断合理分区。本轮使用既有18种几何/36主方向数据进行尺度、残差和分段插值评估；没有OpenLB运行、优化器、旧V2修改、门槛修改或新数值Gate。

## 当前建议

**优先用间隙与槽宽之比α=h/w作为分区轴，每段保留槽深与槽宽之比β=d/w；沿槽和横槽分别建模。尚不确定物理临界值，不将h=25/50nm的既有采样档当作机制分界。**

固定P/w=2、占空比1/2、线性Stokes与同样边界条件时，长度按w缩放、速度按Gw²/μ缩放，可写K_i=w³𝒦_i(α,β)。两个独立几何比都可能影响结果，d/h=β/α不能单独代替完整几何。

## 数据依据

| 无量纲量 | 已覆盖范围 |
|---|---:|
| h/w | 0.2083—1.0417，仅4档 |
| d/w | 0.2083—1.0000，仅5档 |
| d/h | 0.2—4 |
| (h+d)/w | 0.4167—2.0417 |

矩阵是18而非20种几何：h=25nm只有d=25/50/100nm，d75/120缺这一层。25—50nm、75—125nm之间没有内部采样；目前不能确定这些区间内是否存在真实转变及准确位置，也没有充分覆盖h/w远小于1或远大于1的渐近区。

### 只按d/h不够

同为d/h=1时：(h,d)=(25,25)、(50,50)、(75,75)nm的原模型偏差分别为沿槽19.93%、53.13%、90.50%，横槽8.11%、26.69%、40.50%。单独使用该比值会把明显不同的横向约束程度混在一起。

### 只按d/w分段也不够

固定d=100nm（d/w=0.8333），h=25/50/75/125nm的原模型偏差为沿槽139.14/154.24/144.95/108.38%，横槽16.36/37.14/46.51/49.12%。即使把d/w划成再多段，该固定d的四点仍共享一个F(d/w)，仍遗漏h依赖。

可直接给出这个限制的样点下界。设q_h=K_LC/K_ref，某一深度共享正乘法因子F，最小化max_h|Fq_h−1|，则F*=2/(q_min+q_max)，最小最大残差为(q_max−q_min)/(q_max+q_min)。d100横槽四点的下界为12.33968%。这是对这四点且固定局部模型的代数结论，不是连续几何范围的精度下界，也不适用于允许改变局部模型结构或引入h的公式。

### 现V2残差支持加入h，但不证明存在临界h

沿槽h50五点残差全正，h125五点全负；横槽h25最坏残差18.7%，h≥50的15点约6.9%。这些是原始参考网格上的回顾性现象，不足以认定h25和h50之间发生物理机制转变。特别(25,100)横槽有2.5nm对照，不能把该弱点全归因于模型形式，也不能声称h25无加密。

## 两类交付必须区分

### A. 可以马上计算的分段代数表达：固定深度的插值

对固定d、相邻已算间隙h_j和h_(j+1)，写为

K_i(h;d)=K_i(h_j;d)·(h/h_j)^{s_i,j(d)}，h_j≤h≤h_(j+1)，

s_i,j(d)=ln[K_i(h_(j+1);d)/K_i(h_j;d)]/ln[h_(j+1)/h_j]。

这是一组明确、自动连续的幂律插值关系。全部26个方向/深度/间隙段系数见interpolation_segments.csv。它的分界是数值采样点，身份是已有点间插值，不是由机制推导的分段律；不外推，也不填补d75/120的h25层。

例如d=100nm、50≤h≤75nm时，h以nm代入：

- 沿槽K_parallel(h)=5.73603346×10^−23·(h/50)^1.32954857 m³；
- 横槽K_perp(h)=1.46485866×10^−23·(h/50)^2.73987951 m³。

端点由构造精确通过，不是独立验收。另做同一深度内部留去一个h层点、用左右相邻保留点预测的检查，共16项（每方向8项）：最大绝对偏差沿槽16.43%、横槽1.46%，见interior_leave_one_out.csv。检查只覆盖有左右邻点的内部点，没有检验两端、未采样深度或跨几何独立预测；沿槽结果表明“端点能连上”不等于中间区间已经足够准确。

### B. 若老师要求跨h、d的简洁分段公式：尚需另建模型

候选结构应明确为：K_i^seg=K_i^LC F_i^(r)(h/w,d/w)，α落在第r个区间。优先比较一个连续双变量式与最多两个连续分段式；分界α_c和两方向是否共享分界均未冻结。区间连接应连续、K为正、d→0回到平板；物理极限与上下界若要作为约束，还需展示相应理论证明。

新式应和原V2原样比较，不能覆盖原脚本、参数、残差或失败记录。分段不自动优于引入h的连续单段式；须以同一数据范围和验证规则比较。

## 下一步的验证设计

1. 明确输出为K_parallel/K_perp，或乘性修正F_parallel/F_perp；统一K的m³定义及同几何/方向/参考网格的误差分母。
2. 原V2作为固定基线，新候选单独保存；限制段数和参数数目，避免18种几何被过多参数消耗。
3. 若估计分界或选函数形式，所有选择在分组验证的训练部分内进行；同几何两方向及各网格保持同组。考虑整层留一h、整层留一d，并明确哪些验证实际上是外推。
4. 同时检查最坏误差、逐点误差、连续性和对系数舍入的敏感性，不用“每段都穿过数据点”替代预测评价。
5. 若要把分界解释为机制转变，需要分界附近额外几何点及其网格证据；属于后续另行授权工作，本轮不启动。
