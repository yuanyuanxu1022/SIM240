## 2. OpenLB 官方基准怎么验证（源码摘录）

官方自动验证 = **解析解对照 + 网格加密序列 + 回归比对容差**，以 Poiseuille 为标准题：

**表 O1　官方 Poiseuille 基准的速度 L2 误差（非受力，摘自源码期望表）**

| 网格 N | 2D local | 3D Bouzidi |
|---:|---:|---:|
| 11 | 0.0250 | 0.0565 |
| 21 | 0.00673 | 0.0162 |
| 41 | 0.00176 | 0.00445 |
| 相邻比 | 3.71 / 3.83 | 3.48 / 3.65 |

- 误差比 3.5–3.8，**接近二阶收敛的 4 倍律**——官方基准看的是"收敛阶对不对"，不是"误差够不够小"。
- **官方容差是 `errorFactor`（1–2）**：与期望值比对，允许因子级偏差——这是**回归测试**逻辑（防止代码改坏），**不是 ≤1% 的硬门槛**。3D N=41 一档官方自己把因子放宽到 2。
- 官方测试同时对比四种边界格式：**bounceBack 在 N=11 的速度误差 12.8%–23.2%，interpolated/Bouzidi 约 1.1%–5.7%**——官方数据本身就说明插值类边界更准，支撑本文选用 Bouzidi 的合理性。

## 3. 用 OpenLB 发论文的人怎么验证（E01/E02 模式）

- **E01（Bukreev 2025，纳米孔隙耦合）**：各子模块先分别对解析解 → 完整耦合再验 → 自动微分灵敏度与中心有限差分**独立算法交叉**。
- **E02（Czelusniak 2025，伪势一致性）**：推导所逼近的方程 → 物性与 SI 单位关联 → 基准族（平界面/静滴/伽利略不变性/平板两相流）→ 报告对目标方程的二阶收敛。
- 共同结构：**先让每个部分证明自己，再核接口，最后展示能回答的科学问题**；软件通用验证不替代论文特定几何/物理的验证。
