新scripts/run_S0_A1.py默认只读，不给--execute就不调用原生程序；即使传入执行请求，本准备合同仍在binding检查处被拒绝。未来真实获准时必须另存启动合同，明确只批准这两个已绑定身份，输入SHA和授权原话独立封存。旧v1.2的启动许可不能挪用。

未来每方向的顺序已实现为：

1. 重查资源与输入，调用绑定的A1程序；不自动重试。
2. 原生退出成功后，独立finalizer核查实际密度／有序坐标／phase／时间／位模式，生成带SHA的捕获索引；错误保存后停。
3. 保存独立退出、完整原始输出SHA和前后输入映射到completion；捕获错误也保留原始失败记录。
4. 调用补证入口，其中先由原字节URV检查器验收当前原始结果，再独立重放密度，比较完整补偿列、原20旧列及物理输出守卫。
