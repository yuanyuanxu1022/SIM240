## 3. 独立读回方式

### 3.1 reader和“独立”的含义

本机只做了路径/模块可用性检查：/usr/bin/pvpython与/usr/bin/paraview存在；当前普通Python有numpy、未发现vtk模块。本轮没有启动这些程序、没有运行时版本核验。

下一阶段首选pvpython内置VTK的vtkXMLImageDataReader，直接读取所列VTI的原PointData，按名字取material和velocity_m_s；不用OpenLB求解器/旧提取器/旧图像反推数据。它是独立的导出数据读取/算术路径，仍与原求解结果共享同一物理模拟，不是独立物理解或实验验证。无需为此安装包或编译OpenLB。

读回实现需要另写最小分析器及合成夹具，不能把现存通用绘图audit_fields.py直接当体积/截面通量积分器。若reader或运行环境有问题，记录失败；不得静默改用插值或生成新仿真数据。

### 3.2 XML和数组

已核元数据：ImageData、LittleEndian、vtkZLibDataCompressor，PointData中material为1分量、velocity_m_s为3分量，均Float32。pressure_Pa和dissipation_m2_s3仅作元数据记录，不用于本阶段积分。不得用速度大小speed代替带符号分量，不对PointData做Point-to-Cell转换、插值、Threshold重建体网格或自动去重平均。

浅槽WholeExtent/Piece Extent为[-3,50]×[-3,50]×[-3,22]，深槽为[-3,50]×[-3,50]×[-3,37]；Origin=(2.5,2.5,-2.5)nm，Spacing=(5,5,5)nm。reader bounds包括周期/并行外围层。

优先使用VTK读回实际点坐标并核Origin+index×Spacing（index是Extent中的全局整数索引，不先减Extent下界）。若自行排列数组，VTK point ID规则x最快、然后y、z，速度分量相邻；必须用非对称合成场和实际CSV验证，不能靠reshape后图像看起来合理放行。

Float32只限定导出精度；不能把后处理升成Float64称作恢复原始双精度场。用Float64/fSum或补偿累加计算离散积分，保留实际解码精度信息。

## 4. 物理域与分区：先核材料，再求流量

### 4.1 有效格点及体积权重

有效流体F必须同时满足：material恰为1，0≤x<Lx，0≤y<Ly，0≤z<H(x)，其中槽内H=h+d，槽外H=h。先独立检查物理包围盒内保存material与解析几何的流体布尔掩膜逐点一致；不允许先以解析掩膜替换错误material，再宣称材料核对通过。

这是一周期、一个cuboid的受限数据，不把多个重复周期/halo加进去。坐标转整数格点键后检查重复、缺点和步长；出现重复不平均掩盖。坐标匹配容差只由Float64坐标表达的舍入范围确定（64×eps64×max(Lx,Ly,h+d,dx)），不是人为物理厚度。不把坐标推到另一格满足计数。

本数据q=.5且流体点位于格子中心；为复现原measure口径，各有效点按其对应晶格控制体积dx³加权。这里虽为VTK PointData，却按晶格中心采样做离散中点和，不使用普通VTK三线性单元积分来替代。它是匹配保存数值统计的离散积分，不宣称精确连续积分。

G与C互不重叠、并集为F。界面z=h不穿过当前格点中心，但规则仍写为半开区间。先做逐点分区和计数核对，不能只核总数。

### 4.3 浅深比较时再分上槽

为区分“原来已有的空间”和“新增深度”，上槽再分：C0为50≤z<75nm；C+为75≤z<150nm，仅深槽有。C0两几何均5760点、7.20e-22m³；深槽C+为17280点、2.16e-21m³。C+不是把整个深槽C当作全部新增空间。

分区是统计定义，不是可拆除的独立阻力元件。G和C之间可以交换液体，尤其T方向不允许将二者称为各自恒流的并联通道。

## 5. 总通量重建和独立核对

设e_P=(0,1,0)、e_T=(1,0,0)，u_e=u·e；平面面积A=LxLy。

主量J_field=(1/A)Σ_F u_e dx³，单位m²/s。

对照三个既存记录：result.txt的J_main及J_vector；diagnostics.csv末行对应分量；K_from_field=nu J_field/a与result.Keff。K_from_field是相同定义下的派生核对，不能称第二项独立验证。记录同一量的三个入口不统计为三次独立物理实验。

以field_slice.csv作为不同存储精度的空间锚点：按当前生产代码y索引ny/2=24，对应原生y=122.5nm（Origin_y+24dx），不是插值得到的120nm切面。将该原生平面的每个有效点按x,z匹配CSV，检查ux,uy,uz。坐标、行数应分别600/960；记录Float32舍入后逐点匹配。若历史CSV不符合该平面，记录不一致并停下，不自动搜索一个“最像”的平面来调参。

不得未经三维比较直接把CSV切片沿y复制48次充当全场。先报告相同x,z在不同y的速度变化；它只是该导出场中沿y近均匀性的观察，不替代任何精度验收。

## 6. 截面流量：核法向分量，并区分记录一致性与流动诊断

对P：在每个原生y平面，Q_P(y)=Σ_(F∩plane y) u_y dx²，单位m³/s。
对T：在每个原生x平面，Q_T(x)=Σ_(F∩plane x) u_x dx²。

每方向48个有效原生平面。P每平面流体点600（浅）/960（深）；T凸台投影处每平面480点，槽投影处720（浅）/1440（深）。几何截面积不同不妨碍同一稳态总流量近似守恒。源程序选中的截面：P索引12/36，即y=62.5/182.5nm；T索引6/24，即x=32.5/122.5nm。执行前仍按坐标/结果核这项来源解释。

第一类核对：上述两个指定平面的积分分别与原Q_sections、末诊断Q_section1/2比较，允许范围只覆盖Float32导出与累加/文本舍入，不能把旧1e-5连续性门槛当作读错数组也可接受的宽容线。

第二类诊断：对全部48个截面报告min/max/mean、相对跨度、各截面相对平均偏离，以及带符号的分区Q_G(s),Q_C(s)。这是新全截面描述，当前没有给它套新物理PASS阈值，也不以必须各截面逐位相等作为要求。原两截面守卫仍按旧规则，不追改历史结果。

检查离散恒等式：mean_s Q(s) = A J_field/L_e，P中L_e=Ly、T中L_e=Lx；故本几何等于240nm×J_field。这个关系是同一数组下的代数自洽检查，不能替代与原始J/Q记录的独立核对。

T方向的C只在槽投影内存在，凸台投影处Q_C=0由几何就能预期；不能据此说槽区对总横向流动无影响。区域Q_G、Q_C可以随x变化、彼此交换，只有总Q适合做沿程连续性诊断。P方向也先检查分区沿程变化，不能预设单独守恒。

## 7. 分区通量与浅深差分

同样的体积权重定义J_G=(1/A)Σ_G u_e dx³、J_C=(1/A)Σ_C u_e dx³，必须使用同一个A；J_G+J_C=J_field。两者均为带符号的空间平均输运贡献，单位m²/s。J_C/J_field是贡献份额，不是槽体积利用率或阻力份额；出现反向速度时份额可为负或超过1，不能截断至[0,1]。

同时报告体积V_R、带符号平均u_e,R、∫_R|u_e|dV和反向通量，区分空间变大与流速变化；平均速度不能不乘体积就相加。主比较维持四组相同驱动，不各除本组最大速度后比较绝对大小。

浅深增量：ΔJ=J_deep−J_shallow。

按公共区域/新增区域记账：

ΔJ = (J_G,deep−J_G,shallow) + (J_C0,deep−J_C0,shallow) + J_C+,deep。

这允许回答“新增空间与原有空间变化分别占了多少输运增量”；它是精确的离散记账，不是几何变化的因果拆分。深槽新增空间同时改变旧区域速度，不能把第三项独立命名为深度的因果贡献。两方向分别计算，不用P的份额解释T。

所有绝对增量同时给出，先不只报百分比。若ΔJ的导出误差区间含0，禁止输出ΔJ分母的贡献百分比或增量符号定论；即使不含0，仍报告相消程度Σ|分项|/|ΔJ|及导出误差。这个精度检查不能消除已知网格敏感性，尤其T只有3.38%的粗格增益仍有限定。

## 8. 导出一致性检查的数值口径

目标是发现reader、坐标、mask、方向或积分定义错误，不设置新的1%/2%物理门槛。

结构项（文件哈希/帧号、数组名/维度/关联、精确材料标签、去重、分区节点数和mask相等）按离散条件核查；任何不符即停止该条下游量化，留下失败和已有中间记录，不自动修字段或换帧。

读回值与高精度CSV逐点比较：优先要求存储值与CSV速度正确round-to-Float32的位模式一致，并报告绝对差。这个严格检查若不成立，保留失败调查历史writer/坐标/取值，不能先放宽到百分比让它通过。

总J和指定Q的比较使用逐点导出误差预算：对普通Float32数，epsilon32=2^-24；用epsilon32/(1−epsilon32)×Σ|w_i u32_i|界定转换到Float32引入的绝对求和误差，并为subnormal补充每项2^-150|w_i|。加上原/新Float64积和及几何常数的保守舍入项gamma_(N+32)×Σ|w_i u32_i|（gamma_n=n eps64/(1−n eps64)）和被比较文本末位舍入项。权重w_i为dx³/A或dx²。这里是拟用的导出一致性预算，依赖正确的同帧同分量同定义生产假设；不是历史精度证明。若发现其他生产舍入步骤，必须先解释并另版审定预算，不按结果反向定容差。

取消时不只给主量相对误差：同时报绝对差、L1标度及预算组成，不用接近零分量作相对分母。浮点求和用独立实现与源统计对照；结构/解析夹具先于实际场。partition加和仅以其自身积和舍入核对，不能把大导出误差预算套给程序内部漏分区。

若实现对上述预算无法给出可靠支持，先完整报告差值/导出精度和NOT_EVALUATED；不得以“数值很小”冒称读回通过。该检查不评价Mach、网格收敛、材料参数、连续解或真实实验准确性。
