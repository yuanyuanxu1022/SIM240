# 先读这里

本目录交付的是四组历史流场的后处理方案，尚无读回/分区流量结果。

- PLAN.md：完整几何、方向、读回、积分、误差检查与解释边界。
- PLAN.json：机器可读范围与未执行状态。
- INPUTS.csv：四组共84份既有文件的准确路径、SHA与用途；不纳入2.5nm场或保留预测。
- EXPECTED_GEOMETRY.csv：20行区域节点数/体积的几何算术预期，不是场实测。
- CHECKS.csv：13类拟检查项目，全部NOT_EXECUTED。
- QUESTIONS.csv：无需新仿真能回答与不能回答的7类问题。
- source_manifest.json、verification.json：原134项输入及补充来源前后无变化，未解码场、未积分。
- prepare_plan.py：本轮仅用于收集元数据/绑定与生成几何预期的准备脚本，不是reader或积分检查器。

下一步是按本方案实现并验证独立离线读回器，再处理四组已有场；本轮未提供实际启动命令。该后处理不自动恢复耗散收支§12.3、不改原Gate或扩至新仿真。
