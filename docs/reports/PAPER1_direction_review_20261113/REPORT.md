# 第一篇收尾方向：DOE、FVM及老师工单的证据边界审查

2026-11-13。回应作者“我们应该做什么、DOE和FVM表示什么、最后交什么”。本轮读取当前文件、复算既有CSV描述量及保存FVM判定中的基准方向比；不重跑求解器、不修改论文母稿/原行动清单/原综合报告、不新授参考资格，不代作者或老师选择覆盖方案。本报告是接续建议，不是Astra正式终审记录或投稿放行。

## 建议主线

以“局部立方律两方向误差不等，因而扭曲各向异性；这一影响如何随已采样几何变化，经验修正改善到何种程度”为第一篇主问题。DOE整理参数规律，FVM给代表性几何另一种数值参照，已有S14解释指定分解下的梯度结构。V2作为回顾性经验修正，不在本篇为挽救精度重拟合成V3。理论上界的作用和适用假设保持原有边界。

## 必须先纠正的九项

1. **行动清单的状态已过时。** 文献核查及五件母稿定点同步已完成，最新私有交付b863ee3，见PAPER1_literature_sync_20261113/DELIVERY_STATUS.json；WO-1～3已有修订。WO-4～6在另一隔离工作树已存在本地成果和未提交修改，不能叫“完全没做”，也未据本轮只读观察认证其全套远端交付。R2只阻塞依赖覆盖的科学主张/新算例，不阻塞无关的引用纠错与有依据的限定语。
2. **DOE是两因素，方向分别分析。** 当前w固定120nm，主矩阵h={50,75,125}×d={25,50,75,100,120}是非等距3×5组合；h25三点单列。h×d是交互项，不是第三个可调因子；未变w不能推出宽度效应。全18几何必须保留；15点规则矩阵方便描述，不是统计上必须删除h25，更不证明h≥50是有效精度域。
3. **87.7%等可以是描述性平方和份额，p值不能照搬。** 独立复算重现P的87.6536/0.7712/11.5752%，T的40.0812/30.5168/29.4020%。响应是V2的有符号相对残差，不是K或原公式偏差。15个确定性格点，每格一值；包含截距、h、d及完整交互时自由度为1+2+4+8=15，没有独立残差自由度。不能一面将8自由度当真实交互，一面作为随机噪声分母认证所报F/p值。当前未建立随机误差模型；不为此重复运行确定性算例制造统计样本。份额还依赖选点、等权权重与响应定义。不能由d平均效应小推出槽深无关，交互和正负抵消均会掩盖边际效应。依据NIST二维ANOVA模型与自由度表（下列来源）。
4. **不能把2.5110−0.0827当严格物理误差下限。** 协议的细中网格变化是敏感性指标，不是已证参考误差上界；功率差也不是K的误差上界。保留两项原指标及2% FAIL，不能靠相减归因成LB边界误差。NASA网格收敛教程要求误差估计所依赖的渐近条件；本轮不建立新误差界。
5. **h125“地板/不可达/加时间无用”未被所列数据证明。** 报告中Ux连续1000轮比值约0.96574、0.96590，2000轮折算约0.96607，与缓慢几何衰减相容。将重启后的局部步数取对数拟合幂律，再外推到1e11步不具有唯一依据。该证据足以说“现有正式运行未在预算内取得合格参考，续跑属于另行诊断”，不足以说存在非零渐近地板。亦不能由Ux正值衰减推断与平板Uz近零分量归一化问题同因，更不能推断h50T/h100T必有同一障碍。原正式exit124和资格未取得保持；不建议盲目续算，也不据此改门槛。
6. **h25排除了什么要限定。** 按新综合报告中的fine/tight近似不变、加密后功率差减小，证据支持对已测容差不敏感及网格/梯度离散相关贡献。不能称整个解的迭代误差精确为零、唯一可行网格已证明，或由计算困难推出物理域应排除h25。本轮未从服务器重新下载tight原场和回执，正式资格仍须完整证据链。已有0.15625nm结果先审查来源、协议与同网格tight缺口，不以功率单项通过升格。
7. **2%是LB/FVM一致性阈值，不能偷换成V2精度认证线。** 若报告V2满足2%的点数，必须明确它是另列描述性容限统计，非冻结PASS/FAIL或投稿必需线。3P通过与1T失败不等于修正公式“三点对、一点错”。
8. **“放大纵轴”不自动等于作假。** 轴限应服务于清楚比较，范围及单位透明；加2%线、数值标记或总览+局部放大可兼顾可读性。以遮蔽超限为目的不可取，但不能把任何非零起点或调整轴限都认定为违规。会议为机器转写纪要，且把h与节距混用；本研究扫的是h=25–125nm，P=240nm固定，应先核参数名。
9. **A/B/C标签冲突。** 新行动清单A=现有4点，R2_DECISION.json A=19P+4T，后者C才是现有4点。向老师确认必须写完整点集、方向和科学任务，不能只说“选A/B”。R2当前未选。补h100T并不自动带来独立各向异性，仍需同几何P参考；单个新间隙也不能定位精确过零点。

## 最小推进顺序与完成标准

1. **先整理现有DOE图表。** 在15点矩阵逐方向画原公式偏差、V2有符号残差和F*=Kref/KLC，沿固定d比较h、沿固定h比较d；h25三点以明确标记单列，全部18可追溯。连线只辅助阅读，不插补未采样单元。用主效应/交互趋势说明，不给无依据p值或精确过零高度。完成标准：每个趋势能回到CSV并说明响应、参考网格、点集和反例。
2. **把现有合格FVM结果单列成主张—证据表。** 同时列K5、KFVM、delta、原公式偏差、V2偏差、参考资格与历史失败；基准一对另列A和重建角。完成标准：所有偏差分母明确、未合格点标NA、原36分母不变；不强求所有delta通过2%。
3. **覆盖裁定要服务成对各向异性。** 若老师维持原工单19P+4T，需要按原集合完成或逐项交未解决结果，现有4条不等价。若允许代表性缩减，建议以现有h75d100成对基准为中心：优先补h50d120 T以配已有P（原沿槽高偏差代表），再视是否要加强间隙响应归因补h100d100 P和T。后者成对取得后，h75→h100可作固定d的独立间隙对照；三几何不是完整二维参数图，仍不能分离所有h/d交互。所有新增均先定协议再由用户授权启动；不把本建议当运行指令。h125T及h25历史资格问题按目标相关性处理，不能为凑PASS无限续算。
4. **收口为有限交付。** 一张参数/代表点职责图、一组全量描述性趋势图、一张独立方法对照表、一张各向异性/角度后果图、一个限定因果含义的机制讨论、逐项回工单的证据表，最后同步双语正文、补充及可复算交付件。文献已完成项不重开；WO4～6先验现有本地成果并完成其交付，不重造。工艺宽深范围另做定点文献核查，用于解释选择，不自动扩算。

停点标准是“约定点集每项都有明确资格/失败/未解决结论，主要主张与其证据对得上”，不要求全点2% PASS或覆盖连续全域。物理实验与动态压印不属于本篇现有目标。本报告未授权缩减老师工单，也未改变原冻结停止规则。
