研究问题：一个没人量过的速算

第一幕·世界 → 第二幕·疑点

 

为什么必须有它：纳米压印要铺满整块模板，算不起逐条解析每个 240 nm 沟槽 → 工程上普遍折算为等效输运系数

这个速算＝局部立方律：沿槽把深槽与浅台当并联通道，跨槽当两段串联阻力；简洁、无需拟合、只依赖几何

疑点：它假设侧壁不存在；而本文几何槽深 100 ≈ 槽宽 120 nm——侧壁贴在流动的脸上

没有人量过：它在纳米沟槽的双向误差，方向多大、传到哪里

本文问题句（§1.3）：考察两主方向有效导度 → 分析偏差 → 评价修正 → 识别局限

5/13

为什么只能高估：理论上界

第四幕·真相·理论根源（附录 E）

 

附录 E（连续 Stokes 模型，变分论证）证明：局部立方律给出的两个主导度均为上界——只能高估，不可能低估

Kyy ≤ ⟨H³⟩/12，Kxx ≤ 1/(12⟨H⁻³⟩)；一般形式适用于任意周期直槽截面

无槽极限取等号：平板基准 0.444% 已验证等号端

数值与理论方向一致（46 条无一越界）——但上界只给方向，不给幅度

口径纪律：称“与理论方向一致的数值对照”，不称“定理被数值证明”

6/13

代价：误差传到工程决策

第五幕·代价

 

两方向偏差不相等 → 各向异性被系统性夸大：数值 2.21 vs 公式 3.70（高估约 67%）

45° 驱动下重建流向相差 9.20°（24.34° vs 15.14°）——布滴方向就错 9 度

这些系数正是降阶挤压模型压力方程的直接输入（式 7）

→ 误差进入填充压力、荷载与闭合时间的预测；两方向倍率不同还会改变压力分布形态

因此：只核对总输运能力不足以评判此类模型，必须同时检验两个主值及其比值

修正 V2：能与不能

第六幕·说明书（1/3）

 

能：最大绝对残差 沿槽 205% → 10.5%、跨槽 54% → 18.7%；36 点中 35 点改善

不能①：薄隙反例——(h,d)=(25,100) 跨槽 +16.36% → −18.71%，绝对偏差反而增大

不能②：残差随间隙漂移——同一 d/w 下沿槽残差 h75→h100 相差 7.93 个百分点

诊断：乘性修正因子只依赖 d/w（完整公式仍含 h）——间隙依赖未抓全，改进方向明确

口径：V2 为回顾性评价（数据在形式选择时已可见），不称独立预测验证

结论：这个公式的使用说明书

第六幕·收束

 

何时可用：作保守上界（只高不低）；V2 修正后常规间隙残差 10–19%

何时不可信：薄隙跨槽（反例）；精确流向预测（偏差 9.2°）；外推到其他版型/新几何

怎么核查：必须同时报告两个主值及其比值，不能只看总输运能力

边界：单图案族（w=120、φ=0.5、矩形直槽）；5 nm 离散参考；静态全充液；非动态压印

对应论文结论四条（§6），每条可追溯到原始运行
