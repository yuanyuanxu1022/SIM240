## 3. 归纳：文献把哪种问题交给哪种证据

1. 方程或程序是否实现正确：解析极限、收敛、守恒、另一算法对照。
2. 简化模型是否足够：同条件显式参考、参数变化及失败范围；标定表现与新条件检验分开。
3. 机制是否成立：机制先提出可检验预测，再改变相关条件或换尺度检查；图片与总量相关性不独自建立因果或耗散份额。
4. 是否能用于真实过程：比较直接相关的过程量与实验，限定材料、几何和工况。

文献不存在可直接搬来的统一误差标准；本次定向核查也不能证明“所有文献都没有1%门槛”。尤其不能把填充率实验差、速度L2误差、导度网格变化和公式偏差排在同一精度榜上。旧11月6日报告中的相关全称外推已在11月7日纠正，本轮沿用纠正，不修改旧报告。

## 5. 论文还差什么：按所选贡献决定

### 5.1 当前有限比较论文应优先收口的事

**第一，贡献差异。** 将最近的理论/数值/压印降阶工作并排，明确各自几何、加载方式、输出量、已知结论与局限。本文“用OpenLB”和“沿槽比横槽快”本身不能构成新增贡献。可重点检查是否已有工作系统量化相同矩形槽族中两主值偏差、各向异性后果和固定修正失效；本轮检索只建立代表性对照，未证明不存在先前工作。

**第二，完成全文主张—证据审读。** 数值参考的局限是否影响“偏差幅度”“趋势”或“修正改善”的具体结论，应分别判断。当前已有一个薄隙点的改善判断随网格改变，不能只靠补一句局限消解。保留指定离散比较有范围，不因此自动具备连续精度。

**第三，明确主贡献与可选升级。** 推荐用“原式适用局限及双方向后果”为主问题，理论上界为解释，V2为既定经验修正的评价，静态接入为有限用途展示。这是本轮研究设计建议，未自动变更作者已定定位、标题或稿件。

### 5.2 只有扩大主张时才成为必需的补证

- 主张“侧壁/台阶耗散导致并主导偏差”：需定义与总驱动功相容的耗散量，核总收支，再做有物理意义的区域/分量检查及受控对照；不能看红色高值区就定量归因。先查已有场及其来源能否支持，未授权本轮处理或补跑。
- 主张“V2在连续范围内达到某精度”：需冻结模型/域/容限，并建立相匹配的参考可靠性和未参与选择的检验；当前h100单几何不足，OpenFOAM输入同一K也不解决此问题。
- 主张“可准确预测真实压印时间、载荷或缺陷”：需相应动态/界面/材料模型及过程量的独立物理对照；不在固定间隙单相主线内自动执行。

独立显式求解器、额外网格或实验各有用途，不是每篇论文一律三者齐备。对于当前有限理想模型比较，本轮没有发现必须先新增仿真才能继续成稿的具体依据；这是有边界的研究建议，不保证审稿通过。
