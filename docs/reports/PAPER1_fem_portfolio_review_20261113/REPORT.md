## 一、裁定摘要

| 裁定 | 点数 | 含义 |
|---|---:|---|
| 接收为正式独立参考 | **0** | 没有任何点满足"正式接收"的条件 |
| **建议有限采用** | **22** | 数值证据支持作为对照使用，但须以"经复核的 FEM 补充数值结果"名义出现 |
| 不接收 | **0** | 没有发现任何数值缺陷足以否定某个点 |

**为什么"接收"是 0 而不是某个数**：正式接收的门槛不在数值，而在**溯源**。冻结 FVM 协议要求运行当时的回执（run_id、独立退出码、场/网格/日志哈希、release_unchanged），且 `postprocess.py` 明确 CSV+End 不足以构成运行溯源、事后不可补。FEM 试点没有这套运行链：它的证据是"脚本 + 锁定环境 + 保存场 + 从保存场独立复算"。这套证据能支持**复核**，不能伪装成**事前冻结的运行**。因此 22 点的数值可以成立，身份仍是候选。

**为什么"不接收"是 0**：全部 22 点的每一项协议门槛都通过，且余量宽；不存在"某个点数值不可信"的情形。所以没有点应当被剔除，只有"身份"问题，没有"数据报废"问题。

## 五、必须随表格一起披露的限度（承接 h125 审查，适用于全部 22 点）

1. **功率差 3.76e-10% 不是精度证书。** 离散 Stokes 取离散速度为试函数，驱动功与梯度能量本就应几乎相等。该值检验的是代数求解一致，不是"离解析解有多近"。三档功率都极小、K 却仍在变化，正说明二者不是一回事。**不得**写"K 误差仅 3.8e-10%"。
2. **0.1167% 是相邻网格变化，不是剩余误差上界。** 不得写"K 精确到 0.12%"或"完全网格无关"，也不得把 mid→fine 变化直接与 LB/FEM 差相减当严格误差下限。
3. **小残差不等于 K 的前向误差界。** FEM 用稀疏直接法，没有 FVM 式的同网格收紧实验，故未建立代数误差对 K 的严格界。不得声明继承 FVM 的代数敏感性资格。
4. **"独立"要准确命名。** 积分与截面读回是另写的实现；方程重组仍用同一变分式与同一库。它是**保存场复核**，不是第三套独立求解器。
5. **压力乘子未保存**，验证器事后恢复（h125 已核恢复量 1.656e-14，未掩盖明显质量源项）。须披露它是恢复量。
6. **P2/P1 的点态散度不严格为零**，逐单元散度只作诊断，不作一票否决。弱连续性由重组方程残差把关。

## 七、本轮最重要的新发现：V2 会在高方向比几何上由"高估"翻成"低估"

以独立参考为基准（不是以 OpenLB 为基准），固定 V2 的偏差在 24 个点里有 **8 个为负**：

| 点 | V2 相对独立参考 | OpenLB 相对独立参考 |
|---|---:|---:|
| h25/d100 T | **−12.78%** | +7.28% |
| h125/d120 P | **−9.94%** | +0.63% |
| h125/d100 P | **−9.31%** | +0.67% |
| h125/d75 P | **−7.84%** | +0.67% |
| h125/d50 P | **−5.46%** | +0.63% |
| h50/d120 T | −3.53% | +3.65% |
| h125/d25 P | −2.43% | +0.53% |
| h100/d100 P | −1.28% | +0.76% |

关键点：这些点上 OpenLB 本身与参考只差 0.5%–0.8%（横槽 h25 除外），说明**翻转不是 OpenLB 的误差造成的，而是 V2 的函数形式在高方向比区间过度修正**。同一现象在成对量上更清楚：h100/d100 的 A=K_P/K_T，V2 低估 7.17%，h125/d120 低估 14.21%，而同两点 OpenLB 的 A 只差 −1.09%、−0.81%。

这一条对论文是**加强**而不是削弱：它说明"原公式有问题"和"V2 已足够好"是两个不同强度的命题。写作时必须把 V2 的适用范围按方向比分段说明，不能笼统写"V2 修正后吻合"。

## 八、结论与下一步

1. **22 点全部建议有限采用**；**0 点接收为正式参考**；**0 点不接收**。
2. 若要提升到"接收"，缺少的不是算例而是**一份版本化的"既有 FEM 保存场回顾性接收"记录**，明确：实际方法、既有门槛、缺失的历史运行绑定、保存场复核作为何种替代证据、适用点与适用输出的范围。该记录须由作者与复核人签署，不得追溯伪装成运行前批准。
3. 该记录**不解除** 2%/0.40° 判据只适用于 h75 的限制，也不改变 36 条主统计与 4 个合格 FVM 的身份。
4. 第 4 步给老师的材料应据此改写：把"能不能当参考"从开放提问改为"已完成内部审查、建议有限采用、请您裁定接收记录的形式"，并把 h125 的 `1.8371e-22` 与"取消双向 PASS 说法"一并落实。
