## 2. 共同终点及窗口

每几何/网格的n沿用原物理窗口Δt*=.75，细格n=16200，中格n=4050。令`Nbase=max(历史P步数,历史T步数)`，预先取`Nlate=Nbase+2n`，两方向均推进至同一预定步；新增共同观察时间Δt*≥1.5，未超过原物理最大时间。

全过程同时计算原判据，但首次达到旧条件时**记录而不退出**；保留历史停止步及首次原合格步的J/K/R。最终两段不重叠窗口分别为`[Nbase+1,Nbase+n]`和`[Nbase+n+1,Nlate]`。每窗有n样本、首末跨度(n−1)dt；两个块末端相差n·dt。不能把两个重叠滑窗伪装为两段独立观察。

旧停止点的计算路径复现须先通过：在历史同一步，K相对旧K差≤1e−6（相对量，即0.0001%），记录新旧首次原合格步是否一致；若步数不同或输入/路径不同，标记`BASELINE_REPRODUCTION_HOLD`，解释后重新审，不直接计算加强停止PASS。这个新复现目标不修改旧回归门槛。

## 3. 拟议判定

下列是未来新合同的候选门槛，当前均未激活：

- 两个末块各自样本std/|mean|≤1e−7、相对极差≤5e−7，横向通量保持原≤1e−12 m²/s；末两块主通量均值相对差≤1e−6。保持n−1样本分母，不更改旧Δt*来省成本。
- 原全程质量绝对相对漂移<1e−10、密度偏离≤1e−6、Mach<.05、几何/壁面审计与非法处理条件、材料不变、有限值、正主通量、末截面差≤1e−5，全部原样检查；额外时间出现质量FAIL也必须保留，不以“只是停止对照”豁免。
- Qlate取共同Nlate时的末态KP、KT，Alate=KP,late/KT,late；Qold取各自原停止点的KP、KT及其比Aold。P/T/A分别检查`100*|Qlate/Qold−1|≤0.05%`，不得只报平均。原停止点不同是原合同事实，新终点共同以避免配对含混。
- 同时报告各方向J/K/R、末块均值、末态与均值差、两块变化、旧/新A。R与K互为倒数，不能直接复制K的有符号误差；原停止对照的0.05%目标针对P/T/A，阻力差另报。

达到这些目标只支持“相对本次加强观察的变化较小”，不是无限时误差上界。任一门槛未满足，或Nlate仍未足够稳态，记`STOP_COMPARISON_NOT_ESTABLISHED`/实际原数值FAIL，完整保留，不自动延长或追加新步数；追加观察须另立修订，不能看过结果后原地改Nlate。
