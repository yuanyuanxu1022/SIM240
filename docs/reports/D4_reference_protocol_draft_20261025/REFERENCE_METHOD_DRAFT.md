## 1. 问题、独立性与适用边界

目标是为固定几何、充分充液、牛顿单相、无滑移周期直槽建立与原OpenLB不同离散方法的参考，分开检查原速度场离散、体积积分和停止误差。沿槽为+y，横槽为+x。保持ρ=1000 kg/m³、ν=1e−6 m²/s、μ=.001 Pa·s、参考体加速度a=1e5 m/s²，φ=w/P=.5、P=Ly=2w。

截面Ω为下方矩形`0<x<P, 0<z<h`与槽内上方矩形`(P−w)/2<x<(P+w)/2, h<z<h+d`的连通并集，公共接口是内部面，不施加壁面条件。竖直槽壁只存在于h≤z≤h+d。直槽几何、物性和驱动沿y不变；拟议参考不处理有限槽长、入口、接缝、两相、滑移或移动边界。

空间离散拟采用贴合精确多边形壁面的连续有限元，与原D3Q19半格反弹、原速度积分代码和边界距离函数独立实现。几何参数/物性和量的定义保持可比。共享输入应独立核单位、尺寸与方向，不能直接调用旧边界函数、通量求和或候选公式生成参考数值。G4公式不参与参考求解、网格选择或精度判定。

## 2. 沿槽与横槽的方程分别定义

沿槽设`u=(0,v(x,z),0)`，y不变，则对流项为0。在这一充分发展、单向流假设下，稳态Navier–Stokes可退化成：

`−ν Δv = a`，固壁v=0，x=0/P周期。

弱形式为`ν∫Ω ∇v·∇η dA = a∫Ω η dA`，η满足同样的齐次固壁和周期约束。使用标量P2连续有限元。退化条件必须与实际流场相符，不能把它称为任意三维流动的精确解。

横槽先定义周期Stokes参考，u=(ux,uz)，π=p′/ρ为运动学压力扰动：

`−ν Δu + ∇π = (a,0)`，`∇·u=0`。

固壁u=0；x=0/P两端速度与压力扰动周期，取`∫Ω π dA=0`消除常数自由度。通过均匀体加速度驱动，**不再额外施加aP的压力跳跃**。可比的物理总压力为`p_total=−ρax+ρπ`；周期扰动最大减最小不能作为宏观驱动压降。周期面牵引由弱式及相反外法向处理，不同时强加互相冲突的速度/牵引条件。

使用向量P2速度/P1压力（Taylor–Hood）。按物理压力符号，拟议对称弱式为：

`ν∫Ω ∇u:∇w − ∫Ω π div(w) − ∫Ω q div(u) = a∫Ω wx`。

压力约束可用零均值消元或经过验证的常数零空间处理，不能随意固定整条壁面的压力。FEniCSx官方例程支持P2/P1和压力零空间处理；其演示采用翻转的压力符号与方腔边界，**本协议的物理符号及周期边界必须独立实现/验证，不能原样复制该演示当沟槽验证**。[官方方法例程](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_stokes.html)，2026-10-25核对。

为避免纳米SI数值缩放问题，内部采用长度h、速度a h²/ν、π尺度a h的无量纲变量。方程变为`−Δv̂=1`或`−Δû+∇π̂=ex`；输出恢复SI。双精度、压力符号、周期自由度消元和求解器真实残差都须写入manifest。后端候选为FEniCSx/PETSc或经审查的独立有限元组装；本轮未选定/安装版本，系统Python依赖尚不齐全，不能声称已可运行。

## 3. 与旧K、F和阻力的对应

两方向均输出`J=(1/P)∫Ω u_main dA`（m²/s），`K=νJ/a`（m³），`R=ρa/J`。三维原积分中的Ly在均匀直槽下消去，并不是省略一个长度单位。`Href=h+(w/P)d`，`J=Href*<u_main>Ω`，κ=K/Href才是m²普通渗透率。

若`Ĵ=(1/P̂)∫Ω̂ û_main dÂ`，则`K=h³Ĵ`，平板K=h³/12、Ĵ=1/12。F仍相对原同几何理论基准定义，阻力修正为1/F；不改变原理论或用新参照替换G4 v1的5 nm主评分。A=KP/KT，必须同几何、同参考网格/版本配对，不用独立外推的A替换配对方向之比。

输出两种积分：有限元体积分（参考主量）；在原LBM中心节点采样有限元速度后，用独立实现复现原权重的积分（诊断量）。两者分别与旧K比较，分清速度场与积分差异。主参考采用对P2函数足够精确的单元积分；额外提高积分阶次时Q变化须满足下述预算。非多项式制造解和后续非线性方程需要提高积分阶次，不把“P2”当作所有积分都已精确。

制造解在无量纲矩形`0≤x≤2, 0≤z≤1`，ε=.1：

- 标量Poisson：`v=z(1−z)[1+ε cos(πx)]`，右端按`−Δv`独立求导；J_exact=1/6。
- 混合Stokes：`ψ=z²/2−z³/3+ε sin(πx)z²(1−z)²`，`u=(∂zψ,−∂xψ)`；`π=ε cos(πx)cos(πz)`，右端`f=−Δu+∇π`。散度为0、固壁速度为0、x周期，压力零均值；J_exact=1/6。

制造解右端不是均匀驱动，故只验场误差与J泛函，不将其J/a叫物理K。实现中源项与误差计算须独立于组装函数核对。平板P2可能精确表示抛物线；此时不以机器零差值强算收敛阶。

## 5. 网格、角点与条件参考估计
