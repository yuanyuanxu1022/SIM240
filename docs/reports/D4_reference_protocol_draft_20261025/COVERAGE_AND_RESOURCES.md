## 2. 网格规模的可复算估计

仅作贴体均匀三角形基础网格的组合计数，未生成网格或组装矩阵。设nx=P/δ、nh=h/δ、nd=d/δ、nw=w/δ：小矩形数C=nx·nh+nw·nd；三角形T=2C；顶点V=(nx+1)(nh+1)+(nw+1)nd；平面连通多边形边数E=V+T−1。P2标量原始自由度V+E，P2/P1 Stokes原始自由度2(V+E)+V。均为施加周期/Dirichlet约束前、不含可选压力均值乘子的数量，不等于实际矩阵大小或内存。

候选稀疏存储情景：每行100个非零元、每元16字节、矩阵/预条件等4份、另加1 GiB，最大约4.07 GiB。此假设可能低估因子分解填充、约束或预条件器，**不是保证上界**。拟议单进程RAM预算8 GiB、累计磁盘20 GiB作为待审起点；实现后必须用小问题实测峰值并修订资源计划，不能因组合计数通过就放行大问题。
