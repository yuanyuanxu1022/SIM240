## 2 逐条改动

### 2.1 重复段（中文 §4.4 原 L430 尾部 / 英文 §4.4 原 L422 尾部）

中文原段尾：

> V2仅在离散标定集合 $h\in\{50,75,125\}$ nm × $d\in\{25,50,100\}$ nm（9种几何，$w=120$ nm，5 nm网格，二进制身份285f67a0…）上按各方向最大绝对相对残差的极小化目标标定；这一集合不构成连续精度域，也不支持跨 $h$ 的定量外推。$h=100$ nm、$d=100$ nm在该九点集合之外，但在 $h=75$ 与125 nm之间作参数位置上的内插，$d=100$ nm为已标定槽深及标定矩形范围的上边界；该位置关系不保证内插精度。

与 §2.1（L93）逐字相同（英文同理，与 L89 相同）。**处理：整段删除**。保留 §2.1 一处，因为标定集合属于方法交代，位置在方法节更合适；§4.4 讨论的是残差与构建差异，引回 §2.1 即可。

### 2.2 同段自相矛盾

中文原段两处：

> …除 $h=75$ nm、$d=100$ nm 的单几何同条件复算（§3.4，两构建结果一致）外，**尚无**跨这两组程序的进一步同条件对照…
>
> …**已有一组**同条件跨构建对照（$h=75$ nm、$d=100$ nm，两方向K差异均为0.0%，见§3.4与补充S10），但仅覆盖一个几何…

前句把该对照说成不存在，后句说存在且给了数值。**处理：合并为一句**，不再出现"尚无"：

> 跨这两组程序的同条件对照现仅有一处：$h=75$ nm、$d=100$ nm 的单几何复算（§3.4 与补充 S10，两方向 $K$ 差异均为0.0%），该处两构建的主要输运结果一致，但截面流量及横槽截面相对差存在浮点末位差，不表述为所有输出逐字节相同；由于仅覆盖一个几何，现有记录仍不能完全分离潜在构建差异与几何、模型及数值参考因素对残差的贡献。

保留了原句的三项限定（末位差不等于逐字节相同、仅一个几何、不能完全分离），只把"有无"统一成"有一处"。英文同段同处理，措辞为 `at exactly one geometry`，并保留 `floating-point last-digit differences` 与 `covers only one geometry`。

### 2.3 过时表述（中文 §2.4 术语界定，L252）

原文：

> …同一平均流动模型的 OpenFOAM 独立实现已与本项目二维实现互核（见 §5.3），但**显式沟槽几何的独立求解器对照尚未完成**。

§3.4 已改为"本文的显式沟槽几何对照仍限于数值方法"并指向 §4.5；§2.4 仍写"尚未完成"，与新增 §4.5 直接冲突。**处理**：

> …同一平均流动模型的 OpenFOAM 独立实现已与本项目二维实现互核（见 §5.3），§4.5 另以一套二维有限元离散对显式沟槽几何作独立对照，两者同样只支持数值交叉核验。

保留了本节原有的限定——独立求解器对照不能建立物理验证，因此补"两者同样只支持数值交叉核验"，不因新增 §4.5 而抬高验证层级。

英文 §2.4（L304）此前已同步（`Independent comparisons for resolved groove geometries remain numerical only.` 并指向 §4.5），本轮未再动。

## 4 数值不变性的核对

不靠"我记得没改数字"，用程序比对：

1. 取 `git show HEAD:` 的改前全文与改后全文，各自提取全部数字记号（`\d+(\.\d+)?`），比较计数器差集。
2. 结果：中文删 `0,100,120,125,2,25,285,3.4,5,50,67,75,9`，增 `4.5`；英文删同一组数，无增。
3. 其中 `4.5` 是 §2.4 新增的节号回引；其余全部是被删重复段里的标定集合与二进制前缀。逐项核对这些数在文中仍有出现（§2.1 各一份），即**没有任何唯一数字因删除而消失**。
4. **百分比记号 `\d+\.\d{2}%` 单独比对：两稿均 0 删 0 增。**

因此正文报告的任何百分比结果、任何表值均未变。
