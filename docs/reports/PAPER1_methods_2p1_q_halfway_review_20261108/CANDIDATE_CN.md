# §2.1壁面分数距离与半程反弹候选（未合入）

建议仅替换当前正文以“壁面分数距离由几何解析给出……”开头的一段，不改变数字和相邻段落。

壁面分数距离 $q$ 定义为流体节点到壁面交点的距离与该条流体—固体格点连线长度之比。当前稿所列边界审计集合包含46条运行记录（36个主结果＋8个加密结果＋2个黏度对照；不含新增 $h=100$ nm），其记录显示 $q_{\min}=q_{\max}=0.5$（容差 $10^{-10}$）。这表示在上述容差内，所审计有效连线的壁面交点位于连线中点；在 $q=0.5$ 时，本文静止壁面所用的Bouzidi线性插值表达式恢复半程反弹形式 [7,8]。上述46条边界审计记录与公式比较的19种几何、46条记录不是同一集合。该几何一致性说明不能单独证明边界处理无误差，也不能代替边界连线覆盖、回退及几何掩膜的各项检查。第3章平壁基准的收敛行为反映整个离散计算与通量提取过程的综合误差；本文不据此分解各项误差来源，也不将该结果推广到任意分数距离壁面。
