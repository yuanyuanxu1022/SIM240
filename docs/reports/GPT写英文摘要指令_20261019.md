# 文档一：让 GPT 写【英文摘要】的指令

2026-10-19 · 投稿用 · 配套 `SIM240_EJMB_英文整合工作稿_20261019.md`

> **用法**：每块代码框**单独复制一次**发给 GPT，它回一段，你看一眼，再发下一块。
> **不要一次把七块全贴过去**——那样它会揉成一段，又回到你现在摘要的老毛病。
> 目标：英文 150–200 词（目标 170），单段，7 步约 40 分钟。
>
> 中文版请看另一份：`GPT写中文摘要指令_20261019.md`。**两份独立跑，不要让它同时写两版**——
> 同时写，它必然先写英文再把英文翻成中文，中文就变成翻译腔。

---

## 开始前：三件事

1. **新建一个对话**，不要用之前做审查的那个会话（那个是"挑刺"人设，让它写东西会推脱）。
2. **先让它只读、不许写**（第 0 步就是干这个）。
3. **每步只要它输出一小段**。摘要最后是一段，但**思考必须拆成七步**。

---

## 第 0 步：读材料 + 把数字钉成表（不写摘要）

```
这是一个写作任务，不是审查任务。你要为下面这篇论文重写英文摘要。
现在先不要动笔，只做两件事。

【读这些文件】
1. docs/reports/SIM240_EJMB_英文整合工作稿_20261019.md
   —— 重点读 Abstract（第 17 行）、I. INTRODUCTION 末尾三条结论（第 69–95 行）、
      IV. E 小结（第 467–475 行）、V. C 末尾（第 542–545 行）、VI. CONCLUSIONS（第 547–549 行）
2. docs/reports/SIM240_投稿目标决定与写作入口_20261019.md
   —— 了解目标期刊与"当前仍不能称投稿完成"的清单

【第一件：用中文复述】
用 5 句话告诉我：这篇论文要证明什么、靠什么证据、边界在哪。
不要用"本文研究了……"这种没有信息的句式，要写出"和什么比、差多少、所以什么"。

【第二件：把数字列成表】
把下面这些量在原文中的确切数值抄出来（中文说明 + 原值 + 所在行号）：
- 闭合式沿槽高估范围
- 闭合式跨槽高估范围
- 参考几何 (h=75, d=100) 下，闭合式与精确解的各向异性比
- 45° 驱动下的流向角（精确解 / 闭合式 / 差值）
- V2 修正在 18 个沿槽样点上的最大绝对残差
- V2 修正在跨槽样点（h≥50 nm）上的最大绝对残差及样点数
- h=25、d=100 跨槽点，5 nm 与 2.5 nm 两个网格上的残差
- 几何数、主方向工况数、正式运行总数

要求：只抄原文，不要自己算、不要四舍五入、不要补单位。找不到的写"原文未给"。
```

**为什么先做这步**：你的摘要之所以数字堆成山，是因为写的时候边写边找数。先把数字钉在表上，后面每一步都从表里挑，就不会再冒出第十一个。

---

## 第 1 步：只写一句主张（最重要的一步）

```
现在只写一句话，不要写摘要。

这句话是全文的主张，必须满足三个条件：
1. 它必须是可被反驳的 —— 如果有人不同意，他能指出"哪张图能推翻它"；
2. 它必须包含"和什么比、差多少、所以什么"三件事；
3. 它不能出现具体百分数（那是证据，不是主张）。

参考句式（不要照抄，用你自己的话）：
"某类模型在某条件下系统性地偏大，而且两个方向的偏大程度不同，
 因此标量式的修正在原理上就不成立。"

限制：
- 不超过 30 个英文词；
- 不要写 "we investigate" "this paper studies" 这种空头动词；
- 不要写 "novel" "first" "unprecedented"。

只输出这一句英文。同时用中文说明：这句话如果要被推翻，需要哪张图。
```

**这一步值得来回三轮。** 其他六步都是技术活，只有这一步是判断。主张含糊，摘要立刻退回"我们做了 A、B、C"的清单模式。

---

## 第 2 步：只写"缺口"（1–2 句）

```
现在只写摘要里的"缺口"部分，1–2 句英文，不要写别的。

要回答：别人已经做到哪一步了，还差什么？

必须体现这三层（每层一句，可合并）：
1. 把沟槽图案等效成各向异性渗透率张量，是唯一可行的降阶路线，已被压印建模广泛采用；
2. 这条路线依赖的算术–调和平均（局部立方律）闭合式，在"尖锐直角沟槽 + 有限间隙"这个组合上
   没有被逐方向定量检验过 —— 已有对比要么针对光滑剖面，要么只给力/总流量而不给两个主系数；
3. 所以缺的不是"闭合式会不会错"，而是"两个主方向各自错多少、这个差异会不会改变流向"。

硬性禁止：
- 不许写"文献中尚无研究"（检索不完整，这是不实陈述）；
- 不许贬低前人（不要 "however, they failed to..."）；
- 不许出现任何数字；
- 不许出现 "to the best of our knowledge"（本文没做系统检索）。

只输出这 1–2 句英文。
```

---

## 第 3 步：只写"做了什么"（2–3 句）

```
现在只写摘要里的"做了什么"部分，2–3 句英文。

必须包含（读者判断可信度的最低信息量）：
- 方法：格子 Boltzmann 方法（OpenLB），在显式解析的周期矩形沟槽几何中直接求解；
- 状态：稳态、完全充满、单相牛顿流体、无自由面（一句话说清，不展开）；
- 参数：周期 240 nm、槽宽 120 nm、间隙 25–125 nm、槽深 25–120 nm；
- 规模：18 个几何、36 个主方向工况（18 是几何数，36 是工况数，不许混）；
- 对照对象：算术–调和局部立方律闭合式，逐点比较两个主方向的深度积分输运系数。

硬性禁止：
- 不许写网格尺寸、时间步、松弛时间、雷诺数、马赫数；
- 不许写"高精度""可靠""严格验证"；
- 不许写代码版本号或提交哈希。

只输出这 2–3 句英文。
```

---

## 第 4 步：只写"结果"（3 句，只准 4 个数字）

```
现在只写摘要里的"结果"部分，最多 3 句英文。

规则：只准用下面四个数字，一个都不许多、一个都不许改（直接从第 0 步的表里抄）：
1. 沿槽高估范围（百分比区间）
2. 跨槽高估范围（百分比区间）
3. 45° 驱动下流向角偏差（度）
4. V2 修正在沿槽 / 跨槽（h≥50 nm）两组样点上的最大绝对残差

三句分别承担：
- 第 1 句：两个方向都高估，但幅度不同（给出数字 1 和 2）；
- 第 2 句：因为不同，所以各向异性比和斜向流向都被带偏（给出数字 3）；
- 第 3 句：按方向分别做经验修正后残差降到什么水平（给出数字 4）。

硬性禁止：
- 不许再引入各向异性比 3.70 / 2.21（留给正文）；
- 不许引入 h=25 nm 的双网格残差（留给讨论与结论）；
- 不许说"误差来源于尖角/侧壁/台阶"（机制只是候选解释，摘要一个字都不提）；
- 不许说"修正后可推广""可用于任意几何"；
- 每个数字后面必须跟一句"所以呢"——没有含义的数字不要放进来。

只输出这 3 句英文。
```

**为什么只给 4 个数字**：摘要的功能是让读者决定要不要读正文，不是复述结论。你现在有 10 个数字，读者读完一个都记不住。

---

## 第 5 步：只写"边界"（2 句）

```
现在只写摘要末尾的"边界"部分，最多 2 句英文。

必须讲清三件事（可压进两句）：
1. 误差是相对于离散数值参考解而言的，全参数域的不确定度界没有建立；
2. 修正式是"数据知情、回顾性评价"，不是独立预测检验；
3. 结论限于单相、固定几何、完全充满，不涉及动态充填、自由面、润湿或真实光刻胶流变。

硬性禁止：
- 不许写成免责声明清单（最多两句，超过就是自我否定）；
- 不许用 "however" "nevertheless" "it should be noted that"（会让读者以为你在撤回结论）；
- 不许出现 "limitation" 这个词（改用 "restricted to" "does not establish"）；
- 不许重复第 4 步已经说过的数字。

只输出这 2 句英文。
```

---

## 第 6 步：拼装（第一次让它写"摘要"）

```
现在把前五步的结果拼成一段完整英文摘要。

拼装规则：
- 顺序固定：缺口 → 做了什么 → 结果 → 边界。不改顺序，不加过渡句。
- 单段，150–200 词（目标 170）。
- 不加 "Abstract" 标题，不加"以下是摘要"之类前言。
- 前五步的句子可润色衔接，但不许新增任何事实、数字或限定。
```

---

## 第 7 步：自检（最重要的一步）

```
现在对上面这段摘要做自检。逐条回答"是/否"，不许跳过，不许合并。

1. 一共出现了几个数字？（应为 4 个；超过就删）
2. 每个数字都能在第 0 步的表里找到原值吗？
3. 有没有 "novel / first / unprecedented / for the first time"？
4. 有没有 "prove / validate / demonstrate that ... mechanism" 这类声称机制或证明的动词？
5. 有没有把 18 个几何和 36 个工况混用？
6. 有没有说修正可以外推、可以预测未见几何？
7. 有没有提到本文没做的工作（实验、两相、移动边界）？
8. 是否在 150–200 词之间？
9. 有没有超过 45 词的句子？（有就拆）
10. 第一句读完，读者知道"这篇在跟什么较劲"吗？
11. "boundary" 部分是否只占 2 句？超过就删到 2 句。
12. 时态：方法和结果是否用过去时，普遍性结论是否用现在时？

【输出】
第一段：最终英文摘要。
第二段：「自检」下面 12 条的一行答案。
第三段：「数字出处」逐个数字给行号。

不要修改任何文件。
```
