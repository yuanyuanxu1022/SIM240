# h25/d100 横槽“16.36%→18.71%”的原因与证据边界

AI辅助只读解释，采用scientific-critical-thinking技能区分观察、算术原因与未证机制。原始结果与公布V2舍入系数直接复算，无重新拟合、求解、科学验收器重放或服务器状态轮询。

## 已核实的直接原因

百分数是导度K相对指定离散参考的偏差。原有符号偏差+16.3628883902%；V2有符号残差−18.7051471673%。表中16.36/18.71为绝对值，不能读成同方向高估继续增加。

h25、d100、w120nm，局部横槽公式K0=(h+d)^3*h^3/[6((h+d)^3+h^3)]×10^-27=2.58349867725e-24m³。5nm保存Kref=2.22020844703e-24m³。公布V2因子F=1/[1+0.4900(d/w)^0.6990]=0.698632132267，得到K_V2=1.80491518959e-24m³。

将5nm参考归一为100，则原模型116.36288839，V2为81.29485283。原模型乘0.8593805240即可恰好到这个离散参考；V2统一乘0.6986321323，降低30.1368%，相比该点匹配所需降低14.0619%更强，越过参考而低估。这是明确的算术“修正过头”，不是已证的唯一物理机制。

18.71−16.36=2.35是显示值先舍入后相减；未舍入数据的绝对偏差增加2.3422587771个百分点，保留两位为2.34个百分点。不能写误差增加2.35%而混淆百分点与相对百分比。不修改旧稿/幻灯片，本报告只说明口径。

## 为何统一因子不适合这个点

V2的乘性因子只有d/w，没有显式h；K0本身包含h，不能说整个模型没有间隙。固定d100/w120，h25/50/75/125nm都会乘同一个0.69863，但旧5nm数据逐点匹配所需因子不同（算术见arithmetic.json）。原拟合脚本的标定间隙为50/75/125nm，h25不在该9几何拟合目标内，故不能期待同一整体拟合每个外部边界点改善。

这提示修正变量/范围受限；原稿明确扩展数据在模型形式选择时可见、标定与扩展组构建身份与几何分组重合，所以不把h25称真正未见的独立检验，也不能只凭此点归罪“缺h”或唯一归因台阶涡、侧壁耗散。既有5nm原始结果的PASS/converged只是其原记录，不建立连续解精度。

## 参考网格会改变“改善/变差”判断

|参考网格|保存Kref(m³)|原公式有符号偏差|V2有符号残差|绝对偏差变化|
|---|---:|---:|---:|---:|
|5nm|2.2202084470320096e-24|+16.36%|−18.71%|增加约2.34个百分点（原始数复算）|
|2.5nm|2.121836963645658e-24|+21.76%|−14.94%|降低约6.82个百分点|

两个保存参考K差−4.4307318765%（以5nm为分母）。h25在5nm仅跨5格、2.5nm跨10格；这说明需认真界定参考分辨率，不能单凭格数宣判误差大小。已有两网格结果不等于网格独立，亦不能宣布2.5nm为真值。旧2.5nm结果case短标签dx2，以目录、文件实际dx=2.5nm及既有Table S2共同识别，不能误认为实际2nm。

因此，严格结论是“相对5nm离散参考，该点V2绝对残差变大；但这一局部改善判断对参考网格敏感”。不能写成V2在真实连续流动中已被该点确定证伪，也不能用2.5nm改善把5nm反例删除。当前服务器h30/d80的验证属于另一几何，不直接补齐h25/d100的参考资格。
