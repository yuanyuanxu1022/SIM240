1 研究什么 · 比较什么

三个对象、一个误差定义：原公式、显式计算与经验修正

式 (3)(4) 见中文稿 §2.3；V2 系数为公布舍入值，见 §4.4。

6 / 13

 

① 待检验：原局部立方律

K∥ = 1/24 · [ (h+d)³ + h³ ]

K⊥ = 1/6 · (h+d)³h³ / [ (h+d)³ + h³ ]

把深区、浅区各当作独立平行平板，再取算术/调和平均；未显式含侧壁与台阶附近的重分布。

 

② 离散比较基准：OpenLB 显式沟槽（5 nm）

按沟槽几何直接求通量，取 K = νJ/a。

不输入原公式或 V2 的系数。

目前得到相对该离散结果的偏差；参考自身仍需网格与来源检查。

 

③ V2：在原公式上乘经验因子

F∥ = 1 / [1 + 1.7685(d/w)1.6331]

F⊥ = 1 / [1 + 0.4900(d/w)0.6990]

仅修正因子未显式含 h，总导度仍含 h。

残差来源尚未分离，不能只归因于缺少 h。

 

误差定义

E = ( K模型 / K参考 − 1 ) × 100%

正值＝高估导度，也就是低估阻力；负值反之。

K参考 是同几何、同方向、同网格的离散数值解。

换参考网格，E 本身就会变，所以每个偏差都要注明参考。

 

 

全文报告的偏差都是「相对该数值参考」的偏差；这一口径决定了后面每一个数字能说到什么程度。

L 的定义

L = ( max − min ) / mean，取三档末态 K。

它是观测跨度，不是标准差、不是置信区间、也不是绝对准确度。

末窗时间稳态 std 约 1 ppm，比 L 大得多。

所以不能说「导度准到小数点后七八位」。

 

这组检查支持什么

在 h60/d80、2.5 nm 网格与三档驱动力内，未检出超过 0.1% 的驱动力依赖。
