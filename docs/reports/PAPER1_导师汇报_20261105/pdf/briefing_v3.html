槽深涨 4.8 倍，沿槽导度涨 1.4—3.6 倍；横槽几乎不动（< 4%）。
各向异性因此主要由槽深撑起来：
约 1.1（h125/d25）→ 15（h25/d100）。
两个方向对同一几何变化的敏感度相差一个量级 —— 这是「方向性」的直接来源。
看到什么图 2a / 2b 的趋势物理解读
Kyy（实线）随 d 单调上扬槽越深，沿槽越通畅
Kxx（虚线）四条几乎水平槽深不改善横槽通路
A = Kyy/Kxx随 d 快速拉开方向性被槽深放大
限定：已采样 18 格范围内的观察，不外推到未采样几何与动态压印过程。
为什么倍率差这么多：Kyy 走的是「深区 + 浅区并联」，深区一加深，通路立刻变宽；Kxx 走的是「深区 + 浅区串联」，最窄的浅区卡住它，所以加深槽几乎没收益。

2 已有发现 · 各向异性
偏差改变各向异性与预测流向
项（基准几何 h=75 / d=100 nm）显式数值局部立方律差异含义
各向异性 A = Kyy / Kxx2.213.70+67%模型夸大方向性
45° 驱动流向角 β24.34°15.14°−9.20°流向明显偏斜
由主值推流向（线性张量）
tan β = ( Kxx / Kyy ) · tan θ
θ、β 均自槽轴量起。θ = 45° 时，两组主值重建的流向相差 9.20°。
即：总量可能接近，方向已经偏。
为什么只比总量会漏问题
压印填充关心「液体往哪流」，不只是「流了多少」。
总量对上、方向偏 9°，在窄槽里表现为各槽进液不均，进而影响残胶厚度分布。
（此因果链为推断，本文未验证残胶均匀性。）
已有检查 / 理论它能证明什么它不能证明什么
30° / 45° / 60° 斜向驱动检查同一主值的内部自洽不验证主值本身准确
附录 E（T1）理想 Stokes 下给出非严格上界不给偏差幅度、不给方向比符号
9.20° 来自同一张量的重建，不是实验测得的流向误差，不能推广为真实器件精度。
一句话：C3 的价值不在于多一个误差百分比，而在于说明「单一的导度标量不足以描述这个结构」——必须同时给两个主值。
