```bash

```

依赖：`weasyprint`（已装在 `/home/dell/.workbuddy/binaries/python/envs/default`）、`Noto Sans CJK SC` 字体。
预览：`pdftoppm -png -r 96 <pdf> p` 逐页导出 PNG 目检。

实现要点：

- 用绝对定位的 `div` 拼版（1280×720 固定画布），`@page` 尺寸与之严格一致，避免分页漂移。
- 表格统一 `table-layout:fixed`，否则长中文会把列撑宽、越出右边距。
- 符号 `K∥ / K⊥` 在中文字体里缺字形，会渲染成 `〃`；改用 `K<sub>yy</sub>` / `K<sub>xx</sub>`，与论文正文一致。
- 页码由 `page()` 自动编号（`n = len(P)+1`），增删页不必手改；`TOTAL` 常量控制分母。
- 18 行表格用 `rh=24`：行高再大就会被底部说明压住，这是本页版式的上限。
- **第 13 页 OpenFOAM 三条结论**（均按出口流量 Q 现算，与澄清报告一致）：
  ① V2 替换原公式：横槽 −30.14%、沿槽 −56.77%；
  ② 方向比：V2 2.287 对原公式 3.696（原公式高估约 62%）；
  ③ GDI01 / C01 = 1.000，真实动量源接入链自洽。
  边界：用输入的等效阻力、未逐槽解析，只能证明接入一致性，不是公式准确性或挤压/载荷验证。
  该页 2.287 与第 12 页 2.515（显式沟槽）条件不同，相差约 10%，不可当同条件误差比较。
