## 3. 对“系统性高估”的独立理论核对

来源线索为[既有推导§5](../Correction_formula_derivation_20261023/DERIVATION.md)和[2026-10-25来源审查§2.3](../G4_derivation_source_audit_20261025/REPORT.md)。以下重新写出关键步骤；结论来自所列方程与不等式，不能仅以旧审查报告作为证明。

假设：固定二维截面Ω={(x,z):0<x<P,0<z<H(x)}，H为矩形台阶的h或h+d，h>0；沿槽平移不变；固壁静止无滑移；周期面配对；不可压缩Stokes方程、常黏度、单一均匀正驱动G。令V=μu/G，压力扰动周期，

\[
-\Delta\mathbf V+\nabla\Pi=\mathbf e_i,\quad\nabla\cdot\mathbf V=0,
\quad K_i=P^{-1}\int_\Omega V_i\,dA.
\]

弱式取测试函数V，固壁项为零、周期面抵消、压力功为零，故

\[
D:=\int_\Omega|\nabla\mathbf V|^2dA=\int_\Omega V_i dA=P K_i.
\]

沿槽可直接用标量V_y。对几乎每个x，令q_i(x)=∫₀ᴴ V_i dz。零壁迹及ψ=z(H−z)/2给q_i=∫ψ′∂zV_i dz，而∫(ψ′)²dz=H³/12。由Cauchy–Schwarz，

\[
\int_0^{H(x)}|\partial_zV_i|^2dz\ge\frac{12q_i(x)^2}{H(x)^3}.
\]

矩形台阶的竖壁位于有限个x位置，不影响此几乎处处截面不等式；它们的无滑移条件仍包含在完整场及能量中，未被当作内部开口。

沿槽q_y可随x变化，第二次加权Cauchy–Schwarz得

\[
P K_\parallel=D\ge\frac{12(\int_0^P q_y dx)^2}{\int_0^P H^3 dx}
=\frac{12(PK_\parallel)^2}{\int_0^P H^3 dx},
\quad K_\parallel\le\frac{\langle H^3\rangle}{12}.
\]

横槽由连续性和固壁无穿透，q_x为常数且q_x=K_⊥。因此

\[
P K_\perp=D\ge12K_\perp^2\int_0^P H^{-3}dx,
\quad K_\perp\le\frac{1}{12\langle H^{-3}\rangle}.
\]

两式正是局部立方律的两个上界，等宽时化为正文式3。平壁d=0可取等号，本审查保留非严格不等式，不额外声称所有非平壁情形的严格性分类。

**理论裁定：在上述假设下，“局部立方律不低估两个连续Stokes主导度”可作为有推导的结论保留。** 这一结论不需要由36个点归纳；也不证明偏差为10%或200%、A必被高估、通量角差9.20°，更不证明任何LBM值的误差界。没有把LBM保存场假设成严格无散度场去套证明。未推广至滑移、自由表面、非牛顿、任意三维纹理或真实材料。

论文贡献应落在量化方向偏差、各向异性后果与经验修正的局限。不能仅凭这条推导宣称该定理为文献中首次；本轮没有完成理论新颖性检索。当前稿“36点不构成普遍定理”可保留其统计含义，但若纳入此证明，应明确“有限采样本身不能证明；所述理想模型中的上界另有理论依据”，避免同文自相矛盾。

### 5.1 如何避免误差预算含混

令K*为同一连续模型的目标值，K₅为5 nm参考，ε=(K*−K₅)/K₅。所有下式仅是误差传播恒等式，**ε当前未知**：

\[
E_*=(E_5-\varepsilon)/(1+\varepsilon),\qquad
r_*=(r_5-\varepsilon)/(1+\varepsilon).
\]

若以后有经支持的|ε|≤b<1，才可得到|E*−E₅|≤(1+E₅)b/(1−b)。不能直接把“参考差1%”当成“模型偏差只差1个百分点”；大偏差点会放大分母变化。也不能把某两级差当作这里的b。

对同几何A=KP/KT，A*/A₅=(1+εP)/(1+εT)；对不同槽深的倍率q=Kb/Ka，也必须按q*/q₅=(1+εb)/(1+εa)配对传播。无相关性证据时不能假定误差完全抵消。若仅作假设两端均|ε|≤b，则q*>1的一个充分条件为b<(q₅−1)/(q₅+1)。h125/T对应b<0.468062%；这是“只靠数值误差包络确认正增幅”的条件算术示例，**不是新增门槛、不是已达精度，也不是理论单调性证明所需的数值条件**。
