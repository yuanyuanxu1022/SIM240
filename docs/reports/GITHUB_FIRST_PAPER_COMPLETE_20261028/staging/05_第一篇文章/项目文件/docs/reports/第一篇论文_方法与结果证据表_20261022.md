## 一、方法（稿件怎么做的）

### 1.1 物理模型

| 项 | 设定 |
|---|---|
| 求解器 | OpenLB（D3Q19，ForcedBGK，Bouzidi 精确半格壁面） |
| 介质 | **单相、全充液、无自由液面**；无气相、无界面 |
| 几何 | P=240 nm、w=120 nm、d=25–120 nm、h=25–125 nm；x 跨槽、y 沿槽 |
| 边界 | x、y 周期；z 上下为解析平壁 |
| 驱动 | 均匀体积力（`acceleration_m_s²=1e5`） |
| 主流 | 按 x（跨槽，T）或 y（沿槽，P）单向驱动 |
| 物性 | ρ=1000 kg/m³、μ=1 mPa·s（主地图）、ν=1e-6 m²/s |
| 指标 | 深度积分输运系数 $K$，单位 **m³**（= 三维渗透率 × $H_{\rm ref}$） |

### 1.2 三条主链条

```
① 解析算例解析 → 数值 K（LBM）
      ↓
② 条纹平均闭合（式 1）与 DNS 比对 → 误差 E（%）
      ↓
③ 经验修正 V2（式 2b）→ 残差
```

闭合式（条纹平均，单位宽度）：

$$K_\parallel^{stripe}=\frac{1}{12}\cdot\frac{h^3+(h+d)^3}{2},\qquad
K_\perp^{stripe}=\frac{1}{12}\cdot\frac{2}{h^{-3}+(h+d)^{-3}}$$

误差定义：

$$E=\frac{K_{\rm stripe}-K_{\rm DNS}}{K_{\rm DNS}}\times100\%$$

等效体积效率（TABLE VIII 用）：

$$\eta_\alpha=\frac{K_\alpha^{[\rm m^3]}}{H_{\rm ref}^3/12},\qquad H_{\rm ref}=h+\varphi d,\quad \varphi=w/P=0.5$$

### 1.3 验证四层

| 层 | 内容 | 判据 |
|---|---|---|
| I | 平滑通道解析极限 $K_0=h^3/12$ | 复现误差、收敛阶 |
| II | 三网格收敛 + GCI | Richardson、渐近比 |
| III | 内部一致性（张量、黏度） | 方向/黏度无关性 |
| IV | 既有输出审计（48 次历史） | 有限性、质量、Mach、link |
