- 四个指定几何主要是双网格敏感性证据，不能给整个参数图提供连续解误差界。当前正文已经作相应限定。

- 停止窗口统计量不等于剩余稳态K误差界；全图空间误差、稳态误差和连续解精确幅值仍未证明。沿用[既有终审第4–5节](../Paper_core_reference_final_review_20261027/REVIEW.md)，本轮不重算末窗/原场或重判理论。
- 52份原始manifest本轮逐份读回，52/52二进制哈希与表S1对应，组数22/22/6/2；全部仍缺source_sha256、generated_source_sha256、openlb_commit、compiler、compile_flags这五个字段。该字段观察不证明其他位置不存在可补档案。原始读回见 [current_evidence_checks.json](current_evidence_checks.json)。

**对当前限定稿的影响：** 可保留相对于5 nm离散参考的统计比较及V2回顾性残差，必须继续报告网格敏感性、失败和来源范围。本轮没有据此要求自动重跑36点，也不据此宣布投稿就绪或审稿必然接受。
