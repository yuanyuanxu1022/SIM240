## 2 对旧报告的裁决

[指定模型意见及12项逐条定位](ASTRA_REVIEW.md)是本轮整合依据，主代理原始清单核对与之相符。核心处理如下：

- 撤回“28项来源完整”和按mtime补写source_sha的推断；[接收合同](../Primary_text_build_evidence_20261027/MINIMUM_EVIDENCE_CONTRACT.md)明确仅同名源码、修改时间或当前提交不足。四组完整历史构建来源均保持OPEN。
- 当前.d路径、OpenLB HEAD/版本、config.mk是候选线索，不能断言历史依赖内容或生效编译命令。当前D2源码mtime23:29:16、程序23:29:56，D3程序23:29:41，仅同分钟附近，并非完全同一时刻；即使完全相同也不补足绑定。原始时间记录见[文件元数据](evidence/current_file_metadata.json)。
- “所查范围未找回”不能写成“永远不可恢复”；输出字段相同不能定位代码改动，更不能证明程序SHA改变意味着物理结果改变。
- P/T同程序只避免将不同程序直接拼为一个比值，不保证方向误差相同或抵消；单几何对照（若未来另行授权）也不能证明全图数值等价或自动决定全图重算。
- d75是标定槽深范围内留出，d120/h25分别为范围外扩展；不能把全部扩展统称外推或断言误差理应更大。当前正式稿已经说明回顾性和非独立预测，不重复指责其没有限定。

旧[恢复性报告](../Historical_build_binding_recovery_20261028/REPORT.md)及JSON保留原字节作为比较对象。本报告覆盖其中上述越界结论，不追改旧manifest、审计原记录或历史FAIL。
