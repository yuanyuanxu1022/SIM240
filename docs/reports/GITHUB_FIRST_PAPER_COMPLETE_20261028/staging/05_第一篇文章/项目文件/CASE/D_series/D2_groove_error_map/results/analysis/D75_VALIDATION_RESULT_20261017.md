## 结论（论文第③层贡献闭环）

> **Jain 型闭合（局部立方律/条纹平均）在矩形直角槽 + 有限间隙下的误差，可以用两个无量纲修正因子系统性消除：**
> - 沿槽：F∥ = 1/(1 + 1.7207·(d/H_ref)^1.8046)，把 +66~+99% 的误差压到 ±17% 以内；
> - 跨槽：F⟂ = 1/(1 + 0.5276·(d/w)^0.8259)，把 +34~+41% 的误差压到 ±4% 以内；
> - 两者均在**未参与拟合的 d=75 几何**上通过留出验证（6/6，判据提前定死）。
> - 跨槽修正只依赖模具自身形状比 d/w，与间隙无关——与 9 点主矩阵的独立观测一致。
