**读法**（均为模型高估，正号）：
- 两方向**全部高估**，无一例外——不是偶然误差，是模型形式的系统性偏差；
- 沿槽误差随 d 急剧增大（d=100 时 +108%~+154%），且间隙越小越糟；
- 跨槽误差相对温和（+12%~+49%），对 h、d 都不太敏感；
- 各向异性 A：模型从 1.08 一路高估到 7.26，而 DNS 只在 1.09–3.92——**Jain 闭合会把"方向性"夸大最多 ~85%**（h50/d100）。

## 3 12.1 参数敏感性（区间弹性 Ŝ）

- **Ŝ_h**（间隙的影响）：跨槽 Ŝ_h≈2.7–2.8（几乎恒定）；沿槽 Ŝ_h 随 d 增大从 2.4 降到 1.3——**间隙永远是最强旋钮，尤其对跨槽输运**；
- **Ŝ_d**（槽深的影响）：沿槽 0.18–0.91，且随 h 增大递减（加深槽的收益递减）；**跨槽 Ŝ_d≈0.001–0.05 ≈ 0**——**加深沟槽对跨槽输运几乎没有任何帮助**。

一句话设计结论：**想提高跨槽流量，加深槽没用，减间隙才有用；想提高沿槽流量，槽深有收益但递减。**

## 4 12.2 等体积利用效率（η = K/K_flat,V）

| 档 | η∥ | η⟂ |
|---|---:|---:|
| h50/d25 | 0.95 | 0.70 |
| h50/d50 | 0.87 | 0.42 |
| h50/d100 | 0.69 | **0.18** |
| h75/d100 | 0.60 | 0.27 |
| h125/d100 | 0.60 | 0.42 |

**读法**：槽挖得越深，多出来的容积"越不值钱"——沿槽效率从 0.95 掉到 0.60；跨槽效率从 0.70 掉到 **0.18**（h50/d100 时 82% 的槽容积对跨槽输运是"死空间"）。等体积平板是更好的参照系。
