## 1. 原文直接反例：0.06不是已核的文献上限

本地MF正式PDF为32页、印刷pp23—54。印刷p34、图6(b)明确标注S=0.04、0.06、**0.08**。已查看[PDF第12页的局部阅读渲染](MF_page_12.png)，不是只据文本抽取猜测图中标记。因此，“全文S≤0.06”被一个明确反例否定。本轮也**不把0.08改封为全文或方法的新上限**。

应区分四层：一般控制方程/几何表示、首模态几何近似、实际展示的算例范围、经证明或独立核验的适用域。MF式(2.1)用傅里叶表示上下壁，§3保留非线性速度乘积并数值求解；不能仅凭论文聚焦小幅参数，就把某张图的数值封成全部方法的硬性数学适用边界。其首模态近似与完整数值求解也不是同一层级。

§4.2及图4—5确实纳入矩形槽，后续详细参数图集中于正弦形。印刷p34的描述支持的是首模态计算误差“仍在50%以内”，**不证明误差达到50%、恰好50%，或整个方法只有50%精度**。形貌首模态截断误差、数值离散误差与本稿V2偏差不可相互替代。

`check_round2.py`中的所谓“振幅上限0.06”检查只搜索全文是否出现`S = 0.06`，再手设S_CAP=0.06作除数。出现一个数不等于它是最大值；70项文字/算术通过不能证明这一前提。本轮不重跑并覆盖旧回执，保留它的历史身份与缺陷定位。

## 2. 两口径算术成立，排除结论不成立

从原36条主记录得到18种几何，d/h为0.2—4。两项算术结果核对一致：

|参考全高H0|S=2d/H0的范围|可采用的解释|
|---|---|---|
|A：H0=h|0.4000—8.0000|以浅区间隙作参考尺度的峰峰值比|
|B：H0=h+d/2|0.363636—2.666667|以几何平均开度作参考尺度的峰峰值比|

这说明本稿无量纲起伏量不属于MF所展示的几个小幅算例的同一量级，**不证明MF一般方程或求解方法不能处理本稿参数，也不证明误差必然超标**。S=0.06的倍数只能称“相对于某个算例数值的倍数”，不能叫“超出文献适用上限的倍数”。

对MF上壁固定yU=1的表示，若用本稿矩形轮廓作峰峰值尺度对照，参考高变动应同时改变

\[
S=\frac{2d}{H_0},\qquad
S_{\rm ave}=2-\frac{2(h+d/2)}{H_0},\qquad
\tilde\alpha=\frac{\pi H_0}{P}.
\]

A对应Save=−d/h，B对应Save=0；不能只改变S而把平均壁位、波数和基准流动的口径固定不动。原始矩形峰峰值与其首傅里叶模态的振幅也不能不加说明地混同。这些式子仅核对坐标/尺度，不是新输运理论或新匹配解。

“B对文献最有利，任何折算只能在A/B之间改倍数”没有被证明。例如取最大开度H0=h+d，会得到S_C=2d/(h+d)=0.333333—1.6，比B更小，同时Save也变化。此例只反驳A/B穷尽参考选取的说法，**不推荐用另一个参考高度来人为缩小S或回避物理条件**。完整算术见[amplitude_conventions.csv](amplitude_conventions.csv)、[arithmetic.json](arithmetic.json)。

固定流量与固定驱动本身也不是Stokes线性问题不可比的根本理由：同一几何、黏度和边界下，可通过线性阻力关系换算。MF含有限Reynolds数的算例，比较时还必须明确所取低惯性范围、实际几何、波数、方向及通量/压降定义。本轮没有完成它的同条件数值复现或精度排名。

## 3. 开度必须分为几何参考高度与响应等效高度

|量|定义及来源|本轮判定|
|---|---|---|
|H_ref=h+d/2=V_f/A_plan|等宽几何的流体体积除以投影面积，用于J=H_ref〈u〉及κ=K/H_ref|几何量；给定几何下两方向相同，不是导度预测式|
|H_hyd,i=(12K_i)^(1/3)|由某方向导度反算平板通道厚度，本项目独立等效缝高读物已使用|响应重标定；随方向与计算K变化，不增加数据独立信息|
|MF的EC_h|§4.4.2按与带槽通道相同摩擦因子的光滑通道开度定义|属于水力匹配量，与H_hyd同类；不能因H_ref是几何输入，就宣布所有“等效缝高”表达与前人不重复|

以本稿h75/d100、原5 nm离散记录说明：H_ref=125 nm，但H_hyd沿槽约105.67 nm、横槽约81.12 nm。三者不是同一个量。MF的摩擦因子定义与本稿K要先统一流量、参考压降和尺度，才能声称水力开度数值完全等价；本轮只裁定概念类型，不替代这项换算。

印刷p41的EC_h段落还明确说，高波数下接近2−S/2的现象未能以足够高波数计算确认，并提示复杂流动可能使真实极限不同。不能把EC_h→2−S/2作为已证极限或本稿可借用定律。已查看[PDF第19页阅读渲染](MF_page_19.png)。

没有在本轮所查正式两稿中发现所指“首次以等效缝高处理带槽导度”的主张，不应为删除一个未找到的句子制造改稿记录；未来也不应新增该首创表述。独立等效缝高说明原已将其定位为单调重标定，不认定为新计算。

## 4. 局部立方律的解释与误差方向写反了

本稿式(3)同时使用h³与(h+d)³，局部深槽并未被丢掉。h³/12才是只保留贯通h层、上方延零的基础下界。把它们混为一谈会把全文主线反转。

对同一黏度，R_i=μ/K_i；因此K_LCL≥K对应R_LCL≤R。本稿已保存离散结果也体现导度高估、阻力低估。把局部立方律写成“只取h、丢掉槽腔容积，所以高估阻力”同时错在模型内容与偏差方向。

MF关于几何平均开度不能单独决定水力响应的结果，可用于相邻问题的概念比较；**不能据此证明本稿LC偏差的同一个机制**。本文全域梯度诊断仍限于指定基线、分组和所测几何。没有新证据将其升级成独立侧壁/尖角原因或普适机制。
