# 两种方法共用的输入表

日期：2026-10-30。状态：`PREPARATION_ONLY_NOT_FROZEN_NOT_RUN`。字段与程序读入版 [common_inputs.json](common_inputs.json) 对应；SI 单位为运算基准。

“已有”指本项目已有基准或定义，不表示新的宏观算例已获放行。“候选”是具体建议，尚未冻结。“待定”在 JSON 中保留 null，不得由程序自动补一个默认数。

## 1. 共同研究对象与几何

|项目 / 字段|准备值|依据与状态|
|---|---|---|
|物理范围|全充液、单相、牛顿、等温、不可压缩、刚性图案|本轮准备范围；低惯性与尺度适用性仍需核查|
|最小间隙 h|75 nm = 7.5×10⁻⁸ m|已有基准；从基底到凸台底面|
|槽深 d_g|100 nm = 1.0×10⁻⁷ m|已有基准；文档用 d_g，避免与 Darcy 系数 d 混淆|
|槽宽 w|120 nm = 1.2×10⁻⁷ m|已有基准|
|周期 P|240 nm = 2.4×10⁻⁷ m|已有基准；不能当宏观区域长宽|
|槽平面占比 φ_g=w/P|0.5|几何推得；不是任意多孔方程里的体积孔隙率|
|平均储液厚度 H_store=h+φ_g d_g|125 nm = 1.25×10⁻⁷ m|对应完整等宽周期的流体体积/平面面积；与现行稿件 H_ref 定义一致|
|最高液体包络高度 H_env=h+d_g|175 nm = 1.75×10⁻⁷ m|几何推得；不是 H_store|
|包络内流体体积比 H_store/H_env|5/7≈0.7142857|只针对上述理想几何；不能用 φ_g=0.5 代替|
|固定全局坐标|x 沿区域短边；y 沿区域长边；z 从基底向上|候选坐标约定；基准槽沿 y 时与 D2 对齐|
|区域长宽|Lx、Ly 待定；候选 Ly/Lx=2|已有建议；不照搬参考板内 1 mm 方区或 G5A 的旧 1 mm 条带|
|投影面积|A=Lx Ly，数值待定|与力积分、排液量使用同一面积|
|周期数、边缘相位|待定|有限显式区域的储液量须实算；不保证任意截断都严格得到 H_store=125 nm|

该几何已经用于现有系数研究，只能作接口检查点，不能称作未参与研究的新条件。

## 2. 物性、压力与驱动

|项目|准备值|依据与状态|
|---|---|---|
|动力黏度 μ|候选 1.0×10⁻³ Pa·s|现行 D2 基准；是物性建议，不是新算例采用记录|
|密度 ρ|候选 1000 kg/m³|现行 D2 基准；不照搬参考仓库 1510 kg/m³|
|运动黏度 ν=μ/ρ|候选 1.0×10⁻⁶ m²/s|由同一 μ、ρ 推得，不独立乱设|
|重力|候选关闭，g=(0,0,0)|为先隔离导度接口而设；不代表真实工艺重力审定|
|物理环境压力 p_b|绝对值待定；二维比较用过压 p_g=p−p_b|p_g=0 不是绝对真空；单位统一 Pa|
|挤压阶段的宏观四个外边|候选 p_g=0|仅适用于瞬时挤压；OpenFOAM 还需完整边界配套；不能给内部 cellZone 的四边冒设出口|
|静态压力驱动接口检查|V=0；G=−∇p_g，大小待定|边界另定；采用压差或周期体力中的一种。不能在无体力、无运动且四边同压时宣称存在非零压差驱动|
|瞬时挤压|V=−dh/dt>0，数值待定|同一时刻相同 h、V；不得借用旧局部体加速度当压头速度|
|运动或储液源实现|待定|必须让 ∂H_store/∂t 与实际排液一致；存在 movingWallVelocity 名称不算实现证明|
|惯性/毛细/相界面|拟先采用低惯性无界面问题|密度仅在需要的方程/诊断中使用；不新增接触角或表面张力输入|

## 3. 两种槽向与同一组系数

保持固定全局 x/y 与区域长宽，只转动沟槽。θ 从固定全局 +x 轴量起，和原 D2 斜向驱动“从槽轴量起”的角度不是同一记号。

|槽向 ID|槽轴 / θ|全局 Kxx|全局 Kyy|Kxy|
|---|---|---|---|---|
|groove_along_long_y|y / 90°|K_perp|K_parallel|0|
|groove_along_short_x|x / 0°|K_parallel|K_perp|0|

两端主比较使用同样两组输入：`original_local_cubic` 和 `V2_published_rounded`。本轮用公布舍入系数，不重新拟合，也不混用 G4/G6 等另一候选族。现存 OpenLB 5 nm K 可作为第三组输入诊断，明确命名 `OpenLB_dx5_diagnostic_only`；将它放进同一降阶模型不会变成独立挤压参照。

原始来源为 E01（现行稿件§2.2、§2.3、§4.4），原始数值记录为 E03/E04；路径、用途与 SHA256 见 [source_manifest.json](source_manifest.json)。现有源码 E02 用于核定义，不能仅因当前源码存在就替旧运行补齐构建来源。

## 4. 共同输出约定

|输出|定义或记录要求|本轮状态|
|---|---|---|
|过压场|p_g=p_physical−p_b，Pa；约定采样面/厚度平均与投影|定义准备；未求解|
|二维压力载荷 F_p|∫_A p_g dA，N；正值表示抗闭合方向的载荷幅值|准备；不以 abs 消除错误符号|
|三维总法向力 F_σ|环境压力扣除后，液体作用于模具的法向总应力积分|待统一作用面、方向与黏性贡献；另列，不自动等同 F_p|
|主阻力 R_sq|统一 F_net 后取 F_net/V，N·s/m|V>0 的挤压问题才定义；V=0 的静态检查填不适用|
|方向比 χ_sq|R_sq,槽沿短边 / R_sq,槽沿长边|同一区域、同物性、同 V；不混用压力阻力与总应力阻力|
|各边排液量|四条宏观外边分别积分 J·n ds，m³/s；向外为正|不对局部倒流取绝对值后求和|
|体积闭合|均匀刚性闭合候选 Q_net=V A；记录实际 dV_fluid/dt|只用于对应假设；参考有限几何需核实际体积变化|
|压力/载荷差异|两实现同输入差异单列；对独立显式参考的偏差另列|独立参考未合格，不填预测精度改善结论|

网格族、求解误差、检查位置、资源、停止条件和验收阈值均待冻结；不从旧 D2/G5A 或参考仓库搬来当本算例的门槛。JSON 的 launch_ready=false 不是运行结果 FAIL。
