# ParaView 出图教程（组会汇报 & 论文插图用）

> 明天照着做就行，每一步都写了点哪里。目标：存 4 张图，每张都有明确的用途。

## 0. 先打开数据

数据在每一档的 `steady/vtkData/` 目录里，文件是 `.vtm`（多块场文件），含 **4 个场**：
`material`（几何=1 是液体）、`velocity`（速度矢量）、`pressure`（压力）、`dissipation`（能量耗散率——机制分析的现成材料）。

**推荐用这两档打开**（最有代表性的几何 h=75/d=100，即你的真实模具）：
- 沿槽流场：`results/h75_d100_dx5_P/steady/vtkData/`
- 跨槽流场：`results/h75_d100_dx5_T/steady/vtkData/`

**打开方法**：ParaView → File → Open → 选 `vtkData` 目录里的 `.vtm` 文件 → 点左侧眼睛图标显示。

> 打开后默认视角可能是乱的：点顶部工具栏「锁」图标旁的方向按钮，或点 `+X/+Y/+Z` 旋转到正视角。

## 图 1：沿槽方向——槽里流得快（俯视云图）

**用途**：论文最直观的一张图——让人一眼看懂"液体优先走沟槽"。

1. 打开 `h75_d100_dx5_P` 的 vtm；
2. 顶部过滤器：Filters → Alphabetical → **Slice**（切面）→ 点 Z Normal，把原点高度改成 **z = 150 nm**（切在槽内部高度，槽内 75–175 nm 之间）；
3. 左侧工具栏把上色对象从 `Solid Color` 改成 **velocity → magnitude**；
4. 调色板：右侧 Color Map Editor 选 **Blue Orange (divergent)** 或默认 Rainbow；
5. 视角切到 +Z 俯视；File → **Save Screenshot** → 分辨率设 **2400×1200**（比默认高一档）→ PNG。

**预期画面**：沟槽条带颜色深（快）、凸台区域浅（慢）——方向性输运一眼可见。

## 图 2：跨槽方向——台阶处的流动（剖面流线图）

**用途**：台阶耗散机制的直接视觉证据（12.3 机制分析将来要用，先存着）。

1. 打开 `h75_d100_dx5_T` 的 vtm；
2. Filters → **Slice** → 切 **Y Normal**，原点 y=120 nm（任意槽内位置，周期方向都等价）；
3. 上色用 velocity → magnitude；
4. Filters → **Stream Tracer**（流线）→ Seed Type 选 **Line Source**，把种子线画在槽左侧台阶附近（拖拽 3D 手柄或手工输入坐标，起点大约 x=40 nm 到 x=90 nm、z=100 nm 附近）；
5. 流线上色选 velocity → magnitude；显示后看台阶拐角处是否有回流（小涡）；
6. Save Screenshot 2400×1600。

**预期画面**：流体翻过台阶时在拐角绕行——这就是"台阶耗散"长什么样。

## 图 3：速度剖面——公式假设错在哪（曲线图）

**用途**：检验模型的形状假设——Jain 公式假设槽内像平板流动，实测不是。

1. 打开 `h75_d100_dx5_P` 的 vtm；
2. Filters → **Plot Over Line** → 把线段画成**垂直方向**（Z 向，从 z=0 到 z=175 nm），放在**槽中心**（x≈120 nm，任意 y）；
3. 再画第二条 Plot Over Line，放在**凸台下**（x≈30 nm，z 0→75 nm）；
4. 切到 LineChartView 视图（顶部 View 切换图标），两条曲线对比；
5. 数据导出：File → **Save Data** → CSV → 两条线各存一个 csv；
6. 图也可以直接截图（Save Screenshot）。

**预期画面**：凸台下是标准抛物线（平板解），槽内剖面被"拉平"——侧壁剪切让槽中心速度低于平板公式预测，这就是沿槽 +146% 高估的现场。

## 图 4：耗散地图——能量都在哪耗掉（云图）

**用途**：把"侧壁耗散/台阶耗散"从猜测变成看图说话（12.3 的证据储备）。

1. 打开 `h75_d100_dx5_T` 的 vtm；
2. Filters → Slice → Z Normal，z=150 nm（槽内）；
3. 上色改成 **dissipation**（如果列表里没有就选 pressure 以外的场，dissipation 是标量场，直接可选）；
4. 色标调 log 尺度（Color Map Editor 里勾 Use Logarithmic Scale）——因为耗散集中在台阶附近，log 才看得清；
5. Save Screenshot 2400×1200。

**预期画面**：亮斑集中在台阶和侧壁——"耗散位置"的证据图。

## 保存的通用设置（4 张图都一样）

| 项目 | 设置 |
|---|---|
| 分辨率 | Save Screenshot 时至少 **2400 px 宽**（默认 1500 偏小，投 PPT 够用、论文要更高） |
| 背景 | 白色（Edit → Settings → Render View → Background 选白色）——论文图标配 |
| 字体 | 默认即可；论文排版时字号由 Word 调 |
| 文件命名 | `fig1_parallel_velocity.png`、`fig2_perp_streamlines.png`、`fig3_profiles.png`、`fig4_dissipation.png`，存到 `docs/reports/figures/` |

## 常见坑

- **打开 vtm 是一片空白**：先点眼睛，再点顶部 `Apply`；vtm 是多块结构，读入需要 Apply。
- **切片看不到东西**：Slice 默认原点在 0，把 z 改成 150（槽内）就有了。
- **截图只有一半**：把窗口拉大再存；Save Screenshot 是按窗口尺寸渲染的。
- **dissipation 场不存在**：说明该档是旧二进制跑的，用 `h75_d100_dx5_{P,T}`（主矩阵档，新版都含 4 场）即可。
- **不会画那条种子线**：Line Source 会出现在 3D 窗口里，按住两端的球拖动到想要的位置就行；实在拖不动，直接勾 Stream Tracer 的默认种子（Point Cloud），把点云范围拉近台阶处。
