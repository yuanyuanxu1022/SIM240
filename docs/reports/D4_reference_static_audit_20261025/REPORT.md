## 2. 壁面与角点：位置核对通过，审计名义需要收紧

D4源码254–279行用居中槽及半开区间定义液体：下壁z=0；台面上壁z=h；槽内上壁z=h+d；侧壁x=(P−w)/2和(P+w)/2。671–695行的网格中心与精确整倍数尺寸使平面位于流体/固体节点之间半格。距离函数290–347行取水平、竖直壁面的最早交点，并仅将q与.5相差≤1e−10的值对齐到.5。本轮8个网格的全部流体到固体候选连接均在半链处与闭合壁面片相交，节点和连接计数匹配已存实际审计。

这证明的是这些网格的几何安装一致性；不证明壁面离散误差为零，不证明角点速度梯度已充分分辨，也不证明通量应有严格二阶收敛。

## 3. 输运提取：定义、单位与来源可闭合

D4源码514–560行只遍历material=1核心节点（不把重叠/边界节点计入体积），计算：

`J = sum(u_phys * dx³)/(Lx*Ly)`，单位m²/s；

`K = μJ/(ρa) = νJ/a`，单位m³；`R_eff = ρa/J`，单位Pa·s/m³，且`R_eff*K=μ`。

J是按单胞平面面积归一的深度积分输运量，不是平均速度；`Href=h+(w/P)d`，因此`J=Href*<u>volume`。若另定义普通渗透率κ，其单位m²，`κ=K/Href`，不能把κ当K去和h³/12比较。P沿槽取uy、T横槽取ux；截面检查取截面法向速度，源码542–554行并未将横槽局部回流错投影成沿槽量。

强制速度链也已核对：D4 750–755行只写一次`a*dt²/dx`；OpenLB `dynamics.h`224–229行使用ForcedBGK/PlainGuo，`forcing.h`41–65行组合强制动量，`momenta/elements.h`1600–1607行在computeU中加半步力；D4测量与末态切片均调用computeU，再乘dx/dt转物理速度。本轮未见手工再加一次或漏加的提取路径。若人为减掉a·dt/2，改变了模型的速度定义，不是本轮获准的“修正数值误差”。

|---|---:|
|末态J及ν/a重算K，相对原K|3.33067e−16|
|用双精度末态切片重新积分K，相对三维原K|9.97868e−13|

详见[transport_checks16.csv](transport_checks16.csv)。这些差异远小于本次网格敏感性，排除了这16项存在百分数级的末态提取、方向选择或单胞面积系数错误的解释；不排除速度场和离散积分本身对连续解的误差。本轮没有从切片假定所有三维点相同来重新证明完整三维场，原全场完整性沿用此前独立证书。

### 3.1 平板表明：积分一致不等于连续积分无误差

对连续平板`u(z)=a*z*(h−z)/(2ν)`，K_exact=h³/12。即使把**精确解析速度**取在同样的半格节点，再用当前单元体积权重积分，也有：

`K_sampled_exact = h³/12 + h*dx²/24`，相对差`dx²/(2h²)`。

本轮从6份既有平板切片重算了这一离散求和恒等式：

|h，nm（dx=5 nm）|实际LBM K相对解析K的偏差/%|仅解析速度的中点积分偏差/%|LBM与同节点解析速度积分之差，百分点|
|---|---:|---:|---:|
|50|0.999997–0.999998|0.500000|0.499997–0.499998|
|75|0.444441左右|0.222222|0.222219左右|
|125|0.159994–0.159995|0.080000|0.079994–0.079995|

见[smooth_quadrature_decomposition6.csv](smooth_quadrature_decomposition6.csv)。表中最后一列包含离散速度场、停止及舍入等与同节点解析速度的总差，**不是已分离出的纯壁面误差**。这6项仍满足原<2%的平板门槛；h变化不是同一几何的三格验证。

平板诊断说明，网格误差不能只归因于几何错位或角点；数值积分也是需要记录的组成。沟槽的未知精确速度与角点正则性不同，不能把此平板公式直接用于扣除沟槽K，也不能为让数字变准统一去掉半步速度。若将来改积分方法，必须另立参考提取版本，并保持原K可复现。

## 4. 停止误差：最后窗口稳定已核实，最终误差上界尚缺

源码108–140行使用n点样本标准差（n−1分母）和相对极差；822–866行在首个完整窗同时满足std≤1e−6、span≤5e−6、cross≤1e−12时退出。窗口样本数由物理时间尺度决定；n个点的首末时间差是(n−1)dt，不是n·dt，这一采样约定不改旧协议。K取最后时刻的J，不是最后窗口平均。
