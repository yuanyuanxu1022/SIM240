## 3. Jain原文公式核验与换算

原始文件：/home/dell/下载/1-s2.0-S0167931717301296-main.pdf；DOI 10.1016/j.mee.2017.04.001。已提取全文并目视检查PDF第3页（期刊第64页），式(11)(12)(13)。PDF SHA256见JSON。

重要单位区分：原文第63页的大写K为m²的深度平均速度渗透率；第64页式(12)(13)的小写k是无量纲值，不能把公式本身标m²。由原文速度、压力尺度，维度渗透率κ=(H0²/12)k。SIM240的深度积分输运系数M为m³，κ=M/H_ref。原文槽沿x，SIM240沿y，比较时必须交换方向名称，不能直接比同名分量。

等价性不只靠单点代数：设实际凸台间隙H、槽深D、原文宽度比δ=d2/d1，r=1+D/H，则H_ref=H(1+δr)/(1+δ)。条纹立方平均给出

- M_parallel=[H³+δ(H+D)³]/[12(1+δ)]；
- M_perpendicular=(1+δ)/[12(H^(-3)+δ(H+D)^(-3))]。

分别除H_ref后，得到κ_parallel=(H²/12)(1+δr³)/(1+δr)，κ_perpendicular=(H²/12)(1+δ)²/[(1+δr^(-3))(1+δr)]。再乘12/H0²，即原文式(12)(13)。因此在同一满充液、周期线槽、无滑移、润滑闭合与归一化定义下，两套表达确实等价。

本项目H=75 nm、D=100 nm、δ=1、H_ref=125 nm时，推导κ_parallel=1.927083333333333e-15 m²、κ_perpendicular=5.214527027027027e-16 m²。原计划表5.2146e-16只是低精度近似；此处为代数推导值，不是DNS。

## 4. 必须修正的论文定位

原文p.64 §3.1明确H0=1 μm，模拟无量纲间隙从1降至0.01，故实际H从1000 nm降至10 nm（由原文直接换算）。其图案线宽/槽宽各100 nm时周期200 nm，因此H/P覆盖5到0.05（推导）。这包含H/P约0.3，不能说“Jain只研究最终薄隙，没有涉及中间间隙”，也不能以中间间隙本身证明新颖。

能支持的差别是：Jain以等效闭合计算液滴/模板过程；我们计划直接解析局部真实沟槽流场并量化该闭合误差。Jain主文未见此种矩形槽局部K的显式数值误差地图；这不等于后续全部文献均无人做过，补充材料与后续引文仍待查。

Jain是已发表NIL模型使用该公式的直接证据；单篇论文不能证明行业广泛采用。无论人工查新是否发现先例，都不能保证本工作只需改措辞就有同样发表价值：若已有同边界/几何/参数的误差规律与修正，必须进一步形成实质增量。

误差地图是计划；耗散机制需由速度/应变/能量收支等证据区分；修正公式需独立留出工况检验。9个几何点不是完整失效边界或普适预测的自动保证。若初步地图有清晰转折，可据数值不确定度再决定是否补点，不预先扩大计算。
