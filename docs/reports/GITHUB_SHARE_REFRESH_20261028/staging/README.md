代码和数据按用途分别保存。下面的命令会在被Git忽略的`_workspace/`里恢复原项目相对目录，复制数据与代码，并把两个原机器路径替换为当前工作区路径。原始保存副本不改动，也不链接回原项目。需要约1.3GB额外磁盘空间。

## 重新生成主要图片

建议用独立Python环境安装`requirements.txt`。本地验证环境与依赖版本记录在`检查记录/环境版本.json`。普通绘图需要Python、NumPy、Matplotlib和Pillow；修正/误差传播还用到SciPy，其他辅助处理用到Pandas、SciencePlots。ParaView场图需另装ParaView并使用其`pvpython`，不能用普通pip环境替代。

在Linux终端中，可按下面三行创建环境并安装依赖（需联网下载Python包）：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

在已经安装依赖的Python环境中执行：

```bash
python3 tools/workspace.py reproduce
```

调用3个已有作图脚本，生成4张图的12个PNG/PDF/SVG输出，位置是`_workspace/figures/paper/`。只做后处理，保存的原始图像不覆盖。图01中along groove文字靠近横向箭头，可能易读错；源码定义仍为y沿槽、x横槽。旧fRe图仅为历史材料，不采用其量纲/来源未闭合的解释。

## 编译主程序（不会启动计算）

当前入口在Linux环境验证，需要`make`、支持C++20的编译器、OpenMPI开发工具（`mpic++`）和`ar`。Windows原生环境未验证；C++部分需使用可提供这些工具的Linux环境。编译用的目录路径暂不支持空格，请放到不含空格的目录。软件安装由使用者按本机环境准备。

```bash
python3 tools/workspace.py build
```

使用随包提供的依赖源码，在`_workspace/_deps/openlb`编译zlib、tinyxml2和OpenLB核心库，再编译D2主程序。输出只留在`_workspace`，编译日志写入`检查记录`。本入口不启动、重跑或继续任何仿真。其他历史算例按各自技术说明阅读；没有宣称本轮逐个重新编译、运行所有历史程序。
