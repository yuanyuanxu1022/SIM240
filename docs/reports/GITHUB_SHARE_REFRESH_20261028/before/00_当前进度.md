## 研究问题与路线

关心两个问题：矩形沟槽沿槽与横槽的输运能力有何不同；把不同局部高度的平板流动关系组合起来，会对真实沟槽的整体输运产生多大偏差。

路线是：平板基准和数值检查 → 改变间隙h与槽深d → 分别沿槽/横槽提取K → 与局部条纹模型比较 → 检查修正表达与误差向压力/载荷预测的传播。实际液滴、气液界面、移动压头和固化不属于这组数值结果已验证的内容。

## 现在卡在哪里

1. **数值证据范围：** 历史细横槽质量FAIL不能被GCI或新目录覆盖；方案C的输出存在，也不能直接替代尚未闭合的正式放行证据。
2. **历史来源：** 52份指定manifest都有二进制哈希，但这些manifest没有源码哈希、OpenLB提交、编译器与编译参数字段。当前依赖快照和本轮新编译不能倒推历史运行版本。
3. **场图来源：** 可选流场图有原始场和渲染清单，但部分记录仍为unique_run_id_verified=false。图像存在不等于历史代码绑定完成。
4. **模型解释：** 简化模型遗漏的侧壁作用与连接段流动重分布尚未独立分解；不能确定唯一主导机制。部分趋势有局部反例，应以逐点数据限定结论。
5. **跨机器使用：** 已准备恢复原目录和适配路径的工具；本机及本地重新克隆后的主程序编译、主要图片生成情况见[检查记录](检查记录/)。尚未在其他设备上测试。
