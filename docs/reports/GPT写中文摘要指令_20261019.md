# 文档二：让 GPT 写【中文摘要】的指令

2026-10-19 · 导师/组会/学位论文用 · 配套 `SIM240_EJMB_英文整合工作稿_20261019.md`

> **用法**：每块代码框**单独复制一次**发给 GPT。
> 目标：中文 250–320 字（目标 280），单段，7 步约 40 分钟。
>
> **关键：这一份要单独跑一个新对话，不要和英文那份一起做。**
> 同时写两版，它一定是先写英文再把英文翻成中文——那就成了翻译腔。
> 中文摘要不是英文的译本，是同一份论证用中文重讲一遍。

---

## 开始前：中文摘要写给谁看

| 用途 | 要求 |
|---|---|
| 导师/组会 | 术语要能让不同方向的人看懂，机制解释可以多一句 |
| 学位论文中文摘要 | 可以稍长（350–450 字），可加一句"研究意义" |
| 中文期刊/会议 | 按目标刊物字数要求，通常 200–300 字 |

**本文档按"导师/组会"的 280 字口径写。** 如果用途不同，在第 0 步里告诉我，我改字数标准。

## 第 0 步：读材料 + 数字表 + 术语表（不写摘要）

```
这是一个写作任务，不是审查任务。你要为下面这篇论文写中文摘要。
现在先不要动笔，只做三件事。

【读这些文件】
1. docs/reports/SIM240_EJMB_英文整合工作稿_20261019.md
   —— 重点读 Abstract（第 17 行）、I. INTRODUCTION 末尾三条结论（第 69–95 行）、
      IV. E 小结（第 467–475 行）、V. C 末尾（第 542–545 行）、VI. CONCLUSIONS（第 547–549 行）
2. docs/reports/SIM240_投稿目标决定与写作入口_20261019.md

【第一件：用 5 句大白话讲清这篇论文】
要求：假设听众是同实验室但不同方向的同学。不要用"本文研究了"这种句式，
每一句都要有具体内容：跟什么比、差多少、所以什么。

【第二件：把数字列成表】
把下面这些量在原文中的确切数值抄出来（中文说明 + 原值 + 所在行号）：
- 闭合式沿槽高估范围
- 闭合式跨槽高估范围
- 参考几何 (h=75, d=100) 下，闭合式与精确解的各向异性比
- 45° 驱动下的流向角（精确解 / 闭合式 / 差值）
- V2 修正在 18 个沿槽样点上的最大绝对残差
- V2 修正在跨槽样点（h≥50 nm）上的最大绝对残差及样点数
- h=25、d=100 跨槽点，5 nm 与 2.5 nm 两个网格上的残差
- 几何数、主方向工况数、正式运行总数

要求：只抄原文，不要自己算、不要四舍五入、不要补单位。找不到的写"原文未给"。

【第三件：定中文术语表】
把摘要里必须反复出现的术语列成两列（中文写法 | 对应英文），只列 6–10 个，
例如"深度积分输运系数""算术–调和平均""局部立方律""各向异性比""残余间隙""经验修正"。

特别要求：列出那些**容易被乱译**的词，并给出你选定的唯一译法。例如：
- closure（闭合式 / 闭合模型 / 封闭关系？选一个）
- depth-integrated transport（深度积分输运？沿厚度积分的输运？）
- stripe average（条带平均？条纹平均？）
- data-informed（数据知情？数据驱动？——注意这两个意思不同）

说明：这张表一旦定下，全文一律照用，不许中途换词。
```

**为什么第 0 步就要定术语**：中文摘要最常见的毛病不是语句不通，是**同一个东西换了三个名字**——一会儿"闭合式"、一会儿"简化模型"、一会儿"等效模型"，读者以为是三个不同的对象。

## 第 1 步：只写一句主张

```
现在只写一句话，不要写摘要。

这句话是全文的主张，必须满足：
1. 可以被反驳 —— 有人不同意时，能指出"哪张图能推翻它"；
2. 包含"和什么比、差多少、所以什么"三件事；
3. 不出现具体百分数（那是证据，不是主张）。

参考句式（不要照抄）：
"某类简化模型在某条件下会系统性地偏大，而且两个方向的偏大程度不同，
 所以用一个统一的修正系数，在原理上就不成立。"

限制：
- 不超过 40 个中文字；
- 不要写"本文研究了""本文探讨了"；
- 不要写"首次""创新性地""填补了空白"。

只输出这一句中文。另外补一句：这句话如果要被推翻，需要哪张图。
```

**这一步值得来回三轮。** 其他六步是技术活，只有这一步是判断。

## 第 2 步：只写"缺口"（1–2 句）

```
现在只写中文摘要里的"缺口"部分，1–2 句，不要写别的。

要回答：别人做到哪一步了，还差什么？

必须体现三层（可合并成两句）：
1. 把沟槽图案等效成各向异性渗透率张量，是唯一可行的降阶路线，压印建模一直这么用；
2. 这条路线靠的是算术–调和平均（局部立方律）这个闭合式，但在"直角尖锐的沟槽 + 有限间隙"
   这个组合上，没有人把两个主方向的误差分别量过 —— 已有一是对着光滑剖面做的，
   二是只给力或总流量，不给两个主系数；
3. 所以真正缺的不是"闭合式准不准"，而是"两个方向各错多少，这个差异会不会把流向带偏"。

硬性禁止：
- 不许写"国内外尚无研究""目前仍是空白"（检索不完整，这是不实陈述）；
- 不许贬低前人（不要"然而他们未能……"）；
- 不许出现任何数字；
- 不许用"具有重要意义""价值巨大"这类空话。

只输出这 1–2 句中文。
```

## 第 3 步：只写"做了什么"（2–3 句）

```
现在只写中文摘要里的"做了什么"部分，2–3 句。

必须包含：
- 方法：用格子 Boltzmann 方法（OpenLB），在真实画出的周期矩形沟槽里直接求解；
- 状态：稳态、完全充满、单相牛顿流体、没有自由面（一句话说清，不展开）；
- 参数：周期 240 nm、槽宽 120 nm、间隙 25–125 nm、槽深 25–120 nm；
- 规模：18 个几何、36 个主方向工况（18 是几何数，36 是工况数，不许混）；
- 对照：把它和算术–调和局部立方律闭合式逐点比，两个方向分别比。

硬性禁止：
- 不许写网格尺寸、时间步、松弛时间、雷诺数、马赫数；
- 不许写"高精度""准确可靠""严格验证过"；
- 不许写代码版本号。

只输出这 2–3 句中文。
```

## 第 4 步：只写"结果"（3 句，只准 4 个数字）

```
现在只写中文摘要里的"结果"部分，最多 3 句。

规则：只准用下面四个数字，一个都不许多、一个都不许改（从第 0 步的表里抄）：
1. 沿槽高估范围
2. 跨槽高估范围
3. 45° 驱动下流向角偏差
4. V2 修正在沿槽 / 跨槽（h≥50 nm）两组样点上的最大绝对残差

三句分别承担：
- 第 1 句：两个方向都偏大，但差得不一样（给数字 1 和 2）；
- 第 2 句：正因为不一样，各向异性比和斜向流向都被带偏了（给数字 3）；
- 第 3 句：按方向分别修正后，残差降到什么水平（给数字 4）。

中文写法要求：
- 数字必须写全（"10.5%"不要写成"约一成"）；
- 每句先给结论，再给数字，不要写成"经计算发现……"；
- 一句里不要塞超过两个数字。

硬性禁止：
- 不许引入各向异性比 3.70 / 2.21（留给正文）；
- 不许引入 h=25 nm 的双网格残差（留给讨论）；
- 不许说"误差来自尖角/侧壁/台阶"（机制只是候选解释，摘要一个字都不提）；
- 不许说"修正后可推广到任意几何"。

只输出这 3 句中文。
```

---

## 第 5 步：只写"边界"（2 句）

```
现在只写中文摘要末尾的"边界"部分，最多 2 句。

必须讲清三件事（可压进两句）：
1. 误差是相对于离散数值参考解算出来的，整个参数范围的不确定度界还没建立；
2. 修正式是"拿已有数据拟合出来的、事后评价的"，不是独立预测检验；
3. 结论限于单相、固定几何、完全充满，不涉及动态充填、自由面、润湿或真实光刻胶流变。

硬性禁止（中文特有的套话）：
- 不许写"不足之处在于""有待进一步完善""尚需深入研究"—— 这些词什么信息都没有；
- 直接说"本文不涉及……""上述结论不适用于……"；
- 不许写成免责清单，最多两句；
- 不许用"然而""尽管如此"开头（会让读者以为你在撤回前面的结论）；
- 不许重复第 4 步的数字。

只输出这 2 句中文。
```

---

## 第 6 步：拼装

```
现在把前五步拼成一段完整中文摘要。

拼装规则：
- 顺序固定：缺口 → 做了什么 → 结果 → 边界。
- 单段，250–320 字（目标 280）。
- 不加"摘要"标题，不加"本文"开头的套话（除非句子确实需要主语）。
- 前五步的句子可以润色衔接，但不许新增任何事实、数字或限定。
- **语序可以按中文习惯调整**（中文更习惯"先对象、再做法、最后结论"），
  但四个成分必须都在、顺序不变。
```

## 第 7 步：自检 + 反翻译腔

```
现在对上面这段中文摘要做自检。逐条答"是/否"，不许跳过。

【内容自检】
1. 一共几个数字？（应为 4 个）
2. 每个数字都能在第 0 步的表里找到原值吗？逐位相同吗（含正负号、小数位）？
3. 有没有"首次""创新性地""填补空白""具有重要意义"？
4. 有没有"证明了""揭示了……机理""阐明了……本质"？（机制只是候选，不能说证明）
5. 有没有把 18 个几何和 36 个工况混用？
6. 有没有说修正可以外推、可以预测没算过的几何？
7. 有没有提到本文没做的工作（实验、两相、移动边界）？
8. 是否在 250–320 字之间？
9. 边界部分是否只有 2 句？

【反翻译腔自检（中文特有，逐条查）】
10. 有没有"对……进行了研究/分析/计算"？（改成"检验了""测算了"）
11. 有没有"对于……而言"？（删掉，直接说"……的误差是…"）
12. 有没有"由于……的原因"？（改成"因为"，或直接删）
13. 有没有"结果表明，……被高估了"这种被动句？（改主动）
14. 有没有一句话超过 60 字？（拆开）
15. 有没有同一个东西用了两个名字？（对照第 0 步术语表逐条查）

【朗读测试】
把摘要读一遍。如果读起来像一个同行在会议上跟你讲这三件事，就是对的；
如果读起来像翻译软件在念英文，就把那句重写。
```

## 拿到结果后：给我核这五项

| 核什么 | 怎么核 |
|---|---|
| 数字真伪 | 逐个回到整合稿对应行逐字比对 |
| 术语一致 | 同一个量在全段是否只有一个名字（对照第 0 步术语表） |
| 越界表述 | 扫"证明/揭示/阐明了……机理/普适/任意几何/已收敛" |
| 数量口径 | 18 几何 / 36 工况 / 52 次运行有没有混 |
| 中文质量 | 翻译腔六条、句长、有没有"本文研究了"这类空头句 |

## 附：中文摘要最常犯的五个错

| 错 | 例子 | 为什么错 |
|---|---|---|
| 开头空话 | "随着纳米压印技术的发展……" | 占了 20 字，零信息。直接从缺口开始 |
| 一逗到底 | 一句话 80 字，三个转折 | 读者断不开句，就记不住论点 |
| 名词打架 | 闭合式 / 简化模型 / 等效模型 混用 | 读者以为是三个对象 |
| 数字堆砌 | 一段七个百分数 | 记不住任何一个 |
| 自我否定 | 结尾四句"不足之处在于……" | 等于告诉读者这篇不用看 |

## 附：现有英文摘要的中文意思（供你对照，不要照抄）

现有摘要（整合稿第 17 行）翻成中文大意是：

> 图案化间隙的降阶模型需要保留未解析沟槽方向性的输运系数。我们用格子 Boltzmann 方法，
> 计算平壁与周期沟槽壁之间稳态、完全充满的牛顿流动，评估算术–调和局部立方律闭合式。
> 周期与槽宽分别为 240 与 120 nm。18 个采样几何覆盖 25–125 nm 间隙与 25–120 nm 槽深。
> 相对于离散数值参考，闭合式沿槽高估 10.30–204.85%、跨槽高估 8.11–54.19%。
> 在一个代表性几何上，两个主系数误差不等导致 45° 驱动下预测流向偏差 9.20°。
> 一个数据知情的经验修正把 18 个沿槽样点的最大绝对残差降到 10.5%、
> 15 个间隙不小于 50 nm 的跨槽样点降到 6.9%。在 25 nm 间隙、100 nm 槽深处，
> 跨槽残差从 5 nm 网格的 −18.7% 变为 2.5 nm 网格的 −14.9%。
> 这两个网格不能确定收敛阶，全图不确定度界没有建立。修正是回顾性评价而非独立预测检验。
> 结果量化了采样到的方向性闭合偏差，并界定了支持该修正的证据范围；
> 它们不验证动态充填，也不适用于真实光刻胶行为。

这份中文的问题和英文一样：**七个数字、末尾四句否定**。新的中文摘要应该只有四个数字、两句边界。
