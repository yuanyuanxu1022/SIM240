## 逐项判断

| 项目 | 判断及最小改进 |
|---|---|
| Ω | 应明确单胞三维流体域，不含固体；dV表明是体积分。附录E局部重定义的二维截面不能直接混用。 |
| A_plan | 明确为LxLy投影面积，不是流体体积、任一垂直过流截面或真实起伏壁面面积。 |
| J | ∫u dV量纲m⁴/s，除平面面积得到m²/s；建议称“经平面面积归一的深度积分通量”，避免被读成Q/A意义的表观速度。 |
| 总流量Q | J不是m³/s的总流量。在稳态、无漏流的周期单胞中，Jx=Qx/Ly、Jy=Qy/Lx，可用于解释单位，但本轮不读回Q或认证守恒。 |
| 驱动G | ρa是单位体积力，单位N/m³=Pa/m；a本身是加速度。不能将压力差Pa直接放进相同公式。 |
| 等效压力梯度 | 若用压力驱动记号，对正向驱动应取外加宏观G_i=−∂_i P；体力驱动用ρa_i。局部周期压力扰动可存在，不能说局部−∂_i p处处等于ρa_i。 |
| 单轴/斜向 | 式（2）的Ki解释为分别沿主轴、非零Gi驱动下的主导度；不要用Ji/Gi或任意投影商未经张量关系直接定义普遍主值。 |
| K | μJ/G的量纲为m³，保留本文“深度积分导度”的命名及定义。真正J/G的比例为K/μ，不把K当成Q/压差。 |
| H_ref | 从V_f/A_plan定义。一般槽占比φ时为h+φd；本文φ=0.5才为h+d/2。不是最大高度h+d或任意选取的归一长度。 |
| J=H_ref〈u〉_Ω | 是同一流体体积积分下的定义恒等式，不是新的数值验证结论。 |
| κ | K/H_ref量纲m²且在指定约定下自洽；“通常的渗透率”宜改“按该参考高度和平均速度约定定义的等效渗透率”。标准Darcy常使用整个参考体积/截面上的表观平均，不能把任意流体体积平均直接等同。 |
| 可比性 | 比较K仍需同一投影面积/体积分定义；转换κ还需相同参考高度与平均速度定义。 |

## 关于κ的明确限定

以任意明确的参考高度H0定义表观平均速度U0=J/H0，则相应κ^(H0)=μU0/G=K/H0。取H0=V_f/A_plan时，U0与本文流体体积平均相同，得到当前式子。因此不把当前换算直接判为错误，也不把κ当作脱离参考体积约定的唯一数值。若另用包络高度，应同时改变表观平均口径，不能只保留旧〈u〉_Ω再替换高度。
