## 暂定的闭环含义：须由原文与导师目标进一步确定

候选链条为：几何与物性 -> 局部输运系数K -> 更大尺度模型的可观测输出 -> 与独立证据对照。既有中文稿§5.2已把固定间隙K列为降阶模型的候选局部输入，但尚未验证动态挤压；§4.4与§5.3保留V2回顾性身份及数值参考限制。

需要区分：

1. 系数关系的检验：冻结修正关系后，用未参与关系选择与拟合的条件检验K。评价数值参考自身的精度，不把其视作无误差真值。
2. 应用预测的检验：在假设和尺度适用时，把K接入更大尺度模型，比较同一几何、物性、驱动和边界下的压力、荷载或流动输出。动态填充、自由表面和困气是否需要另加方程，由指定文献及目标决定。
3. 实验证据的检验：同条件实验若可取得，可以支持物理验证；同方程的独立求解器对照属于数值交叉核验，不能代替实验。

用同一批数据拟合，再回代同一批数据，只能说明拟合残差；不能作为独立预测检验。
