# 新增结果的论文候选表述

作者审阅工作稿，2026-11-07。拟置于当前§4.4的旧36结果与数据使用限制之后；构建段也可置补充S10。未合入正式稿。数值表见 comparison.csv、ratios.csv，完整范围见 REPORT.md。

## 新增间隙的固定公式对照

为考察既定经验修正在新增间隙下的表现，保持槽宽w=120 nm、周期P=240 nm和槽深d=100 nm，补充了h=100 nm的两主方向计算，网格间距为5 nm。该间隙未包含在原九种几何的系数标定集中；本次比较使用原先公布的V2系数，未据新增结果重新拟合。横槽与沿槽的OpenLB深度积分导度分别为9.914424×10⁻²³ m³和1.654764×10⁻²² m³。以同条件OpenLB离散值为分母，原公式的相对偏差分别为+49.43%和+126.62%，V2的偏差为+4.39%和−2.03%。方向比A=Kyy/Kxx的OpenLB值为1.6690，V2预测为1.5664，对应相对偏差−6.15%。这组结果为固定V2在一个新增间隙下的表现提供了补充数值证据；其精度比较限于所用5 nm网格，不构成连续参数范围的精度保证，也不据现有记录认证严格盲测身份。

保持d/w不变时，沿槽V2残差由h=75 nm的+5.90%变为h=100 nm的−2.03%，相差7.93个百分点；横槽对应变化为2.04个百分点。沿槽变化未满足该批次记录的5个百分点结构筛查条件。结果提示应继续考察乘性修正因子的间隙依赖，但尚不能将残差唯一归因于缺少间隙变量，或据此确定新的修正形式。

## 单几何的构建复现

为检查历史构建差异在指定几何上的影响，使用当前可核对身份的程序对h=75 nm、d=100 nm的两主方向进行了同条件复算。两次构建记录中的横槽导度均为4.449022×10⁻²³ m³，沿槽导度均为9.834076×10⁻²³ m³，且各方向的稳态停止步数和逐步主通量数值一致。截面流量诊断存在末位差别，最大绝对差为3.66×10⁻³³ m³/s。因此，本对照支持该几何下主要输运结果的复现，不等价于全部历史几何的构建等价或完整源码与依赖的历史绑定。

## 如需更新上界比较的计数

原18种几何共36个主方向导度结果，以及其中4种几何的8条加密记录，现增加h=100 nm的一种几何、两个主方向结果。共19种几何的46条离散记录均低于对应局部立方律值，与连续模型上界的方向一致。构建复跑用于重复性检查，不重复计入这一集合。理论证明与离散比较的证据角色保持区分。
