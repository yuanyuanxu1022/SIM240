# h100 两方向与 h75 构建对照的只读验收

日期：2026-11-07。作者内部 AI 辅助审查工作稿，使用 peer-review 技能；作者负责最终科学采用。本轮只读原结果，新增本目录审查材料并同步项目状态。未启动、编译或重跑求解器，未拟合、改系数、改原检查器、改正式稿或推进 Gate。

## 1. 验收结论

**四例新增计算及两例历史对照的保存记录通过本轮限定核查。h100 结果可以作为“新增间隙下、固定 V2 的两方向离散数值对照”单独入稿；h75 结果可以作为“同一几何的两构建导度复现”入稿。不能据此宣称严格盲测认证、全图构建等价、连续解精度认证或整篇论文已经闭环。**

与上轮仅抽查两个 K 的区别：本轮直接读取六份完整 diagnostics.csv，重算全部质量误差、两截面差、终止前后窗口和首次满足收敛的步数，并从原始 J、τ、dx、dt、加速度重建 K；读取预检查、边界记录、运行清单、日志和独立退出码。没有直接调用会覆盖原结果的旧检查器。

主产物：[逐例验收](case_audits.json)、[统一公式比较表](comparison.csv)、[方向比](ratios.csv)、[构建诊断差异](build_diagnostic_differences.csv)、[预测身份](prediction_identity.json)、[来源保护](source_manifest.json)、[校验回执](verification.json)。可复算脚本：[audit_four.py](audit_four.py)。

\varepsilon_X=100\left(X_{\mathrm{formula}}/X_{\mathrm{LB}}-1\right)\%,\qquad X\in\{K_{xx},K_{yy},A\}.

旧 `closure_blindtest_verdict.json` 对 A 使用100(A_LB/A_V2−1)，得到+6.555150830%；其 K 偏差却使用预测/参考−1。该数值不是随意捏造，但分母和符号不符合论文统一定义，不能与本表混用。旧检查器/JSON保持原样，纠正仅记录在本次派生表和论文候选中。历史状态中 h100 Kyy 的 e−23 是转述笔误，原 result 为 e−22。

运行脚本记载的两方向绝对偏差≤10%筛查，在本组算术上满足；统一 A 口径后绝对偏差也低于10%。但本轮只报告该批次记录中的筛查结果，不把10%提升为发表通行线、URV门槛或连续域精度承诺。与 h75 相比，V2 残差变化为横槽2.03945、沿槽7.92504个百分点，故脚本列出的“均≤5个百分点”结构筛查**未满足**。该负结果须保留。

## 6. 预测冻结与独立性

[chronology.csv](chronology.csv)记录所查文件的mtime及本轮哈希。2026-11-05既有[独立预测算术表](../PAPER1_bound_closure_review_20261105/proposed_geometry_scalar_checks.csv)已列 h100/d100 的相同 V2 数值，当前文件mtime为11月5日22:43；本批首次precheck清单mtime为11月6日15:33。运行脚本mtime早于这些结果，检查器mtime在首例运行期间。它们与“已有公式先预测、随后计算”的叙述一致，且本轮重算再次确认预测值相符。

但是，mtime可变且不是完整接触时间线；旧提案的本轮版本已含运行结果，11月5日审查所留旧提案hash与现版本不同。早期审查明确未建立正式预测合同，现有清单没有将运行前预测/判据文件hash绑定到该批运行；未找到可据此完整认证的事前不可变合同，也未核全团队是否预先接触相同条件的数值结果。不能据检查器中硬编码的 `criteria_frozen=true` 认证这些事实。

可确认：h100不是现有D2系数标定的h50/75/125九几何之一；固定舍入V2预测与较早保存预测表相符，本轮没有再拟合。可采用“未参与原九几何系数标定的新增间隙对照”。**暂不用“严格盲测通过”“独立预测能力已验证”**。这不是认定曾发生数据泄漏，而是限定已有证据能够认证的范围。

A的≤10%和构建差≤1%没有写在运行脚本头部；当前检查器含这些条件，文件时间线只能提供有限旁证，不能混称所有条件都已正式前瞻冻结。最稳妥正文写实际偏差，不依赖争议的PASS标签。
