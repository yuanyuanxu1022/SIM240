### 根因（不是"换个环境重导试试"，是可解释的机制）

对比 **A 初版** 与 **B 首重导版** 的图像对象字典：

| | A 初版（正常） | B 首重导版（损坏） |
|---|---|---|
| 跨槽热图色彩空间 | `/Indexed /DeviceRGB 15` | `/Indexed /DeviceRGB 15` |
| 位深 | `/BitsPerComponent 4` | `/BitsPerComponent 4` |
| **`/DecodeParms`** | `/Predictor 10 /Colors 1 /Columns 971 /BitsPerComponent 4` | `/Predictor 10 /Colors 1 /Columns 974` ← **缺 `BitsPerComponent 4`** |

图块是 **4-bit 打包**数据，但 PDF 的 PNG predictor 解码参数里**没有声明位深**，解码器按默认 8-bit 计算行宽 → 每行少读/多读，误差逐行累积 → 表现为**斜向色带**；掩码格因 SMask 与主图行偏移不一致，表现为**黑色三角**。

这正是 Codex 观察到的"斜向色带 + 黑区"，也是 Ghostscript 报 `recoverable image error`、Poppler 仍能勉强出图的原因（后者对畸形 predictor 更宽容）。

触发条件（**分级陈述，勿混为一谈**）：

- **已验证**：本机 matplotlib 为 **3.6.3**，A 初版由 3.11.2 生成；两份文件该处 `/DecodeParms` 记录确有差异（旧有 `/BitsPerComponent 4`，新无）。
- **推测，未验证**："只要用 3.6.3 走 imshow 的索引图像路径就会复现"是本轮**未做最小复现实验**的推广。未覆盖不同位深、不同图像尺寸与其他 matplotlib 版本的对照，故不能作为触发条件的充分性结论。
- **未验证**：字段差异是否为该渲染异常的**唯一**根因，本轮未做"仅补该字段后重新渲染"的对照实验。

修复有效性与上述两条解释无关：改后两种引擎渲染均正常（见下），这是对成品本身的验证。

### 修复方式：不走栅格图像路径

把热图从 `imshow`（光栅图像）改为 `pcolormesh`（矢量四边形）。数据、colormap、vmin/vmax、打印数值全部不变，只是绘制后端从"打包位图"变成"矢量几何"，**从根上消除了该解码路径**。

代码改动（`make_fig7_fig8.py`，附原因注释）：

```python
# 原：im = ax.imshow(G, ... interpolation="nearest")
# 新：矢量四边形，规避 3.6.3 的 4-bit DecodeParms 缺陷
xe = np.arange(len(DS)+1) - 0.5
ye = np.arange(len(HS)+1) - 0.5
im = ax.pcolormesh(xe, ye, G, cmap=cmap, vmin=0, vmax=vmax,
                   shading="flat", antialiased=False,
                   edgecolors="face", linewidth=0.4, zorder=1)
```

另修复：`pcolormesh` 下格子间出现细白缝，用 `edgecolors="face"` 消除；y 轴标签 `labelpad=6` 避免与刻度重叠。

## 三、Fig 7 说明段"平均化效应所支配"——已改为证据边界内的表述

**原文**：
> 能支持：…因此误差不是由单一的、对两个分量作用相同的平均化效应所支配。

**改后**：
> - **能支持**：两个分量对间隙 $h$ 的响应方向大体相反，且存在明确反例；因此**两个方向需要分别描述其误差及间隙依赖，不能用同一个相对误差函数完整刻画两者**。
> - **不能支持**：由这些整体趋势去识别或排除某种局部物理机制的主导地位。"平均化效应"在本稿中没有可检验的数学定义，也没有独立的局部耗散或分段阻力分解证据；整体输运系数及其误差趋势是空间积分量，本身不含有误差来源的空间信息。

理由：原句虽比"角部确定性归因"弱，但"由 X 所支配"仍是**排他性机制判断**，而整体 K 是积分量，无法支撑"排除某机制"。
