## 0 结论摘要

**问题一（程序是否等于 Celik 正式方法）：公式层面基本一致，但有一处判据不是 Celik 的、且在本数据下恒成立；另有一项 Celik 要求报告的量没有算。**

- 与文稿一致的部分：安全因子 `Fs=1.25`、观测阶闭式、外推式、`ea21`、`GCI_fine` 的定义与式(7)，以及"内层判据不过就不硬给阶"的拒绝逻辑，均与 ASME 文稿吻合。观测阶用闭式 `p=ln|ε32/ε21|/ln r` 而非迭代式，**不构成偏离**——文稿式(3b)后自注 "Note that q(p)=0 for r=const."，本算例 r21=r32=2 严格相等，故 q(p)≡0，闭式与迭代式逐位相同（已数值复核，见 §2）。
- **偏离一（实质）**：程序第 208 行把 `GCI_medium/(r^p·GCI_fine) ∈ [0.95,1.05]` 当作"渐近区判据"，并在第 220 行据此写出 `asymptotic range confirmed`。**这个比值判据不在 ASME 文稿步骤 1—5 中**（文稿表 1 也没有这一列）；而且当 r21=r32 时它恒等于 `φ1/φ2`，是一个恒等式（§2 已逐位验证）。因此该列的 PASS **不携带关于渐近性的信息**，"asymptotic range confirmed" 这个标注是错的。
- **偏离二（据 Celik 自己的判据，结论反向）**：文稿给出的渐近区判据是"观测阶与所用格式的形式阶相符"。按此判据，平板算例 p=1.991（形式阶 2）合格；但沟槽算例 p=1.513 / 1.256 / 0.938 / 1.088 / 1.098，只有形式阶的 0.47—0.76 倍。**即按 Celik 的方法本身，沟槽三网格不能被宣称为"已进入渐近区"**，而现在归档 CSV 与报告写的是相反的话。
- **偏离三（缺项）**：式(6) 的 `e_ext^21` 没有实现也没有报告。这是 Celik 步骤 5 明确要求"calculate and report"的量之一。

**问题二（稿件是否满足所引方法的适用条件）：当前稿没有过度声称，但有"引而不报"，且失败点未被带到引用处。**

- 稿件的核心口径是"以 5 nm 生产网格为参考"，§3.3 明确写"两级网格不能确定观测阶"，并明确不把三网格细网格估计套用到全部生产样点（第 264 行）。**这条边界与 Celik 的适用范围一致，没有违规**；§2.3 也已把"双网格差值即不确定度"改成"不作为离散误差界或不确定度估计"。
- 但 [10] 全文只在第 264 行被引用一次，**没有报告 Celik 步骤 5 要求的任何一个量**（p、φ_ext、ea、e_ext、GCI、Fs、r）。按该方法"estimation **and reporting**"的定位，这属于引而不报：审稿人问"你引 Celik，请给出表"时无表可给。
- 若任何图注、表注或回复信里出现"asymptotic range confirmed"，必须改口径（见 §5）。
- `K_perp` 细网格（1.25 nm）那次运行质量门 FAIL（1.197e-10 > 1e-10，独立 exit 3），而 GCI=0.551% 正是由该点算出。补充材料 S9 已披露该 FAIL，**但引用 GCI 的位置必须同时带上这条**，否则构成"用未过门的点算出的误差估计去支撑结论"。

**综合判定**：Q1 = **部分对应**（核心公式一致，渐近判据张冠李戴，缺 e_ext）；Q2 = **不违规但报告不完整**（口径保守，缺 Celik 要求的报告表，且渐近性结论方向需纠正）。两者都不使历史 FAIL 转 PASS，也不建立全图误差界。

## 2 "渐近检查"为何在本数据下是恒等式

程序第 208 行：

```
asymptotic_ratio = GCI_medium / (R**p * GCI_fine)
```

当 r21=r32=R，两个 GCI 的分母同为 `R^p−1`，故

```
GCI_medium/GCI_fine = ea32/ea21 = (|ε32|/|φ2|)/(|ε21|/|φ1|) = R^p · |φ1/φ2|
⇒ asymptotic_ratio ≡ |φ1/φ2|
```

这是恒等式，与"是否进入渐近区"无关。数值上逐位吻合（重算所得）：

| 指标 | p_obs | asymptotic_ratio（程序输出） | \|φ1/φ2\|（手算） | 是否逐位相同 |
|---|---:|---:|---:|:--:|
| K_smooth | 1.9909 | 0.9991621479849622 | 0.999162 | 是 |
| K_parallel | 1.5130 | 0.9981499297766432 | 0.998150 | 是 |
| K_perpendicular | 1.2562 | 0.9939159959945745 | 0.993916 | 是 |
| eta_parallel | 0.9398 | 0.9989869329914468 | 0.998987 | 是 |
| eta_perpendicular | 1.0884 | 0.9947494488247304 | 0.994749 | 是 |
| anisotropy | 1.0982 | 1.0042598507309783 | 1.004260 | 是 |

**含义**：`asymptotic_PASS=True` 只等价于"细网格与中网格之差小于 5%"。它是一个**网格差幅**指标，不是渐近性指标。因此：

1. `g2_richardson_gci.csv` 的 `diagnosis="asymptotic range confirmed"` 和 `G2_GRID_CONVERGENCE_REPORT.md` 中六行的 "Check=PASS / asymptotic range confirmed" **属于错误标注**，应改为"细/中两格相对差 <5%"或"asymptotic check: not applicable (degenerate for r=const)"。
2. 这条检查**永远不可能失败**（只要细中两格差 <5%），所以它不能被当作"方法已验证"的证据。这正好对上"收敛看起来稳定 ≠ 误差估计方法已被验证"。
3. 若要恢复这条检查的信息量，必须让 r21≠r32（例如用 5/2.5/1.25 与另一套 4/2/1.25 nm 混搭），或直接加第四套网格。

## 3 按 Celik 自己的判据重看渐近性

ASME 文稿原文（步骤 3 之后）："Agreement of the observed apparent order with the formal order of the scheme used can be taken as a good indication of the grids being in the asymptotic range; **the converse should not necessarily be taken as a sign of unsatisfactory calculations**."

| 指标 | p_obs | p_obs / 形式阶 2 | 判定 |
|---|---:|---:|:--|
| K_smooth（平壁） | 1.9909 | 0.995 | 与形式阶相符 → 可宣称渐近区 |
| K_parallel | 1.5130 | 0.756 | 低于形式阶 |
| K_perpendicular | 1.2562 | 0.628 | 明显低于形式阶 |
| eta_parallel | 0.9398 | 0.470 | 明显低于形式阶 |
| eta_perpendicular | 1.0884 | 0.544 | 明显低于形式阶 |
| anisotropy | 1.0982 | 0.549 | 明显低于形式阶 |

结论有三层，需分开写：

1. **平板算例**：p=1.99 与二阶格式相符，这一条是干净的、可宣称的。
2. **沟槽算例**：p 只有形式阶的 0.47—0.76 倍。按 Celik 的原话，这**不能宣称已进入渐近区**，但也**不等于算错**（"the converse should not necessarily be taken as a sign of unsatisfactory calculations"）。正确写法是"按观测阶报告 p，并注明其低于形式阶"。
3. **对 GCI 数值的影响**：GCI 对 p 敏感。若强行用形式阶 p=2，`K_perp` 的细网格 GCI 会从 0.551% 降到 0.255%（K_parallel：0.125%→0.077%）。本程序用 p_obs 计算，得到的是**偏保守**的值，这个选择本身是正确的；但不能同时声称"已确认渐近区"——两者不能并存。

**p 偏低的两个候选原因（推测，未验证）**：

- 沟槽 90° 拐角是几何奇性点，局部解非光滑，边界格式在角点邻域降阶；这与"平板 p≈2、沟槽 p<2"的对照一致。
- 三套网格保持物理加速度固定，格子加速度 `a_lattice ∝ dx³`（3.47e-10 / 4.34e-11 / 5.43e-12），对应的格子 Mach 数随 dx 变化。可压缩性误差不按 dx² 缩放，会混入观测阶。此项属推测，需单独算例才能分离。

**最小代价的补证方案（待用户裁定，本轮未执行）**：只对 `K_perpendicular` 加一套 0.625 nm（细网格再加密一倍），构成四网格。若 p 从 1.256 向 2 收敛，则支持"尚未进入渐近区但趋于渐近"；若仍停在 1.26，则是几何奇性导致的真实降阶，可写成结论而不是缺陷。代价约为 1.25 nm 那套的 4 倍（2D 格数）——注意 1.25 nm 已是三套中最贵的一套。

## 4 误差估计器本身唯一的独立校准（正面证据，建议写进补充材料）

Celik 方法估计的是"离散误差"，因此可以用**已知解析解**的算例反过来检验估计器本身。项目手里正好有：

| 检验 | 真误差（对解析解） | GCI_fine 估计 | 覆盖倍数 |
|---|---:|---:|---:|
| G2 Smooth75（h=75 nm，dx=1.25 nm） | 0.0272% | 0.0352% | 1.29 |
| G1 平板（`richardson_summary.csv`） | 外推值对理论 0.098% | 1.32% | 13.5 |

第一行覆盖倍数 1.29 与 `Fs=1.25` 的设计意图高度一致（GCI 应略大于真误差），这是目前**唯一一条说明"这个估计器在本项目里量级是对的"的证据**，目前没有写进任何文稿。第二行是更粗的平板配置，倍数偏大（保守），也不矛盾。

**适用边界必须同时写明**：这两条只校准了"平滑壁 + 良解析几何"下估计器的量级；**不能**用它证明沟槽几何的 GCI 可信——沟槽正是 p 偏离形式阶的那一类。
