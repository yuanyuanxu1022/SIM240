## 4. 观测收敛阶 p = 1.237，明显低于 2

```
p = log2( (K_coarse − K_mid) / (K_mid − K_fine) ) = log2(2.357048) = 1.2370
```

三档差额：`Kc−Km = 8.455173e-26`、`Km−Kf = 3.587187e-26`，比值 2.357。若为二阶收敛，加密一倍应使差额缩小 4 倍；实测只缩小 2.36 倍。

**Richardson 外推**（用实测阶）：`K_e = K_fine + (K_fine − K_mid)/(2^p − 1) = 4.337398287683e-23`。`K_fine` 与 `K_e` 差 **0.060944%**。

低阶的候选解释（按可能性排序，均未在本轮证实）：

1. **重入角奇异性**。沟槽两处 90° 凹角（x=0,z=d 与 x=120,z=d）在 Stokes 流中速度场有 `r^λ`（λ≈0.54）型奇异，导数无界，均匀加密无法恢复二阶收敛。这是该几何的物理事实，不是实现缺陷。
2. 尚未进入渐近区。`d32/d21 = 0.425`，理论二阶应为 0.25；0.425 说明可能仍在过渡段。
3. 迭代误差污染。若 `K_fine` 本身含 0.05% 量级的迭代误差，则 `K_mid−K_fine` 会被显著扭曲。**这一点正是 tight 层要排除的**。
