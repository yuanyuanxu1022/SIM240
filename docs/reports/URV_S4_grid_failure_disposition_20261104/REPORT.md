## 2. 已确认的失败是什么

原几何U_THIN：h30/d80/w120/P=Ly240nm，固定无滑移全充液单相，P沿槽+y、T横槽+x。nu=1e-6m²/s、rho1000kg/m³、a100000m/s²、tau1；K=nu·J/a，单位m³。三网格dx5/2.5/1.25nm；薄层分别6/12/24格。配置除网格和运行身份/路径外逐项一致，同一封存ELF。

中细差D=abs(K中/K细−1)，p=ln(abs((K粗−K中)/(K中−K细)))/ln2，GCI细=1.25D/(2^p−1)。按原规则，两项均须≤1%，还须单调、非近零差分、正有限p。

T超过门槛0.328387035个百分点。D与GCI衡量不同量；GCI使用观测阶和安全因子，不要求等于相邻网格变化。二者一过一不过在算术上相容，不是需改检查器的证据。重新计算与原独立网格报告一致。
