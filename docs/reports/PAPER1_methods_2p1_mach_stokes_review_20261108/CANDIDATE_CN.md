# §2.1 Mach数与Stokes条件候选（未合入）

建议替换当前“各算例的最大Mach数……”一句。保持所有原数值；不据本候选增加已验证范围。

以流场最大格子速度与D3Q19格子声速之比定义最大格子Mach数。补充材料S3所列已有记录中，各工况保存的最大格子Mach数介于 $5.7\times10^{-10}$ 与 $4.1\times10^{-7}$ 之间；其中最高值仍比所用低Mach检查阈值0.05低约五个数量级。这些记录支持所报告计算满足低Mach检查要求，为控制格子Boltzmann计算中的弱可压缩性影响提供数值依据，但不单独给出可压缩性误差界。低Mach条件不等同于可忽略惯性的Stokes条件，不能单凭上述数值认定全部算例满足Stokes近似。密度与稳态诊断分别报告（§3.1）；已有基准几何的驱动力线性检查及其范围见§2.4。
