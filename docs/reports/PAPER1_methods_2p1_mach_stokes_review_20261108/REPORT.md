裁定：当前Ma范围及与0.05的数量级比较可保留；“流动处于不可压缩区间”建议收紧为“所报告记录满足低Mach检查要求，支持控制LB弱可压缩性影响”。小Ma不单独证明密度恒定、误差为零、惯性可忽略或全图Stokes条件成立。

## 本轮依据

使用当前双语§2.1、§2.4、§3.1与附录E及当前双语补充S3。主科学数字按用户确认的当前口径保留；未采用旧状态/报告覆盖现稿，未读取原始运行记录重算Ma或Re。scientific-writing技能用于定义、范围及语义检查。

当前D2源码measure在流体节点上用computeU提取格子速度模长，保存maxLatticeSpeed；主循环按maxLatticeSpeed/sqrt(1/3)计算Ma并更新maxMach。这支持将所讨论量称为最大格子Mach数。当前代码语义不是每一历史运行的构建绑定证明。本轮只静态阅读，不执行CASE或验收轨迹。

公开依据：

- [OpenLB UnitConverter文档](https://www.openlb.net/DoxyGen/html/d6/d92/classolb_1_1UnitConverter.html)：getMachNumber采用特征格子速度与格子声速之比。实际保存的场最大Ma应以当前应用源码为准，不能误用单位转换器的特征速度值代替流场最大值。
- [MIT课程讲义§7.2](https://math.mit.edu/~dunkel/Teach/18.354_2014S/lecture_notes/L08_navier_stokes.pdf)：Re=ρUL/μ衡量惯性/黏性作用，忽略惯性另需依据。该来源只支持一般方法区别，不验证本文具体工况。关于LB不可压缩极限的一篇搜索结果正文403，未用其摘要充作全文核验。

## 逐项审读

| 问题 | 判断及建议 |
|---|---|
| Ma定义 | 应说明是格子速度/格子声速；D3Q19格子声速为sqrt(1/3)。该数值诊断不等于真实液体声速测量。 |
| 数值范围 | 保留5.7×10⁻¹⁰～4.1×10⁻⁷，不重新认定范围来源。当前补充S3报告跨工况范围，表S1本身没有逐行Ma列，因此不把它扩写为新h100、S4等所有后续记录的范围。 |
| 五个数量级 | 指范围中最高值4.1×10⁻⁷与0.05相比。threshold_comparison.json仅以现稿数值作比例核对，不是安全倍数、误差界或仿真重算。 |
| 0.05身份 | 按当前稿作为所用低Mach检查阈值，不能写成所有模型通用的“严格不可压缩分界”。 |
| 低Ma支持什么 | 支持所报告LB记录处于低Mach计算条件，有利于控制弱可压缩性影响；不能给出全图压缩性误差界或物理验证。密度诊断应分别报告。 |
| Stokes要求 | 忽略惯性须有独立依据，通常用定义清楚U、L的Re=UL/ν等判断；稳态条件也另行检查。低Ma不直接给出低Re。特殊流动结构可能使某些惯性项消失，不把Re≪1说成一切Stokes形式的唯一来源。 |
| 当前主地图Re说明 | 在当前双语正文未找到主地图Re定义和数值范围；Reynolds平均模型的名称不是流动Re诊断。本轮不据此认定实际Re大，也不宣称所有工况的低惯性已逐点核实。 |
| 驱动力线性 | 当前§2.4已有h75/d100、2.5 nm、所检驱动力范围内线性支持，并明确不是36条主地图逐点多力检查。不能拿该单几何结果替代全图低惯性检查。 |
| 理论上界 | 附录E是在理想连续Stokes假设下的条件性结论，Ma检查不认证离散结果精度或V2准确度；本轮不重审或重写定理。 |

这是表述链的范围问题，不是本轮发现了新的求解器失败，也不据此要求新仿真。若后续需要补齐主地图Stokes适用性的定量说明，先定义物理U和L，并查看已有物性/速度/几何记录是否足以整理Re；这属于另一项审查，本轮没有计算、采用新Re或另立阈值。
