### 2.2 各向异性比误差（**本文件新增计算**）

论文的核心量不是单方向导度，而是**各向异性比 A = K∥/K⊥**（同样液体占比下方向性输运强不强）。这个量的误差由两方向误差共同决定，且带符号偏差可能部分相消或叠加：

| 方案 | 留间隙 A比 MAE/最坏 | 留槽深 A比 MAE/最坏 |
|---|---|---|
| G4 | 2.78% / 6.36% | 2.21% / 5.93% |
| G6 | 2.99% / 4.12% | **1.53% / 3.48%** |
| **混合C（P取G4、T取G6）** | **1.43% / 2.17%** | **0.85% / 1.63%** |

**关键发现**：
- 按 A 比指标，**G6 整体优于 G4**（与单方向印象相反——G4 的两方向误差在 A 比中部分叠加，G6 的横槽优势抵消了沿槽劣势）；
- **混合方案 C 的 A 比误差是三者中最小的**（约 1–2%），因为取了两家的长板。

### 2.3 混合方案 C 的结构风险检查（**本文件新增计算**）

混合方案的理论顾虑：G4、G6 各自都保证"横槽导度 ≤ 沿槽导度"，但两式来自不同拟合，拼起来后这个物理顺序**不能自动继承**。检查结果：

- 目标矩形（0.8≤w/h≤3.2，1/3≤d/h≤1.6）6561 个抽查点：**0 违反**；
- 扩展域（s 从 0.001 到 1000，t 从 1e-7 到 1e4）10201 点：**0 违反**。

即在已检查范围内，混合方案不破坏物理顺序约束。注意：这是有限扫描证据，不是代数证明；6 条物理性质中其余 5 条（d=0 平板退化、上下界、单调性、λ³ 缩放）因两式各自成立，混合后自动保持。

### 2.4 参数稳定性（已有的证据，如实摆出）

- G4：3 次留间隙拟合中 2 次触参数下界；G6：3 次全部触下界；
- 触界意味着"只剩两层间隙数据时，沿槽公式里控制宽高比响应的指数定不出来"——**不是公式错，是数据量不够**；对新槽宽（w≠120nm）的预测，这个指数最不可靠；
- 两个模型在此项上都不干净，G6 稍差（3/3 vs 2/3）。

## 3. 三个选项

### 选项 A：G4 单一公式（原推荐）
- 优点：结构最简（4 参数）、两方向一套体系、沿槽最准、单方向误差全部 ≤3.4%；
- 缺点：论文核心量 A 比误差最大（最坏 6.36%）；横槽明显不如 G6。
- 适合场景：老师若最看重"沿槽输运量"或要求"两方向必须同构"。

### 选项 B：G6 单一公式
- 优点：A 比整体误差小于 G4（留槽深 1.53% vs 2.21%）、横槽压倒性优势、薄间隙表现更好；
- 缺点：沿槽单方向最坏 4.78%（三方案中最差）；参数触下界 3/3；结构多 2 参数。
- 适合场景：老师若最看重"各向异性/方向对比"——第一篇的科学主张正是方向性输运。

### 选项 C：分方向混合（沿槽 G4 + 横槽 G6）★ 本草案倾向
- 优点：**每个方向都用最准的那套**（沿槽 2.00%/0.95%，横槽 0.58%/0.29%），A 比误差三者最小（1.43%/0.85%）；结构风险已扫描排除；
- 缺点：①"两方向用不同公式"在论文中需额外一段方法学说明（为何允许：两方向物理机制不同——沿槽是持续流道、横槽是串联瓶颈，本就无强制的同构理由）；②终审工作量翻倍（两套系数都要锁）；③其余物理性质的代数证明需重新组织（非重推，G4/G6 各自的证明分别适用于各自方向）。
- 适合场景：老师若接受"分方向闭合"，这是精度最优解。

**本草案的倾向是 C，但明确标注：这是基于数据的倾向，不是已定结论；最终选择权在老师。** 若老师只接受单一公式，则在 A/B 之间按"A 比误差 vs 沿槽单方向误差"哪个更重要来定。

## 4. 预测冻结规则草案（无论选哪个方案都适用）

**冻结的定义**：公式形式 + 全部系数 + 适用域 + 逐点预测表，四者一次性锁死，此后只允许加数据，不允许改结构重拟合再宣称"同一模型"。

### 冻结前必须完成（缺一不可）

1. **规则先行**：用户与老师先书面确认选择（A/B/C）和验收标准（建议：留组 A 比与单方向 MAE 均 ≤3%、最坏 ≤5%；若采用更严标准须在看到新数据前声明，不得事后放宽）；
2. **独立预测验证（核心缺口）**：用 D4 保留预测组做盲测——这是唯一真正独立的"新槽宽"数据。**【2026-10-23 23:00 更正：预测组 8 个几何（h60/h100 × d40/d80 × w90/w180，共 16 个方向）目前尚未计算**——盘上只有 foundation（地基 8 项，独立验收 PASS）和 development_screen（开发筛选）两阶段结果，预测组仅完成零步预检。**盲测的正确顺序因此是**：① 老师/用户先拍板方案与验收标准 → ② 授权运行预测组 16 个方向计算（tmux 后台，按长仿真规矩由用户启动）→ ③ 由 WorkBuddy（GLM-5.3，拟合方之外的第二套独立实现）读取结果、按已声明标准判 PASS/FAIL。**注意：预测组几何 s=w/h 覆盖 0.9–3.0，比开发集（1.6–2.4）宽，本身就是对"参数触下界最敏感的宽高比方向"的直接检验**；
3. **h25 网格澄清**（若老师要求薄间隙可用）：h25 在 dx=5nm 仅 5 格的等效误差约 42%（此前独立审计结论），冻结前须决定"薄间隙档是否纳入适用域"或补 dx=2.5nm 算例；
4. **冻结终审**：上 GPT-6 Astra｜High（按 2026-10-23 额度规则，这是四类必上场景之一），对公式、系数、适用域、预测表做最终审查；通过后写入 model_lock 文件并同步 GitHub。

### 冻结流程（建议顺序）

```
老师拍板方案与验收标准（书面）
→ 授权并运行 D4 预测组 16 方向计算（用户 tmux 启动，2026-10-23 核实：尚未计算）
→ WorkBuddy/GLM-5.3 独立读取，按冻结前已声明的标准判 PASS/FAIL
→ PASS：Astra 终审 → model_lock + GitHub 同步
→ FAIL：如实记录，回到候选改进或补数据（不得放宽标准硬过）
```

### 明确不做的事

- 不因"误差已经很小"跳过盲测直接冻结；
- 不在看到保留组结果后修改公式或标准再宣称通过；
- 不把 G4/G6 的"物理约束结构"说成"精确解析解"；
- 不自动启动任何新仿真（D4 剩余开发几何、网格加密等均需另行授权）。
