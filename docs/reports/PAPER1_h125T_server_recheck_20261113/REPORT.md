## 3 结论：数值条件已具备，资格仍未授予

**可以说的**：h125/d120 T 在服务器续跑后已原生收敛（SIMPLE converged，日志记累计 131278.5 次迭代，本次续跑 99378 轮，exit 0），三项自洽（残差、功率 0.0390%、网格收敛 0.0488%）均通过冻结门槛的数值要求。

**不能说的**：

1. **不能宣布"已取得参考资格"。** 服务器产物目录没有 `runtime/receipt.json` 与 `exit_code.txt`（仅 `logs/*.status` 记 solver exit=0），也没有走 `read_case` 的正式接收链。按既有规则，回执存在不等于 LOCAL_CHECKS_PASS，何况回执本身缺失。
2. **不能忽略执行链是跨机器拼接。** fine 是"本地 0.5→31900.5、服务器 31900.5→131278.5"两段拼成的连续轨迹。跨机器数值等价此前有逐位相同实证，但这属于需要在验收文件里**明写的偏离**，不能被当作单一连续运行。
3. **不能据此回头改历史记述。** 此前"exit 124、无完整末态证据"对**本地那次运行**仍然成立；服务器续跑是后续事件。

**因此正确的状态是**：`NUMERICALLY_CONSISTENT_BUT_NOT_QUALIFIED`——数值自洽已复算通过，正式参考资格待按协议验收（补回执、写明续跑偏离、完成接收链）。
