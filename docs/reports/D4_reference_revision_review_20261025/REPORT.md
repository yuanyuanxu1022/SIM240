原规则对每个几何分别要求KP、KT、A的E(5对1.25)≤1%、E(2.5对1.25)≤0.5%，并满足预设趋势。d25/d120、w60两窄槽共5FAIL/1PASS。六条数列均单调且差值收缩，不能用趋势合格覆盖差异大小失败。

具体影响如下：

1. **5 nm结果仍是合格的固定分辨率开发记录。** 其收敛、守恒、来源和保存流场的阶段验收没有被推翻；但不能再附带“所检窄槽满足≤1%的原粗格差异目标”这一承诺。独立退出码、NUMERICAL_GATE、geometry_PASS、源RESULT_PASS与网格目标分别保留。
2. **1.25 nm仍是最细的已计算结果，不是真值。** 条件性GCI诊断中KP约0.217%–0.225%、KT约0.581%–0.594%、A约0.438%–0.460%；这些不是严格误差界或独立渐近性证据，尤其不能把横槽0.67%的两格差值改称物理误差上界。条件观测阶约0.921–1.537，不强制二阶。
3. **不能由两个窄槽判定所有训练点的网格误差。** 当前证据只有h75、w60、d25/120三格；宽槽w240只有两格。旧训练w120跨h/d、拟议w/h与d/h域及保留组其他几何的参考精度均需独立覆盖。也不能认为更宽必更易、把某个百分数乘到全矩阵作为修正。
4. **不能直接宣布换成2.5 nm解决。** 窄槽KT的2.5对1.25差仍约0.66%–0.67%，已超过旧0.5%目标；继续细化只会给旧粗格的偏差提供更多证据，不会自动修复旧粗格。
5. **没有证据定位唯一根因。** 台阶/角点处理、壁面误差、积分方式、低Mach/舍入、停止误差及联动时间离散应分项排查；q=.5、总体积正确和很小的Mach不能单独证明其余误差可忽略。当前证据不足，无法判定哪一项主导。

NASA NPARC教程说明三格观测阶、Richardson外推/GCI及其渐近假设，也说明观测阶可能低于形式阶；本项目把它们作为条件诊断。**原1%/0.5%目标是本项目预先选定的研究容差，不来自NASA，也不是连续解误差界。** [NASA方法来源，2026-10-25复核](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)。

## 3. 对G4公式及F、阻力评价的实际影响

同一几何令Q表示KP、KT或A，Q5为5 nm记录、Qf为某更细记录，M为保持不变的锁定公式。定义e5=M/Q5−1、δ=Q5/Qf−1，则有**精确恒等式**：

`ef = M/Qf − 1 = (1+e5)(1+δ) − 1`。

不能把“模型绝对偏差”和“网格差异”直接相减，不能假定细化一定让模型更准。下表全部是已知开发几何的诊断，有符号百分比；未改原合同或主评分。

|h/d/w（nm）|量|相对5 nm的G4偏差/%|相对2.5 nm的偏差/%|相对1.25 nm的偏差/%|
|---|---|---:|---:|---:|
|75/25/60|KP|+0.392374|+1.315889|+1.647587|
|75/25/60|KT|−2.293986|−0.724560|−0.058736|
|75/25/60|A|+2.749432|+2.055342|+1.707325|
|75/120/60|KP|+1.053668|+2.017806|+2.354356|
|75/120/60|KT|−0.802596|+0.772618|+1.438256|
|75/120/60|A|+1.871284|+1.235642|+0.903111|
|75/120/240|KP|+3.652525|+3.889240|未计算|
|75/120/240|KT|+2.025464|+3.133396|未计算|
|75/120/240|A|+1.594759|+0.732880|未计算|

窄槽KT偏差因更细参照移动约+2.24个百分点；d120的KT还发生偏差符号变化。窄槽KP的偏差反而增大约1.26–1.30个百分点。**当前证据说明参照分辨率足以改变对公式的判断方向；不支持“细格证明公式全面改善”或“网格失败证明公式错误”。** 更细参照并没有改变G4的解析正值、退化或方向结构，但其宽度规律、饱和量值、参数取值与连续物理精度仍需合格参考验证。

定义链保持：Kf=h³/12，Ki=Kf(1+Ei)，基准理论Ki,base=Kf(1+Li)，修正Fi=Ki/Ki,base=(1+Ei)/(1+Li)，阻力修正为1/Fi。对同一精确几何，基准理论不随dx变，因此F的相对模型偏差与K相同；不能通过改归一化把网格误差消掉。在相同μ及阻力定义下R∝1/K，`eR=Rmodel/Rref−1=−eK/(1+eK)`，正负及幅值均不等同于eK。A必须取同几何同网格两方向之比。

若以后用新开发数据更新G4，网格偏差可能被拟合参数吸收；更好的训练误差不等于连续物理规律更可靠。旧参数触界、删层敏感性等记录保留，不能在没有分析时认定这些问题全部由网格造成。公式本身仍为有物理约束的经验闭合，不因维度分析或本轮比较成为流动方程的严格解析解。

## 4. 误差预算：保留原目标，另写物理解释条件

原G4 v1目标为P/T/A各自MAE≤3%、最大绝对偏差≤5%，相对原5 nm数值参考。它们不能直接改称相对连续物理值的3%/5%。数值收敛窗口的1e−6等门槛也不是K相对连续解的误差上限。

假设将来有独立充分的证据，使每个量的数值参考满足`|r|=|Qref/Q*−1|≤u`，则同一恒等式给出`|e*|≤|eref|+(1+|eref|)u`。**这里只是附条件的代数推论，当前没有建立这个u的严格界。** 例如u=0.5%时，相对数值参考的3%/5%最多只支持上述不等式下的3.515%/5.525%；若坚持相对Q*的3%/5%，相对参考的充分条件分别约2.487562%/4.477612%。这些数字是预算示例，不写入或替换原评分门槛，不从GCI或两格差值冒充严格u。

A误差需单独控制。如果只知两方向各自|rP|、|rT|≤u，Aref/A*=(1+rP)/(1+rT)，保守界为2u/(1−u)。u=0.5%时约1.005025%，并不能推出A也≤0.5%；即便已观察到两方向偏差相关，也不能默认全域抵消。阻力的相应参考界为u/(1−u)。因此数值参考预算必须分别列P/T/A，以及需报告的倒数阻力。

供审阅的**新预算建议**是：将合格参考的条件误差估计目标设为P/T/A各≤0.5%，并另外要求加强停止检查所致K/A变化≤0.05%。0.5%用于在3%模型平均偏差目标下留出较小的数值参考份额，0.05%是其十分之一的迭代稳定性预算；二者都是本轮看过结果后提出、尚未批准的研究目标，不是误差定理，不能改变旧FAIL。新版本必须同时说明估计器可靠性证据及各误差项关系，不能机械用RSS或假定独立的统计合成。当前最细KT条件GCI仍超过这一拟议0.5%目标，也未获得独立渐近性证据，故本轮不选定1.25 nm作已合格新参考。
