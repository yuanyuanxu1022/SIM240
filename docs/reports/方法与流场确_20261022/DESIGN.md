# DESIGN.md — 方法与流场确认材料（导师审阅版）

## 设计依据

命中预设风格：**学术风**（design-principle.academic.md）。场景=科研汇报/导师审阅，蓝白克制、证据驱动。本设计文档仅记录对该预设的落地参数与素材映射，不另造风格。

## 母版

- 页眉：A3 模式（深蓝顶条 56px 高 + 右侧页码），内容页全篇锁定。封面/目录/扉页/结束页省略页眉。
- 页脚：y 660–700，左=「SIM240 · 第一篇论文方法确认」14px 灰 #8B97A8，右=页码 NN/18 深蓝 14px。
- 画布 1280×720，安全边距左右 40。
