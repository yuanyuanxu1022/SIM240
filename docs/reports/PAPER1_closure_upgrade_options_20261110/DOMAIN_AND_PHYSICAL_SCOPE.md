# 参数覆盖与物理验证：闭环补强的两个独立方向

日期：2026-11-10。用户追问是否还有超出点状、理想模型内验证的方法。本轮为方法澄清，未新增计算、数值验收、模型证明或执行授权；当前母稿不改。

## 裁定

“独立参考试点只验证所查理想模型条件”正确；不能据此把当前所有贡献称为点状。当前附录E/E.1的上下界是满足其假设的一类连续问题的结构约束，数值误差与V2精度仍没有全域证明。物理真实性和参数域覆盖是两个独立维度；有限实验也不证明全域。

## 路线

1. 无量纲与尺度相似：对固定占空比、直矩形槽、无滑移、恒黏度Stokes模型，以w为尺度，可写K_i=w^3 f_i(h/w,d/w)。这是本轮按现有量纲和方程缩放给出的条件性推论，不是新算例或V2认证。几何同比放大lambda时K_i乘lambda^3；仅沿相似几何族拓展，不覆盖不同h/w、d/w。有限惯性、滑移长度、圆角等新增参数需另纳入。
2. 从点走向明确参数域：先定义有限D，再为K建立可核验区间或参数敏感度界，对参数子区域给误差包络；普通加密采样、代理拟合、逐查询证书均不自动成为连续D的统一保证。可评估带后验误差控制的降阶基方法，但必须另外控制高保真离散误差、稳定性常数和导度输出误差。成本/适配未核，不建议仅为使用先进名称立刻建设整套框架。
3. 解析或渐近结构：平板极限与现有界可作起点，其他极限必须明确无量纲极限路径并推导，矩形台阶不能直接套光滑薄膜展开。极限式加余项控制才可能支撑一段参数区域；只拟合趋势不能代替。
4. 模型假设稳健性：在有来源的几何/物性/边界不确定范围内，检查主要结论是否翻转；无测量来源的扰动范围只能算假设情景。它加强结论的条件稳健性，不构成实验物理验证。
5. 物理外部证据：匹配且具有足够元数据的公开实验可复用，不强制自己新做实验。几何同比放大的低Re、近无滑移实验可测Q-压差及方向比，检验相似几何阻力规律；不能直接认证纳米壁面、材料效应。真实纳米尺度实验才直接针对这些具体假设。实验几何与物性应独立测定，避免用同一流量反拟合参数后又称独立验证。分子动力学是另一模型层次，不自动替代实验。

## 建议

第一篇若保留理想模型定位：先写清无量纲参数及理论命题覆盖范围，再做前轮独立参考试点；是否发展域内认证取决于实际需承诺的精度。若目标是超出理想模型，则优先评估匹配公开实验或相似实验条件，而非无限增加同类计算。没有一项方法同时保证所有参数、所有物理机制与真实工艺。未选定参数域或新精度门槛。
