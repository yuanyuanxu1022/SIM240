## 2. 对所贴意见的裁定

| 所贴说法 | 裁定及原因 |
|---|---|
| “环A零证据”“前三级都用自己5nm作参考” | 不成立。已有平板解析解、加密、守恒及边界检查对不同问题提供部分证据；解析基准并非自己算出的5nm值。正确缺口是没有同一显式沟槽的独立高精度参考，也没有全地图连续解误差界。 |
| “只能另一个求解器或实验，没有第三条路” | 不成立。匹配解析/半解析解、已验证高精度基准、可计算后验误差界也能加强数值解证据。实验承担物理模型验证，与方程求解正确性是不同任务，不能混成必须逐级登上的五级台阶。 |

判断“自己家里/外面”不是可靠分类。关键是基准是否来自独立数学信息、算法/实现误差如何控制、对应哪一个声明，而非作者是否不同。两个软件同意也可能共享边界、几何或归一化错误；不同数值方法与独立网格能减少部分共同误差，仍非物理真实性证明。

## 3. 第一优先：同一显式几何的独立二维解

在稿件既定模型内，几何沿y平移不变、壁面静止无滑移、全充液、周期且满足Stokes。可利用该结构对同一个理想边值问题降维：

- 沿槽y：u_y=u_y(x,z)，u_x=u_z=0；解−μ(∂xx+∂zz)u_y=G_y，是二维标量Poisson问题。
- 横槽x：解(x,z)中的二维速度—压力Stokes系统，保留不可压约束、竖壁/台阶、壁面无滑移与x方向周期驱动；不是局部立方律或平均Darcy阻力。
- 用截面D的全流体积分提取J_i=(1/P)∫_D u_i dx dz，K_i=μJ_i/G_i；与原3D定义一致，因为沿y不变且A_plan=P L_y。坐标、压力宏观驱动/周期扰动和几何高度须一致。
- 建议独立贴体三角网格、稳定混合有限元或适用的散度受控方法，并对角点附近作目标量导向加密。普通Taylor–Hood可作交叉对照起点，但不自动具有严格无散度或误差认证性质。

可考虑FEniCSx或同类独立有限元平台；官方有二维Stokes/Taylor–Hood基础例程。这个例程是方腔流，不是周期沟槽成品，必须另建周期约束、压力规范、槽几何与积分。尤其不能将两侧也设成无滑移而复制腔流边界：封闭域的均匀体力可以被压力梯度抵消，得到的零流不是本周期输运问题。

这种二维处理是对上述Stokes模型的结构性简化，不额外平均掉槽腔；它不直接证明原3D LBM每个离散运行已满足Stokes极限。横槽若保留有限惯性则是另一问题，因此仍需核对已有Re/力幅适用证据，不能仅拿低Mach替代。

### 最小试点（未授权执行）

1. 新参考程序先做平板已知解核验、边界/周期与驱动检查，并记录源码/环境/收敛。
2. 用两个已有几何h75/d100与h25/d100，各沿/横方向，构成4条方向比较。前者接基准链，后者针对V2最坏横槽残差和参考敏感性。尺寸单位nm，保持w120/P240/占空比0.5。
3. 参考端至少检查独立网格/阶次加密及线性代数误差，比较K、沿截面通量、守恒和驱动功—耗散；能量闭合是内部检查，不能单独认证精度。
4. 结果表并列原5nm、已有2.5nm、新参考及其误差证据、LC与固定V2。不得为追求一致而调几何、V2或容差；不合则先查差异。

## 4. 更强路线：对连续K建立可计算夹逼

文献已有针对Stokes的平衡通量/应力重构、Prager–Synge型后验误差控制。目标从“两个软件接近”变为“所解连续问题的K落在可核验区间内”。此处文献给的是速度能量误差框架，导度输出需再适配，不直接声称获得K证书。

当前附录E.1已有变分身份：对满足无滑移、周期及相应不可压条件的试探速度v，L_i(v)=[2ℓ_i(v)−a(v,v)]/P≤K_i。现有简单试探只给h³/12；优化更丰富的可容许试探场可能提高下界。一般离散速度的散度仅弱满足时，不能直接塞进该式充当严格下界；LBM节点场也不能未经可容许重构直接使用。对上界可研究满足平衡/周期条件的对偶通量或应力重构。最终期望0<L_i≤K_i^*≤U_i，且区间足够窄。

必须区分：稿件现有h³/12≤K≤K_LC是基础物理/变分约束，部分区间很宽；LBM值在区间内只表示相容，不能视为已经认证数值精度。后验方法需解决周期面、台阶角点、常数、散度/应力平衡、积分与代数误差等条件。若要求严格包含浮点舍入，还需可靠数值界定，不能只凭残差很小自称机器可证。

有了K区间且K_formula>0，可将公式相对连续解的偏差约束为：

$$
\left(\frac{K_i^{\mathrm{formula}}}{U_i}-1\right)100\%
\le\varepsilon_i^*\le
\left(\frac{K_i^{\mathrm{formula}}}{L_i}-1\right)100\%.
$$

这是区间单调性的条件推论，不是本轮得到的新数值结果。若区间仍跨过“改善/恶化”的分界，应报告不能判别；若足够窄，才可能将某个薄隙点的判断从“随网格改变”推进到“对该连续模型可分辨”。它仍不验证真实材料、润湿或实验物理。没有承诺这条路线在本项目能以小成本得到窄界。

## 6. 推荐顺序与证据意义

优先顺序：同一槽几何独立二维解的可行性/配置契约 → 两已有几何四方向试点 → 视需要加入输出误差控制/夹逼 → 再冻结少量新几何检验V2。不是先用更多OpenLB开发点加固一个尚不够稳的参考，也不是断言一定要推到实验才能完成理想模型论文。
