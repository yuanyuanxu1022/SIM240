# 论文主线讲述稿（审查候选，未合入正式稿）

本文评价一个明确的局部简化：在固定、全充液的矩形槽中，把深区和浅区分别当作平行平板，再按沿槽算术平均、横槽调和平均组合。这种构造简洁，适合未逐槽解析的平均模型；我们关心的是，它在指定几何族中偏离显式沟槽结果多少，以及偏差会带来什么后果。

第一步，限定问题。主集合固定槽宽120nm、周期240nm、等宽槽与凸台，在18种已采样几何上分别计算沿槽和横槽导度。间隙与槽深覆盖给定尺寸，但不是连续参数域的完整扫描；问题不只由槽深/间隙之比决定，还受相对槽宽尺度影响。该研究限定静止壁、无滑移、常黏度与全充液，不承担实际压印过程精度验证。

第二步，建立可比的离散比较。显式几何计算与局部模型采用一致的目标尺寸、物性、理想边界及深度积分通量定义。原36条5nm方向结果用于主统计，已有加密与新增间隙结果单列。它们提供指定网格下的数值比较，网格敏感性和构建来源限制同时报告。

第三步，量化幅度及其后果。局部模型在原36条主方向结果上均高估导度，且两个方向的偏差不同。除了分别报告偏差，还检查导度比与同一线性张量关系重建的流向：在h75/d100基准几何下，离散参考与局部模型的方向比分别约2.21和3.70，45°驱动下重建通量方向相差9.20°。这说明使用模型时，两主值及其比值都需要检查。

第四步，把理论约束与结构诊断分开。连续Stokes问题中的基础上下界约束导度范围，解释局部模型的上界性质，不给出具体偏差百分数。对另列的h75/d120、w60/240两宽度组，再用相对局部平板基线的全域梯度能量分解诊断额外阻力，观察到所定义分组中的方向与宽度依赖。该诊断提供所测条件下的结构解释，不宣称覆盖整个主图或辨识出独立侧壁、尖角原因与唯一控制尺度。

第五步，评价有限修正并保留失败。保持公布四参数V2不变，在同一原36条主结果中，35条绝对偏差减小；同时保留h25/d100横槽的局部恶化、参考网格影响及构建来源限制。V2是回顾性经验描述，论文的价值不依赖把它改成普适准确公式，也不通过删除最坏点来维护其表现。

可用一句话概括：**在明确几何、定义和参考条件下，把一个局部简化的双向偏差、使用后果、受限解释与修正边界逐项对应到证据。**
