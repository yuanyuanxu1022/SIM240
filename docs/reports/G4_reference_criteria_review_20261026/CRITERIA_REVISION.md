## 1. 适用问题和统一符号

本稿使用无量纲坐标，常黏度系数已归一为1。混合问题为

`−Δu + ∇p = f, div u = 0`，

`a(u,v) − (p,div v) − (q,div u) = (f,v)`。

固壁静止无滑移，成对周期面的速度、压力扰动及测试函数迹匹配。显式体力与等效压降只取一种，压力p是周期扰动压力，不能再包含已由体力表示的线性压降。标量沿槽为`−Δv=f`，不构造虚假的横槽速度/压力场。

`Q`在预算节专指正的方向迁移率K；A=KP/KT。MMS非均匀源项的Jhat不是K，矩形方法资格的MMS误差条款不混入沟槽K预算。所有相对指标分母须有限、严格正，输入缺失或分母为零时为INVALID/INCOMPLETE；零场合成夹具单列绝对误差，不冒充驱动问题的通过记录。

## 2. 连续性：三种量各有用途

### 2.1 离散弱连续性：检查方程有没有解对

对**约束后的独立压力测试基**ψj，记录`cj=∫ψj div uh`。周期从属压力基要按原MPC变换聚合到主基，不对每个未约束局部基分别要求为零。壁面、从属占位行和压力规范处理须有明确行映射，不用索引猜测。

沿用原无量纲系统、原基底和行缩放，令`r=b−Ax`，I_p为独立物理压力行集合：

`eta_c=||r[I_p]||2 / ||b||2`，`eta_all=||r||2/||b||2`。

候选门槛均为`≤1e−10`，每个未来混合/横向方法记录均适用，ALG对照保留其更紧的完整残差目标。不能除以为零的连续性右端，也不能在改行缩放后沿用旧数值而不另审。

以本项目负连续性符号，齐次连续性右端下r[I_p]对应聚合的c。独立单元积分c与矩阵压力残差另作一致性核验；其浮点比较容差须按F02冻结，未实现时不能称该复核通过。完整残差小已蕴含所抽子块小，因此两项不是两份独立精度证据。保留c的物理积分路径用于发现矩阵/映射/提取不一致。

### 2.2 强散度：检查局部不可压缩程度

`eta_div=||div uh||L2 / ||grad uh||L2`，另报`∫div uh`及逐单元散度积分/范数。

P2速度的散度一般为不连续P1；连续P1压力空间无法测试其全部分量。因此弱残差近零不意味着eta_div近零。**删除新参考草案中对所有P2/P1场一律要求eta_div≤1e−6的候选条款**，改为每网格必报指标、网格变化与截面关系。此项没有统一PASS阈值，也不能据此豁免通量和空间精度检查。

光滑MMS加密时散度不下降是调查信号；没有固定理论常数和误差分辨条件时不据单一非单调点判整个方法错误。真实沟槽角点不得套用光滑解的阶数保证。沿槽标量问题在`u=(0,v(x,z),0)`且∂y=0的约定下连续性解析成立；对应混合压力/横槽截面指标标NOT_APPLICABLE，不写实测0。

### 2.3 截面流量：检查所用流量的空间一致性

仅对混合MMS、平板T及真实横槽T：`q(x)=∫液体截面 ux(x,z) dz`，`Jhat=P^−1∫Ω ux dA`，

`eta_q=max_registered_sections abs(q(xj)−Jhat)/abs(Jhat)`。

采用原登记7个截面x/P={1/8,1/4,3/8,1/2,5/8,3/4,7/8}；真实沟槽还必须事前登记两槽口竖壁位置两侧的截面，具体坐标随几何合同冻结。不得看结果挑截面。截面只穿流体，P2分片积分，单元边重合只计一次。

推荐`eta_q≤1e−6`用于未来**最细**混合MMS N32、每档平板T、作为参考交付的最细沟槽T及相应最细对照；粗/中MMS和沟槽只报告诊断。该门槛是项目的通量一致性要求，不由Taylor–Hood弱式自动保证。未满足则该参考通量检查FAIL，不等于方法原则错误，不自动改用更宽门槛。

有限截面检查的证书只能写“登记截面一致性”。另核相邻登记截面间控制体：

`q(xb)−q(xa)=∫Ω[a,b] div uh dA`

（固壁零通量；若壁迹有缺陷需显式保留壁通量项）。这检验提取链与散度积分一致性；恒等式成立不意味着其两端差都小。七个点不保证截面之间没有峰值。若未来论文需“所有截面”的保证，必须另做全区间极值或经证明的全域界，不自动扩大本合同。

## 3. 能量：三项分别检查，不允许抵消掩盖问题

定义

`D=∫Ω grad uh:grad uh dA`，`W=∫Ω f·uh dA`，`Pdiv=∫Ω ph^0 div uh dA`，`S=max(D,abs(W))`。

ph^0是面积去均值压力。当前正驱动问题要求D>0、W>0且有限。**分母不含abs(Pdiv)**，防止压力异常增大时把检验自动变松。

取测试速度v=uh、q=0，得`D−Pdiv−W=0`；取v=0、q=ph^0，得`Pdiv=0`。故对精确解或精确积分下充分解好的本离散方程有`D=W`。据此分别保存：

|指标|明确定义|推荐门槛/适用|
|---|---|---|
|弱动量能量余额|abs(D−Pdiv−W)/S|≤1e−6；所有未来方法基准与沟槽记录|
|压力连续性功项|abs(Pdiv)/S|≤1e−6；所有未来混合/横槽记录|
|功率与梯度能量直接余额|abs(D−W)/S|≤1e−6；所有未来方法基准与沟槽记录|

三条分别满足，不能只凭其中一条通过；两个≤1e−6的分项只给和≤2e−6，故直接余额必须单独核验。标量仅检查abs(D−W)/S，压力项为NOT_APPLICABLE。

不把整个混合向量的xᵀAx直接叫作D：本对称块的该二次型包含D−2Pdiv（另需处理约束占位行）。动量能量式要从速度测试部分或独立单元积分提取。

这些是拟采用的内部一致性门槛，不是速度、K或总误差≤1e−6的证明。能量式对粗网格的离散解同样成立，所以可以检查各档；这与仅在最细场要求通量空间一致性有本质不同。MMS须用其实际非均匀f，平板/沟槽单位体力才可令W=∫u_main。压力规范平移不应改变Pdiv，另报`∫div uh`核全边界通量；不以去均值掩盖边界错误。

既有N8的历史代数诊断验收不被追溯改判；未来只读提取时可按新定义记录指标和“候选准则比较”，须另标ANALYSIS_ONLY，不能倒填原验收器为物理PASS。

### 3.1 梯度能量与黏性耗散的差别

令`ε(u)=(grad u+grad u^T)/2`，`Dsym=2∫ε(uh):ε(uh)`。在本稿H1连续速度、静止无滑移固壁、周期面配对、仿射贴体网格及一致积分下，分部积分得到

`∫∂j ui ∂i uj=∫(div uh)^2`，因此

`Dsym−D=||div uh||L2²`，`(Dsym−D)/D=eta_div²`。

这也是一个独立提取恒等式，可用作将来夹具/真实场交叉核验，不是本轮已有测量。若开放边界、壁面运动、滑移或周期不匹配，须重新加入边界项，不能套用。

因此不能把本弱式的D直接宣称为已验证的局部真实黏性耗散。若未来额外声称两种积分耗散的相对差≤1e−6，在上述条件下对应`eta_div≤1e−3`，并非1e−6；这只是条件代数换算，不在本轮新增强散度验收门槛，也不控制K误差。真实局部耗散机制图需要另审其定义和收敛。

## 4. 独立提取的精度层：不与装配积分混同

仿射三角形P2/P1下：J为二次；D、Pdiv、div²为二次；压力均值一次；uh²四次。使用相应多项式精确积分规则或解析积分，记录规则和实现。截面分段P2积分也可精确处理。多项式“理论精确”仍有浮点误差，须用夹具核映射/取向/累加/单位。

解析三角函数误差范数及MMS做功不属于有限次多项式精确积分。独立提高后处理积分阶次需分别报告J、D、W、Pdiv、L2分子分母等；对近零余额用S，对误差积分用解析场范数归一，禁止除以近零误差自身。后处理积分变化≤1e−8（归一后的指标绝对变化）作为推荐控制目标，至少比1e−6能量/截面门槛小两个数量级；它是变化诊断，不单独证明积分误差界。

提取对最终K的预算为1e−6（0.0001%）；所有实际提取缺陷/误差必须可解释为该Q的影响，不能从任一夹具的1e−8自动推出。F02仍需给出具体规则阶次、夹具浮点容差、误差地板和独立实现验证。误差幅度若可能跨过验收阈值，状态INCONCLUSIVE，不把中心值贴线算PASS。可用可靠区间时，整个区间在阈值内才PASS，整个区间在阈值外才FAIL。

装配QUAD8→12需要另一组真实方程解；已有场上后处理换积分规则不替代装配QUAD。连续性积分、压力残差与Pdiv的离散多项式一致性也要避免混入不同约束基或不同源项积分。

## 5. 逐点Stokes参考预算及其适用强度

### 5.1 对象与分项

Q0=同一**精确规定几何/边界/驱动**的连续Stokes方向K；Q1=理想精确积分、精确代数解的所选最细有限元K；Q2=指定装配积分下的精确代数解K；Q3=实际迭代解的理想提取K；Q4=独立提取报告值。

则`Q4/Q0=(Q1/Q0)(Q2/Q1)(Q3/Q2)(Q4/Q3)`。四个比值的分母由定义固定，不把不同方向的相对变化偷偷倒置。

|分项|符号与候选额度|必要证据及不能替代的内容|
|---|---|---|
|空间离散|bs=.0012，0.12%|同几何三格+拓扑、估计适用条件；小中细差不是界|
|装配积分|bq=.0001，0.01%|同网格只变装配积分的对照；高阶结果本身仍须足够可靠|
|代数求解|ba=.0001，0.01%|同方程只收紧求解的对照；残差/变化小不自动成为Q误差界|
|独立提取|be=.000001，0.0001%|插值/积分/浮点与单位的独立验证；后处理不替代装配对照|

几何、单位、符号、壁面或周期错配属于前置INVALID，不用0.12%空间额度包容。拓扑属于空间证据，不另当统计独立项相加；守恒/能量门槛是有效性检查，也不再作为可相加误差项。禁止RSS、默认方向抵消、把所有“变化量”直接改名为真实误差界。

### 5.2 空间证据的确定规则

1. 同几何同方法同驱动三格，完整P/T配对，最细值作为交付Q，不用未经验证的外推值偷偷替换它。三格必须有可核的统一细化比例；以下简式只用于比例r=2，局部非统一加密不得硬套。
2. 记dc=Qc−Qm、df=Qm−Qf。仅当dc·df>0、abs(dc)>abs(df)>0且两差分可与非空间误差区分时，报`p=log2(abs(dc/df))>0`和`GCI_f=1.25*abs(df/Qf)/(2^p−1)`。差分可分辨需其误差区间不含0且收缩关系在误差范围内成立；缺乏可信误差地板时只能报条件结果。
3. P/T各自的中细差abs(df/Qf)≤0.25%只是筛查。GCI_f以Qf为分母，空间预算bs却以Q0为分母，必须先换算：`b_space_proxy=GCI_f/(1−GCI_f)`（要求0≤GCI_f<1），推荐b_space_proxy≤0.12%，即原始GCI_f≤.0012/1.0012≈0.11985617%。最细翻转拓扑差abs(Qtop/Qf−1)≤0.12%另作必要筛查。**本版不再使用旧未生效GCI≤0.5%/拓扑≤0.25%作为资格标准。** 旧LBM1%/.5%和FAIL完全不受此修订影响。
4. b_space_proxy是按目标分母换算的条件空间估计；拓扑差仅作冲突检查，不能与它取最大后冒充可靠界。满足阈值仍须说明渐近假设/角点正则性/非空间误差控制。拓扑对照单点不能证明收敛阶，三点拟合出来的渐近比也不是独立证明。
5. 近乎平坦、振荡、不收缩、不可分辨、估计与拓扑矛盾时均为INCONCLUSIVE或对应筛查FAIL；不记GCI=0、不临时指定理论p、不自动追加网格。若两差分均≤abs(Qf)*1e−6，记录SENSITIVITY_NEAR_FLAT，仍不能作为严格界。
6. A必须逐格由同版本KP/KT生成，另报A的中细差、条件GCI和拓扑差，筛查目标各≤0.25%。若A差分因P/T抵消而不可分辨，不独立外推A；可依合格P/T区间传播评估A，同时明确其直接GCI为NOT_IDENTIFIABLE。A表观平坦不能豁免任一方向的空间不确定性。

这些规则规定如何报告/筛查，**不声称仅凭三格和一次拓扑即证明估计可靠**。更强的渐近支持、独立方法对比或可靠后验估计可补证据；新增计算须另审。不能为了声称“最小合同已满足”把必要可靠性证据省去。

### 5.3 比值传播与精度目标

若四分项真正满足上述比值界，则

`l=(1−bs)(1−bq)(1−ba)(1−be)`，`u=(1+bs)(1+bq)(1+ba)(1+be)`，

`Q4/Q0∈[l,u]`，`bK=max(u−1,1−l)`。

对于正KP、KT，若各有[lP,uP]与[lT,uT]，则

`Aref/A0∈[lP/uT,uP/lT]`。

方向取相同额度时，可用对称化保守包络`bA=2*bK/(1−bK)`；保留原非对称区间可略收紧，不能用bP+bT冒充精确比值界。

本稿推荐汇总目标：**每方向估计额度≤0.15%，A估计额度≤0.31%**。实际采用须同时满足每个分项，不能拿总额度余量填补未验证分项。若仅有条件估计，结论中必须保留“条件估计”；没有严格界时不出现“保证小于”。所有条件预算数值见[budget_arithmetic.json](budget_arithmetic.json)。这是未来设计，不是本轮验收结果。

F=K/Klub，在Klub/几何精确且一致时相对误差与K相同；R=μ/K在μ作为固定精确输入时区间反转`Rref/R0∈[1/u,1/l]`，不得直接复制K的有符号误差。A配对及R变换不带来新的独立物理验证。材料参数不确定性或真实几何误差不在此数值参考预算中。

**所有控制对照先统一分母。** 旧ALG/QUAD相对变化常以基础解为分母，它不是表中以理想目标为分母的分项界。即使较紧/较高阶结果能作为精确目标，若`d=abs(Qcheck−Qbase)/abs(Qbase)`，也只可用d/(1−d)作为Qbase相对Qcheck的对称包络；要满足b=.0001，需d≤b/(1+b)，不能把d=.0001直接当成同幅界。若Qcheck尚有未量化误差，仅做这一步换算也不够，分项可靠性仍未建立。对比检查保存两个原始Q、相对差分母、检查结果剩余误差及换算区间，不把两个近似解之差等同任一解到精确目标的距离。

### 5.4 两层结论不混用

- `STOKES_REFERENCE_ESTIMATED_AT_CASE`：方法/几何有效、所有检查与分项敏感性证据齐全、条件估计按规则报告且满足推荐目标；仍明示模型假设及估计可靠性限制。
- 若科学采用“逐点估计型合格参考”，证书须显式带`evidence_strength=CONDITIONAL_ESTIMATE`，不可简称真值/严格界。正式采用和实际验收目前均未发生。
- `STRICT_BOUND_ESTABLISHED`另要求每个比值界及传播的可靠性已证明；本合同当前无此证据。仅三格GCI和ALG/QUAD差不能签发该证书。

## 6. NS、停止及G4评分：独立比较层

本版Stokes参考预算中**没有**NS建模差和旧LBM停止项；这不表示它们为零。要据新参考解释LBM物理偏差时，须另提供这些证据。低Mach不等价于低惯性误差，也不是不可压缩模型误差界；有限晚时刻结果不等于无限时稳态。

保留旧报告0.482365598%作为旧方案的条件“比较因子干扰包络”，不把它移作本版Stokes参考总误差。旧0.05%模型/0.05%停止仍是独立未激活候选，不是本次通过的数字。新提取层也意味着旧包络不能不重新定义就作为新版精确数字。
