# 区间图修正版说明（未合入正式稿）

在固定全充液、常黏度、静止无滑移壁面的连续Stokes模型下，两个主方向的导度满足

\[
L=h^3/12\le K_i\le U_i=K_i^{\rm LC}.
\]

这里L是共同的公式形式；不同h对应的有量纲下界不同。图中横轴为K/L，所以每条横条左端统一为1；右端为该几何和方向的U/L。圆点是5 nm网格计算结果，空心菱形是已有2.5 nm加密结果。图的横轴为对数坐标，横条表示连续理论上下界，不表示数值误差范围或统计置信区间。

图覆盖19种几何，每种几何分别展示沿槽和横槽两方向，共38条理论区间。记录包括38条5 nm结果和其中4种几何的8条2.5 nm加密结果，共46条不同的数值记录。38条主图/新增间隙结果已包含在46条审计记录中，两者不能相加解释成84条不同结果。

这46条离散结果均处于相应理论区间内。最接近下界的是h=125 nm、d=25 nm的横槽2.5 nm结果，K/L=1.1263。这说明已有记录与连续界限相容；下界成立的依据仍是可容许试探场及变分证明，数据相容不替代理论证明或连续精度验收。

沿槽区间最大U/L=63，横槽最大U/L约1.984。横槽区间较窄，沿槽区间在薄隙深槽条件下很宽；仅给区间仍不能代替具有精度依据的点预测。

另对原18种几何的36条5 nm主方向结果，按相对于离散K的偏差比较：沿槽下界平均低估58.2%、局部立方律平均高估88.8%；横槽分别为23.8%和30.6%。两个方向各有11/18个几何的下界更接近离散结果。这组统计没有纳入新增h=100 nm或2.5 nm加密记录，也包含离散参考的网格影响，不能用作连续模型误差或普适预测精度。

因此，基础下界适合用于完整呈现理论约束，并作为透明的简单比较基线；它不含槽宽信息，不能独立解释已有宽度依赖。论文的贡献仍需落在具体局部模型的双向偏差及其后果、受证据限制的流动结构解释和最近文献比较上，不能仅靠“多了一个下界”建立主要创新。
