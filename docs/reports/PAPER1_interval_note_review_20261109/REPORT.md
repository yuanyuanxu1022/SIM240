## 裁决

下界及区间比较有解释价值，但用户转来的说明不能原样采用：84条不是84条不同记录，旧图漏画h100两条，归一化后的共同左端不代表有量纲下界相同，不到2倍的区间也不代表精确预测。建议保持原A的有限用途——基础界限与同集合基线补充，不以区间包装新的预测定律或主要创新。本轮没有实施A/C合稿。

重叠记录在两个CSV中的最大相对差为4.0322856165×10⁻¹⁰，为保存位数差；图优先使用map36全精度值，其余10条用审计CSV。没有平均两份数值或重算导度。CSV字段below_bound原指低于LC上界，本轮直接重算L与U比较，不把其名字误当下界标志。

“下界比上界更近”由相对于同一离散K的绝对相对偏差判定，不由对数图的视觉中点判定。只给上界并非数学错误；上界仍可作为原局部立方律这一具体模型的比较基准。补下界可以使理论范围和基线对照完整，不能保证增强预测能力。上界在连续模型中给出偏差方向；具体离散数据的正偏差还需读数核对，不是由本轮图自动认证。

基础界限本身不足以解决核心文献增量问题。当前可辩护的论文主线及最近工作缺口，仍以[贡献裁决](../PAPER1_contribution_bound_audit_20261109/CONTRIBUTION_VERDICT.md)为准：特定矩形槽族的局部立方律双向偏差、各向异性后果与受限梯度结构诊断。不得改写成首创各向异性、普适机制或新通用预测律。
