## 2. 本质判断及限制

S1 宿主已去掉 h75 专用密度捕获调用，支持通用矩形槽参数，当前无需改物理内核或重新编译。S1 检查器的精确阶段守卫仍只接受两条平板，因此需要新隔离 S2 来源分支，而不是扩大旧 S1 合同。新增分支只允许原六条S2输入，不放开全矩阵。

性能标定不能叫零步：原ELF只能通过steady实际推进；因此协议保留其原始字段/真实退出和可能缺失的末态文件，独立标为性能诊断，拒绝送入正式验收。外部观察只能测短时吞吐量，不能证明12小时一定收敛，更未覆盖完整统计窗后的计算成本。此处是现有程序的设计限制，没有构成新原始证据矛盾，本轮未触发新的 Astra 裁定。
