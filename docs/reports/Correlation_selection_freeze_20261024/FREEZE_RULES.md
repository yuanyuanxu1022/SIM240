# 预测冻结合同：G4 candidate v1，2026-10-24

本合同是用户授权的内部研究决策，不是老师已签字的方案、期刊审稿决定或D4运行许可。模型选择规则来自已知开发证据，是回顾性选择；对尚未读取的保留结果采用前瞻预测合同。本轮不声称查明其他人是否已经查看结果，运行前仍须核验其生成时间与接触记录。

## 1. 主候选及选择顺序

主候选G4：保留联合结构中的四个原始全开发系数，mP=mT=1。先要求同一结构解析保证平板退化、正值、方向顺序、深度单调和缩放，再在满足条件的G4/G6中，等重考虑两个方向与两种留组方式，优先降低最差单方向MAE，再参考参数扰动和复杂度。此规则不把各向异性比A的误差隐藏为两方向平均；A另设共同验收条件。

G6是预先登记的比较候选。MIX7是回顾性挑方向的探索对照，P=G4完整预测（内部T仍是G4），T=G6预测，共7个独立系数；不得直接把G6的T代入G4的P，否则构成未拟合新模型。没有跨方向解析保证，有限扫描不能升级为全域证书。两对照即使在新结果上更好，也不得事后替换主候选并称主验证通过。

## 2. 锁定对象

`candidate_lock.json` 绑定原始模型实现、全部精度系数、逐点预测、A预测、规则文件、逐算例计划和本轮证据。`candidate_lock.sha256` 是锁文件摘要。`freeze.py` 遇到既有锁拒绝覆盖。任何结构、系数、训练集合、评价阈值或测试集合变更必须另立v2并保留v1；已读结果永久记为已知，不能重新命名盲测。

训练集合仅旧w120、h50/75/125、d25/50/75/100/120nm的15几何30方向、dx5。没有把新开发筛选或h25补充数据加入拟合。不能把这次锁定解释成新开发矩阵已完成或已验收。后续若使用新开发数据拟合，须重新立版本并在保留结果产生前另行冻结。

目标仅固定间隙、充分充液、牛顿单相、无滑移直沟槽，φ=0.5、P=2w；拟议验证范围0.8≤w/h≤3.2，1/3≤d/h≤1.6。此范围没有获得全域精度保证；h25旧数据、φ变化、接触极限和无限深槽精度不在本次验收承诺中。

## 3. 样本、预测及误差定义

正式主比较：h={60,100}、d={40,80}、w={90,180}nm，P=2w，8几何×两方向=16项，dx5nm。逐项ID、几何、K（m³）、F及阻力修正1/F在`reserved_predictions.csv`。4项细格参考仅h60/d80/w180、dx2.5/1.25nm、P/T，预测的物理K与dx5相同。总20项几何/方向/网格预测，不把网格重复计入16项均值；三模型共60条预测行。

定义eK=100*(K预测/K数值参考−1)，A=KP/KT，eA=100*(A预测/A数值参考−1)。同几何两方向必须匹配，A有8项。每个量独立报告有符号偏差、MAE=mean(abs(e))、RMSE、max(abs(e))及最坏ID；不得把两方向混合平均掩盖失败。A直接计算，不用两个方向MAE相减。

本轮新增前瞻目标：P、T、A各自均要求MAE≤3%且max(abs(e))≤5%，共6个条件全部满足才记`MODEL_PREDICTION_TARGET=PASS`。3%/5%沿用待审草案建议，属于本次设定的研究精度目标，不是老师要求、行业标准或已有数值门槛；不改任何旧协议。G4旧留组A最大6.36%/5.93%，因此这一目标有已知失败风险，不能声称旧数据已经全通过。预先声明目标并不等于已经达到目标。

## 4. 判定先后及缺失处理

先核对锁与输入SHA、源代码/二进制/构建、run_id、独立退出码、完整日志/数据/场、实际几何和参数、原冻结收敛/质量/Mach/密度/剖面/线性及几何规则；仅成功退出不足以放行。继续分别记录NUMERICAL_GATE、RESULT_PASS、geometry_PASS，历史FAIL不抹除。

任一计划主项缺失、来源不一致或未通过原始验收：总体`INCOMPLETE_OR_REFERENCE_INVALID`，列出问题项；不删除坏点缩小分母，不用细格替换粗格以改善主分数。齐全且合格后计算主比较六条件；任一失败则目标FAIL，完整保留16项及8项A。诊断指标可以在不完整时输出，但不得标作完整集PASS。

4项细格参考单列每方向K变化与各级模型误差，A按同dx配对。细格未验收则`GRID_EVIDENCE=PENDING/FAIL`，即使粗格预测目标通过，也只能称“与5nm数值参考一致到该目标”。本合同不新增或伪造三格精度阈值；没有有效网格论证时不宣布连续物理预测已验证，更不能由单个几何保证整个范围。
