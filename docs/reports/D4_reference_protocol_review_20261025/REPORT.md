## 2. 压力与周期约束的裁定

### 2.1 驱动、压力和功率必须一致

有体力形式：`−νΔu+∇π=a ex`，π周期且去常数。无体力等效形式：`−νΔu+∇(p_eq/ρ)=0`，`p_eq/ρ=π−ax`，跨周期压差为−ρaP。两者可选其一，不能在后一压力场上再保留相同体力。平板无量纲u=z(1−z)/2时，`−u''=1`；采用π=0、a=1成立；采用p_eq/ρ=−x、a=0也成立；再加a=1会使方程不平衡。若实际把驱动叠成2倍，线性平板K的推导/归一化链也会错误。

π是实际体力周期计算中的压力扰动；p_eq用于等效压力驱动解释，不是同时施加的第二个物理场。能量检查相应采用一次体力功率a∫ux，或一次等效压差功率，不能相加。

### 2.2 周期自由度与压力规范

矩形首阶段在x=0/P配对相同z的P2速度顶点与边中点、P1压力顶点。固壁速度优先固定；周期面与固壁交点不重复引入相互冲突的自由度。每侧P2迹有2nz+1点，其中两端已为固壁0，待配对的自由速度迹为2nz−1；压力配对nz+1点。将识别矩阵T应用为`Ared=Tᵀ A T`、`bred=Tᵀb`，不能只在输出中复制两侧值。

压力常数n之所以是零空间，来自`∫div w=∮w·n=0`：固壁测试函数为0，周期面外法向相反而迹相等。右端连续项为0，故nᵀb应为0。压力最终去均值用`∫π/|Ω|`，不是任意网格下无权系数平均；不得固定平均流速为0，否则会消除所要测量的净输运。常数压力平移应不改变速度、通量或真实残差，后续实施要作代数和输出核验。

上述节点数量见[periodic_topology6.csv](periodic_topology6.csv)。本轮只核对计数与解析关系，**没有验证后端已经正确施加这些约束**。非零压力的制造解是必要检查，平板零压力单独通过不足以核定压力符号。

官方例程明确说明演示采用翻转压力符号，并给出P2/P1、压力常数零空间及线性求解方法；本审查仍以物理π的独立推导为准。[DOLFINx官方例程，2026-10-25核对](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_stokes.html)。

## 3. 总预算：给出可算通的候选分配，不宣称已有界

原草案第55/72行条件GCI≤0.5%只是一个空间诊断目标，再加代数、积分、建模和停止变化，不能仍称总误差≤0.5%。如果P/T各允许0.5%，即使真是误差界，A=KP/KT的保守界也达到`2u/(1−u)=1.005025%`；不能假定两方向误差抵消。

本轮提出更紧的**每方向候选预算**，只用于后续新参考方案，不改变任何旧Gate：

|分项|候选百分比|明确定义与证据边界|
|---|---:|---|
|新参考空间离散|0.12%|可靠性经审查的条件空间误差估计；单个中细差小不等于这个界成立|
|代数求解影响|0.01%|同问题收紧真残差目标后的Q变化，仍需检查对连续误差解释是否充分|
|积分影响|0.01%|提高单元/源项/误差积分阶次的Q变化，不直接扣除LBM中点积分偏差|
|Stokes对NS建模差|0.05%|`Q_NS/Q_Stokes−1`的幅值；沿槽在规定充分发展假设下该项可为0，统一预算按更不利方向预留|
|LBM有限时停止影响|0.05%|`Q_late/Q_old−1`的幅值，沿用原停止对照草案方向；不是无限时误差界|

新空间0.12%取代的是**未冻结草案**中的每方向0.5%候选分配，不改已运行LBM的1%/0.5%目标。新参考的中细差0.25%仍作筛查，不单独证明0.12%估计；拓扑对照若其方向变化超过0.12%，不能忽略该冲突继续认定0.12%空间预算充分。A必须由同网格同版本KP/KT生成，同时单列A空间估计/拓扑差，建议诊断门槛0.25%，并遵守传播预算；不能把独立拟合的A外推值混入参考。

### 3.1 预算恒等式与数值

所有以下不等式**均以分项能作为相应比值的有效界为条件**；当前并未建立这些界，不以“收紧后变化小”或GCI数值单独冒充证明。

设bs=.0012、ba=bq=.0001、bm=bt=.0005。按上述建模差分母方向，新参考相对NS目标的正向候选包络为：

`r+=(1+bs)(1+ba)(1+bq)/(1−bm)−1`；负向为`r−=1−(1−bs)(1−ba)(1−bq)/(1+bm)`，取r=max(r+,r−)。

得到每方向r约**0.190120061%**；A参考比值的保守包络约**0.380964412%**（完整精度见JSON）。

再定义`R=Qref/QNS`、`S=Qlate/Qold`，且`D=Qlate_LBM/QNS`包含原LBM的空间偏差和未定的更晚尾部误差，则：

`(Qold_LBM/Qref)/D = C = 1/(S R)`。

正向干扰包络`c+=1/[(1−bt)(1−r)]−1`，负向`c−=1−1/[(1+bt)(1+r)]`，取c=max(c+,c−)，不是直接将百分数相加。

|条件预算结果|百分比|
|---|---:|
|新参考每方向r|约0.190120061%|
|有限停止与新参考共同造成的每方向比较因子包络c|约0.240602507%|
|不利用方向误差抵消时，A比较因子的保守包络2c/(1−c)|约0.482365598%|
|相对0.5%目标剩余的预算空间|约0.017634402个百分点|

分母逆比值已显式保留；不能把Qlate/Qold门槛直接当成Qold/Qlate的同幅界。上述分配不使用RSS或统计独立性假设。原直接A停止变化≤0.05%、NS对A变化≤0.05%的单独检查仍保留，不因传播预算而删除。

**这里的0.482%是候选“比较因子干扰”预算，不是旧LBM总物理误差，更不是G4预测误差。** 原网格的约1%–2%差异属于D中的研究信号，未被预算吸收或扣除；Qlate只是有限时刻，不是已知无限时稳态。新参考本身的可靠性、末期尾部、压缩性/其他未覆盖模型差及域覆盖仍须各自说明。几何/单位/周期错误作为前置无效处理，不能用一笔小预算豁免。
