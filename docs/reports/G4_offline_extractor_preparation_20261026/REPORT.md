## 2. 已实现的指标与边界

1. 使用单元顶点、P2节点/分量坐标、P1坐标与显式混合索引恢复局部顺序；支持全局编号打乱、局部编号打乱、单元取向翻转。显式二维Jacobian处理物理梯度；不用原组装模块或原提取程序。
2. 计算面积、独立压力面积权重/均值、速度L2、去均值压力L2、Jhat、D、Dsym、实际f·u做功W、Pdiv、强散度及各能量余额；输出中保留中间积分、分子分母和单元诊断。平板零解析压力不计算相对压力L2。
3. 七个预登记截面分片积分，落在共享边时避免重复；同时核相邻截面控制体的散度积分与上下壁面通量。非零壁面通量的人工例也能核恒等式，避免仅零场测试掩盖漏项。
4. 从保存CSR和代数向量仅作乘法重算残差，抽取独立压力行；独立积分压力测试函数后按周期基聚合，核积分路径与矩阵残差的符号/数值。没有矩阵求解或PDE组装。
5. 周期回填、周期坐标/分量、壁面索引覆盖、压力共享节点、P2共享节点及保存值副本一致性均有检查/诊断。诊断不签发geometry_PASS。
6. 制造解通过独立的流函数多项式求导实现，不导入生产physics.py或UFL；已核非平凡解析范数、功率积分及另一有限差分路径的源项。独立是指代码路径和校验依据，并非另一个人/代理已复审。

目前限定**无量纲2×1矩形、二维混合P2/P1、单位周期系数、无链式周期约束**，与当前首项N8对象匹配。标量九项、真实沟槽、其他尺度/边界与全部18项资格不在本次实现范围。不同范围输入应拒绝或另版实现，不能直接把本次夹具PASS外推。
