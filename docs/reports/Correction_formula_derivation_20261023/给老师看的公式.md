# 以间隙为尺度的矩形沟槽修正相关式

2026-10-23。针对固定间隙、充分充液、低Re、牛顿液体、无滑移周期矩形槽，保持沟槽占比φ=w/P=.5，即P=2w。w为槽宽，h为凸台下间隙，d为槽深。沿槽y记∥，横槽x记⊥。

**当前已完成：由方程推导变量与尺度，再把既有DNS标定的C4写成明确的F(w,h,d)。** 函数形式及数值系数仍属于经验闭合；尚未从完整流动方程推出不含拟合系数的有限闭式解。完整推导和能量约束见[DERIVATION.md](DERIVATION.md)。

以Gap=h为特征长度，令s=w/h、t=d/h，有

\[
 K_i=h^3\kappa_i(s,t;\phi),\qquad
 K_i(\lambda w,\lambda h,\lambda d)=\lambda^3K_i(w,h,d).
\]

该相似性来自Stokes方程无量纲化。因此固定w下改变h、d，已经提供了两个独立比例的信息；新增w结果用于检验转用和扩展比例域，不是建立二维相关式的数学必要前提。

可计算的修正因子为

\[
 \boxed{F_i(w,h,d)=\left[1+A_i
 \left(\frac dh\right)^{b_i}
 \left(\frac hw\right)^{p_i}
 \exp\left(-r_i\left[\ln\left(\frac wh\right)\right]^2\right)\right]^{-1}}.
\]

|方向|A_i|b_i|p_i|r_i|
|---|---:|---:|---:|---:|
|沿槽∥|1.439322109362748|1.5996745971805324|0.9067146568707773|0.28288991331900903|
|横槽⊥|0.5282632943141873|0.7768339511443813|0.5411597594375912|0.4708598723288494|

两个方向使用各自的一组固定系数，不随每个算例另换系数。几何连续变化，公式也连续变化。

局部立方律基准与实际预测的关系：

\[
 K_\parallel^{LC}=\frac{h^3+(h+d)^3}{24},\qquad
 K_\perp^{LC}=\frac{h^3(h+d)^3}{6[h^3+(h+d)^3]},\qquad
 K_i=F_iK_i^{LC}.
\]

阻力修正为C_i=1/F_i，R_i=μ/K_i；驱动G=ρa时J_i=K_iG/μ。w、h、d先统一单位；用米计算时K为m³，μ为Pa·s时R为Pa·s/m³。不能把F当阻力乘数直接乘到R。

**系数与验证身份：** 系数沿用18种几何、36个方向点的C4回顾性拟合，本轮不重新拟合或替换V2。原h/w、d/w式与上述Gap尺度式对36个原始点重算一致，最大相对差1.11e−15；不是新增独立槽宽验证。全数据拟合MAE沿槽1.6483%、横槽2.1010%，属于训练表现；整层留h的既有MAE分别2.1201%、2.6006%，也仍为旧数据的回顾性检查。

**适用域：** 当前φ=.5；已有采样h/w从5/24至25/24，d/w从5/24至1，组合不完整。程序采用原样点在对数比例平面中的凸包筛选，包络内部也不保证统一误差。改变w时按比例定位，不能给出与h、d无关的任意绝对槽宽范围。8种新开发几何中3种在旧包络内、5种在外。

**物理限制：** 理想Stokes模型中，平板下界h³/12≤K_i≤K_i^LC。该C4在现有点及已做域内扫描中未违反下界，但域外极深/极浅横槽存在反例，故不能宣称任意槽深的普适公式。若目标是全域公式，应先完善满足极限的闭合结构，再做预先声明的拟合/验证；当前不强行划两个物理区间，也不把经验系数称为理论常数。

推导、计算脚本、原始结果追踪和检查结果已经保存在本目录。本轮没有新OpenLB或新流场求解；尚未生成最终模型锁定文件，没有改变或执行已准备的计算许可。
