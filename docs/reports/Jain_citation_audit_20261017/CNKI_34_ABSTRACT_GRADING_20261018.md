## 2 两条升级（本次唯一新增的实质内容）

### #21 孔槽泡沫夹芯复合材料真空辅助树脂传递工艺仿真与优化

- **《材料导报》**，期刊
- 关键词：夹芯复合材料 / 等效渗透率 / 真空辅助树脂传递 / 芯材加工 / 工艺优化 / 孔隙率
- 摘要关键句：「利用 **Hagen–Poiseuill 方程和达西定律算出孔洞和沟槽的等效渗透率**」；再用 PAM-RTM 模拟灌注并与实验比对；给出灌注时间预测函数。

**为什么升级**：这是中文侧**唯一一篇明确把「沟槽」折算成「等效渗透率」并与实验对照**的工作。
方向上与我们完全一致——把槽当作等效 K 处理，而不是逐格算槽内流场。

**差在哪（所以不是先例）**：
1. 只取**流向标量**，不构造张量，故不涉及「沿槽 / 跨槽」两个主分量；
2. 等效 K 是**输入**，不是**被检验的对象**——它把 K 代进 RTM 模型后比的是**灌注时间**，K 本身的误差从未被量化；
3. 无解析式与精细解的对比，因此不含任何「闭合误差」概念。

### #29 泡沫夹芯结构板泡沫壁流道内的流动特性

- **《化工学报》**，期刊
- 关键词：夹芯结构 / 泡沫壁 / VARTM / 等效渗透率 / 沟槽
- 摘要关键句：「提出了相应的**压力驱动流动方程**，并采用**等效渗透率**来表征液体在泡沫壁流道内的流动能力，得到了**考虑粗糙表面影响的等效渗透率计算公式**」；
  实测「液体在泡沫壁流道的流动能力大幅降低，只有**光滑壁流道的 60% 左右**，泡沫壁流道的**粗糙内表面**是造成这种现象的主要原因」。

**为什么升级**：它做的事在结构上就是我们的 $F_\parallel$：
**光滑壁 → 粗糙壁，通道输运能力打一个折减因子（这里是 0.6），并给出公式**。
这已经是「形貌修正闭合」的雏形，而不只是测一个 K。

**差在哪（所以不是先例）**：
1. 粗糙是**泡沫壁的随机粗糙**，不是**周期矩形直角槽**；
2. 给的是**标量折减**，没有方向性——而矩形槽的关键恰恰是沿槽/跨槽差 2 倍以上；
3. 参考解是**实验**（光滑壁自身对照），不是解析解与精细数值解的互校，故无误差律；
4. 不涉及角部——随机粗糙没有「直角」这个几何奇点。

> **合起来这两条说明一件事，对论文有利**：
> 中文侧确实有人「把槽折成等效 K」（#21）与「给粗糙壁的输运打折减」（#29），
> **但两者都不检验这个 K / 这个折减因子本身对不对**，只把它当作往下游算的输入。
> 这正是我们第 1 章 ¶3 那句「缺的不是换算这件事，而是换算的误差」的中文侧证据。

### 8.6 关于"为什么导出的还是同一批"——一个可能的技术原因

CNKI 的导出默认导出**已勾选的文献**，而不是"当前检索结果"。若第一次检索后勾选了那 34 条，
之后即便换了检索式，再次导出仍可能把这 34 条原样导出——这与观察到的现象吻合：
**条数恒定 34、内容恒定、只有字段数在变**（字段数变化来自导出对话框里的格式选项）。

**两秒自检方法**：导出后看**第一条标题**。
- 若是「**裂隙粗糙度对渗流–溶蚀过程的影响机制研究**」⇒ 还是旧结果，检索式没生效。
- 若第一条变了 ⇒ 新检索成功。

**建议步骤**：
1. 高级检索页 → 先点「**清空条件**」或「重置」（不同版本叫法不同）；
2. **取消勾选**结果页上的「全选」（关键：不要带着旧的勾选状态）；
3. 只填一组条件，例如第 1 行「主题」= `流量因子`，检索；
4. 结果页若条数很少（预计个位数到几十条），**直接点导出，不要先勾选**；
5. 导出前把字段选成 18 列那套（已含年/卷/期/页）；
