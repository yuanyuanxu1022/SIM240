# 公式已有之后，推荐用什么实现闭环

> 目标选择已进一步具体化：以[第一篇预测目标说明](PAPER1_PREDICTION_TARGET.md)为准，主量为瞬时挤压阻力F_net/V，槽向阻力比为次量；下文保留较早的方案比较。本次仍未实现或运行。

日期：2026-10-29。用户最新澄清：已有公式，现在要选择合适的闭环应用与方法。本文件是方案推荐，不是已采用的研究路线、冻结协议、代码实现或运行记录。

## 推荐组合

应用端采用二维各向异性Reynolds薄膜模型；输出选择给定瞬时间隙和闭合速度下的压力分布与净挤压载荷。参照端采用经验证的、显式解析沟槽的独立Stokes有限元计算。Python可用于实现较小的二维模型；FEniCSx/DOLFINx可作为独立Stokes实现选项，实际参考程序尚须核准，不能从官方示例存在推断项目参考已合格。

首选瞬时压力/载荷的理由：它把K从被比较的局部量推进到可比较的应用输出，与当前稿件§5.2已有讨论衔接；不用立刻预测整个填充行程，也不默认同时增加界面推进、气体和设备控制模块。它仍是新增的受限应用问题，不能说已被固定壁面主地图验证。

## 最小算例建议

1. 先采用已有h=75nm、d=100nm、w=120nm、P=240nm几何作为接口检查候选；这是已见基准，不是盲测。
2. 建议用全充液长方形区域，同一时刻给定h和闭合速度V，规定边缘压力、常黏度与刚性模板。先只取一个间隙，不把瞬时解扩展成完整时间历程。
3. 为避免单一对称载荷掩盖方向性误差，可比较槽沿长边/短边两种对齐条件。长宽比、周期数、参考边界、网格和计算资源须后续预审，不在本轮任意冻结。
4. 两个应用预测仅更改导度：A使用原局部立方律，B使用固定V2关系；独立参照C直接解析沟槽，不把A/B关系作为输入，也不通过调参强制匹配B。
5. 主要结果为压力图及载荷对比，另给流出量/质量守恒。比较法向力时需统一环境压力扣除、投影面积及压力与法向黏性应力的口径；不能把有限元总力和降阶压力积分不加说明地视为同一定义。
6. 若初步核对可行，再用未参与选择/拟合的几何检验；现有基准示例本身不证明可迁移性。

## 物理与数值前提

- 必须是瞬时挤压问题：固定该时刻的几何来求Stokes响应时，独立参照仍须施加与闭合速度一致的壁面速度和开放边界，不能将全部固壁设为零速度后称挤压验证。
- 二维Reynolds与显式沟槽的对照包含微观导度和尺度缩减两方面因素；需检查图案周期与区域尺度、边缘效应、几何相位/截断及薄膜假设，不预设修正后必然更准。
- 所比较的参考本身须通过基准、网格、守恒、边界、压力基准及构建来源等审查；换软件或退出码0不是独立参考合格证明。旧N8只是代数诊断，其授权和验收不能扩展到本方案。
- 两个系数在同一个降阶求解器中的差异是输入影响；只有再与同条件独立显式参照比较，才能评价此应用下的数值预测。即便通过，仍不等于实验物理验证或整个动态行程验证。
- 不预设软件可直接支持最终规模。先做静态问题/资源设计审核；若显式区域不可承受，应缩减有科学意义的参考问题，不能用同一降阶方程生成的曲线冒充独立参照。
