# 根据第一篇保留结论确定预测目标

日期：2026-10-29。任务：用户要求按第一篇要保留的结论确定公式最适合服务的具体预测目标。本轮完成目标选择建议；不冻结新理论、数值门槛或运行协议，不修改正式稿结论。

## 1. 推荐的主目标与次目标

**主目标：全充液长方形沟槽图案区，在给定瞬时间隙和刚性闭合速度下的净挤压阻力。**

用统一定义的净法向液体载荷F_net和闭合速度V>0表示：

\[
R_{\rm sq}=\frac{F_{\rm net}}{V},
\qquad [R_{\rm sq}]=\mathrm{N\,s/m}.
\]

比较时固定宏观区域形状、图案取向与边界等条件。阻力随黏度、区域尺寸与条件变化，不是一个通用常数；式子只是本轮建议评价量的定义，不是新推导的物理定律。

**次目标：同一非正方形区域、槽分别沿长边和短边时的挤压阻力比。** 定义候选方向性指标：

\[
\chi_{\rm sq}=\frac{R_{\rm sq}^{\rm groove\ along\ short}}
{R_{\rm sq}^{\rm groove\ along\ long}}.
\]

两取向比较必须保持面积、长宽、图案参数、物性、瞬时间隙、速度及边缘条件一致，仅改变槽向。比值的具体大小与符号趋势由计算检验，不先宣称已经证实。

**诊断输出：过压分布p-p_b、按预定位置选取的压力剖面和体积守恒。** 不把压力峰值或单一总载荷当作所有局部与方向性误差的证明。

## 2. 为什么该目标与现有结论匹配

依据当前正式工作稿§6四条结论以及§5.2的受限模型讨论：

|要保留的结论|与预测目标的对应|不能直接推出什么|
|---|---|---|
|槽深增加对沿槽/跨槽K作用不同|检查这种方向差异是否在有限长方形区域的挤压阻力及槽向比中体现|不能把某一K倍率当作挤压阻力或整个行程时间的同一倍率|
|局部立方律相对5nm参考系统高估K|检验原导度输入是否导致指定应用下阻力预测偏差|独立显式区域还包含尺度缩减/边缘等因素，不能仅据局部上界冻结应用误差符号或幅度|
|基准各向异性及主值重建流向有偏差|将两种槽向的阻力比列为次目标，避免只看一个总载荷掩盖方向性|该槽向比不能替代原有斜向流向角检验；原9.20°仍保留其5nm主值重建限定|
|V2回顾性降低整体最坏偏差，薄间隙有局部失效|检查固定V2是否也降低载荷/阻力预测偏差；薄间隙作为后续风险条件|不能保证应用必然改善，也不把已有扩展数据称作新盲测|

目标选择的主张可以表述为：**评价局部方向性导度修正能否改善指定全充液、准静态条件下的瞬时挤压阻力预测。** 这是一项待检验的问题；不是当前论文已经得出的第五条结论。

## 3. 为什么不把其他量作为本轮主目标

|候选量|判断|
|---|---|
|给定闭合速度下的净总排液量|在不可压缩、全充液、刚性几何闭合且无其他体积来源时，净排液量受体积守恒约束；不同K可主要改变压力、载荷及各边流量分配。适合作守恒检查，不宜单独判修正是否有效。|
|完整填充时间|需完整间隙历程、界面/毛细/气体等适用条件；当前固定壁面主图不支持直接给出。|
|气泡缺陷或套刻误差|除液体导度外，需气体、变形、测量或反馈模块；不能从现有四个系数直接得到。|
|同一单胞下J和流向角|对局部系数验证很有价值，但现有D3已含内部自洽检查；若做新检验应有独立参考与新条件，不把重复代入同一张量关系包装为新增工艺闭环。|
|瞬时载荷/阻力|与导度、方向性和现有§5.2讨论连接直接；需要新增独立应用对照，但可先限制为一个瞬间，不预测全行程。|

## 4. 最小对比结构

1. 原局部立方律K_mod进入二维各向异性Reynolds模型，给出R_sq,mod。
2. 固定版本V2给出的K_corr进入同一二维模型，给出R_sq,corr。两项除导度输入外其余条件相同。
3. 经验证的独立Stokes显式沟槽解在同条件下给出R_sq,ref，不把V2作为输入或据其调参。
4. 比较两模型相对独立参照的阻力偏差及方向性指标；预定验收方式后，保留修正不改善的情形。

已有h=75nm、d=100nm、w=120nm、P=240nm只作为接口/问题搭建候选；这不是新检验点。实际长宽、周期数、闭合速度、网格、参考程序、资源与阈值尚未冻结。应先核参考/协议可行性，再决定后续新条件，而不是自动新增算例或启动旧N8第二项。

## 5. 必须在实现前解决的物理与定义问题

- 本主目标是新增的瞬时挤压应用模块；原第一篇主图仍是静止壁面、固定几何的输运数据。固定一个时刻的几何来解瞬时Stokes时，应施加与闭合相符的壁面速度与开放边界，不能所有壁速置零。
- 明确图案尺度与宏观区域尺度，检查有限边缘和周期截断影响。正方形区域在对称边界下交换两主值可能得到相同总载荷，因此槽向效应研究用长方形候选，但长宽比仍需预审。
- 明确F_net是怎样从压力/应力和环境压力得到。独立Stokes的总法向力与降阶压力积分需统一口径，检查法向黏性应力及作用面/投影面积，不掩盖降阶模型省略项。
- K(m³)、物理渗透率(m²)及无量纲量不能直接互换；二维模型优先沿用本项目深度积分导度K定义。
- 独立求解器自身要有基准、空间精度、守恒、来源和失败记录。旧N8仅代数诊断，不是已合格的沟槽或挤压参考。
- 同一二维模型用三组K生成曲线只属输入敏感性；只有外部同条件直接参照才能检验该应用的数值预测。通过后仍不称实验物理验证或动态填充验证。
