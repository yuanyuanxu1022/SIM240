## 1. 方程、方向与直接来源

充分充液、固定壁面、单相牛顿液体、周期240×240nm，槽宽120nm、中心槽区x∈[60,180)nm、槽深100nm、平台间隙75nm、平均流体厚度125nm。沿槽+y为P，横槽+x为T。rho=1000kg/m³、nu=1e-6m²/s、mu=.001Pa·s、a=1e5m/s²，G=rho*a=1e8Pa/m。D3Q19_FORCE、ForcedBGK、零速Bouzidi，tau=1、dt随dx²变化。

J由有效流体速度体积分除以平面面积，K=mu*J/G=nu*J/a，单位m³；不是通常单位m²的渗透率。周期压力是扰动，不能将p_max−p_min当全周期驱动压降。与GDI01/C01不同驱动幅度的J/Q比较前，应先统一为K。

本轮核对：C的19个原始输出哈希、9个来源条目、原程序及1541项保存的OpenLB源/库绑定；旧有效8个运行的24条源文件/程序/协议哈希。旧绝对目录按三条明确迁移规则解析，并以原哈希确认身份，不按同名文件猜测版本。1609条所选绑定中，只有原动态库的libz.so.1与libudev.so.1两项当前哈希不同；原数据与所选源/程序绑定相符。详见[binding_review.json](binding_review.json)、[目录迁移核对](original_manifest_aliases.json)。

旧G2的版本字符串不能独立充当完整依赖版本证明；C构建记录本身注明CONTROLLED_CURRENT_ENVIRONMENT_NOT_HISTORICAL_REBUILD。当前库变化不等于原始输出损坏，但也不能被删除、替换或豁免后写“精确复现”。原历史报告入口缺失继续保留，本次使用新编号重建审查证据。
