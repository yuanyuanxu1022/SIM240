# 作者自审范围

用户自有稿件按明确请求开展内部AI辅助核对和小范围事实订正；沿用已记录的项目授权、处理和留存规则。不是期刊委托审稿。intake中open表示作者可见内部协作，venue_policy.checked只指核项目AGENTS及本次范围；没有声明任何目标期刊已批准或政策已核验。human_accountable指作者保留最终责任，不代表本轮已经人工核验或签字。local_only指CLI/文件操作，不能把整个助手对话称为离线模型。额外网络请求只含公开文献标识或已授权私有仓库的只读API，不发送未发表稿件/私有研究数据到检索服务。retention按项目协议解释，不伪造期刊留存许可。AI参与过此前稿件，因此不声称为外部独立审稿人。
