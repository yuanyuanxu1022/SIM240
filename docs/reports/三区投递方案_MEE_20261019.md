## 三、三区稿件的核心叙事（必须改的落脚点）

### 当前叙事的弱点

现在稿件主要在说「公式不准」。这在 MEE 不够——**审稿人会问：那又怎样？**

### 建议的叙事调整

把落脚点从「误差有多大」推到「**什么条件下必须用精确解、什么条件下公式够用**」：

1. **先给判据**：误差何时超过工程可接受范围（例如 10%）？
   - 从你自己的数据：跨槽偏差最小 +8.1%，已经接近 10%；沿槽从 +10.3% 起，最大 +205%。
   - 也就是说：**在本研究覆盖的几何范围内，这个公式几乎总是不够用的。**
2. **再给分级**：
   - 浅槽 / 大间隙 → 公式勉强可用（偏差小）；
   - 深槽 / 薄间隙 → 公式严重失真（可达 2 倍以上），**必须用精确解或修正**。
3. **最后给可操作的修正**：V2，并明确它的适用边界（h≥50 nm、样点范围内、非预测工具）。
4. **明确指出各向异性风险**：45° 驱动下流向差 9.2°，意味着**用公式做斜向工艺设计会指错方向**。

**这个叙事对 MEE 的读者（模板设计师）才是有用的。**

## 四、机制部分怎么写（不补计算的前提下）

**不能写**「因为尖角所以高估」——这是已撤回的表述。

**可以写**：

> 闭式模型把每个截面当作独立平板（局部立方律），忽略了流向的黏性耦合与台阶附近的流动重分布。全局输运系数与这一图像相容，但作为积分量无法定位差异来源；侧壁剪切与台阶重分布都是候选机制，二者的定量分离留待后续工作。

这段话诚实、有物理内容、不越界。**三区可以接受这种程度的解释。**

## 五、结论章必须守住的边界

新写的 Conclusions 只能包含这四类陈述：

| 可以写 | 不可以写 |
|---|---|
| 36 个工况上公式**全部高估**（+10.3~+204.8% / +8.1~+54.2%） | 「证明了公式在任意几何上都高估」 |
| 两方向误差不等 → 各向异性被扭曲，45° 流向差 9.2° | 「证明了误差来源是尖角」 |
| V2 在**样点范围内**把残差降到 ≤10.5% / ≤6.9% | 「V2 可用于未见几何的预测」 |
| h=25/d=100 跨槽残差 −18.7%（5nm）/ −14.9%（2.5nm），且观测阶未定 | 「加密后已收敛」 |

**此外必须保留的三条限制句**（审稿人会看）：
1. 参考解是离散数值解，不是解析真值；全图误差界未建立；
2. V2 是数据知情的经验修订，非独立最终检验；
3. 历史构建与源码绑定未完整核实。
