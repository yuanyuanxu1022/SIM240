# v2确认稿入稿前的定点口径复核

2026-11-13。作者请求的AI辅助审查建议。只核当前表格、记录与协议并重算代数；没有新求解、原场再验收、改母稿/CASE/原v2稿或资格放行。来源及复算见RECALC.json。

## 结论

接受“覆盖已有数值依据、FEM有限采用、原主统计保留”的总体方向，但现v2不能原样充当科学定稿口径。以下更正可直接用于改稿准备；本轮不视作授权合入母稿或签署参考接收。

## 必须更正的事项

1. **几何与方向记录**：24个FEM算例目录包括2个平板和22条沟槽方向记录（17P+5T），这些沟槽记录涉及19种几何；不是22种几何。再用2条FVM-P补齐，得到19种几何、24条方向比较（19P+5T）。老师原目标19P+4T为23条方向记录；h125T为额外补充，不因这一点把原目标“横槽4个”判成计数错误。22点“建议有限采用/0正式接收/0不接收”只指22条FEM沟槽方向记录，不取消原4条合格FVM。

2. **2%判据**：原FVM PROTOCOL.md §4规定，合格参考下abs(K5/Kref−1)≤2%为每个固定方向的一致性PASS；原六方向含h25T、h50P、h75P/T、h125P/T。专指h75基准的，是A差≤2%与角差≤0.40°。因此“2%与0.40°都是h75专用”不对。新增FEM尚未正式接收，且新增点未自动继承旧协议身份，当前可描述偏差，不标正式PASS；理由应写资格与适用协议，不应改写历史判据。h125原合格FVM-P的一致性PASS保留。

3. **负偏差与改善**：以当前24条数值对照为分母，固定V2有8条负偏差；但24/24的绝对偏差都小于原LC，最大绝对偏差约12.78352%在h25/d100 T。“V2全部改善不能说，因为有8条负偏差”的论证不成立；只能限制在该24条集合、当前参考身份下报告24/24改善，不能替换原36条中的35/36。负偏差表示低估，不自动表示比原公式更差。

4. **过度修正的归因**：h100与h125的A低估在FEM/FVM补充对照下仍存在，支持“固定V2在这些条件下修正过强，不能仅由原OpenLB方向比差异解释”。不能排他归因于函数形式、不能声明OpenLB完全无错：系数标定、形式/变量选择和参考离散误差仍可能共同作用。标量8个负偏差也不能都归于高或低A；同组中包含多种A和方向。

5. **不据此划连续分段适用域**：5个配对几何足以列出局部差异和反例，尚未建立以A阈值划分的连续精度域。A本身还是待预测导度之比，若用它作输入选修正分段，需要额外定义可获得的预测变量，不能默认事先知道。现稿宜逐几何/按h、d条件报告残差，不新拟合分段式、不新增范围保证。

6. **方法独立性**：OpenLB/LBM、FVM和FEM是不同数值离散实现；在有同条件三种结果的h75，可讨论三方法对照。FEM的保存场积分/方程重组复核器不是额外独立求解器。不得把“复核器不是第三求解器”误写为“FEM本身不是相对OpenLB与FVM的第三种方法”；也不得把局部三方法对照推广为全24条均经三方确认。

7. **FEM与FVM接收框架**：不能写“按与FVM完全相同的门槛和全部条款验收”：FEM为自己的试点协议，横槽截面门槛0.01%，FVM为0.1%；网格序列与代数接收方式也不同，FEM没有继承FVM的同网格tight检查。当前0正式接收可按既有项目状态保留，但不能把FVM运行回执格式当成所有FEM参考的普遍科学必要条件。应单独说明FEM接收依据、现有场/哈希/依赖、缺失的历史绑定及有限采用范围；不能伪造历史执行回执。FEM若另建版本化规范运行包，并不当然令旧FVM的23份回执失配；那一问题涉及原FVM发布身份被改写，不能作为FEM选择的通用“整链重跑成本”。本轮不建议或授权重跑。

8. **如实报告差异不是可选项**：保留所采用点集中的h25/h50/h75横槽偏差，不请老师选择是否隐藏超2%的点。需要确认的是采用范围与主张强度。当前FEM-P相对对照18/19在2%内、FEM/FVM组合T为2/5在2%内，都可作描述性计数，不能偷换成全部正式门槛已通过。

## 核实保留的数字

19P+5T共24条比较，LC全部为正；P范围+10.8888317%～+206.9577344%，T为+24.8389183%～+56.4176598%。V2有8条负偏差，且24条绝对偏差全部小于LC。h100/h125的V2 A差−7.1711%/−14.2124%，OpenLB A差−1.0860%/−0.8065%，按当前同条件候选对照分别报告。h75的多种参考组合反映该几何对参考来源的敏感性，不增加独立几何数或盲测数。

## 可用于正文的限定表述

在涉及19种几何的24条补充方向比较中（19条沿槽、5条横槽），采用FEM保存场复核结果及已合格FVM值作为所注明身份的数值对照，局部立方律的导度偏差均为正，沿槽与横槽分别为+10.89%～+206.96%和+24.84%～+56.42%。保持系数不变的V2在这24条比较中均减小绝对偏差，其中8条转为负偏差。改善幅度与几何和方向有关；在h100/d100及h125/d120两个成对几何上，V2仍分别低估方向比约7.17%和14.21%。这些补充比较单列于原36条5nm主统计之外，不构成连续适用范围、严格误差界或独立盲测认证。
