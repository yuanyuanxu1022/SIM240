## 4. 唯一的技术阻断项：pvpython 里没有 numpy

`read_fields.py`（读场脚本）需要 `import numpy`，但 ParaView 自带的 python **既没有 numpy，也没有 pip**：

```
/usr/bin/pvpython -m pip --version  →  No module named 'pip'
```

**已找到不需要 sudo 的解法**：系统的 python3 恰好也是 3.10，且自带 numpy 1.21.5。直接把系统 numpy 的目录挂给 pvpython 就行。已实测通过：

```
$ PYTHONPATH=/usr/lib/python3/dist-packages /usr/bin/pvpython -c "import numpy,vtk;print(...)"
OK numpy 1.21.5 vtk 9.1.20211106
```

**所以读场那一步将来这样跑**（在原来命令前加一个环境变量即可）：

```
PYTHONPATH=/usr/lib/python3/dist-packages pvpython --force-offscreen-rendering -B read_fields.py ...
```

不需要装任何东西，也不需要管理员权限。
