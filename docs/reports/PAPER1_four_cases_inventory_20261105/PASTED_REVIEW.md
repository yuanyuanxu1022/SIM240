# 对用户补充“文献怎么闭环”调研的定向核查

2026-11-05。本文与四组只读盘点一起交付，作为研究路线论证检查，不是对所列全部文献的系统复审。本轮读取用户附件，公开检索只使用公开题名/DOI，没有上传项目结果或附件全文。

## 可以采纳的方向

按用户补充，接受“老师希望暂不继续纠缠S4的1%门槛，先看论文怎样形成可信科学结论”作为当前工作优先级。有限验证、限定范围、保留失败与局限是合理的论文组织方式。网格检查不能成为唯一研究目标；以可检验机制和适当独立对照组织证据值得采用。

这与“已经科学闭环/已经足够发表”是两个判断。本轮不恢复0.625或自动S5，也不自行选择附件路线A/B。

## 必须修正的关键推断

1. “没有一篇使用1%硬线”的总断言证据不足。附件自身承认OpenLB综述全文门槛未核，不能由未见证明不存在。即使所查论文没写某个数字，也不能推出没有做定量网格误差评估或领域统一不需要。建议改成：“所查可得材料采用多种验证方式，未建立跨文章统一1%标准。”本轮不为所有列举论文作有无门槛的全文判定。

2. 1.328%和10%不能直接比较。前者是特定几何两档数值解间的变化，不是已知真解误差；Ryu的10%是特定填充率模拟—实验差异，含模型和实验等不同来源，输出/分母/问题也不同。文献10%不是本项目通用允许线，不能说本项目“好得不能再好”。Ryu原摘要写最大差异10%，不宜无依据改为严格小于10%。本轮核：https://pmc.ncbi.nlm.nih.gov/articles/PMC5487822/ （摘要），DOI10.1186/s40580-017-0108-z。

3. 不能从“没有写1%”直接推“咱们S1/S2/S3+C系列+V2够闭环”。平板/线性/局部网格支撑的是相应计算性质；平均模型接口吻合支撑实现；V2旧样本残差是回顾性评价。这些各有用，但不会自动完成新几何预测、物理机制或实验验证。要先固定论文主张，再判断证据是否足够，不用程序Gate语句替代科学结论，也不用文献发表事实替代本项目证据。

4. 当前第一篇四组对象为单相全充液、D3Q19 ForcedBGK、固定无滑移固壁，不含Cahn–Hilliard液气界面或移动接触线。附件“咱们正用well-balanced CH+移动接触线边界”混入了另一研究范围，不能据此迁移两相验证结论。

5. 变分推导支持特定方程和假设下的热力学结构，不自动保证真实材料模型、离散算法、参数或适用域正确。Xu/Thiele/Qian2015的摘要明确为二元混合薄膜：Onsager变分→二维动力学→长波一维约化，与梯度动力学连接，互易对称保持；不能写成一切“模型正确性靠构造保证”。本轮核作者机构摘要：https://researchportal.hkust.edu.hk/en/publications/a-variational-approach-to-thin-film-hydrodynamics-of-binary-mixtu/ ，DOI10.1088/0953-8984/27/8/085005。

6. 跨方法比较要区分标定与检验。Qian/Wang/Sheng2003的公开原文引言说有两个动力学参数由一个MD流动剖面确定，再检查其他Couette/Poiseuille流动。这个结构值得学习，不能把输入MD标定和后续独立条件合成“所有对照都是独立预测”，也不能视MD为实验真值。该页支持连续模型/MD互证，不代表每篇都同时完成实验。来源：https://sheng.people.ust.hk/wp-content/uploads/2017/08/Molecular-Scale-Contact-Line-Hydrodynamics-of-Immiscible-Flows.pdf ，DOI10.1103/PhysRevE.68.016306。本轮核首页/引言公开文本，非15页全文逐式审定。附件2003“从Onsager推导”的归属另需原节核对，不据此认定已核；作者主页单列2006的变分文章：https://sheng.people.ust.hk/?p=174 。

7. 不能把所有网格门槛直接替换成跨尺度/实验对照。两者检查的问题不同，恰当组合由主张决定。原S4的FAIL保留；若作者日后选择限定的历史离散结果主张，可独立写明新的范围和局限，不追改旧协议为PASS。是否需要数值补证，看对应结论是否受其影响。当前四组横槽增益3.38%，而仅深槽细化已变化2.11%，浅槽无匹配细档，正是需要具体分析而不能套用10%通用线的例子。

8. 实验不是这次四组局部输运盘点唯一缺口；没有实验不能声称已物理验证，但理论/数值模型论文可用解析/独立数值/适用范围支撑有限主张。随意一张J-FIL填充图与全充液固定间隙K并不对应，不能填上所有缺口。若保留真实工艺主张，再选择相匹配的几何、物性、驱动、相态和输出的实验或独立证据。

## 建议给老师的准确说法

“我们先不围绕1%继续追加计算，而把已有结果整理为方向输运规律、局部近似的可检验解释和适用边界。四组原始数据与流场齐全；已有证据可以报告保存离散结果及其局限，但薄弱处包括浅槽缺匹配网格、历史构建来源和机制量化。先用现存场补最小分析，再据具体主张决定是否需要新算例/实验。原S4历史FAIL保留，不把它混同论文所有有限结论。”

这段是建议汇报口径，未替老师采用新协议或冻结最终科学结论。其余列举的Kunert/Harting/Sbragaglia/Ban/徐祖顺等细节本轮未逐篇复核；不沿用附件勾选标志当已核证据。
