## A. 合同目标、量与独立性

沿槽：−Δv_hat=f_hat（均匀驱动f_hat=1）；横槽：−Δu_hat+grad(pi_hat)=f_hat、div(u_hat)=0。物理压力符号与对称块[K,−Bᵀ;−B,0]一致。只施加一次显式体力或等效压降，不重复驱动。周期/壁面优先级和常数零空间沿已审方法。

统一定义：J_hat=P_hat^−1∫Ω_hat u_main_hat dA_hat；均匀驱动的K=h³J_hat（m³）、J=a h³J_hat/ν（m²/s）、R=ρa/J=μ/K（Pa·s/m³），A=KP/KT。制造解源项非均匀，只记录无量纲场/泛函，禁止把J_hat=1/6叫作物理迁移率；平板均匀驱动J_hat=1/12。

几何/物性输入需独立核P、w、h、d、φ=.5、单位与方向。槽域面积Ph+wd；槽口是内部连通面，不能误作墙。外侧周期液体段只有x=0/P且0<z<h；上下/竖壁片与凸台区域分别标记。矩形使用整高周期面，不能直接照搬到槽顶高度。P2边中点周期约束、固壁交点优先、P1压力常数规范逐项核验。

1. **重建：** 从三角顶点和每单元P2/P1混合索引重建插值；P2节点由顶点/边中点坐标与分量识别，不能假设cell_velocity_mixed_dofs中的12值恰好按手写局部顺序排列。梯度使用仿射映射的物理坐标Jacobian，面积使用绝对行列式；单元取向不得改变泛函。
2. **提取器夹具：** 常数/线性P1、完整二次P2、零场、已知面积/积分/梯度、多种顶点顺序及坐标单位测试；真实数组/合成夹具类型分开。压力均值独立积分核，与现存P1面积权重比较。夹具不导入PDE后端，不伪造真实解。
3. **解析误差：** eu=||uh−uex||L2/||uex||L2；ep=||ph^0−pex^0||L2/||pex^0||L2。两压力分别按相同几何连续面积积分去均值；使用非零的解析范数作分母，不用节点均方误差替代单元L2。标量/向量分开，MMS解析场与f由手写公式独立评估，不调用组装UFL源项函数作为唯一校验。
4. **通量：** J_hat为单元连续积分除P_hat，MMS报告绝对误差|J_hat−1/6|；均匀平板对1/12比较。横槽截面用预登记的7个x/P位置{1/8,1/4,3/8,1/2,5/8,3/4,7/8}；精确相交三角形并分段积分P2，不靠最近节点、不跨固体。位置落在单元边时采用一致单侧规则且避免重复积分；通量场连续时两侧应一致。后续沟槽还需按几何特征登记转角两侧截面，不能只用这7处冒称处处守恒。ηq=max_j|q(xj)−J_hat|/|J_hat|；J非正/零则不合格，不以任意1掩盖分母。
5. **能量：** D=∫|grad uh|²，W=∫f·uh，Pdiv=∫ph^0 div uh。标量用D=∫|grad vh|²、W=∫f vh。混合弱式检查D−Pdiv−W，另报D−W及Pdiv；均匀驱动时W=∫u_main，MMS必须用实际f，不能把f换成单位体力。归一化分别用max(D,|W|,|Pdiv|)或max(D,|W|)，正驱动的D/W需有限且为正；不另加重复压降功。梯度积分不是原VTK耗散字段的直接替代。
