# 第一篇论文如何形成闭环：重新组织科学问题与最小证据

2026-11-05，北京时间。用户明确要求重新思考闭环。本报告为可审阅的研究设计建议，非最终公式/机制冻结、非新计算协议，未自动采用新路线或启动运行。

## 一、推荐与纠偏

推荐核心：固定间隙、全充液矩形沟槽中，局部平板组合对几何变化产生的方向输运收益作出了怎样的预测，哪些预测被显式槽结果支持，哪些被否定；据此形成受限定的修正/使用建议。

候选论文问题：“局部立方律为何高估加深矩形沟槽带来的输运收益，这种偏离如何随方向及公共液层间隙改变？”其中“为何”尚待机制证据；如果不能检验解释，标题和主张应退回“如何偏离”，不能先宣布原因。

前轮建议把选5/10/20%容限放在首位，容易让工作继续围着门槛转；当前先确定可检验的科学主张，再匹配证据，容限服务具体用途，不是本轮整理的前提。

单纯“沿槽快于横槽”“加深沟槽更有利沿槽”已被原模型和文献预期，不能独立作为创新。单纯“V2对参与修正的旧数据更贴近”是回顾性拟合成绩，不能成为预测闭环。模型取同一K的两套程序吻合不独立验证K。不要自动通过新增软件、完整两相压印、MD或更多网格层级寻找闭环；新增内容需直接回答一个尚缺的判断。

## 三、五个相连的问题和结束标准

### 1. 规律是否存在、是否足以区别旧模型？

先用已有资料画固定h的K∥/K⊥随d变化及无量纲几何坐标下的模型/离散对比，保留全部18几何36点与反例。检查不同构建组、网格、驱动和方向的来源。选择同一来源下的浅/深槽为主证据候选，历史完整地图作探索材料。结束条件：明确到底哪条趋势被旧模型漏掉或幅度高估，以及该判断受哪些参考不确定性限制。不能把已知各向异性包装成首次发现。

### 2. 哪个物理解释经得起对照？

候选解释：局部平板组合未解析有限槽宽/侧向黏性耦合及深浅区域连接处流动，公共薄液层改变横槽通过能力。这些是待检验假说，不是已识别唯一原因。优先选同h浅槽/深槽两个几何、每个P/T，共四组场的既有证据做可用性盘点；具体点可先考虑h50/d25与d100，不能因此称已获准正式四次运行。

能提取时核：同驱动下速度/通量在公共液层和槽区的分配，剖面与局部平板近似的偏离；若用耗散，则先统一积分、流量、功率和壁面口径。固定压差时流量较大也可能耗散功率较大，不能直接把全域耗散大小当阻力排序。若需比较阻力代价，明确相同总流量或合适的归一化；分区耗散份额不等于“移除该区域能减少的阻力份额”。本轮不推导最终能量公式、不执行场提取。

已有附录E在特定理想Stokes条件下论证立方律上界，本轮不重新终审该证明；上界不确定偏离幅度、不确定各向异性比偏差符号、不证明角点唯一原因。已有20261018机制审查明确§12.3暂缓，本方案只列科学需求，不自动恢复该工作包。若不补机制证据，保留现象和模型比较，撤下强因果解释。

结束条件：候选解释导出至少一项能被条件变化否定的预测，并有相应对照；证据只支持“与某解释一致”时沿用这个强度，不强写因果。

### 3. 模型能否面对未用于选择它的条件？

原公式作为固定基线，V2先保留已公布系数，不为画好曲线现场重拟合。18几何是已知数据，事后留几行不自动恢复为盲测；已见反例重算可检查可靠性，不能算新预测。若要宣传预测能力，先审旧D4保留条件是否真的未进入任何选择/调参，原许可是否适用；本轮不读取封存预测结果。不可用时，另定少量新条件，在结果出现前存下原公式/V2的逐点预测、目标量与比较规则。选中间条件检查插值，另选薄间隙/边界检查失败范围；不是先定必须若干条运行，数量取决于主张和可复用证据。

V2若未改善新条件，照实保留结果，论文仍可研究旧闭合局限；不能以“闭环”名义保证V2获胜。要换模型需新版本和下一轮独立检验。限定结束条件：已冻结模型经同条件可靠参考评价，成功和失败均能解释为有边界的结论；不是要求所有条件全PASS。

### 4. 这项区别影响什么输出？

第一篇最小终点可以是固定间隙方向流量/水力阻力及槽深选择含义，不必自动做动态填充。建议以同驱动下深槽相对浅槽的输运增益作为直接设计相关输出；如称“优化”，还需设计目标/约束和比较候选，目前只够提出设计启示。

若希望展示应用，可另选一个明确固定间隙流动问题，三套K（原公式、V2、可靠显式槽导出的K）输入同一平均模型，比较同压差下排液Q或相同Q所需压差。该层是系数影响传播，参考K输入不构成独立宏观验证。恒K一维定压差算例的压力线可能完全一样，应看Q而非用压力重合证明模型准确；若要判断张量方向预测，必须用独立直接计算的斜向驱动场，不能把两主值代数重建当新增验证。

现有OpenFOAM C01—C04/GDI01已提供同一平均模型的接口与输出差异，可复用其限定证据，不重复造软件。新宿主P1—P4和A/B/C尚非运行就绪，其C包含间隙变化，不能无声纳入固定间隙最小闭环。真实压印时间/缺陷/载荷的主张需要另立过程与独立验证，不在本轮自动范围。

### 5. 数值证据是否足以支持上述具体判断？

已有S0—S3和原始诊断是基础，S4原横槽1.328387035%>1%FAIL不追改。网格间变化不是连续误差上界，更不能把h30/d80变化统一套给h50或18几何。严格URV参考路线仍按原协议S4/S5及来源事项完成才有相应资格；本方案不声明可跳过。若作者决定只做较弱、明确限于历史离散结果的研究，应形成单独主张/协议修订并保留原FAIL，而非改旧门槛。不能只因沿槽变化大就说所有重要主张稳定，也不能只因“未到1%”就否定所有已有有限证据。判断稳定性应落实到对应几何和对应比较。
