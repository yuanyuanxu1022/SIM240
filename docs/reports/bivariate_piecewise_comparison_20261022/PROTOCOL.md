# 双变量连续式与连续两段式：运行前比较协议 v1

日期2026-10-22。用户授权比较双变量连续式与连续两段式，检验分段是否改善预测。本协议在本轮拟合与验证输出产生前写入，不修改OpenLB冻结协议或数值门槛。分析属于基于已查看数据的回顾性建模，不是独立最终验证；没有新仿真授权。

## 目标量与固定输入

主数据为5nm的18种几何、36个P/T结果，沿槽与横槽分开拟合。w=120nm、P/w=2固定，K单位m³。按各run原始result核对h、d、dx与K，不将先前派生表作为唯一来源。原V2四位舍入式仅作固定描述性基线；它已使用数据知情的模型选择，不当成严格外样本对照。8个2.5nm记录仅用于全数据模型的参考网格敏感性表，不进入拟合，也不当独立新几何。

记α=h/w，β=d/w，x=lnα，z=lnβ，K0为已有局部立方律式，E=K0/K_ref−1。36点E>0须从原始结果复核；如不成立则停止本协议，另记偏离，不静默改目标。

## 固定候选

全部预测K_hat=K0/[1+exp(g)]，保证正值且不超过局部模型。下述仅为样点域内的经验候选，不声称全参数空间物理极限或机制已证明。

- C3（简单双变量连续，3参数）：g=a+b z+c x。
- C4（光滑双变量连续，4参数，主要对照）：g=a+b z+c x+d x²。
- H4（连续两段，固定断点时4参数）：g=a+b z+c x+s max(x−τ,0)。α_c=expτ。两侧自动连续，但斜率可变；两个方向独立选择τ。

每个训练集独立拟合，以等几何权重最小化Σ[g−lnE]²，b≥1e−8，其余系数不加界。使用全局线性最小二乘；若无约束解满足b限制直接采用，否则用凸约束线性最小二乘并保存状态。该目标强调乘性超额导度偏差，非最小化最坏K误差；所有候选用同一目标。没有增加候选、多起点或根据结果改模型的计划。

C4与H4的条件系数数相同，但H4还选择断点，灵活性更大；须通过内部选择和外层留出处理，不能称参数预算完全相等。

## H4断点选择（严格限训练资料）

候选τ为当前训练集相邻不同x层的中点，即h_c为相邻训练h的几何平均。两侧至少各有一个h层，并要求设计矩阵满列秩及至少3个h层；不将候选点称物理临界值。

在每个外层训练集内，使用整层留一d的内部检查选择τ，评分为各内部d组相对K误差平方均值的等权平均，再取最小。候选在每次内部拟合中固定，仅由外层训练h产生；内部验证层的K不参与拟合。内部训练若秩不足则该候选无效，记录原因，不借用外层测试数据补救。评分在1e−10绝对数值容差内并列时，选最接近训练x范围中点的τ，再选较小τ。保存所有候选分数、并列集与设计条件数。

当训练只剩3个h层时，H4的分界可能有多个等价内插表现；必须报告这种不可辨识性和留出预测差异，不把某个确定选值当物理证据。

## 外层检查与分组

两条各自独立的外层方案，所有候选使用完全相同的分组：

1. Leave-h：整层留出h=25、50、75、125nm，4折；每方向18个一次性外层预测。
2. Leave-d：整层留出d=25、50、75、100、120nm，5折；每方向18个一次性外层预测。

同一几何的P/T与各网格不拆开用于验证：两方向虽然分别建模，但留出同一几何层。5nm仅作为模型输入。所有模型选择（H4的τ）均在外层训练集进行。

对留出的最小/最大轴层标记为“该轴外推”，中间层标“该轴内插”；这只是边际轴标签，不代表已证明处于二维凸包内部。Leave-h与Leave-d重复使用同18种几何，指标不能当成36种独立新几何，也不进行基于独立随机样本假设的p值检验。

## 指标与判读（分析判据，不是新数值Gate）

误差e=100(K_hat/K_ref−1)。分别对每方向、每外层方案报告：MAE、RMSE、最大绝对误差、平均有符号误差；另列每个留出组、内插/外推子集和逐点误差。比较H4−C4为主要比较，H4−C3为补充；报告相对改善率及组别胜负。

每个方向：若H4在两条外层方案中均降低MAE与RMSE、且两条最大绝对误差均不增加，称“该协议下有一致的回顾性改善”；若指标相互取舍，称“结果混合，不能认定稳定优于连续式”；若两方案MAE与RMSE均不改善，称“没有预测改善证据”。数值容差1e−10只用于并列，不作科学显著性门槛。任何结论仅限这三种形式、目标函数和现有数据范围。

完整18点训练误差单列，不用它替代外层预测。全数据最终系数仅为后续复核与代数计算提供，不自动替换V2或主结论。报告分界跨外层的变化、并列情况、正值/连续性、端点与系数舍入影响。
