## 二、最容易犯的三个错（务必先看）

### 错法 1：按文件名里的日期判断新旧 —— 错

文件名里的 `20261022` / `20261028` / `20261024` 是**建档日期，不是内容版本**。

- 中文稿名字里是 `20261022`，内容已同步到 **2026-11-10**；
- 英文稿名字里是 `20261028`，内容也已同步到 **2026-11-10**。

**所以"找带 20261110 的文件名"永远找不到正文。** 判断新旧请看：①上表哈希；②文件头"同步日期"行；③`ls -la` 的修改时间。

### 错法 2：把 `before/`、`historical_` 目录里的文件当成正文 —— 错

以下目录里的文件全是**合入前的自动快照**，内容比现稿旧，只用于回滚与审计：

- `PAPER1_width_evidence_merge_20261110/before/...`
- `PAPER1_mechanism_merge_20261109/historical_post_abstract_...`
- `PAPER1_v3_literature_merge_20261110/`、`PAPER1_lower_bound_merge_20261109/` 下的同类快照
- 任何名字以 `before_` 开头的文件

### 错法 3：拿 `20261019` 那批整合稿当参考 —— 错，且已证实会误导

见下节清单。**特别是 `SIM240_EJMB_中文重写稿_v2_20261019.md`：它的 §5.1 与现行 §5.1 结论相反**，
