# archive —— 已作废文件归档区

用途：存放**已被取代、但仍需保留证据身份**的文件。移入此目录的文件一律在开头加"已作废、请勿引用"横幅，正文一字不改，并附保真核验方法。

## 为什么是归档而不是删除

1. 本项目多数稿件与报告**未纳入 git**，物理删除不可恢复。
2. 大量历史快照（如 `*/before_*`、`*.md.before`）按文件名引用这些文件，删掉会使记录变成死链。
3. 项目既有约定：历史 FAIL、历史快照、旧停点原样保留，不用新结论覆盖旧记录。

## 保真核验方法

对归档文件取**末尾 N 行**（N = 上表"正文行数"）计算 SHA256，应与上表一致。例如：

```bash
tail -n 186 docs/reports/archive/SIM240_EJMB_中文重写稿_v2_20261019.md | sha256sum
# 期望：5b4a6c199774194d96969192f00664a4735030231930e34afa45a8e847555bd7
```

**不要**对整个文件取哈希——加了横幅必然不同。

## 引用规则

- 引用章节号、数字、系数、结论时，**一律以现行正式稿为准**，不引 archive 内文件。
- 需要追溯"当时是怎么写的"时，可以引 archive 内文件，但必须同时注明**已作废**及其取代者。
