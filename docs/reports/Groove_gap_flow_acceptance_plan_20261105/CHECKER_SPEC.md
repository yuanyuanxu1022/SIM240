# 独立流场检查器规格（尚未实现）

本文件是运行前设计，不能以存在本文件推断检查器可执行或结果已通过。实现应使用只读原始文件及独立数值核对，不调用宿主、旧拟合模块或模拟器，不回写输入/原结果。

## 输入与绑定

逐例读取最终采用的输入合同、source/ELF/库/检查器manifest、全部mesh文件、初态p/U、当前与前一间隙、gapDeltaT/epoch、fvModels、求解设置、正式执行命令、完整日志、独立exit/completion以及完整输出清单。校验重复/缺失/路径越界/哈希漂移。测试夹具、GAP_audit、旧GDI01或其他输入的输出不得作为本例正式结果。

执行成功只接受独立退出0、未超时、有限原生场与完整历史；缺文件、输出NaN、参数/模型/坐标不符、预置解析初态、未solve或伪造身份须拒绝，不仅警告。

## 必须从原始数据独立重建的项目

1. 解析输入中的目标仅用于比较。实际压力读原生p，实际Q读保守phi，实际储量读两个原始h字段和mesh平面面积。
2. 对所有单元校验H=h+50nm、Hdot=(h_new-h_old)/dt及J=HU；对所有面校验实际H_face/b0和面积/法向。守恒主通量不以U插值重构覆盖；U重构是另一项检查。
3. 用owner/neighbour和边界法向求所有单元E=sumQ+A*Hdot、全部边界各自带符号Q、总S=sum(AHdot)、V_old/new及dtQ体积收支。零净流工况使用预先固定Q_star，禁止除0。y漏流统计逐面绝对值。
4. 读完整p/U/J剖面，以坐标对应解析目标；不得挑中心点替代全场。统计RMS和max，使用合同固定尺度；非主方向用主向尺度，无局部零值相对误差。
5. 从网格和边界独立Gauss重建grad(p)，从实际D/U/μ重算未分裂阻力，并核动量残差；以原始压力矩阵系数、源、边界项重算每轮真残差。所需数据未导出就列不具备，不能用生产端报告值顶替。
6. 独立重算当前液体体积加权耗散及边界/储量压力功；力响应若已含μ和参考体积，不再乘一次。核时间戳/epoch/模型及所有场/CSV一致。
7. 核每一轮内/外收敛、最后ΔU/Δp，防止压力第一次收敛而动量未收敛即停。正式数据中的1/输出标签不视为物理时间推进。

边界U若由压力校正Q更新，再由U回算Q的一致性只检查接口，不能单独证明正确性。必须同时对照独立解析压力/两端Q与原始储量收支，避免用反算恒等式代替流场验收。

## 必要软件测试

- 公开标注的合成正确数据可测试算术，但不记正式仿真PASS；旧GDI数据只作原状态下回归。
- 破坏一个边界Q、翻转法向、漏一个边界、删除h_old、改变dt/epoch、漏储量项、把b0代H、交换方向、改K系数、错误Pa/运动学压力、CSV与原生场不符、缺退出码/未solve、修改来源哈希，均应被具体守卫拒绝。
- 对A/B的零净流与C的两端均外流分别验证分母和符号。必须有“全局抵消但局部不守恒”的负样本。
- 对矩阵来源及残差构造不同的正/负样本，不让测试只重复检查器自己的生成函数。

## 输出

输出逐指标expected/observed/normalization/threshold/PASS与证据定位、缺失列表、整体运行身份及范围。NUMERICAL_GATE、RESULT_PASS、geometry_PASS分别给出，缺几何资料不能按程序退出补为true。physical_validation=NOT_EVALUATED、reference_qualified=false、model_prediction_accuracy=NOT_EVALUATED。

检查器不得启动第二例或重试；不得自动放宽合同门槛，不回写solver.json中的原始接受状态。最终科学签字仍由作者/导师负责。
