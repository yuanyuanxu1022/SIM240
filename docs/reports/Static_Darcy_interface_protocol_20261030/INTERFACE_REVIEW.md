# 平均速度与壁面阻力审核

日期：2026-10-30。SDI-v1；用于静态接口实现的工作规格。审核者为 AI，尚无独立人工科学签字。证据路径与哈希见 source_manifest.json；方程推导为本轮分析，不伪称文献结论。

## 1. 结论与适用范围

选用**总阻力的厚度平均 Darcy 模型**。在固定、均匀 H 下，OpenFOAM 的 U 明确定义为液体体积平均速度，H=125 nm；其计算薄层用于承载平均守恒方程。原沟槽无滑移壁面导致的阻力已包含在 K/D 中，不在此平均层再解析上下壁剪切。

这是对首个静态接口检查的路线选择。它不表示已经建立全三维 OpenFOAM 流动模型，也不代表动态挤压、边缘层、局部应力或气液界面已获验证。将来若要比较更完整的动量方程，须另行限定面内黏性与惯性项，不能把本协议的一致性结果外推。

## 2. 从原始平均定义到接口

现有 D2 源码 `measure()` 在材料1流体内累计 u·dV，分别除以流体体积和单胞平面面积；最终由 μJ/(ρa) 提取 K（E01）。因此

\[
\overline{\mathbf U}_f=\frac{1}{V_f}\int_{\Omega_f}\mathbf u\,dV,
\quad\mathbf J=\frac{1}{A}\int_{\Omega_f}\mathbf u\,dV
=H\overline{\mathbf U}_f,\quad H=V_f/A.
\]

这一关系是定义恒等式，不需要假定真实厚度方向速度均匀。**平均模型的均匀速度不能被解读成真实沟槽内处处均匀的速度。** 对理想完整周期，H=h+(w/P)d_g=125 nm；当前定义/已存数值核对不补齐历史可执行文件来源。

采用物理过压 p（Pa）、G=−∇p，有

\[
\mathbf J=\frac{\mathbf K}{\mu}\mathbf G,
\quad\overline{\mathbf U}_f=\frac{\mathbf K}{\mu H}\mathbf G,
\quad\mathbf D=H\mathbf K^{-1},
\quad\mathbf M=(\mu\mathbf D)^{-1}=\frac{\mathbf K}{\mu H}.
\]

K：m³；J：m²/s；D：m⁻²；M：m²/(Pa·s)。于是 `U=−M grad(p)`，定间隙守恒 `div U=0`，等价于 `div(K grad p)=0`。此处 H、μ 均为空间常数；不得据此将可变 H 问题写成无条件 div U=0。

若改用175 nm包络上的表观速度 U_s，则 U_s=(125/175)U_f、D_s=175 nm·K⁻¹，在相同压力项约定下 D_s=(7/5)D_f。两组 U/D 必须成对改变。只保留旧 D 却把原生三维面的面积增大到175 nm，会把流量高估7/5；反之将 D_s 当成 D_f，速度会低估为5/7。φ_g=1/2 是槽平面占比，不能替代体积比5/7。

本次选计算层厚度 b=H=125 nm，且无独立孔隙率字段，则有限体积面的流量 `phi=U·Sf` 与二维 `∫J·n ds` 一致。若日后仅为网格便利更换 b，必须将输出流量乘 H/b，并重新审查方程；本协议禁止静默改厚度。

## 3. 阻力已经包含什么

原始立方律包含局部平板无滑移阻力，V2 在其上修正，现有 OpenLB K 来自有固壁的流体流动。三者都不是“去掉上下壁后剩下的附加阻力”。因此不能把 μDU 当纯沟槽增量叠加给另一套完整壁面剪切。

用一个可精确求解的模型说明这一点。设厚度 b 的平板、均匀驱动 G>0，保留分子黏性并叠加正 Darcy 系数 D，满足

\[
\mu u''-\mu D u+G=0,\quad u(-b/2)=u(b/2)=0.
\]

对 D>0，解和深度积分导度为

\[
u(z)=\frac{G}{\mu D}\left[1-\frac{\cosh(\sqrt D z)}{\cosh(\sqrt D b/2)}\right],
\]
\[
K_{\rm slab}(D)=\frac{b}{D}\left[1-\frac{\tanh a}{a}\right],
\quad a=\frac{b\sqrt D}{2}.
\]

若误填 D=b/K_target，则 K_slab/K_target=1−tanh(a)/a<1。对 b=125 nm，本轮解析复算：原公式沿槽约0.3746、横槽约0.6377；V2沿槽约0.5502、横槽约0.6955（完整值见 analytic_checks.json）。这些是平板解析反例，不能直接视作实际沟槽或现有 nanrPrint 的误差。

D→0 时 K_slab→b³/12；正 D 只会降低该平板导度。b=125 nm 时 b³/12≈1.62760×10⁻²² m³，小于原公式沿槽2.40885×10⁻²² m³，因此该通道连“用非负附加阻力匹配所有目标”的条件都不满足。它不否定有175 nm局部深区的沟槽原模型，只否定125 nm无滑移平板作为这组总导度的通用承载几何。

所谓 D_add=b(1/K_target−1/K_wall) 也不是上述微分方程的一般精确反演：壁面剪切随速度剖面一起改变。若采用解析壁面路线，应针对选定几何/边界反解完整模型，并先证明可实现范围；本次不采用该路线。OpenFOAM 的负 Darcy 输入另有倍率语义，不能用来补偿虚构的负阻力（E04）。

能量也一致：平均模型单位平面面积耗散 μ U·D U H=μ J·K⁻¹J≥0，等于压力驱动功率密度 G·J。这里的耗散是原微观黏性耗散的平均表示，不再加上同一微观壁面的另一份耗散。

## 4. OpenFOAM 接口的具体选择

采用 Foundation 13 的有限体积运算构建独立应用，暂定名 `depthAveragedDarcyFoam`（尚不存在可执行文件）。二维程序读取 K；OpenFOAM 读取 D、μ、H，在程序内只对面内2×2矩阵求逆生成 M，然后解 `div(M grad p)=0` 并输出 U/J/phi。不能绕开 D 直接读 K，否则没有检查阻力接口。

二维端用 K/μ，OpenFOAM 端用 (μD)⁻¹；两者由独立的离散代码形成压力系统，不把一端的场当另一端的答案。它们依然共享相同物理闭合；一致性不等于独立物理验证。

z 正负面使用 empty、z仅一层；在运算中将面内 M 嵌入三维数组，Mzz=0、Mxz=Myz=0，**先求面内逆，再嵌入**。这里的零是被排除方向的运算占位，不是实际竖向渗透率测量，不定义Dzz，更不对奇异三维矩阵求逆。所有压力/系数/输出场的z边界类型须相容。

empty 的官方用途就是减少求解维度，并非无滑移固壁（E05）。不启用 `fvModels` 中的第二份 Darcy 源，不解含上下壁黏性项的动量方程，不加 Forchheimer、重力或体力。物理压力以Pa读写；ρ只用于可选量级诊断，不进入该静态方程。若以后换成运动学压力，必须同步将μ换成ν，作为新接口版本处理。

官方 DarcyForchheimer 定义 S=−(μD+ρ|U|F/2)U 支持这里的单位链（E04），但本次选择是消元后的压力应用，**不验证内置 porosityForce 的加载、源项装配或两相接入**。本机 fvmLaplacian 模板、Gauss 张量通量以及 fvMatrix::flux() 已读取（E06—E08）；这属于源码可行性依据，编译兼容性仍待实际检查。

## 5. 审核事项与裁定

|事项|证据与风险|本次处理|
|---|---|---|
|U 与 J 混用|D2按不同分母定义，单位相差m|固定 U=J/H，输入/输出双向核对|
|125/175 nm混用|体积平均与包络平均不同|选125 nm等体积平均层，输出面面积相同|
|重复壁面阻力|上述解析反例及总K定义|采用总阻力，排除再次解析厚度剪切|
|静态无驱动却期待流动|四边同压且V=0只有零流|两端给压差，另两边零法向通量|
|非对角边界错误|零法向压力梯度未必零法向流量|v1仅0°/90°对角K；一般斜槽另制协议|
|最小算例过于简单|线性解不检验复杂压力/边缘层|只授予接口一致性结论，不作网格独立或准确性证据|
|平均模型被称为三维验证|无真实沟槽/局部应力/运动|所有产物标记平均接口检查，后续显式参考独立建立|

本轮已排除定义歧义并给出可实现的静态选择；无新增流动解，所有未来算例的结果仍未评价。独立参照、未参与拟合条件、可变H守恒、挤压力/总应力对应仍在本协议范围之外。
