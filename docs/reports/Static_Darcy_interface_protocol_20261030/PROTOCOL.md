# 最小静态压力驱动接口实施协议

协议ID：SDI-v1；日期：2026-10-30。**设计规格已明确；未实现、未编译、未运行，launch_ready=false。** 本文件确定本诊断的输入和检查门槛；不替代现有项目冻结协议，不追认旧 Gate，不授权仿真启动。规格变更须先生成新版本及原因，再看新结果，不能按结果调门槛。

## 1. 目的与最小启动单元

检查两条实现链是否给出相同的压力—平均通量关系：

- 二维端：K → 压力方程 → J。
- OpenFOAM端：D → (μD)⁻¹ → 压力方程 → U → H U。

首个独立启动单元仅为 C01。随后四个主对照及控制项均是预先设计，不构成本轮或单例启动授权的自动扩大。两端都实际运行、原始输出齐全且独立结果读取器检查后，才能标记某项接口检查满足。

## 2. 模型与坐标

采用 INTERFACE_REVIEW.md 中的总 Darcy 阻力平均模型；H、μ、K 均恒定。全局x短边、y长边、z被排除。物理压力p为相对于出口环境的过压（Pa）。

二维：J=−(K/μ)∇p，div J=0。

OpenFOAM：M=(μD)⁻¹，U=−M∇p，div U=0，J=H U。

不解惯性、厚度方向剪切、面内Brinkman黏性扩散、两相或热方程。没有壁面运动、体积源、体力、重力、Forchheimer项和额外孔隙率。V=0，挤压阻力F/V不适用。

## 3. 本诊断采用的具体输入

|量|SDI-v1设置|理由/范围|

|μ、ρ、ν|0.001 Pa·s、1000 kg/m³、10⁻⁶ m²/s|本静态诊断采用；ρ不参与物理压力方程|
|基准G|10⁶ Pa/m，沿指定主轴|x驱动压差24 Pa；y驱动48 Pa|

该尺寸是本轮有意识选择的诊断设计，不是已测量事实。它的长宽分别等于100、200个名义周期，但此计算不解析任何周期，因此不能由此宣称有限真实沟槽边缘相位已被处理。

基准解析最大U约1.9271×10⁻⁶ m/s，对H的Re约2.41×10⁻⁷；这是输入量级估计，不能当真实流场低惯性验证。倍增驱动时该估计也倍增。不可压缩压力应用不定义LBM Mach、密度漂移或population指标；这些记not_applicable，而不是写成通过。

## 4. 边界与解析答案

对x驱动：x=0给p=G Lx，x=Lx给p=0；y两边给J·n=0。OpenFOAM压力对应fixedValue、fixedValue、zeroGradient。对y驱动交换边的角色，压差G Ly。仅因v1张量对角且边与主轴对齐，zeroGradient才等价于零法向通量；斜槽不能照搬。

z两面在网格和所有相关场上为empty，不是noSlip、不代表真实上下模具。U是压力解的派生场，不另加入口流速边界与压力过度约束；输出边界值由同一压力梯度及M计算，普通面可采用calculated，z保持empty。两侧是平均模型的无通量边，不施加切向壁面剪切。

压力从坐标s=0至L_s：p(s)=G(L_s−s)。主向J_s=K_ss G/μ，U_s=J_s/H，横向U=0。穿过固定坐标高端出口的有符号Q_high=J_s W，其中W是另一个面内边长。G<0时Q_high<0，物理入口出口角色相反，不能取绝对值伪装成正驱动。G=0时所有压力和速度为零。

边界流量一律按向外法向计：Q_low=−Q_high，总和为零。压力差可以为负，但绝对环境压力不在本模型中求解，负过压不是负绝对压力。

## 6. 实现规格与最小文件架构

后续在独立目录创建两端程序与算例，不修改现有D2/D3或nanrPrint源码。拟用 `CASE/interface_static_darcy_v1/`；目录尚未建立，若已存在则先核所有权，不覆盖。结构拟为：

```text
common/                       # 签名输入、schema、协议副本
two_dimensional/              # 独立有限体积/差分压力实现，读取K
openfoam/application/         # depthAveragedDarcyFoam.C及Make配置
openfoam/cases/<case_id>/     # 0/p、constant、system；无Allrun自动批量
analysis/                    # 只读原始结果与解析参照的验收器
runs/<run_id>/               # 后续获授权运行时创建，不在本轮创建
```

二维端必须真实装配并求解压力系统，而不是直接输出解析式；OpenFOAM端同理。解析式只供独立结果读取器使用，不允许填入求解器的最终场冒充计算。

OpenFOAM实现目标为本机Foundation 13。读取 `Dxx,Dxy,Dyy,H,mu`，检查有限值、对称与面内正定；v1要求Dxy=0。对面内D求逆构造M；三维数组中Mzz=0只是empty方向占位，不读取/推定Dzz。p维度为`[1 -1 -2 0 0 0 0]`，U为`[0 1 -1 0 0 0 0]`，J为`[0 2 -1 0 0 0 0]`，M为`[-1 3 1 0 0 0 0]`，phi为`[0 3 -1 0 0 0 0]`。

推荐按正定算子构造 `A = -fvm::laplacian(M,p)`，解A=0；对应守恒流量应从这一负Laplacian矩阵的 `A.flux()` 获取。若实现选择正Laplacian，流量符号需相反。必须用C01/C06解析符号独立检查，不把此伪代码当编译成功证明。`fvSchemes`显式声明p的fluxRequired；官方fvMatrix::flux在缺此声明时会报错。

U另由`-M & grad(p)`恢复，J=H U；输出矩阵面流量phi和由U插值得到的面流量诊断，两者分别保留，守恒验收使用矩阵通量，不能用后处理平均消去局部不守恒。z分量须为零。不得在字典中再激活porosityForce或其他阻力源。

正交网格采用线性插值/Gauss梯度与正交Laplacian离散；本协议没有非正交修正或斜向张量验收。压力线性系统拟用PCG/DIC，绝对归一化残差目标10⁻¹²、relTol=0、maxIter=2000；二维端用同等残差定义并同时报告未归一化方程残差，具体库在实现清单中绑定。若矩阵不对称或编译API不符，应停止并报告实现差异，不静默换掉物理模型。

## 7. 预定检查门槛与结果口径

以下阈值是**新设的静态接口诊断规格**，不是已通过结果，也不修改旧D2/G1/Gate阈值。容差宽于舍入误差以允许独立离散实现，又显著小于错误平均厚度造成的40%比例偏差。恒系数线性解应远比0.1%更准；偏差接近上限也需保留原值供审查。

非零驱动每端分别对解析答案检查：

|指标|定义|门槛|
|---|---|---|
|压力|体积/面积加权RMS(p−p*)及最大绝对误差，分别除以\|Δp\||均≤10⁻³|
|主向U/J|加权相对L2及均值偏差，相对于非零解析主向值|均≤10⁻³|
|横向/竖向流速|max\|U_transverse\|、max\|Uz\|除以\|U_main*\||均≤10⁻⁸|
|出口流量|\|Q_high−Q_high*\|/\|Q_high*\||≤10⁻³且符号一致|
|恢复导度|K_rec=μH mean(U_s)/G_s；另由Q_high/W恢复|均相对输入K_ss≤10⁻³|
|全域质量守恒|\|Σ外边phi\|/\|Q_high*\||≤10⁻⁸|
|局部质量守恒|Σ_cells\|Σ_cellfaces phi_out\|/\|Q_high*\||≤10⁻⁸|
|封闭侧边泄漏|Σ_sidefaces\|phi\|/\|Q_high*\||≤10⁻⁸|
|两种面通量一致|Σ_allactivefaces\|phi_matrix−phi_U\| / Σ_allactivefaces\|phi_matrix\||≤10⁻³|
|耗散与功率|E=∫μU·DU dV；W=Δp Q_high；\|E−W\|/\|W\||≤10⁻³，E≥0，W>0|

两端同一网格上的压力、J和Q差异也按相同解析尺度归一化，须≤10⁻³；不只检查“两边彼此接近”。导度恢复不能从输入D倒算后冒充实测，必须来自计算速度或通量。检查所有输出为有限值，输入源、模型、边界、维度不匹配均停止。

C06对C01要求主向J与Q反号、幅值相对差≤10⁻³；C08/C01倍率为2，归一化倍率误差≤10⁻³。C05与C02的主向U应相同，因出口宽度变半，Q比为1/2（相同G、同K_parallel）。C01-R与C01的J/Q相对变化≤10⁻³，两级各自仍须满足解析误差门槛。

C07不得除零：max\|p\|≤10⁻⁹ Pa，max\|U\|≤10⁻¹² m/s，各外边流量绝对值及全域净流量≤10⁻²⁴ m³/s；R_sq、相对主向误差和恢复K填not_applicable。其矩阵残差、隐藏源检查和有限值检查仍必需。

网格检查须确认512/2048单元、实际长宽厚度、z一层、empty配对、正交和无负体积；仅可据此评价**合成平均域**的geometry_PASS，不能升级为真实沟槽geometry_PASS。线性场两级一致也不能建立一般问题网格独立性、Richardson阶数或严格误差界。无真实z剖面，不能将本项记成平板Poiseuille剖面验证通过。
