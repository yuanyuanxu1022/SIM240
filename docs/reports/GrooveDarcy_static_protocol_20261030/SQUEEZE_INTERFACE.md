# 后续挤压连续性与间隙更新接口

状态：**接口已明确；动态宿主未实现，具体速度/时间/载荷验收未冻结，未运行。** 本文件为GDI-v1后续衔接，不向本轮加入挤压求解，也不把静态Δp/Q改名为F/V。

## 1. 首选的平均模型范围

先采用固定平面区域、全充液、刚性均匀闭合、固定槽深/槽宽/周期的瞬时准稳态模型。计算网格保持参考层厚b0，间隙变化通过深度积分质量守恒表达。这里不移动三维网格、不解界面或气体；空间不均匀间隙、可变形模具、ALE和接触线均另定范围。

以闭合速度大小V_close>0表示模具靠近。槽顶间隙h_m(t)满足dh_m/dt=−V_close，H(t)=h_m(t)+(w/P)d_g，所以dH/dt=−V_close。禁止用H替换h_m代入K公式；K用槽顶间隙，D换算分子用平均厚度。

## 3. 必须使用的守恒方程

\[
\partial_tH+\nabla_{xy}\cdot\mathbf J=0,\qquad
\mathbf J=H\mathbf U=-\mathbf K\nabla p_g/\mu.
\]

因此正闭合时

\[
\nabla_{xy}\cdot\mathbf J=V_{close},\qquad
-\nabla_{xy}\cdot(\mathbf K\nabla p_g)=\mu V_{close}.
\]

对空间均匀H，可写div(U)=V_close/H；一般空间变H时必须保留div(HU)，不能直接沿用该简式。静态协议div(U)=0只适用于dH/dt=0且H恒定的当前问题。

对固定平面单元面积A_c、向外为正的边流量，离散式应满足

\[
\sum_{e\in c}Q_e=-A_c\frac{H_c^{n+1}-H_c^n}{\Delta t}.
\]

瞬时准稳态可使用给定\(\partial_tH=-V_{close}\)而不推进时间，但必须明确这是瞬时状态，不输出虚构的填充历程。若推进间隙，则用与间隙更新同一离散导数驱动连续性。

## 4. 固定网格厚度与面通量

固定参考厚度b0的网格面面积为b0*l_edge，原生phi_U=U_f·S_f。要得到深度积分对应的实际Q，需要相容的面重建：

\[
Q_{J,f}=(H_f/b_0)\phi_{U,f}.
\]

H_f必须来自同一面插值和压力校正约定；不能分别插值HU与H再假定两种离散实现完全相等。以压力校正得到的守恒Q_J为主通量，另输出由U/H重建的流量作一致性检查。当前静态H=b0，所以两者才退化为相同单位和数值。

若沿用动量分裂U=HbyA−rAU*grad(p)，其二维压力方程为

\[
\nabla_{xy}\cdot(HrAU\nabla p)
=\nabla_{xy}\cdot(H\,HbyA)+\partial_tH.
\]

在参考三维单层网格上相应使用H/b0加权的压力系数与预测面通量，右端体积源为(∂tH)/b0；只给原来的零散度压力方程更新D不够。不得把物理源同时加入连续性和一个额外ALE网格收缩，再把同一储液体积变化计算两次。是否采用真实运动网格若另定，必须重推相对通量和几何守恒关系。

## 5. 边界、力和独立参考

当前静态是两端24/0Pa、侧边无通量；后续开放四边零环境过压是另一个边界问题，需在新协议中明确，不能直接继承成“同一算例”。均匀正闭合、正K、边缘零过压条件下，应出现正内部过压；若得到相反符号应停止核查，不能用abs(p)掩盖。

压力载荷候选为F_p=∫_A p_g dA，瞬时阻力R_p=F_p/V_close，单位N·s/m。若与显式沟槽三维参考比较，必须记录作用面、投影面积、环境压力扣除及总法向力中的压力/黏性应力分项；平均压力积分不自动等于完整总应力积分。
