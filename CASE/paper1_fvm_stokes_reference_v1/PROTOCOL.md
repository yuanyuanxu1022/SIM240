# 固定六方向显式沟槽独立参考：准备协议 v1

日期：2026-11-10。状态：配置和源码准备；尚无本协议求解结果。采用OpenFOAM Foundation 13，不混用ESI字典。用户本轮授权落实配置/后处理并交Astra审查；不包括启动沟槽、自动追加方向、重拟合、改历史Gate或投稿。

## 1. 比较对象和三个实现决定

本协议对应理想、稳态、全充液、不可压、恒黏度、无滑移的周期直矩形槽Stokes问题。x横槽、y沿槽、z高度；槽宽120nm，周期240nm，槽/凸台各半。mu=1e-3 Pa s，rho=1000 kg/m³，nu=1e-6 m²/s，加速度1e5 m/s²。只施加一次体力；压力扰动周期，不再同时施加压降。

1. **K归一化**：J_i=sum(u_i V)/Aplan，K_i=nu*J_i/a，单位m³。另输出ubar=sum(u_i V)/Vfluid、kappa=nu*ubar/a(m²)、Href=Vfluid/Aplan(m)，并核K=Href*kappa。禁止把体积平均速度算出的kappa直接拿来与论文K比较。
2. **沿槽P**：求解标量v(x,z)，-nu*Laplacian(v)=a；物理速度(Ux,Uy,Uz)=(0,v,0)。y方向empty只用于标量的平移不变性，不删除物理Uy。v在固壁为0、x周期。没有压力求解或跨槽流动。独立导出物理Uy，不能把v当Ux。
3. **横槽T**：独立源码求解-nu*Laplacian(U)+grad(p)=a*ex、div(U)=0。源码没有fvm::ddt或fvm::div(phi,U)项，也不依赖日志中的应力模型名称推断Stokes。压力为运动学压力p'/rho，固定一个参考单元消除常数零空间；x周期，固壁noSlip和fixedFluxPressure，配合constrainPressure使用；y empty，Uy=0。

这里是有限体积第二实现，不输入局部立方律或V2的K。不声称不存在共同几何/边界/归一化错误，不称第二方实验或物理验证。LBM是有限离散运行；独立端精确Stokes与其有限惯性/弱可压缩差异必须保留在模型映射说明，低Mach不代替Stokes证明。既有基准线性检查仅有其指定范围，本次不声称各点已独立验过零惯性极限。

## 2. 真实边界和挤出厚度

沟槽在0<x<120nm、0<z<d；贯通间隙在0<x<240nm、d<z<d+h；120<x<240nm、z<d为固体。周期端只连接z>d的流体；x=0、z<d是上一周期凸台的侧壁，必须设wall，不能误接周期。x=120、z<d也是wall。三块网格共形，没有内部人造壁或挡板。平板d=0另用完整单块。

数值挤出厚度Ly=1nm、单层empty；几何和解严格沿y不变。其体积V=P*Ly*(h+d/2)，Aplan=P*Ly；积分除以Aplan后Ly消去，等价于原Ly=240nm的连续平移不变模型。P的通量为沿y完整截面流量、由不变性精确满足；不把这一恒等关系计为额外质量验证。T在每个x位置积分完整流体截面，侧壁零通量，保存校正后面通量并与体积积分主通量交叉检查。

## 4. 接收和比较：沿用事前标准，输出目标采用方案A

- 平板两方向K相对解析h³/12差≤0.1%，单元中心体积加权速度剖面L2差≤0.1%。数值积分定义明确，不冒称连续L2误差界。
- 每方向d21=abs(Kmid/Kcoarse−1)≤1%，d32=abs(Kfine/Kmid−1)≤0.5%，且d32≤d21；两者均≤0.05%时免除递减关系。
- abs(Ktight/Kfine−1)≤0.05%。tight不当第四档网格。
- 各层均须正体积/有限值/几何与来源无误。最细fine及同网格tight、平板flat要求：T完整截面面通量最大极差/平均值≤0.1%，校正面通量与体积主通量差≤0.1%；驱动功与黏性耗散相对差≤0.1%。coarse/mid保存这些诊断，不额外施加最细层0.1%门槛。P的y不变通量关系不计作独立测试。
- 原始场+日志、独立退出码、run_id、源码/字典/二进制/库身份、证据hash均绑定；只看程序End或CSV不接收。
- 满足上述参考条件才计算delta=(K5/Kref−1)*100%；abs(delta)≤2%为该方向交叉一致性PASS，>2%为FAIL。参考未取得是NOT_ASSESSABLE，不是LB被判错。
- 基准A差abs(A5/Aref−1)*100%≤2%，beta差abs(beta5−betaref)≤0.40度；均由同一P/T参考导出，不计成额外独立样本。正确A5/Aref=(1+delta_y)/(1+delta_x)，delta在该式以小数代入。角度始终从槽轴量起，beta=atan(Kxx/Kyy)，原公式角差=betaLC−betaref。

方案A是本轮落实的明确准备规格，未执行前写定；不是修改S4原1%或旧统计的精度门槛。这些是有限核验容限，不是严格后验误差证书；六方向通过也不认证全36/全域/物理真实性。原19几何46比较记录和36条统计身份不变。

## 6. 资源与执行边界

run_one.py只允许操作员明确指定一份已发布输入；默认不执行，--execute表示未来显式启动，不能从本次准备授权推断。要求已加载/opt/openfoam13，拒其他版本和MPI。每次运行预先检查release_manifest.json、源码/输入/可执行文件/外部库指纹；拒覆盖、续跑与自动重试。单进程，线程1，地址空间硬上限4GiB，单文件硬上限256MiB；blockMesh/checkMesh各120秒，求解1800秒墙钟上限，超时杀整个子进程组并记录失败；总目录1GiB是结束后的接收检查而非实时磁盘配额。无法保证所有实例在预算内通过，不自动增配。

每次只运行一份输入，完成后不自动进入下一层/方向或接收，原始失败保留。日志/退出码/source hash/资源记录写receipt，postprocess单独分析。本轮未调用run_one.py，也不交付正式长算命令。不存在已授权待运行的批量26例任务。

执行是否结束与参考是否合格分开：全部固定运行记录结束但参考失败时，标记COMPLETE_WITH_REFERENCE_FAILURE；提前出现失败则STOPPED_ON_FAILURE，后续未运行项仍原样列出。它们均不授权继续加算，不能为了得到COMPLETE而追算。原生最终v或U/p/phi、五份mesh、独立退出码、日志和运行时release快照均必须留存且哈希一致；删除原场不能用CSV补足接收资格。
