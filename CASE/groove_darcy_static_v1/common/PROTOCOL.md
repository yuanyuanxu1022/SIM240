# GDI-v1：grooveDarcy 最小定间隙流场接入协议

日期2026-10-30。**实施规格已准备；宿主求解器、正式运行包和新检查器尚未实现，没有启动授权。** `protocol.json` 为对应机器可读规格。本协议新增子类实际流场接入检查，原SDI-v1及旧结果保持原字节。规格改动须先升版本和说明原因，不能在取得新结果后放宽门槛。

## 1. 科学问题与最小单元

检验“几何参数→grooveDarcy→标准porosityForce动量源→压力/速度耦合→J和Q”这条链，是否在同一个定间隙问题下再现已有二维与OpenFOAM压力应用的结果。它是软件与平均模型接入验证，不判断原公式或V2是否更接近真实沟槽。

首例编号 **GDI01**，对应已有 **C01（V2横槽）**，两者身份不同。新run_id当前为null；未来另行发布绑定后分配GDI01前缀，不能使用旧SDI run_id或把检查器输入冒写成C01。GDI02—04只为已有C02—04建立后续映射，没有自动准备/启动权限；SDI C05也不在本次范围。

## 2. 采用的方程与架构

本问题是稳态、全充液、单相、固定间隙的总Darcy平均模型：

\[
\mu\mathbf D\mathbf U+\nabla p_g=0,\quad
\nabla\cdot\mathbf U=0,\quad
\mathbf J=H\mathbf U,\quad
H=h_m+(w/P)d_g,\quad\mathbf D=H\mathbf K^{-1}.
\]

K为深度积分导度(m³)，U为液体体积平均速度(m/s)，J为m²/s，D为m⁻²，p_g为物理过压(Pa)。宿主注册rho、mu、nu，先核mu=rho*nu一致；本例使用物理动量矩阵(dimForce)，源项由标准porosityForce的rho/U调用路径提供，不能又把rho或mu乘入D。

拟建专用小宿主 `grooveDarcyStaticFoam`（当前不存在）。它使用标准fvModel/porosityForce选择子类并装配动量矩阵，再做压力—速度迭代。**不能从输入表直接拿D构造旧压力应用而绕过子类，也不能在宿主重复计算K作为实际阻力来源。** 独立解析K/D只供检查器或审计输出比较，不能注入求解链。

本例不含惯性时间项、对流、面内黏性Laplacian、厚度方向壁面剪切、重力、体力、Forchheimer、湍流、额外孔隙率或第二份Darcy源。标准porosityForce负责源项装配；使用专用宿主是为了保持与原SDI相同的方程，不能直接使用默认含惯性/黏性项的通用求解器并假定等价。真实上下壁影响已经包含在K中。

## 4. 边界与初始值

|边界|p_g|U|通量含义|
|---|---|---|---|
|xLow|fixedValue 24Pa|zeroGradient|不固定入口速度；由压力—动量求解得到|
|xHigh|fixedValue 0Pa|zeroGradient|不固定出口流量|
|yLow/yHigh|zeroGradient|slip：法向零、切向自由|同旧例侧边无通量，不增加侧壁剪切|
|frontAndBack|empty|empty|不作为真实壁面|

压力zeroGradient等于侧边零法向Darcy通量仅因本例张量主轴与边对齐；本协议不覆盖45°。x端U的zeroGradient不施加已知解析速度。侧边phiHbyA和最终phi均须与法向零约束相容，不能只在输出时把泄漏清零。

内部初始p=0、U=(0,0,0)，压力边界24/0Pa从开始固定。不得以解析p/U或旧C01场初始化，也不得用旧phi作为求解输出。固定压力边界已消除压力常数自由度，不再添加内部压力参考点或额外端部压力条件。

## 5. 子类实际装配和压力—速度迭代

Foundation13 porosityForce把正阻力矩阵作为负源项返回。宿主应将这份源移至动量方程左端，保证最终为R(U)+grad(p)=0；必须保留标准source调用的矩阵/源项审计，防止加错符号或重复装配。现有子类标量装配采用迹分裂：

\[
R_i/V_i = a_iU_i-c_i,\quad
a_i=\mathrm{tr}(\mu D_i),\quad
c_i=(a_iI-\mu D_i)U_i^{old}.
\]

只在外迭代固定点才恢复完整各向异性阻力，因此不能用单次压力求解收敛代替整个问题收敛。以下为需实现的数学步骤，不是已编译宿主源码：

1. 保存U_old、p_old；子类按当前固定几何重新装配源，形成正阻力UEqn。核矩阵按体积归一后的A=a>0，source/V=c，源仅出现一次。
2. rAU=1/UEqn.A()，HbyA=rAU*UEqn.H()；继承/约束U边界，构造phiHbyA=flux(HbyA)，侧边法向零。
3. 每次外迭代把压力内部求解初值置0（边界不改），记录本次已装配压力矩阵的初始原始L1残差。求解laplacian(rAU,p)=div(phiHbyA)。固定正rAU与正交网格下为对称压力问题，采用PCG/DIC；实现时核矩阵对称和正定所需的符号约定。
4. phi=phiHbyA−pEqn.flux()；U=HbyA−rAU*grad(p)，按规定更新边界；J=H*U。phi是压力校正后的质量通量，phi_U=flux(U)另行保留用于一致性检查。不能用phi_U覆盖phi、不能用解析phi替换它。
5. 用当前新U重新计算模型正积分阻力R_cell=porosityModel.force(U,rho,mu)，独立计算R_cell/V+grad(p)；保存完整、未分裂的动量残差以及U、p外迭代变化。
6. 内外残差、守恒和通量一致性全部满足才能停止。否则继续，最多2000次外迭代；每次压力最多2000次线性迭代，relTol=0。没有物理/伪时间项，不能靠增添一个隐式时间项改善收敛后仍称同一规格。

外迭代松弛因子为1。若需要其他策略，应在运行前修改协议版本并重新审查；运行失败不能自动改策略重试。

## 6. 原门槛与新增接入检查

protocol.json逐项复制原SDI的thresholds与linear_solver，源SHA固定。主要要求：p/主向U和J/Q/恢复K/跨实现相对偏差≤1e-3；横向与z速度归一最大值≤1e-8；全局守恒、逐单元不平衡绝对和、侧边泄漏归一值≤1e-8；矩阵phi与phi_U一致性及能量差≤1e-3；正流向、有限量、非负耗散、正压力功率。

压力线性求解记录每次OpenFOAM归一化残差≤1e-12，同时真残差L1_final/L1_initial≤1e-12。L1_initial在该次压力矩阵、内部p=0时直接计算，分母不得为零或非有限值，不使用上一步已收敛残差重新归一化。最后一轮和完整历史均保留，不把外迭代次数混写成线性迭代次数。

新增以下预先指定的接入守卫，**不是修改旧SDI门槛**：

|新增项|定义与门槛|
|---|---|
|子类系数一致性|实际装配恢复的D与独立解析D相对偏差≤1e-12；不将模型输入直接拷贝作“恢复值”|
|完整动量残差|r_i=R_cell/V_i+grad(p)_i；体积加权L2和单元最大向量模除G，均≤1e-10|
|外迭代速度变化|U_new−U_old的体积加权L2和最大向量模除解析主向U，均≤1e-10|
|外迭代压力变化|max|p_new−p_old|/24Pa≤1e-10；使用求解后的新旧压力比较，不与零初猜比较|
|装配身份|标准wrapper、grooveDarcy类型、全部512区域单元、单次阻力、物理压力单位均核实；布尔守卫|

耗散用sum(R_cell·U_cell)，R_cell本身已含mu和体积，不得再乘一次。压力功率为24Pa*Q_out。由U恢复Kxx=mu*H*Umean/G；由Q恢复Kxx=mu*Q/(G*Ly)，不能仅将H/D倒算冒充流场恢复值。
