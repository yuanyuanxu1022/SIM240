# SIM240 不同流阻计算方案对比

> **汇报摘要**
> - 压力入口出口方案与周期方案回答不同层面的问题，二者互补而非互相替代；
> - 压力入口出口方案用 R = ΔP / Q 描述一段有限通道的实际压降—流量关系；
> - SIM240 周期方案用 R_J = ρa / J 描述周期纳米结构的本征输运阻力；
> - 采用周期体力驱动，是为了剥离入口 / 出口扰动、研究结构—输运规律与尺度收敛。

## 背景与依据

核心科学问题：

| 问题 | 研究内容 |
| --- | --- |
| 周期尺度问题 | 单周期是否能够代表宏观输运性能？ |
| 结构规律问题 | 沟槽深度、周期、占空比如何影响有效阻力？ |
| 机制问题 | 纳米结构如何通过流场重构和耗散改变阻力？ |
| 理论问题 | 经典润滑模型在纳米周期结构中是否适用？ |

## 1. 研究目标区别

| 维度 | 入口出口方案 | 周期结构方案 |
| --- | --- | --- |
| 研究目标 | 实际流动条件下的压降与流阻 | 周期纳米结构本征水力阻力 |
| 研究对象 | 有限长度通道 | 周期结构（重复单元） |
| 核心指标 | R = ΔP / Q | R_J = ρa / J |
| 回答的问题 | 该通道需要多大压差推动液体 | 周期结构本身产生多大阻力、如何随结构变化 |

### 入口 / 出口压力边界方案 —— 实际流动条件下的压降与流阻

研究目标：在给定几何的有限通道中，用压力边界直接计算压降与流阻。

- 采用入口 / 出口压力边界；
- 通过压力差 ΔP 计算流阻 R = ΔP / Q；
- 其中 ΔP 为入口与出口的压力差，Q 为流量；
- 回答：推动液体通过该通道需要多大的压差。

### 周期方案 —— 周期纳米结构的本征水力阻力

研究目标：研究周期纳米结构的本征水力阻力及其随结构尺度的变化规律（结构—输运关系）。

- 采用周期结构模型 + 周期体力驱动；
- 通过等效压力梯度计算阻力 R_J = ρa / J；
- 其中 ρa 为等效压力梯度（由体力 F = ρa 给出），J 为平均通量；
- 回答：周期结构本身产生多大的流动阻力，以及几何参数如何改变该阻力。

> 一句话：入口 / 出口压力边界方案关注"某一条通道的实际压降"，周期 方案关注"周期结构本身的本征输运性质"。

## 2. 计算方法对比表

| 项目 | 压力入口出口方案 | 周期结构方案 |
| --- | --- | --- |
| 驱动方式 | 压力差驱动 | 周期体力驱动 |
| 边界条件 | 入口压力 / 出口压力 | 周期边界 |
| 流阻定义 | R = ΔP / Q | R_J = ρa / J |
| 研究对象 | 有限通道流动 | 周期结构输运 |
| 优势 | 接近实际过程 | 适合周期结构规律研究 |
| 不足 | 存在入口出口影响 | 需要后处理转换 |

**符号说明**

- ΔP：入口与出口的压力差；
- Q：体积流量；
- ρa：等效压力梯度，由周期体力 F = ρa 引入；
- J：平均通量。

R_J 的压力梯度形式可由 ρa 转换得到（依据 SIM240 研究 Draft v1.1）。

**数值实现（SIM240 周期方案）**

SIM240 周期方案采用 D3Q19 格子模型 + ForcedBGK 碰撞 + 周期边界 + 体力驱动（$F=\rho a$）；壁面采用与真实纳米几何一致的无滑移边界。当前正在通过平板 Poiseuille 流验证壁面离散精度：Bouzidi link 安装审计已通过，稳态解析精度尚未验证。

## 3. 两种方法物理意义

**压力驱动 —— "这个具体通道需要多大压力才能推动液体"**

R = ΔP / Q 直接度量一段有限长度通道的宏观压降与流量之比，结果包含入口发展区、出口与充分发展区的综合效应，贴近实际填充 / 输运过程的"表观阻力"。

**周期驱动 —— "这个周期结构本身产生多大流动阻力"**

R_J = ρa / J 度量单位周期结构在等效压力梯度 ρa 下的本征阻力，通过周期边界消除入口 / 出口扰动，反映结构几何本身（而非边界布置）带来的输运阻力。


## 4. 两种方法关系

两种方法不是互相替代，而是互补：

- 压力驱动：适合真实填充 / 实际流动过程验证；
- 周期驱动：适合基础输运规律研究。

未来可形成闭环：

- 周期驱动建立结构—输运规律（R* = f(D/P, W/P, H/P)）；
- 压力驱动在真实填充过程中验证上述规律。
