## 3 接触角（**两面不同**，关键）

| 面 | **采用值** | 规则 | 状态 |
|---|---|---|---|
| **模具**（含 recess 顶壁 + 凸台侧壁） | **110°** | 实际做防粘 → 104–126°；未处理 → 34–68° | **待实测确认**（临界值 104.3°，跨在两侧） |
| **基板**（平壁） | **15°** | 文献：Si 上 6–24°、Si/HMDS 12–42° | **待实测确认** |

**采用这组值时的毛细压力**（σ=0.03，H=175 nm 槽、W=120 nm 槽宽）：

| 位置 | Δp_cap | 含义 |
|---|---|:--|
| 槽截面（顶 θ_m、底 θ_s、两侧 θ_m） | **−0.64 bar** | **阻碍入槽** → 需 ≥0.64 bar 超压 |
| 75 nm 基底层（横向开放） | **+2.50 bar** | **自吸** → 液体易在基底层铺展 |

→ 物理图景：**液体先在 75 nm 基底层快速铺开，而进槽必须靠外加压力**——这正是 R2-Z 超压扫描要测的东西。

## 4 格子与单位口径（**口径 (a′) 匹配 σ**）

| 参量 | 值 | 说明 |
|---|---|---|
| dx | **5 nm** | 界面宽 4dx = 20 nm；60/180/75/100 nm 均为 5 的整数倍 → q = 0.5 对齐 |
| σ_lat | 0.01 | 沿用 R1 已验证点 |
| τ_L / τ_G | 1.0 / 0.8（ν_lat = 1/6） | 沿用 R1 |
| τ_phase | 1（迁移率 M = 1.5） | 沿用 R1 |
| ρ_l = ρ_g | 1（**等密度**） | L2 可排气假设；**不是真实气液密度比** |
| **dt** | **6.455×10⁻¹² s** | 匹配 σ；**与 μ 无关** |
| **μ_eff** | **6.455×10⁻⁴ Pa·s = 真实 1/23.2** | |
| **时间换算** | **t_phys = 23.2 × t_sim** | 必须声明 |
| 初值 | `--init-phi tanh` + `--init-pressure laplace` | E0/R1 结论，**必用** |

**为何 (a′) 是精确解而非妥协**：本项目 Re ≈ 10⁻¹⁰（Stokes 区），毛细驱动 $u\propto\sigma/\mu$、压力驱动 $u=(K/\mu)(\Delta p/L)$ ⇒ **$Ca=\mu u/\sigma$ 与 μ 无关**。故只要 σ 正确，**Ca、界面形状、F_g、前沿比、临界压力全部精确**，μ 只决定时间尺度，可整体换算。
（对照：匹配 μ 口径 dt = 2.778×10⁻¹³ s；不仅 dt 小 23.2 倍，需模拟的物理时长还长 23.2 倍 ⇒ **总步数多 539 倍**，不可行。）

## 5 初态（**随基板接触角改变，需重定**）

| 项 | 值 |
|---|---|
| 液量 V | 0.1114 fL（= 1.114×10⁸ nm³） |
| 坐在 θ_s = 15° 基板上 | **直径 1624 nm（6.8 周期）、高 107 nm**，有自由表面 |
| 压到 h = 75 nm 后 | 受限足迹 **边长 944 nm（3.93 周期）**，填满局部空间 |
| 过程 | **收拢**：横向 1624 → 944 nm、垂向填入沟槽（体积守恒） |

⚠️ 这与原冻结的"0.96 μm / 277 nm 球冠（θ=60°）"**不同**——后者对应假想的 60° 基板。

## 7 R2-Z 超压扫描档位

门槛 P_c ≈ 0.64 bar（θ_m = 110° 时）→ 建议档位：

**Δp = 0 / 0.3 / 0.64 / 1.0 / 2.0 bar**（覆盖门槛两侧），固定 h = 75 nm，测逐槽填充率 F_g(Δp)。

## 8 判据门槛（沿用 R1 冻结口径）

| 量 | 门槛 |
|---|---|

| max Mach | ≤ 0.05 |
| φ 范围 | [−0.05, 1.05] |
| 接触角误差 | ≤ 5° |
| Laplace 压差误差 | ≤ 15% |

## 9 待补 / 待确认（不得跳过）

1. **模具是否做防粘处理** → 决定 θ_m 取 104–126 还是 34–68（**临界 104.3° 就跨在分界上**）；
2. **基板材质与处理**（Si / 玻璃 / HMDS / ARC）→ 决定 θ_s；
3. **密度**（比重 1.08–1.15 → ρ 可能应取 1080–1150，而非 1000）；
4. **表面张力实测值**（现为文献 30 mN/m）；
5. 各接触角需在**本算例口径下各校准一次 run**（模具侧可引 R1 的 100°，110° 需核对；**基板 ~15° 必补**）。
