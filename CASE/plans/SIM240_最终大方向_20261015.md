## 附｜入槽毛细门槛压力（决定 1 的物理核心，2026-10-15 20:52 计算）

**为什么需要"超压扫描"**：关键是模具接触角是否越过临界值。

$$\Delta p_{cap}=p_{gas}-p_{liquid}=\sigma\left[\frac{\cos\theta_{模具}+\cos\theta_{基板}}{H}+\frac{2\cos\theta_{模具}}{W}\right]$$

（槽 H = 175 nm：顶 = 模具 recess 面、底 = 基板；W = 120 nm：两侧 = 凸台侧壁，**属模具**；σ = 0.03 N/m）

- **Δp > 0 → 毛细吸槽**（不需超压）；**Δp < 0 → 毛细挡槽，需 |Δp| 的超压才能灌入**。

| 模具角 | 基板 10° | 基板 15° | 基板 20° | 基板 15° 时所需超压 |
|---:|---:|---:|---:|---:|
| 100° | +0.52 | +0.49 | +0.45 | 无需（毛细自吸） |
| **104.3°** | — | **0** | — | **临界角** |
| 110° | −0.61 | −0.64 | −0.69 | **0.64 bar** |
| 120° | −1.67 | −1.70 | −1.75 | **1.70 bar** |
| 126° | −2.26 | −2.29 | −2.34 | **2.29 bar** |

（对照：若模具也亲水 60°，Δp = +5.0 bar，强吸槽）

**结论**：
1. **临界模具接触角 ≈ 104°**——正好落在文献防粘模具区间（104–126°）的中间，**必须实测才能定性**；
2. 模具角 <104° → 毛细自吸，**超压扫描没有意义**（Δp=0 就已填满）；
3. 模具角 >104° → 存在明确门槛（0.6–2.3 bar），**超压扫描是核心实验**，且门槛压力可与上表做解析对照（又一处 H1 型验证）；
4. **超压扫描的档位与价值，取决于先确定模具接触角**（回到决定 2 的待确认项）。

建议档位（若模具 110°）：Δp = 0 / 0.3 / 0.64 / 1.0 / 2.0 bar（覆盖门槛两侧）。
