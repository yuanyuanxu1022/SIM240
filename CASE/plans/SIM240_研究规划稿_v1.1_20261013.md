## 执行摘要与研究定位

核心研究问题：在给定压头尺寸、下压速度、目标间隙及排液边界的条件下，能否仅通过微尺度周期沟槽的等效水力迁移率，定量预测二维有限压头的压力分布与挤压载荷，并给出具有实际制造约束的沟槽设计准则？

建议定位为"经验证的跨尺度预测方法 + 方向性排液机制 + 受约束的设计规律"，而非笼统宣称首次提出各向异性迁移率或 Reynolds 型挤压模型。研究的首要目标应是证明模型从微尺度到压头尺度的预测有效性，其次才是优化。

| 研究层次 | 模型/手段 | 输入 | 需验证的输出 |
|---|---|---|---|
| 微观输运（XY） | OpenLB 显式沟槽单元 | 节距、槽宽、深度、参考间隙、流体性质 | K⊥(h)、K∥(h)、数值不确定度、线性响应 |
| 介尺度挤压（Z） | 有限域各向异性 Reynolds 型方程 | 迁移率张量、压头形状、速度、出口边界 | p(x,y)、F(h,V)、排液守恒 |
| 结构优化 | 约束参数扫描/敏感性分析 | 工艺边界与几何可制造性 | 载荷降低量、鲁棒设计与适用范围 |

论文成立的最低证据链：数值正确 → 参数可信 → 模型闭合 → 独立验证 → 机制解释 → 工程价值。若其中"独立验证"不能完成，只能定位为探索性计算研究，投稿竞争力相应下降。

## 1. 研究背景与现有工作

### 1.1 研究背景

纳米压印过程中，压头与基底之间的液体必须通过有限空间排出或重新分配。壁面周期沟槽会改变压力驱动流动的阻力与方向性；这种微观结构作用可能影响有限区域内的二维压力场、峰值压力、外加载荷与达到目标间隙的排液时间。对于大尺度压头，逐条显式解析沟槽成本较高，因此有必要研究"微观结构—等效迁移率—宏观挤压响应"的参数传递与预测精度。

SIM240 已以 OpenLB 为基础开展 EX240 周期沟槽的显式单相液体输运计算，方向以沿槽和横槽为主，属于较好的微观参数获取基础。[1][2][8] 截至 2026-10-13：G0 边界审计、G1 平板迁移率验证、G2 主证据与生产网格选择、G4 周期复制数值不变性审查、三高度固定网格候选与 G5A 一维挤压初算均已有仓库证据（详见 §6）；细网格横槽质量门禁异常已进入隔离诊断准备阶段。但微观固定间隙流动计算与真实压印排液并不等同；在引入有限压头、排液边界及材料约束前，不能直接把"输运阻力更小"表述为"压印一定更省力"。

## 2. 研究问题：从微观输运到工程载荷的缺口

### 2.1 主问题（RQ）

RQ：通过显式沟槽流动获得的 K⊥(h)、K∥(h)，能否在无需逐槽计算完整压头的情况下，在限定误差内预测有限压头挤压过程中的压力场与流体载荷？

### 2.2 子问题与边界

1. RQ1 数值可信性：迁移率对网格、驱动力、基准平板模型、几何离散和边界处理是否收敛？
2. RQ2 模型可转移性：所计算的 K 是否与二维方程所需的"深度积分流量迁移率"量纲和定义一致？是否只由 h 决定，还是还依赖其他应变量或流场？
3. RQ3 排液可预测性：有限几何与非周期排液出口下，预测的 p、F 与独立数值解相差多少？
4. RQ4 机制及优化：压头形状、出口位置、槽向角度和沟槽尺寸的交互作用是否存在可复现规律？

研究不覆盖：非牛顿黏弹性树脂、大变形柔性模具、明显两相界面与气体滞留、热固化/UV 固化、壁面接触/毛细主导等未经加入模型的物理过程。对此只可讨论适用性与后续扩展，不能越界推断。

## 3. 研究目标与可证伪假设

### 3.1 总体与分目标

总体目标：构建并验证一条面向 EX240 类周期纳米沟槽的"几何参数 → 迁移率张量 → 有限域挤压载荷 → 约束优化"预测链，给出误差、适用范围及与工艺目标相关的设计规律。

- O1：获得 50/75/125 nm 参考间隙的高可信 K⊥、K∥，建立含不确定度的 K(h) 数据库。
- O2：开发二维有限压头各向异性挤压求解器，验证经典平板解析解、守恒和网格收敛。
- O3：使用独立全分辨率模型或可比较实验数据验证预测误差，识别均匀化失效区域。
- O4：在相同 V、h、压头与排液边界条件下比较结构，形成可解释的参数敏感性与约束优化结果。

### 3.2 假设及其否证条件

| 假设 | 预期（待验证） | 推翻/修正该假设的结果 |
|---|---|---|
| H1 方向性 | 在低雷诺数、充分润湿、线性响应条件下 K∥ 与 K⊥ 可能显著不同。 | 网格收敛后比值≈1，或随压力梯度明显非线性。 |
| H2 可传递性 | 用 K(h) 输入有限域模型可预测 F(h,V)，误差在预设容差内。 | 独立直接解误差系统性超阈值，且非数值误差所致。 |
| H3 方向-边界耦合 | 矩形/非对称出口下，沟槽取向可改变总载荷。 | 在控制几何后载荷差异不显著；对称场景可能严格不变。 |
| H4 工程优化 | 某些几何在不违反填充与尺寸约束时可降低给定速度下的载荷。 | 改善来自放大有效间隙、改变待排液体积或非公平对照。 |

## 4. 核心思路与技术路线

采用层级方法而非直接做全三维压头沟槽模拟。先在微尺度得到已验证的压力驱动深度积分迁移率；再在有限域把此张量作为本构关系，计算压力与总载荷；最后在合理制造/几何/性能约束下比较结构。

| 环节 | 核心任务 | 交付物/转阶段门槛 |
|---|---|---|
| S1 显式沟槽 RVE | 重做可追溯的几何/网格/驱动力审计 | 可复核的 K⊥(h), K∥(h) ± 不确定度 |
| S2 方向张量检验 | 0°/45°/90° 驱动或旋转结构验证 | K(θ) 的非对角分量、方向预测对照 |
| S3 有限域挤压 | 有限矩形压头；开放或封闭边界明确 | p(x,y)、F、质量/体积守恒、网格收敛 |
| S4 独立交叉验证 | 直接计算小尺度有限域或可靠独立基准 | 误差随尺度分离/间隙变化的图谱 |
| S5 机制与优化 | 结构/角度/出口/目标间隙多参数扫描 | 载荷-性能权衡、设计准则与有效边界 |

流程闭环：宏观误差过大时，必须返回微观参数定义、尺度分离假设和边界建模，而不是在宏观模型里自由拟合常数去强行追平结果。

## 5. 方法设计与数学模型

### 5.1 几何与工况定义

已知 EX240 几何线索：节距 P=240 nm、槽宽 w=120 nm、深度 d=100 nm，参考液层高度 h=50/75/125 nm，结构沿 y 方向布置，x 为横槽方向。既往计算包含单周期与 NX2/NX4/NX8 沿 x 复制。具体 h 的零位与流道有效高度必须依据源码/几何定义核查，不能仅根据数字推测。

将形貌参数向量记为 g=(P,w,d,θ,形状)；μ 为动态黏度；压头面内域 Ω，边界 ∂Ω 分为开放出口 Γout 与不透流边界 Γwall。压头顶面参考位置以 h(x,y,t) 表示，所有层次须使用一致的参考面。

### 5.2 迁移率的定义与量纲（必须优先统一）

定义深度积分的面内体积通量 J=(Jx,Jy)，单位 m²/s；J 是单位横向宽度上的流量，与三维局部速度 u [m/s] 不同。压差驱动下：

J = −[K(h,g)/μ] · ∇ₓᵧ p

若 K 用此定义，则 [K]=m³，平板无滑移 Stokes/Poiseuille 基准为 Kflat(h)=h³/12。若仓库里的原始字段称作 permeability [m²]，或记录的是 Q、平均速度、受力密度而非压差梯度，必须换算成一致的深度积分迁移率后再联立，禁止仅因字母同为 K 就直接代入。

Kᵢ(h) = μ · (Qᵢ/Wᵢ) / (Δpᵢ/Lᵢ) ，i ∈ {⊥,∥}

式中 Wᵢ 为流量截面中的面内横向宽度，Lᵢ 为压差方向跨度。对周期体积力驱动，可用等效压强梯度替换 Δp/L，但必须记录体积力的物理维度以及 LBM→SI 的转换。

### 5.3 沟槽各向异性张量与旋转

K₀(h) = diag[K⊥(h), K∥(h)]

Kθ(h) = R(θ) · K₀(h) · R(θ)ᵀ，且 Kθ,xy = Kθ,yx（对称）

定义各向异性比 A(h)=K∥(h)/K⊥(h)。任意 θ 下即使主轴张量对角，实验坐标中的 Kxy 一般不为 0。因此"用独立的 Kx、Ky 解两个互不相关的一维问题"不足以代表旋转沟槽的二维排液。若直接旋转壁面几何验证 45°，需采用与周期几何相容的计算域。

### 5.4 有限压头广义 Reynolds 型挤压模型

假设：等温不可压牛顿单相液体、流动惯性可忽略、上下固壁无滑移、底面沟槽固定、压头主要作法向运动、几何周期显著小于宏观压力变化尺度，且液体充分润湿所有联通空间。设单位投影面积实际储液体积为 H(h,g)，则：

∂H(h,g)/∂t + ∇ₓᵧ · J = 0

∂H/∂t = ∇ₓᵧ · { [Kθ(h,g)/μ] · ∇ₓᵧ p }

若固定沟槽在研究范围内一直保持充液、其几何体积不随压头变化，则 H = h + 常量，因此 ∂H/∂t=∂h/∂t；否则必须按实际间隙、沟槽填充状态重新推导储液项。对平行刚性压头，下压速度 V>0 表示 dh/dt=−V。

在 h 空间均匀、K 空间常量时：∇·(Kθ ∇p) = −μV

常见边界：开放边缘指定 p=p_ext；实墙指定 J·n=0；如设置局部出口，则需混合边界。不可将微观 RVE 的双周期边界复制到宏观有限压头上，否则无净排液出口时准静态模型难以闭合。

Fhyd(h,V) = ∫Ω [p(x,y) − p_ext] dA

Fhyd 仅代表流体压力载荷。若有固体接触、模具变形、毛细压力、黏附与惯性等，则须增加独立力项和适当耦合；不能直接将 Fhyd 视为完整压印机载荷。

### 5.5 对称性是方向优化的关键反例

对于圆形压头、全周恒定出口压力、空间均匀的正定 Kθ，旋转张量不改变迹 tr(Kθ)=K∥+K⊥。此时解析解为：

p − p_ext = [μV/(2 tr Kθ)] · (R² − x² − y²)

Fhyd = πμVR⁴/[4 tr Kθ]

因此该理想圆盘问题下，总挤压载荷对沟槽旋转角度 θ 严格不敏感；只比较圆盘方向不应声称发现降低总载荷的取向。类似地，对正方形压头且边界完全四重对称，交换 0° 与 90° 方向总载荷也应相等。若模型预测违反这类对称性，应优先排查边界/离散错误。

要检验取向优化，需要具备可解释的对称性破缺，例如矩形长宽比、特定单侧出口、局部排液槽或空间非均匀 h(x,y)。这既是科学假设的必要条件，也可构成机制论文的重要分析。

### 5.6 两类工况的区分

定速工况：给定 V、h 与 Ω，求 p、F，作为第一阶段主要评价。定载工况：给定有效法向载荷，求 V(h) 及到达 htarget 的时间；只有在明确载荷平衡、运动学关系和非流体力项后才进行。禁止把两类条件下的优化结论直接互换。

t_target = ∫(h_target→h₀) [C(h)/F_eff(h)] dh （仅在线性 Fhyd=C(h)V 且力平衡成立时）

### 5.7 数值实现建议

- RVE：对每个 h、方向、驱动力保留 Q、压降/体力、截面尺寸、物性、LBM 转换系数、网格 dx、收敛日志与源代码哈希。
- 迁移率插值：仅在验证的 h 范围内用保正插值（如合适的分段单调方法），传播插值及网格不确定度，不擅自外推到更小间隙。
- 二维方程：使用有限体积或有限元，保证 Kθ 正定，设置压力参考，检验边界通量与 ∂H/∂t 的积分守恒，逐级细化网格。
- 对照框架：先解平板/圆盘解析基准，再算矩形和局部出口；之后才引入微观 K(h)。

### 7.3 E2：有限压头模型的独立基准

1. 均匀平板 K=h³/12：矩形、圆盘对照经典或独立数值基准，检查 F 与 μ、V、h、尺寸的标度。
2. 圆盘对称性：旋转 θ 时 F 应不变；矩形 0°/90° 对换并交换长宽可得到可检验对称映射。
3. 流量守恒：对任意 h，计算 ∮Γout J·n ds 与 −d∫Ω H dA/dt 的相对偏差。
4. 数值收敛：至少三套介尺度网格，外加压力场与总载荷误差分析；出口局部梯度可做网格局部加密。
5. 独立验证：选择较小有限域使用可计算的显式沟槽三维 Stokes/LBM 模型；逐步增加压头尺度 / 周期数，检验均匀化误差，并统计计算成本。

重要：G5A 已有的一维挤压模块应作为"既有求解器/解析基准"审查复用，核对其力积分、边界和单位后再扩展为二维，而不是从零丢弃。

## 8. 预期结果及科学解释（全部待验证）

预期观察 1：对给定几何，沿槽与横槽输运的 K 差异可能随间隙变化；如果 A(h) 随 h 增大趋向 1，应结合沟槽近壁效应和主流通道占比进行物理解释。此规律尚不能依据未验证的三点直接宣称单调或普适（现有三点 K_P/K_T=3.98/2.23/1.44 仅为固定网格候选趋势）。

预期观察 2：有限矩形压头、非对称出口下，沟槽方向会改变局部压强与总流体载荷；对称压头下的零效应也应当作为正面结果，用解析式解释何时"取向优化"没有意义。

预期观察 3：若均匀化成立，模型相对直接全分辨率求解可获得显著计算效率优势；具体加速比和预测误差必须实测。

预期观察 4：在满足制造与残余层约束下，可能存在载荷较低的结构；如最优值只是通过增加间隙或减少排液体积获得，则需要改变评价指标，不能把它称为结构水力优势。

论文结论必须同时包含成立的规律、不成立的假设、误差范围和适用边界。没有经验证的载荷改善，不应人为组织成"优化成功"的故事。

## 9. 研究创新性、投稿潜力与审稿风险

### 9.1 可尝试论证的贡献（候选，不是已成立创新）

1. C1 可转移且可量化误差的迁移率提取：针对 EX240 几何，在多个间隙/方向上给出经过数值验证的 K(h)，把不确定度传入宏观预测。
2. C2 有限域排液的跨尺度预测及失效边界：与解析式/独立显式计算比对，指出何时基于 K 的 Reynolds 型模型可信、何时需要高保真流动求解。
3. C3 受约束的几何-边界联合设计规律：区分对称压头取向无效与非对称出口取向有效的情形，并给出可复核的载荷改善边界。

### 9.4 必须预防的审稿问题

- "所谓方向优化是否违反对称性？"——圆盘/正方形反例及正确的出口-形状场景。
- "K 的定义、参考 h、单位是否在两个模型间一致？"——保留从 Q 到 K 到 F 的逐级量纲审计。

## 12. 向导师汇报的简明版本

### 12.1 已开展工作的表述

"目前围绕 EX240 周期纳米沟槽，在固定几何、单相液体条件下，利用 OpenLB 研究沿槽与横槽输运。已完成：几何/边界审计（G0）、平板迁移率验证（G1-v3 协议 PASS）、沟槽主证据与生产网格选择（G2：线性、三网格收敛，稳态矩阵 8/9，dx=2.5 nm）、周期复制数值不变性审查（G4：Nx=2/4/8 共 18 点全部通过）、三高度固定网格候选数据与一维挤压初算（G5A）。h75/dx1.25 横槽质量门禁异常已完成离线复核与 4000 步隔离诊断：旧 FAIL 精确复现，高精度账本全程 ≤1.8e-14，初步确认旧门禁超限来自全域顺序求和统计偏差；正式验证报告与仅统计修复的独立完整验证正在推进。在关闭该问题并完成量纲审计前，不发布最终 K(h) 数值。下一步以经过验证的迁移率张量作为有限压头挤压模型输入。"

### 12.2 拟向导师确认的问题

1. 首篇论文是否限定为刚性压头下的单相牛顿液体排液阻力？是否暂不涉及真实树脂填充、固化与模具变形？
2. 实际压头轮廓是圆形、矩形还是具有排液通道的特定图案？液体从哪些边界排出？
3. 第一阶段以"相同下压速度下的流体载荷"作为主指标，是否符合组内研究目标？
4. 可否提供/建立独立的直接数值算例或可比较实验用于跨尺度误差验证？
5. 压印实际约束中，目标最终间隙、残余层厚度与几何可制造性应如何定义？

### 12.3 一句话汇报目标

以显式纳米沟槽输运数据为基础，建立可验证的方向性挤压排液降阶模型，区分结构、压头形状与排液出口对载荷的真实贡献，最终给出带有误差边界和工艺约束的设计规律。
