## 1 ★ 最有价值：`porousMedia/gasStorage2d` —— 双材质不同接触角

**这是我们最需要的那一块，官方已经写好了。**

**文件**：`examples/porousMedia/gasStorage2d/gasStorage2d.cpp`

```cpp
// L325, L333-334 —— 定义两个不同的角
const T theta = params.get<parameters::THETA>();
AnalyticalConst2D<T, T> angleInside( theta );        // 多孔介质内部
AnalyticalConst2D<T, T> angleOutside( M_PI/2. );     // 外部壁面

// L362-363 —— 按材质分别设置
fields::set<descriptors::THETA>( sLatticeAC, geometry.getMaterialIndicator({2}), angleOutside);
fields::set<descriptors::THETA>( sLatticeAC, geometry.getMaterialIndicator({5}), angleInside);
```

**⇒ 这就是"模具面 θ_m / 基板面 θ_s"的标准写法。** 关键要素：

| 要素 | 写法 |
|---|---|
| 逐格场设置 API | **`fields::set<descriptors::THETA>(lattice, indicator, value)`** |
| 值的类型 | `AnalyticalConst{D,T}`（也可换成任意空间变化的 functor） |
| 选择区域 | `geometry.getMaterialIndicator({material})` |
| 前提 | **不同表面必须编成不同 material 号** |

**修正**：上一版方案里我推测用 `defineField`，**官方实际用的是 `fields::set`**（两者都是逐格 API，但应照官方写法用 `fields::set`）。

**同一文件的其他可借点**：
- `boundary::set<boundary::PhaseFieldCurvedWall>(sLatticeAC, wall);`（L233）—— 曲面壁相场边界，比 `setBouzidiWellBalanced` 更通用；
- `geometry.rename(1, 5, indicator);`（L116）—— 从几何指标批量改材质号的写法；
- **几何可来自真实 vti 数据**（`vtiReader` / `IndicatorBlockData2Dvti`），说明支持任意复杂壁面。

## 4 ⚠️ 模型差异警告（不可照搬）

`gasStorage2d` 与 `bubbleChannel2d` 用的是：

```cpp
using ACBulkDynamics = ConservativePhaseFieldBGKdynamics<...>;   // Allen–Cahn 型
```

**而我们 R1 已验证的是 well-balanced Cahn–Hilliard（CH）**，两者不是同一界面模型。

**⇒ 可迁移的部分**：`fields::set<descriptors::THETA>` 是**逐格场操作，与界面模型无关**，可直接用于 CH lattice。
**⇒ 不可迁移的部分**：dynamics 类型、coupling 配置、boundary 处理器——**必须沿用 contactAngle3d / 我们 R1 的 CH 配置**。

**建议**：只借"接触角逐材质设置"这一段写法，**不要整案例复制**。

## 5 对润湿校准改动方案的影响

`SIM240_润湿校准代码改动方案_20261016.md` 中的**单角校准（改动 1–4）不受影响**，仍按原计划：加 `--theta`，四档各跑一次。

**新增一条**：进入 R2-XY 源码设计时，按 `gasStorage2d` 范式实现双面接触角：

```cpp
// 概念示意（R2-XY，CH lattice）
AnalyticalConst3D<T,T> thetaMold( M_PI - thetaM_deg*M_PI/180. );        // 注意 π−θ 约定
AnalyticalConst3D<T,T> thetaSubstrate( M_PI - thetaS_deg*M_PI/180. );
fields::set<descriptors::THETA>( ch, geometry.getMaterialIndicator({MAT_MOLD}),      thetaMold );
fields::set<descriptors::THETA>( ch, geometry.getMaterialIndicator({MAT_SUBSTRATE}), thetaSubstrate );
```

**前置**：几何必须把模具面与基板面标成**两个不同 material**（参照 `resolvedRock3d` 的 `rename` 写法），并删除全局 `setParameter<THETA>`。
