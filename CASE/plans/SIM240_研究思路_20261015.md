## 主线 1｜对比：OpenLB 直接算的流阻 ↔ 等效/简化模型的流阻

**必须先把"对照对象"分清，否则比了也没意义：**

| 对照 | 目的 | 现状 |
|---|---|---|
| **（a）简化理论模型**（把二维流动拆成串联一维流阻、给等效 KXX/KYY） | 得出**修正系数**——导师要的就是这个 | 已有事前预测可做：DNS 前沿比 ≈ **1.5**，而 K 比值 = **2.23**（K 只以 √ 进入前沿位置） |
| **（b）其他求解器算的版图 KXX/KYY**（如 OpenFOAM） | **跨求解器交叉验证** | 项目已裁定**求解器锁定 OpenLB**；外部 K 只能作对照，且必须核对网格、边界、周期口径是否一致，否则不可比 |

**提醒**：(a) 与 (b) 是两件事，论文里要分开写——(a) 是"简化模型够不够准、要不要修正"，(b) 是"我这套 DNS 本身可不可信"。顺序上先做 (a)（成本低、有预测值），(b) 视需要。

### 主线 1 的对照结构（2026-10-15 20:48 澄清，重要）

**分工已明确**：**OpenLB DNS = 微观标定工具**（240 nm 级 RVE，出 KXX/KYY 与修正系数）；**OpenFOAM = 宏观/版图级模型**（用等效 K 算全版图的填充时间与填充率）。

因此"拿 OpenFOAM 算的版图 KXX/KYY 来对照"有**两种含义，价值完全不同**：

| 情形 | 对照性质 | 价值 |
|---|---|---|
| **(i) 对方的 K 也是 RVE 级**（同几何、同周期/边界） | **同层级、跨求解器交叉验证** | 中等——只证明"我这套没算错"。**必须核对网格、边界、周期口径，否则不可比** |
| **(ii) 对方的 K 是从全版图反演的等效参数** | **跨尺度一致性检查**：微观标定值 ↔ 宏观等效值 | **高**——直接回答"等效模型够不够准"，能把修正系数落到宏观预测上 |

**行动**：先问清对方那组 K 的**定义层级与口径**（几何尺寸、网格、边界是周期还是有限、是否含接触角、驱动方式），再决定按 (i) 还是 (ii) 对照。

**论文的写法**（整条链）：微观 DNS 标定 KXX/KYY 与修正系数 → 作为**本构输入**进宏观版图模型 → 用**宏观实验**（填充率 / 填充时间）验证整条链。这与导师在会上说的"模拟出来 → 弄到大规模模型里 → 挑光刻实验数据比一下 → 拿实验作为验证"完全一致。

### 主线 1 的意义与升级（2026-10-15 20:55，重要）

**对比 KXX/KYY 是手段，不是目的。** 它的意义有三层：

| 层 | 意义 |
|---|---|
| **科学** | 检验"**等效化**"这个近似是否成立、误差多大、**在什么条件下失效**——这是多尺度方法的核心问题（微观结构能不能被一个二阶张量代表） |
| **工程** | 若成立 + 一个修正系数 → 工业界可用便宜的**宏观模型预测填充率**，不必每次做纳米级 DNS（= 导师说的"弄到大模型里"） |
| **参数** | KXX/KYY 是把"**结构**"变成"**材料参数**"的桥梁；可交付物是**经微观 DNS 标定的本构 + 修正系数 + 不确定度** |

**但"只对比一个数字"不足以成文**，必须升级为**适用域图谱**：

```
纵轴：K 预测 ÷ DNS 实测
  1.0 ┤━━━━━━━━━━━━━━╮
      │  等效成立区   │╲___ 偏离区：必须引入
  0.5 ┤              │     界面曲率 / 接触线（H2）
      └──────────────┴────────────────────→ 横轴
        离前沿距离 / 填充程度 / 接触角 / 间隙 h
```

**两种结果都成立，只是写法不同**：
- **一致** → 结论："等效模型可用，误差 X%，**适用域为……**"；
- **不一致** → 结论："等效化在此失效，**原因是……**"（落到 H2，**更有价值**）。

**Motivation 的标准表述**：工业需要宏观模型，但微观结构（沟槽）无法在宏观网格上解析 → 需要一套**经微观 DNS 标定、且给出适用域与不确定度**的等效本构。这正是导师要求"Motivation 清楚 + Methodology 做得对"的落点。

## 主线 3｜物理层级递进（三级）

| 级 | 内容 | 状态 / 门槛 |
|---|---|---|
| **L1 纯液体（单相）** | 等密度相场、平壁/周期球滴基准 | **R1 已 PASS**；单相全充液 K 数据库已放行 |
| **L2 纯液体 + 真实物性/接触角 + 显式沟槽** | 即 R2-XY（面内）与 R2-Z（入槽） | 当前主攻；需 60°→实测双面接触角、实测黏度，以及 §2.8 口径订正 |

**L1 / L2 / L3 的区别，关键在"空的那一侧怎么处理"：**

- **L1**：液体**填满**整个空间（全充液），**没有界面** → 只能测本构参数 KXX/KYY，看不到铺展与入槽。
- **L2**：有**液/气界面**，但气相**不求解**——被当作可自由排出、无阻力的气体（可排气假设）。→ 能看铺展、入槽、液量分配；**不能看困气**。
- **L3**：气相是**真实流体**（真实密度比、真实黏度）→ 能看困气、气泡滞留、气相压缩。

**L2 的一句话定义**：**在真实沟槽几何里，用真实固化胶参数（黏度 / 双面接触角 / 表面张力），算滴合并后连续液膜中一个局部液区的铺展与入槽分配**——它就是首篇 Q1 + Q2 的全部内容，也是 R2-XY 与 R2-Z 要交付的东西。

> **⚠️ 观测单元定位（2026-10-15 21:3x 修正）**：本项目 V = 0.1114 fL = 1.114×10⁻⁴ pL，而真实 J-FIL 单滴为 **1–6 pL**（典型 ~5 pL，文献给出布滴密度 10000 drops/cm²、合并气穴 ~100 μm）。**我们解析的是"滴合并后连续液膜中的局部液区"，不是单个喷墨滴。** 该定位对 H1 有利：连续液膜内才存在远离前沿的饱和区；孤立小滴内部全是接触线主导，尺度分离先天不足。

**L2 产出**：L∥(t)/L⟂(t) 前沿、成对截面 Q∥/Q⟂、**逐槽填充率 F_g(t) 与 F_g(h)（毛细自吸主线）**、超压档 F_g(Δp)（补充工况）、液量分配；以及与 KXX/KYY 预测的对比（→ 修正系数，主线 1(a)）。

**L2 的前置（目前还差）**：双面接触角各校准一次（模具侧 R1 的 100° 可引，基板 ~10–20° 必补）；实测物性替换；§2.8 单位口径订正；几何审计后的短测通过（当前 200 步短测 2 步即 FAIL）。

**L2 不能说**：困气（气相未求解）、下压速率效应（若用固定 h/准静态）、未声明口径的绝对时间。
| **L3 气液两相**（沟槽内为气、下方为液） | 真实液-气密度比 | **本机未验证能力**：当前 ρ_l=ρ_g=1（等密度），真实密度比 ≥10² 未验证 → 立为前置门槛，**不自动进入** |

## 主线 4｜因素递进：一次只改一个

建议顺序（**每级一个对照基准，优先选有解析解的**）：
