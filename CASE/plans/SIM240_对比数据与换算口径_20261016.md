## 1. 这份文档解决什么问题

别人论文给出来的往往**不是 K**，而是阻力、滑移长度、无量纲系数、甚至是一个填充时间。直接把这些数字和我们 OpenLB 的 K 放在一起比，比出来的差是"单位差"，不是"物理差"——**这是最容易被打回的一类错误**。

本文件规定两件事：**我们要输出什么**（§2）、**别人的怎么换成能比的东西**（§4）。

---

## 2. OpenLB 每档必须输出的 8 项

符号约定（与范围文档 v2 §4 一致）：G = 宏观压力梯度大小 [Pa/m]（体力驱动时 G=ρa）；J = 单位宽度通量 [m²/s]；W = 垂直驱动方向的周期宽度 [m]；Q = W·J [m³/s]；K = μJ/G [m³] 输运系数。**三者不可混用，每张表必须写清单位。**

| # | 量 | 说明 |
|---|---|---|
| 1 | J∥、J⟂（单位宽度通量，m²/s） | 给定压力梯度下的通量；Q = W·J 才是体积流量 |
| 2 | 平均速度的三种口径 | 按声明分别报告：Darcy 速度（固定投影截面）、局部截面平均（截面积随 x 变的横槽尤其小心）、体积平均速度（V_f/A_plan）——三者不是无条件相同 |
| 3 | K∥、K⟂（m³ 输运系数） | K = μJ/G；按冻结卡口径记录，**单位必须同时写清来源文件** |
| 4 | **A = K∥ / K⟂** | 主指标之一，无单位。⚠ A 正确**不等于**两方向 K 都正确（同倍高估时 A 不变）——主结果必须同时报方向系数与各自误差 |
| 5 | **增益 Γ = K∥ / K_smooth** | 相对无槽平板的增益（符号用 Γ，避免与压力梯度 G 重名） |
| 6 | **f = Q_槽内 / Q_总量** | 需注明截面位置与正负流量定义；**跨槽方向槽区可能存在局部回流**，f 随截面/区域定义而变，不能当作统一物理量 |
| 7 | u(z)、u(y) 速度剖面 | 检验对方模型的**形状假设**（比单个数更狠） |
| 8 | 元数据 | h、d、dx、周期数 N、驱动力、边界条件、git commit、H_ref（逐档计算 h+φd） |

**内部交叉核对（待验收，非已完成）**：能量闭合 D=∫2μE:E dV = G·A_plan·J、K_energy=μD/(G²A_plan) 属待验收项；且流量与耗散出自同一数值场，交叉核对不是独立实验验证。

## 3. 四层参照梯子（顺序不能反）

| 级别 | 参照对象 | 用途 | 引用状态 |
|---|---|---|---|
| **L0** | 教科书平行平板 **k = h²/12**（自行把槽深设 0） | 把尺子对零，校准单位与边界 | 不用引 |
| **L1** | 一维变厚度平板理论：沿槽 ⟨h³⟩、跨槽 1/⟨h⁻³⟩ | 是"最常见等效假设"的理论版，自己推就有 | **自推可写**（要写推导过程） |
| **L2** | 文献里的等效 K 公式 | 论文的主对手 | **必须有 DOI + 公式编号/页码 + 适用域** |
| **L3** | 旧的 OpenFOAM KXX/KYY | 只能私下核对数量级 | ⛔ **禁止引用**（他人横向项目，不可复现，无 DOI） |

> **为什么 L3 必须禁**：它是别人横向项目的产物，没有 DOI、审稿人查不到来源、无法复现。放进去就是给论文埋雷。它唯一的作用是你私下看一眼数量级对不对。
> **为什么 L0/L1 必须先做**：在第 0、1 级证明自己算得对之后，才有资格在第 2 级说"别人在这里不准"。

## 4. 单位换算速查表

### 4.1 四种常见口径怎么换

| 对方给什么 | 换算办法 | 备注 |
|---|---|---|
| 渗透率 k [m²] | 直接比；或无量纲化 **k / (h+d)²** | 最省事。**务必确认他归一化时除以的是总面积还是液体面积** |
| 流动阻力 R | 迁移率 M = 1/R | ⚠ 见 §4.2，最大的坑 |
| 无量纲阻力系数 D | 取倒数得无量纲迁移率 | 注意参考长度是 **h 还是 (h+d)** |
| 滑移长度 b | **k_eff = h²/12 · (1 + 6b/h)** | 双侧 Navier 滑移结果，**本项目自推，待复核** |
| 填充时间 t_fill | 通过 Washburn 型关系反算 | ⚠ **第二篇才用到**，本篇不要碰 |

### 4.2 ⚠ 最大的坑：R 里到底含不含 μ

判断办法（**30 秒搞定，不许跳过**）：

> **把对方的公式代入"平行平板"极限（槽深 d = 0），看它给出的是 `h²/12`、`h²/(12μ)` 还是 `12μ/h³`。**
> - 给出 `h²/12` → 渗透率类几何量，**不含 μ**，直接比
> - 给出 `h²/(12μ)`（迁移率口径）→ **乘** μ 才得 K
> - 给出 `12μ/h³`（阻力口径）→ 用 μ **除以**它才得 K
> ⚠ 乘除方向搞反是这里最常见的错误；判不准时回到本节的代入法，不要凭感觉。
> ⚠ **R 必须先说明定义才能取倒数**：Δp/Q、G/J、1/K 是三个不同的量（量纲、长度、黏度因子各不相同），不能只靠"迁移率"统称省略。

**本项目的实证教训**：同一个 h = 75 nm 档，两个文件的 R 精确相差 1000 倍
- `analysis/transport_parameter_extraction/transport_database/transport_database.csv`：R∥ = 1.02224155e+22（K×R = 1.0）
- `transport_database/G3_height_resistance.csv`：R∥ = 1.02224155e+19（K×R = 1e-3）

⇒ 两者不是同一个东西。**引用任何 R 都必须写清来源文件路径。**

### 4.3 换算结果统一落到这张表上

每做完一次换算，登记这五项，少一项就不可比：

```
几何: h = __ nm, d = __ nm, α = 1（部分充液后置，见范围 v2）
方向: ∥ 沿槽 = Kyy / ⟂ 跨槽 = Kxx（与 G2 旧库一致，冻结卡 §2.2）
归一化: 除以总面积 / 只除液体面积
参考高度: H_ref = h + φd（φ=w/P=0.5，逐档计算，勿写死 125）/ h / (h+d) / P
来源: 文件路径 或 DOI + 公式编号
```

## 6. 五个禁止混比（踩中一条就可能被打回）

1. **不同 dx 的 K 混在一张表里**
2. **不同归一化**（除以总面积 vs 只除液体面积）
3. **单周期平均 vs 整块模板平均**
4. **有无部分填充 α 的数据混用**（α = 1 是满槽，α < 1 必须单独说明液体贴哪一侧）
5. **稳态 vs 瞬态结果混用**
