# R2-XY 协议 §2.8 单位与量纲口径审计

- 日期：2026-10-15
- 性质：**只读审计**。不修改 `SIM240_液滴R2-XY最小验证协议_20261015.md`（冻结文件）、不修改任何源码、不编译、不运行仿真。
- 起因：协议 §2.8 被标为"唯一保留项（正式长算前必须确认）"。本审计复核该节全部换算、并复核 §4 足迹/体积口径。
- 结论：**§2.8 的两处 dt 数值各有算术错误（分别差 31.6 倍与 10 倍），其"μ_eff ≈ 真实 1/500"的结论不成立；同时该节的"硬限制"表述不成立——存在三个自洽口径，其中两个可同时精确匹配 σ 与 μ。** 足迹/体积口径（§4）复核通过。

## 1 审计依据（不凭教科书公式，先锚定项目内既有约定）

| 依据 | 内容 |
|---|---|
| F1 源码 `f1_liquid_film_compression.cpp:44` | `dt = (tau - 0.5) * dx*dx / (3.0 * nuPhys)` → **本项目以匹配 ν 定 dt** |
| F1/G2 源码 `:606` / `:591` | `UnitConverter<T,DESCRIPTOR> converter(dx, dt, lx, 1.0, nuPhys, rhoPhys)` → 质量单位 = ρ_phys·dx³，长度 dx，时间 dt |
| G2 源码 `:27` | `nuPhys = 1.0e-6`（水）——**注意：R2 的目标液体为 μ=0.01 Pa·s、ρ=1000 → ν=1e-5 m²/s，与 F1/G2 的水不同** |
| `phaseFieldCoupling.h:546-548` | CH 自由能参数由 σ 与 w 线性生成：`k = 1.5·sigma·w`、`beta = 12·sigma/w` → σ_lat 与 w 是输入 |
| R1 两个正式 run | `radius_lattice=16`、`surface_tension_lattice=0.01`、实测 `delta_pressure_lattice=1.1031e-3 ≈ 2σ_lat/R = 1.25e-3`（离散偏差 11.75%） |

**量纲映射（两个独立要求）**：

$$
\text{匹配 }\sigma:\quad \sigma_{phys}=\sigma_{lat}\frac{\rho_{phys}\,dx^{3}}{dt^{2}}
\;\Longrightarrow\;
dt_\sigma=\sqrt{\frac{\sigma_{lat}\,\rho_{phys}\,dx^{3}}{\sigma_{phys}}}
$$

$$
\text{匹配 }\mu:\quad \nu_{phys}=\nu_{lat}\frac{dx^{2}}{dt},\quad \nu_{lat}=\frac{\tau_L-0.5}{3}
\;\Longrightarrow\;
dt_\nu=\frac{\nu_{lat}\,dx^{2}}{\nu_{phys}}
$$

## 2 数值复核（dx = 5 nm；τ_L = 1 → ν_lat = 1/6；σ_lat = 0.01；ρ = 1000；μ = 0.01 Pa·s；σ = 0.03 N/m）

| 量 | 值 |
|---|---|
| dt_σ（匹配 σ） | **6.4550×10⁻¹² s** |
| dt_ν（匹配 μ，ν = 1e-5 m²/s） | **4.1667×10⁻¹³ s** |
| 两者之比 dt_σ / dt_ν | **15.49** |

### 2.1 协议 §2.8 声称值与正确值的对照

| 项 | 协议 §2.8 声称 | 审计重算 | 偏差原因 |
|---|---|---|---|
| (a) dt（匹配 σ） | 2.04×10⁻¹⁰ s | **6.455×10⁻¹² s** | 偏大 **31.6 倍 = √1000 = √(ρ_phys)**，即公式里多乘了一次 ρ（或用了 ρ² ） |
| (a) 等效 μ_eff | ≈2.0×10⁻⁵ Pa·s（真实 1/500） | **6.455×10⁻⁴ Pa·s = 真实 1/15.5** | 由上一行的 dt 错误直接传导 |
| (a) Mach 上限对应界面速度 | ≈0.71 m/s | **22.36 m/s**（=0.05·c_s·dx/dt） | 同上（该量只是可压性上限，非实际流速） |
| (b) dt（匹配 μ） | 4.17×10⁻¹² s | **4.167×10⁻¹³ s** | 偏大 **10.0 倍**：用了 ν=1e-6（F1/G2 的水），而非本液体的 ν=1e-5 |
| (b) 若要在此 dt 下匹配 σ，所需 σ_lat | ≈4.2×10⁻⁶（"过小、不可用"） | **4.167×10⁻⁵** | 同样由 dt 错误传导（差 100 倍，非 1000 倍） |

### 2.2 决定性交叉检验：用 R1 实测数据反标定 dt

R1 laplace run 的格子量是干净的（`radius_lattice=16`、`σ_lat=0.01`、实测 `Δp_lat = 1.1031e-3`，理论 `2σ_lat/R = 1.25e-3`）。把它映射到物理量：

- 取 **dt = 6.455×10⁻¹² s**：`p_phys = p_lat · ρ_phys dx²/dt² = 1.25e-3 × 6.0×10⁸ = 7.5×10⁵ Pa`
  对照物理目标：`2σ/R = 2×0.03/(16×5 nm) = 7.5×10⁵ Pa` → **完全一致**；
- 取协议 §2.8 的 **dt = 2.04×10⁻¹⁰ s**：`p_phys ≈ 751 Pa` → 与 7.5×10⁵ Pa **差 1000 倍**。

**判定：匹配 σ 的正确 dt 就是 6.455×10⁻¹² s。§2.8 的 (a) 数值确定错误。**

## 3 "硬限制"不成立：三个自洽口径

§2.8 断言"dx = 5 nm 时无法同时匹配 μ 与 σ"。该断言**只在 τ_L 与 σ_lat 都被冻结于 step6G 验证点时**成立。放开任一即破解：

| 口径 | 设置 | 结果 | 代价 / 风险 |
|---|---|---|---|
| **(a′) 匹配 σ（保留 τ_L=1、σ_lat=0.01）** | dt = **6.455×10⁻¹² s** | σ 精确匹配；**μ_eff = 6.455×10⁻⁴ Pa·s = 真实 μ 的 1/15.5** | **零额外验证成本**（=R1 已验证的参数点）；代价：黏度低 15.5 倍，绝对时间/速度**不可**直接对应工艺，Ca 相对真实液体偏大 15.5 倍 |
| **(c) 匹配 σ 与 μ：放开 τ_L** | dt = 6.455×10⁻¹² s，ν_lat = 2.582 → **τ_L = 8.246**（格子 Re(h_gap=15 格) = 0.168，稳定） | **σ 与 μ 同时精确匹配** | 需重跑 R1 两项（分钟级）再放行；**风险**：`phaseFieldCoupling.h:541/615` 的部分后处理里存在 τ 依赖经验式（`(1-scale)*5.`、`(1-scale)*((tau_l-0.5)*125+0.5)`，属其他模型分支），step6G 实际使用的 WellBalanced + `LinearTauViscosity` 链是否受影响须先核对 |
| **(d) 匹配 σ 与 μ：放开 σ_lat** | dt = **4.1667×10⁻¹³ s**，**σ_lat = 4.167×10⁻⁵**（τ_L=1 不变，w=4 格不变） | **σ 与 μ 同时精确匹配** | 需重跑 R1 两项；**风险**：σ_lat 比已验证点小 240 倍，CH 界面项（k=1.5σw、β=12σ/w 同步缩小 240 倍）相对固定的迁移动力学变弱，可能出现界面过度形变——**须以 R1 Laplace 判据实测**（`Δp_lat` 是否仍等于 2σ_lat/R） |

**旁证：无量纲量在一致映射下自动保持。** 例：Ca_lat = μ_lat·U_lat/σ_lat = 0.1667·U_lat/4.167e-5 = 4000·U_lat；Ca_phys = 0.01·(U_lat·dx/dt)/0.03 = 4000·U_lat。两者相等 → 口径 (c)/(d) 下 L∥/L⟂、Q∥/Q⟂ 等**比值**在物理上等价于真实液体；而 (a′) 下的比值仍由几何主导，但绝对时间与 Ca 需按 15.5 倍换算声明。

**若坚持 τ_L=1 又要两者同时匹配，所需 dx\* = 1.20 μm**（≈液区自身尺度 944 nm）→ 不可能。这才是真正的"硬限制"：**在 5 nm 网格上，不能既不改 τ 也不改 σ_lat 地同时匹配两个物性。**

## 5 观测量口径的一个缺口（建议在 §5 补定义）

协议 §5 把 **V_out(t)** 定义为"越过初始足迹之外的液体体积"。该定义把**两件不同的事混在一起**：

1. **足迹外重新分布**（液体离开足迹但仍留在计算域内，例如进入相邻槽/缓冲区的薄隙）；
2. **穿出计算域外排**（经 x 两端的控制面流出）。

且本协议 **x 两端是无滑移壁**——液体**无法**穿出计算域，因此"外排"在物理上只能表现为**缓冲区积累**。建议补两个独立量并从守恒关系交叉校核：

- `V_footprint_out(t)`：初始足迹之外、控制盒之内的液体体积（重新分布）；
- `V_flux(t)`：在足迹外约 0.5 μm 处取**一对**控制面，对法向通量做时间积分（真正的输运量）；
- 守恒检查：`V_flux(t) + V_inside(t) ≈ V_0`（残差即数值质量误差，应与相场漂移同量级）。

## 6 对正式长算预算的附带发现（漂移余量）

由 R1 contact run 外推（详见 `R1_wetting_benchmark_validation_20261015.md` §6）：

- contact 的相场漂移**不是收敛到常数**，而是单调缓慢爬升，增量按 ≈0.782/1000 步几何衰减 → **外推渐近值 ≈ 9.81×10⁻⁴ = 1e-3 门槛的 98.1%**（余量仅 1.9×10⁻⁵）。该值为**外推估计（推测）**，非实测。
- 含义：R2-XY 含**带图案的模具壁面 + 更长的接触线**，若正式 run 显著长于 6000 步，"全程最大漂移 ≤1e-3"的余量极小。建议在 R2 协议里**显式写明漂移预算与判读口径**（是否允许弛豫窗口须**事先**声明，不得事后调整）。

## 7 建议（待用户/导师决策，本审计不改冻结协议）

1. **必须先订正 §2.8 的 dt 数值**（(a) 6.455×10⁻¹² s；(b) 4.167×10⁻¹³ s），并撤下"μ_eff ≈ 1/500"的表述；
2. 口径选择三选一：
   - 若论文只需机制与比值、且能接受"绝对时间为该口径下"→ 选 **(a′)**，零额外验证成本；
   - 若论文要写**真实物理时间/速度/Ca** → 选 **(c)** 或 **(d)**，各自重跑 R1 两项（分钟级）即可放行；其中 (d) 只改输入、不动 τ，但需实测确认小 σ_lat 下界面仍稳定；
3. §5 观测量补 `V_footprint_out` / `V_flux` 两量并加守恒交叉校核；
4. §4 的"< 3%"订正为"3.4%"。

**范围边界**：本审计不改变任何历史结论，不放行任何计算；§2.8 仍为"未确认"，正式长算前须先完成上述订正与口径选择。
