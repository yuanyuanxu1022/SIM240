# SIM240_First_Validation_Task_v2.0

# 第一阶段 OpenLB 单相流基础验证与论文模型建立任务

## 0. 研究目标与论文科学问题

本阶段目标：

> 基于 OpenLB-LBM
> 建立显式纳米压印周期结构液体输运模型，为研究周期纳米结构、水力阻力及尺度效应提供可靠数值基础。

本阶段不研究：

-   动态压头下压；
-   气液两相全过程填充；
-   动态移动边界；
-   大规模参数扫描。

第一阶段重点回答：

1.  周期纳米压印结构是否改变液体有效输运阻力？
2.  沟槽拓扑如何影响压力损失和局部流场？
3.  显式LBM是否能够解析纳米结构诱导的流动重构机制？

------------------------------------------------------------------------

# 1. 研究假设

## 假设1：周期结构改变有效水力阻力

光滑通道与周期沟槽结构具有不同有效阻力：

\[ R\_{groove}`\neq `{=tex}R\_{smooth} \]

------------------------------------------------------------------------

## 假设2：沟槽方向导致输运各向异性

沿槽方向：

\[ R\_{`\parallel`{=tex}} \]

横槽方向：

\[ R\_{`\perp`{=tex}} \]

预计：

\[ R\_{`\perp`{=tex}}\>R\_{`\parallel`{=tex}} \]

------------------------------------------------------------------------

## 假设3：周期数量影响有效输运尺度

定义单位长度阻力：

\[ r_N=`\frac{\Delta P}{QL_N}`{=tex} \]

随着周期数量增加：

\[ r_N`\rightarrow `{=tex}r\_{`\infty`{=tex}} \]

寻找代表性周期尺度。

------------------------------------------------------------------------

# Case01：平板 Poiseuille 流验证

## 目的

验证：

-   OpenLB求解流程；
-   入口速度边界；
-   出口压力边界；
-   固壁no-slip；
-   压降计算；
-   流量统计。

作为后续结构流阻计算基准。

------------------------------------------------------------------------

## 几何参数

平行板模型：

-   液膜高度 H = 75 nm
-   流动方向：y方向
-   计算长度：2.4 μm
-   计算宽度：240 nm
-   网格尺寸：Δx=5 nm

------------------------------------------------------------------------

## 输出

必须获得：

1.  速度场；
2.  压力场；
3.  流量 Q；
4.  压力-流量关系：

\[ `\Delta `{=tex}P-Q \]

5.  基准阻力：

\[ R_0=`\frac{\Delta P}{Q}`{=tex} \]

6.  数值稳定性：

-   Mach数；
-   密度范围；
-   质量守恒误差；
-   稳态步数。

\[ R\_{smooth}=`\frac{\Delta P}{Q}`{=tex} \]

\[ R\^\*=`\frac{R_{groove}}{R_{smooth}}`{=tex} \]

用于评价周期拓扑影响。

# Case02：EX240单周期直沟槽沿槽方向流动

## 目的

研究真实纳米压印周期结构中的单相输运。

回答：

> EX240周期沟槽是否改变液体输运阻力？

------------------------------------------------------------------------

## 几何参数

周期：

\[ P=240nm \]

结构：

60 nm wall + 120 nm groove + 60 nm wall

参数：

-   周期 P = 240 nm
-   沟槽宽度 = 120 nm
-   墙宽 = 60 nm
-   槽深 = 100 nm
-   液膜高度 = 75 nm
-   总流体高度 = 175 nm

------------------------------------------------------------------------

## 流动方向

第一阶段：

沿槽方向：

\[ U\_{`\parallel`{=tex}} \]

------------------------------------------------------------------------

## 输出结果

### 宏观结果

1.  流量：

\[ Q \]

2.  压降：

\[ `\Delta `{=tex}P \]

3.  水力阻力：

\[ R\_{groove}=`\frac{\Delta P}{Q}`{=tex} \]

4.  阻力比：

\[ R\^\*=`\frac{R_{groove}}{R_{smooth}}`{=tex} \]

------------------------------------------------------------------------

### 微观机制

输出：

-   三维速度场；
-   压力分布；
-   流线；
-   壁面剪切分布。

分析：

-   流线重构；
-   局部速度梯度；
-   黏性耗散。
