# SIM240 "我这一档算对了没" 检查清单 v1.0

- 日期：2026-10-16
- 用法：**每跑完一档（一个 h × α × dx 的组合），照着从头到尾打一遍勾。**没打的勾不许进论文。
- 配套：`SIM240_几何与单位口径冻结_20261016.md`（几何与单位口径）、`SIM240_第一篇范围重定位_纯液体单相_20261016.md`（范围）
- 核心规矩三条：
  1. **历史 FAIL 永远是 FAIL**，不得改写、不得"四舍五入"、不得因为后面算顺了回头擦掉。
  2. 每一档一个编号，记录写进档内 `CHECKLIST.md`，不写=没做。
  3. 五项检查只能报告"过了第几层"，**不许说"算对了"这种没有层次的话**。

---

## 0. 五个层次是什么（先记住这个）

| 层 | 名字 | 回答的问题 | 谁说了算 |
|---|---|---|---|
| **L1** | 能跑起来 | 有没有炸（发散、NaN、物质凭空消失） | 我们自己 |
| **L2** | 精确解复现 | 简化到教科书情形，能不能算准 | 教科书，不靠任何人 |
| **L3** | 内部自洽 | 线性、网格收敛、周期性、对称性自洽吗 | 我们自己 |
| **L4** | 外部对齐 | 别人的模型**在他们自己的适用范围内**能不能复现 | 别人的论文 + DOI |
| **L5** | 实验验证 | 真实世界符不符合 | 实验，本篇不做 |

> **本篇第一篇论文只宣称到 L4。** 写论文时原话必须是"本文的 DNS 结果已通过 L1–L4 验证"，不许升格为"已验证/已探明真相"。

## 2. L1 运行层：有没有炸

| # | 检查 | 判据 | ☐ | 不过怎么办 |
|---|---|---|---|---|
| 1.1 | 跑完不发散 | 速度/密度全程有界，无 NaN | ☐ | 降驱动力或降 dt，别硬调别的 |
| 1.2 | 质量守恒 | **记录实际冻结协议**：D2 源码全域质量漂移 < **1e-10**；截面通量一致性 ≤ **1e-5**。两者是不同的量，分别记录；旧移动边界/两相的 1e-3 残差门槛**不移植**到单相周期输运 | ☐ | 查边界通量统计口径 |
| 1.3 | 马赫数 Ma | < **0.05**（只判 LBM 可压缩误差；**惯性另看 Re**，小 Ma 不等于无惯性） | ☐ | 降驱动力 |
| 1.4 | 到稳态 | **记录实际冻结协议**：D2 收敛窗口 1000 步，窗口相对标准差 ≤ **1e-6**、相对跨度 ≤ **5e-6**；写明窗口长度与指标 | ☐ | 加步数 |
| 1.5 | 磁盘/日志 | 输出目录独立（用 `--RUN_TAG`），没覆盖别人的结果 | ☐ | 立刻补 `--RUN_TAG` |

> 注：清单里的门槛必须与实际源码协议一致；若未来拟定新协议须升版本，**不许看完成绩后改旧门槛**。历史 moving-boundary 曾卡在 1.62e-3 判 FAIL，该记录原样保留、独立存档，不作现行门槛。

## 3. L2 精确解：把模型降成教科书

| # | 检查 | 判据 | ☐ | 不过怎么办 |
|---|---|---|---|---|
| 2.1 | **第 0 级平行平板**：把槽深 d 设成 0 | 算出的 k 与解析值 **k = h²/12** 相差 < **1%** | ☐ | **不许往下算任何正常工况**，先修单位/边界/后处理 |
| 2.2 | Poiseuille 剖面（**仅限平板退化 d=0 或远离台阶的间隙区**） | 该区域取直线，速度剖面 vs 抛物线 | ☐ | 查壁面边界条件是不是真的无滑移；⚠ 真实带槽截面存在侧壁影响，**不要求任意槽内直线都是抛物线**——否则会把真实几何效应误判为程序错误 |
| 2.3 | d=0 时 ∥ 与 ⟂ 必须相等（各向同性） | 两者相对差 < **1%** | ☐ | 说明几何/设置有隐性方向差异，必查 |

> 2.1 是全套检查里**最值钱的一条**：它不依赖任何文献、不依赖老师的项目、不需要花钱，纯逻辑自洽。
> 现状：现有 G2 管线已由 Smooth75 通过本级（冻结卡 §5.4，误差 ≤0.44%）。**换 τ、换边界格式、新 case 代码后必须重跑。**

## 4. L3 内部自洽：自己和自己对不对得上

| # | 检查 | 判据 | ☐ | 不过怎么办 |
|---|---|---|---|---|
| 3.1 | **线性响应** | 驱动力加倍 ⇒ 流量加倍，相对偏差 < **1%** | ☐ | 说明有非线性/惯性未忽略，降雷诺数 |
| 3.2 | **网格收敛** | 至少两个 dx；历史基线 GCI：∥ 0.125%、⟂ 0.551%。新工况偏差应保持同量级 | ☐ | 加一档更细网格，算 GCI |
| 3.3 | **周期性一致性** | N 与 2N 周期结果相对差 < **1%**；⚠ 这只支持理想周期介质的数值实现一致性，**不等于**真实非周期版图的代表性体积收敛 | ☐ | 查实现；真实版图 RVE 是另一问题 |
| 3.4 | **对称性** | 几何对称 ⇒ 流场对称，非对角项 K_xy ≈ 0（相对主项 < 1%） | ☐ | 查网格是否非对称、边界是否写错 |
| 3.5 | **倒易性** | 线性 Stokes + 相容边界下的倒易性是 **K_xy = K_yx**（Onsager）；"反向驱动下同一方向 K 不变"是线性奇对称，是**另一个独立测试**；都不要求各向异性表面上 K_xx=K_yy | ☐ | 后处理口径不一致 |

## 5. L4 外部对齐：别人的模型，在他们的地盘上复现出来

**两阶段，顺序不能反：**

> **阶段一「对齐」**：主动把我们的工况**退化到文献模型的适用范围内**（无限周期、稳态、满填充 α=1、浅槽、低雷诺数），此时我们**必须**复现他们的公式。做不到 ⇒ 说明我们有问题，不是别人有问题。
> **阶段二「放松」**：一旦验证过了，再一步步把条件放松到真实压印条件（部分填充、有限 patch、槽更深、间隙更小），**这时候出现的偏差才是我们的新结果**，才值得写成"等效模型在这里失效"。

| # | 检查 | 判据 | ☐ |
|---|---|---|---|
| 4.1 | 文献来源可查 | 每个被引用的公式必须有 **作者+年份+DOI+公式编号/页码**，arXiv 预印本标注清楚 | ☐ |
| 4.2 | 阶段一对齐 | 在文献适用域内，相对偏差 < **该文献自己声明的精度**（文献没写 ⇒ 我们自行定 5%，并在论文里说明为什么定这个值） | ☐ |
| 4.3 | 单位已换算 | 冻结卡 §5 口径已执行（k = K/H_ref，H_ref = 125 nm）；无量纲比优先 | ☐ |
| 4.4 | 区分"原文值 / 自推值" | 表格里每个数标清楚是 (a) 原文抄的、(b) 我们按他的公式算的、(c) 我们自己推的 | ☐ |
| 4.5 | 阶段二偏差登记 | 放松每一步，记录偏差量级、方向（高估还是低估）、**失效边界写成一个具体数字**（例："α < 0.4 时误差超过 20%"） | ☐ |

### 关于"我担心的：引用别人、说别人不准，会不会被打回来"

处理方式（这三条照做，风险基本可控）：
1. **只评方法，不评人**。写法是"该类等效方法在 XX 条件下会 XX"，不是"某某作者算错了"。
2. **必须先对齐再批评**。阶段一证明我们能复现他们 ⇒ 我们不是不懂，是在他们的适用域外发现偏差。这是最有力的护身符。
3. **不许说"首次/没人做过"**。任何 AI 工具都不准替我们下这个判断；要下这个断语必须自己走一遍传统数据库检索并在论文里写出检索式。

## 8. 本清单自身的维护

- 阈值改动必须在注释里写明理由，**不许悄悄改阈值让数据"通过"**——这是最容易变成学术不端的一步。
- 每次因为修 bug 而重算，原档保留，新档末尾加 `-r2`，并在 `遗留问题` 里写清改了什么。
