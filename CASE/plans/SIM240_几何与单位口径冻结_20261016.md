## 1. 为什么必须先冻这一页（一句话）

我们要做"真实 K（OpenLB 显式算） vs 假设 K（文献常见等效做法）"的对比。**对比的前提是两边的几何、单位、归一化方式完全一致**，否则比出来的差是"单位差"，不是"物理差"——这是最容易被审稿人一枪打死的地方。

## 2. 几何冻结（装置侧）

### 2.1 装置拓扑（已经你确认，不再变）

```
            ↓ 模具下压方向（-Z）
  ┌──────────────────────────────┐
  │  模具（上）：周期直沟槽       │   ← 图案在模具上
  │  ▄▄▄▄      ▄▄▄▄      ▄▄▄▄    │
  │      ▀▀▀▀▀▀      ▀▀▀▀▀▀      │
  ├──────────────────────────────┤
  │  液体（充满沟槽 + 残余间隙）  │
  ├──────────────────────────────┤
  │  基板（下）：平板             │   ← 基板是平的
  └──────────────────────────────┘
```

- 上模 = 开槽（基准 relieve 结构），下基板 = 平板。
- 下压时**模具向下移动**，间隙从大变小。本篇（单相）不模拟下压过程本身，而是**对若干固定间隙 h 分别算稳态 K**。

### 2.2 尺寸（唯一口径）

| 量 | 符号 | 数值 | 格数（dx=5 nm） | 说明 |
|---|---|---:|---:|---|
| 周期（一个沟槽 + 一个凸台） | P | **240 nm** | 48 | 一个周期 = 一个直沟槽 |
| 槽宽 | w | **120 nm** | 24 | 占空比 w/P = 0.5 |
| 凸台宽（land） | P−w | 120 nm | 24 | |
| 槽深 | d | **100 nm** | 20 | 2026-10-16 你确认 |
| 残余间隙（凸台下方） | h | **75 nm**（基准档） | 15 | 另有 50 / 125 nm 两档（见 §3） |
| 槽内总净空 | h+d | **175 nm** | 35 | 仅几何描述；**数据库归一化用 H_ref=125 nm（等体积高度，见 §5.2），两者勿混** |
| 宽深比 | w/d | **1.2**（深宽比 d/w≈0.83） | 槽宽大于槽深 20% |
| 周期数 | N | **单胞即可**（研究对象=理想周期介质的输运系数）；重复 N 周期为实现一致性检查，不证明真实非周期版图的代表性 | | |

**边界方向约定（必须每次写明，与 G2 既有数据保持一致）**：沟槽**沿 Y 延伸**（几何只随 x 变化：槽在 x∈[60,180] nm）；沿槽方向 = **Y**（周期边界）；跨槽方向 = **X**（周期边界，有限 patch 时取无滑移壁）；膜厚方向 = Z（上下均为无滑移壁）。⇒ **K∥ = Kyy（沿槽），K⟂ = Kxx（跨槽）**。

> ⚠ 历史教训：v1.0 曾误写为"沿槽=X"，2026-10-16 晚更正——G2/G3 数据库中 K_parallel 对应 y 方向驱动（源码 `p.drive=1`=y 为平行档）。新 D 系列必须与旧库同口径，否则与旧数据、与老师旧 OpenFOAM 的 KXX/KYY 对表时会错位。**"∥/⟂"容易和"⊥ 于壁面"混淆，每次出图必须在图注里写死"∥=Kyy 沿槽 / ⟂=Kxx 跨槽"。**

## 3. 工况网格（要算哪些点）

### 3.1 h 扫描（已有）

来源：`transport_database/G3_height_resistance.csv`（dx = 2.5 nm）

| h (nm) | K∥ (库单位 m³) | K⟂ (库单位 m³) | 各向异性比 A = K∥/K⟂ |
|---:|---:|---:|---:|
| 50  | 5.706271666888214e-23 | 1.433909095144954e-23 | **3.979521** |
| 75  | 9.782423697043172e-23 | 4.3852935121144107e-23 | **2.230734** |
| 125 | 2.6572537243855455e-22 | 1.8481391634985746e-22 | **1.437800** |

物理读法：间隙越小，沿槽越占便宜（A 越大）；间隙一大，沟槽的相对贡献被稀释（A → 1）。**这条趋势本身就是论文的一张主图。**

### 3.2 填充率 α（单相必须人为给定）

单相没有自由液面 ⇒ **"槽填了多少"不是算出来的，是我们设出来的**。定义：

> α = 液体占据的槽内体积 / 槽的总体积，α ∈ [0, 1]
> - α = 1：满槽（对应 §3.1 现有数据）
> - α = 0：完全没进槽 ⇒ 液体只剩凸台下间隙 ⇒ **等价于 h 的纯平板（= K_smooth，即第 0 级）**
> - 0 < α < 1：部分填充。必须同时说明**液体趴在哪一侧**（贴底 / 贴顶 / 居中贴壁），因为位置影响流阻。

计划取值：α ∈ {0, 0.25, 0.5, 0.75, 1.0}，每个 α × 每个 h 至少一个算例。**α 的物理来源在下压过程中由上一时刻的填充历史决定，本篇先当作给定参数，明确声明这是单相模型的假设。**

> ⚠ **文献复审补充（2026-10-16，报告 D0 节）**：α 单独不足以确定液区——相同 α 可对应不同液区形状与连通方式（连续底膜 / 沿槽液柱 / 断开液区），阻力一般不同；未填区域是什么（固体/气体）及**液体边缘的边界条件**（固壁 / 自由面 / 人工截断）必须先冻结。**把 d 换成 αd 只是改流道，不自动代表部分充液。**
> **裁决**：首篇先以 **α=1 全充液的 K(h) 基准**为主（已有 h=50/75/125 三档）；α<1 工况须待「液区形状 + 边界族」冻结后再排表。⇒ D3 扫描层暂时只包含 α=1 行，其余行挂起。

## 5. 单位口径（最大的坑）

### 5.1 三种口径必须区分

| 口径 | 俗名 | 单位 | 谁在用 |
|---|---|---|---|
| A | 我们库里的 K | **m³**（已确认 = μ·J/G，见 §5.2） | 本项目历史数据库 |
| B | 常规渗透率 k | **m²** | 多孔介质、大部分压印填充论文 |
| C | 无量纲比 A = K∥/K⟂、增益 Γ = K∥/K_smooth（符号用 Γ，避免与压力梯度 G 重名） | **无单位** | 谁都能用 |

**建议（重要）**：论文**主表优先报口径 C（无量纲比）**，因为
- 它不依赖任何单位换算 ⇒ 不可能因为单位搞错被打回；
- 它正是"各向异性"这个科学问题的核心量；
- 文献里的等效模型哪怕单位不同，几乎都能换算成比值来比。

绝对量（口径 A/B）放在附录；第 0 级校核已由 Smooth75 完成（见 §5.4），换算公式 k = K/H_ref 已锁定（见 §5.2）。**换 τ、换边界格式、换 case 代码后，须按 §6 重跑第 0 级。**

### 5.2 已查实的两个硬事实

**事实 1：同一个 h=75 nm 档，两个文件的阻力 R 精确相差 1000 倍。**

| 文件 | R∥ 数值 | K∥ × R∥ |
|---|---:|---:|
| `analysis/transport_parameter_extraction/transport_database/transport_database.csv` | 1.02224155e+22 | = 1.0 |
| `transport_database/G3_height_resistance.csv` | 1.02224155e+19 | = 1.0e-3 |

⇒ **两个 R 不是同一个东西。绝对不可以混在一张表里，引用时必须写清来源文件路径。**

**事实 2：库存 K 的量纲已查明（2026-10-16 晚核实）——它不是渗透率，是"每单位宽度通流率"。**
用数据库数字反推：K = μ·J/G（μ=1e-3 Pa·s，G=∇p=ρa=1e8 Pa/m，J=每单位宽度通量 m²/s）。验证：K∥(dx=2.5)=9.7824e-23 = 9.7824e-12 × 1e-3/1e8，精确成立。
⇒ **换算公式：常规渗透率 k = K / H_ref**，其中 **H_ref = V_f/A_plan = h + φ·d，φ=w/P=0.5**——逐几何计算，**125 nm 只对应基准点 (h=75,d=100)**；矩阵九档的 H_ref ∈ [62.5, 175] nm。
例（基准点）：k∥ = 9.7824e-23 / 125e-9 = **7.83e-16 m²**；k⟂ = 4.3853e-23/125e-9 = **3.51e-16 m²**；比值不变，A = 2.23。

### 5.3 原"未解决"问题已解决（2026-10-16 晚核实）

原疑点：`G3/transport_summary.md` 写"R=1/K，单位 Pa·s/m³"，与 K[m³] 不自洽。**现已查明，是两种不同定义并存，都对，但不能混：**

| 文件 | R 的实际定义 | 数值验证（h=75, dx=2.5, ∥） |
|---|---|---|
| `transport_database.csv` | R = 1/K（纯倒数，单位 m⁻³） | 1/9.7824e-23 = 1.0222e22 ✓ |
| `G3_height_resistance.csv` | R = ∇p/J（物理流阻/单位宽度，Pa·s/m³） | 1e8 / 9.7824e-12 = 1.0222e19 ✓ |

两者恰好相差 μ = 1e-3 Pa·s ⇒ "1000 倍之谜"破解。**规则不变：引用 R 必须写来源文件。**

单位换算链自此闭合：**K[m³] →（除以 H_ref = 125 nm）→ k[m²]**。方案甲/乙之争随之消解——保留建议不变：主表报无量纲比，附录报 k = K/H_ref。

## 6. 第 0 级：平行平板校核（把尺子对零）

> **状态：现有 G2 管线已由 Smooth75 通过本级**（§5.4，误差 ≤0.44%，二阶收敛）。本节保留为**「新配置必跑」规程**：换 τ、换边界格式、换 case 代码后必须重跑本级。

**做法**：把槽深 d 设成 0 ⇒ 几何退化为纯平行平板，间隙 = h。此时答案**不依赖任何文献**，教科书上就有：

> 单位宽度流量 Q = (h³ / 12μ) · (Δp / L)
> 等效渗透率 k = h² / 12

**这一档的意义**：它同时检验三件事——单位换算对不对、边界（无滑移/周期）设对了没、后处理提取 K 的流程有没有 bug。

**判据**：无论是 h=50 / 75 / 125 nm，d=0 算出来的 k 都必须落在解析值 h²/12 的 **±1%** 以内。做不到 ⇒ 不许往下算任何正常工况。

**附带产出**：换算系数 k = K/H_ref 已由本级实测锁定（§5.2）；换配置后需重新锁定，否则之后所有绝对值不许往外报。

## 附录 A：一维润滑近似的粗略预期（**自推未复核，仅用于建立量级，禁止引用进论文**）

> **v1.1 更正（2026-10-16 晚）**：v1.0 的"沿槽增益 2.94 vs DNS 2.78，差 5%"算错了——当时给两个 K 除了**不同的**参考高度，归一化不一致，结论作废。以下为更正版。统一口径：K 一律用与数据库相同的"每单位宽度通流率"（m³），不再除任何高度。

一维变厚度平板近似（占空比 0.5、h=75、d=100 nm，槽内总高 175 nm；**= Reynolds 条纹平均 / 局部立方律，2026-10-16 文献复审认定 Tavakol 2017 Proc R Soc A 为可核对出处，双路独立推导数值一致**）：

| 量 | 一维近似 | DNS（dx=2.5 nm） | 关系 |
|---|---:|---:|---|
| 无槽平板 K_smooth | h³/12 = 3.5156e-23 | 3.5195e-23 | 吻合，+0.11% ✓ |
| 沿槽 K∥ = ⟨h³⟩/12 | 2.40885e-22 | 9.782e-23 | 一维**高估 ~2.46 倍** |
| 跨槽 K⟂ = 1/⟨h⁻³⟩/12 | 6.51816e-23 | 4.385e-23 | 一维串联**高估 ~1.49 倍**（已核实非口径问题，见下） |
| 各向异性 A = K∥/K⟂ | 3.6956 | 2.23 | 一维高估 ~66% |

读法（v1.2，2026-10-16 晚口径核查完成后解冻）：

- **沿槽高估 2.5 倍，方向合理**：一维把槽当成"无限宽的平板条"，完全忽略槽的两侧壁。槽宽只有 120 nm、侧壁阻力极大，所以高估是应该的。
- **跨槽"低于串联下限"曾被我误判为可疑，现已查清不是口径 bug**：G2 源码里两个方向共用同一段统计代码、同一个归一化——`fluxJ = ∫u dV / A_plan`，A_plan = 240×240 nm² 固定，P/T 仅差驱动分量索引（`p.drive`=1 沿槽 / 0 跨槽），定义完全一致。
- **物理上反而讲得通，而且是更好的故事**：一维串联模型假设每条流带内是局部平行流，在 100 nm 的突变台阶处这个假设根本不成立（速度场在台阶处间断，不是容许流场，所以串联估计**不是**下界）。尖锐台阶的收缩/扩张产生附加耗散，把真实跨槽流量压到串联估计之下。
- **网格收敛趋势支持这是真值**：K⟂ 随加密单调下降（4.4490 → 4.3853 → 4.3586e-23），Richardson 外推 ≈ 4.35e-23——离串联估计 6.52e-23 越来越远，不是粗网格假象。
- **升级后的故事线（仍属自推，正式引用前需独立复核）**：一维变厚度平板等效在两个方向都高估通流——沿槽高估 ~2.46×（忽略槽侧壁）、跨槽高估 ~1.49×（忽略台阶突变耗散）⇒ 各向异性被高估 ~66%（3.6956 vs 2.23）。这就是"常见等效做法与实际不符"的定量证据雏形。
- **出处的独立印证（2026-10-16 晚）**：GPT-6 Astra 文献复审（`docs/reports/SIM240_LITERATURE_REVIEW_20261016.md` D1 节）独立推导出完全一致的数值（2.4088542e-22 / 6.5181588e-23 / 3.6956052），并给出可核对现代出处 Tavakol et al. 2017（Proc R Soc A 473, 20170234，式(8) 已目视核对）。⇒ 本附录从"单人自推"升为"双路独立推导 + 有出处"，**但仍是 Reynolds 近似基线，不是验证过的真实 K，论文里不得宣称已验证**。
- 遗留加固项（非阻塞）：做一个槽深减半（d=50 nm）的对照档——若台阶耗散解释正确，跨槽偏差应随 d 减小而单调缩小，d→0 时必须回到串联=并联=平滑值。
