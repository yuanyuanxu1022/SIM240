# 模具接触角未知时的判别方案（2026-10-16）

> 触发：用户明确"模具的接触角我们只是模拟，暂时不知道"（无法实测）。
> 性质：**方案文件**。不启动计算、不改冻结协议、不改写历史结论。

---

## 1 先点破一个循环依赖（否则会走错方向）

原计划的判别思路是"**跑一次 Δp=0，看 L∥/L⟂ 是 1.5 还是 1.0，就知道走哪条路**"。

**但这是循环的**：跑模拟必须**先给定 θ_m** 作为输入。不知道 θ_m ⇒ 无法构造那个判别算例。

```
要知道走哪条路 → 需要跑模拟 → 模拟要输入 θ_m → θ_m 正是我们不知道的  ⇒ 死循环
```

**⇒ 判别算例不能用来"替代实测"，它只能用来检验"给定 θ_m 下理论是否成立"。**

## 2 破局：把 θ_m 从「待定未知数」升级为「被研究的变量」

既然不知道真实值，**就把 θ_m 扫描本身变成研究内容**——不问"真实是多少度"，而问：

> **填充行为如何随模具润湿性变化？出现在理论预测的哪个位置转换？**

**这不仅不损失，反而更契合主线**：导师明确说过"**接触角对液体在沟槽里的铺展、影响和阻力是核心的**"。接触角本来就是首篇要回答的因素之一（对应 H2）。

## 3 ★ 意外收获：一次免费的「理论 vs DNS」验证

理论（毛细静力学）预测的**临界模具接触角 = 104.28°**（θ_s=15°、σ=30 mN/m、H=175 nm、W=120 nm）。

**若 DNS 独立自主地复现出这个转换点，就是一次漂亮的 Validation**——用一个数值实验去印证一个解析预测，且**不需要任何实测输入**。这是 Reddy/Schunk 2005 那条脉络的自然延伸，但落在 θ 维度上。

## 4 θ_m 扫描设计

Δp_cap（槽截面）= σ[(cosθ_m + cosθ_s)/H + 2cosθ_m/W]。θ_s=15°、σ=30 mN/m：

| θ_m | 槽截面 Δp | 机制 | Δp=0 时的预期现象 |
|---:|---:|:--|:--|
| 60° | +5.01 bar | 毛细强吸 | 快速入槽，L∥/L⟂ ≈ 1.5 |
| 80° | +2.82 bar | 毛细吸 | 入槽，≈1.5 |
| 90° | +1.66 bar | 毛细吸 | 入槽，≈1.5 |
| 100° | +0.49 bar | 毛细吸 | 入槽，≈1.5（**R1 已校准此角**） |
| **104°** | **+0.03** | **临界** | 分界 |
| 106° | −0.19 bar | 需 0.19 bar | 不进槽，≈1.0 |
| 110° | −0.64 bar | 需 0.64 bar | 不进槽，≈1.0 |
| 120° | −1.70 bar | 需 1.70 bar | 不进槽，≈1.0 |
| 126° | −2.29 bar | 需 2.29 bar | 不进槽，≈1.0 |

**最小判别集（先跑两档即可定趋势）**：

| 档 | θ_m | 侧 | 作用 |
|---|---|---|---|
| A | **80°** | 自吸侧 | 预期 L∥/L⟂ ≈ 1.5 |
| B | **120°** | 门槛侧 | 预期 L∥/L⟂ ≈ 1.0 |
| C（第二步） | **104°** | 临界 | 钉住转换点，与前两个做对照 |

**判据**：A 与 B 的入槽行为**显著不同** ⇒ DNS 复现了理论分界 ⇒ 补 C 定出 DNS 实测临界角（与 104.28° 对比）。

## 5 降本：判别不需要正式长算

**要判定的只是"液体进没进槽"**，不需要等到前沿比收敛。因此可用**降配配置**先做判别：

| 项 | 正式算例 | **判别用降配** |
|---|---|---|
| 域 | 8 周期 | **4–6 周期** |
| dx | 5 nm | **10 nm** |
| 步数 | ~6×10⁴ | **2×10³ – 5×10³** |
| 观测量 | L∥/L⟂ 收敛值、F_g(t) 全程 | **只需 F_g 是否 >0（槽内有无液体）** |

⇒ 判别成本可从"每档 ~5 h"降到**几十分钟量级**。确认机制后，再按正式配置精算选定的那条路。

## 6 前置：每个 θ_m 都要做润湿校准（不可跳过）

**这是 A2 缺口**：R1 只验证过 **θ=100° 平壁**。相场润湿边界在每个新接触角上**都没有校验过**，尤其：
- **小接触角（θ_s ≈ 15°）** 是全新数值区间，必补；
- 每一个 θ_m 档也需至少核对一次角度精度与稳定性。

**校准 run 是分钟级**（远低于正式算例），但**必须先于正式扫描完成**，否则 PASS 不能外推。

## 7 执行顺序

1. **润湿校准**（分钟级）：θ_s=15°（基板）+ θ_m = 80° / 104° / 120° 三个；确认角度精度 ≤5°、无寄生流、φ 有界；
2. **降配判别**（几十分钟/档）：Δp=0，跑 θ_m=80° 与 120°，看槽内是否进液；
3. 若两侧行为分离 ⇒ 补 104°（及可选的 106/110°）钉住 **DNS 实测临界角**；
4. 与理论值 **104.28°** 对照 → 一次独立的 Validation；
5. 之后按选定路径（自吸或门槛）进入正式 R2-XY / R2-Z。

## 8 论文写法（不必知道真实值也能成立）

> 由于实际模具表面处理条件未在本文实测，我们将模具接触角作为**控制变量**处理：通过 θ_m ∈ [80°, 120°] 的扫描，给出填充机制的转换边界并与毛细静力学解析预测（θ_c = 104.3°）对照。实际工艺的 θ_m 一旦测得，可直接在本图谱上定位其所属机制。

**⇒ 真实值缺失不再是阻塞项**，而是转化为"参数化图谱 + 解析对照"的双重结果。

## 9 边界

- 本文件不构成"用模拟代替实测"的主张：**θ_m 的真实值仍属待测输入**，扫描只提供机制与转换边界；
- 每个 θ_m 档的数值校准不可省略，否则 DNS 结果与几何/润湿设置无法对应；
- 历史 FAIL 与已放行 K 数据库原样保留。
