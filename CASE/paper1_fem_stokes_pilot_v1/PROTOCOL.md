# 二维 FEM 定点试点协议 v1

日期：2026-11-13。状态：最小试点，自动扩点禁止。本文档不修改既有FVM协议，不授予论文参考资格。

## 1. 目的与顺序

目的：在现冻结FVM无法新增合规横槽运行的情况下，用独立有限元离散检查同一连续Stokes边值问题，并尝试补齐h50/d120 T候选参考。

固定顺序：

1. `flat_h75_P`、`flat_h75_T`：解析Poiseuille基准；
2. `h75_d100_P`、`h75_d100_T`：与既有合格FVM对照；
3. 前两级全部通过后，才运行 `h50_d120_T`。

不自动运行h125、h25、h100或19P+4T，不重拟合V2，不改OpenLB/FVM历史结果。

## 2. 几何、驱动与归一化

单位长度取 `L0=1 nm`，单位深度 `Ly=1 nm`。周期 `P=240 nm`、槽宽 `w=120 nm`、槽深 `d`、凸台上方间隙 `h`；总高度 `H=h+d`。坐标 `0<x<P, 0<z<H`，去掉 `w<x<P, 0<z<d` 的固体凸台。左右仅 `d<z<H` 部分为周期边界；其余外边界均为无滑移壁面，包括槽底、槽侧壁、台阶、凸台顶面及上平板。

物理参数沿用FVM：`nu=1e-6 m²/s`、`rho=1000 kg/m³`、加速度 `a=1e5 m/s²`。速度尺度 `U0=a L0²/nu=1e-7 m/s`，无量纲速度 `U=u/U0`。

沿槽P：在二维截面上求 `-ΔU=1`，壁面 `U=0`，左右上部周期。

横槽T：求 `-ΔU+∇π=e_x`、`div U=0`，速度和扰动压力在左右上部周期，壁面 `U=0`，以额外约束 `∫π dA=0` 去除压力零空间。采用P2速度/P1压力Taylor–Hood元及稀疏直接求解，不使用SIMPLE外迭代。

两方向均由 `K=(1e-27/P_nm)*∫Ω U_main dA` 恢复物理深度积分导度，单位m³。该式与FVM的 `K=nu/a*(∫u dV)/Aplan` 在上述尺度选择下等价。平板解析值为 `K=(h*1e-9)^3/12`。

## 3. 网格与代数检查

每例最多三档均匀贴体三角网格：5、2.5、1.25 nm；P2/P1离散。网格节点对齐 `x=0,w,P` 与 `z=0,d,H`，不把固体凸台纳入流体单元。细网格不能运行或矩阵非有限时记失败，不自动降低科学门槛或增加网格档。

记录每档单元/节点/自由度数、矩阵尺寸、直接求解相对残差、K、驱动—黏性功率差、横槽截面通量极差及截面/体积分通量差。压力均值约束、周期配对和壁面自由度数量写入结果。

## 4. 试点内部门槛（不是既有FVM资格继承）

- 所有输出有限，流体面积与解析面积相对差 `<1e-10`；周期配对完整，无遗漏或错误配对。
- 直接解相对残差 `||b-Ax||/(||b||+eps) ≤1e-10`；独立复核器从保存场、相同积分阶次重新装配方程并计算该残差，不采用求解器JSON自报值。
- 横槽额外检查：速度及压力周期差归一化最大值≤1e-10；压力均值归一化值≤1e-10；壁面无滑移归一化最大值≤1e-10。逐单元散度加权L2量保留为诊断值；P2/P1只保证弱形式不可压缩，不将逐点散度设为一票否决门槛，弱连续性由重组离散方程残差检查。
- 横槽截面通量由独立复核器在三角形内重建垂直截线、计算交点并以P2基函数积分，不调用求解器插值函数。
- 平板：K相对解析误差≤0.1%，剖面加权L2误差≤0.1%，功率差≤0.1%。
- 沟槽：coarse→mid的K变化≤1%，mid→fine≤0.5%；fine功率差≤0.1%。
- 横槽fine：至少9个非壁面截面的通量极差≤0.01%，截面平均通量与体积分通量差≤0.01%。
- h75基准：fine K与现有合格FVM值差异≤0.5%才进入h50T；超过则停止并审查，不选择较接近OpenLB的解释。
- h50T：满足上述自身检查后仅记 `PILOT_NUMERICAL_CHECKS_PASS`，与OpenLB的2%一致性另判PASS/FAIL。成为论文正式参考仍需独立科学审查，不能由本脚本自动授格。
