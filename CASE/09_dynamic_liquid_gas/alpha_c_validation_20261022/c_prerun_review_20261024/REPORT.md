## 2. 独立复算：预测为什么成立

冻结程序为四组 64³、64 步、全周期、单 MPI rank 的 NS/CH 诊断。dx=2.5 nm，物理盒 160 nm；dt=1.0416666667e-13 s，64 步仅 6.6666666667 ps。CH alpha=1、tau=1，beta=6.25e-5、kappa=1.25e-4。NS tau 端点 [1,1.25]；密度端点 equal=[1,1]、target=[1,.0012]。

### 2.1 从源码零阶矩到全局预测

定义 `Q=sum(phi)`，此处 phi=1 对应气相端。D3Q19 源项系数

\[
b_i=w_i[-5/2+3|c_i|^2/2],\qquad \sum_i b_i=-1.
\]

tau_CH=1 的局部更新是

\[
\Delta\phi(x)=\frac16 L_h\mu(x)+\sum_i b_i B(x-c_i).
\]

这里 B 是碰撞实际读取的 `SOURCE`，不总等于当前物理 S。由于周期链接拉普拉斯全域和为零、周期迁移是节点置换，

\[
\Delta Q=-\sum_x B(x).
\]

初始化明确执行一次耦合，再令 `SOURCE=SOURCE_OLD=S0`，故首步 **B0=S0=u0·G_h phi0**，不是 1.5S0。后续才使用 `B_n=1.5S_n−.5S_(n−1)`。相关原源码：`../src/dimension_corrected_ch.h:20–30`、`../src/coupled_check.cpp:96–102,168,181–192,202`；耦合端 `OpenLB/src/dynamics/phaseFieldCoupling.h:692–732`。

独立脚本 `recompute_initial_budget.py` 没有导入旧分析助手，直接读取四组 gzip 原始字段：**4×262144=1,048,576 行、16 字段**，逐项核对配置、schema、解压字节长度、有限值、初场形状、rho/tau/mu/F/S、半步力速度、SOURCE 启动规则和历史第0行。最大初场核对误差 **1.2768e-15**，小于冻结局部限 1e-12。预测与旧 `../evidence/c_initial_budget_forecast.json` 数值一致。原始输入读取哈希在 `inputs_sha256.json`。

### 2.2 相量与插值质量的对应

\[
M=\sum\rho=N^3\rho_0+(\rho_1-\rho_0)Q,
\quad\Delta M=(\rho_1-\rho_0)\Delta Q.
\]

target 中 rho1−rho0=−.9988，Q0≈131072，M0≈131229.2864。因此 Q 相对增加时，插值质量相对减少。equal 中 rho1−rho0=0，M 按构造恒定，**不能以此证明相量或两相体积守恒**。液体量 `sum(1−phi)` 的变化为 −DeltaQ，三者并非三份独立证据。

| 冻结算例 | sum(S0) | 预测首步 DeltaQ/Q0 | 预测首步 DeltaM/M0 | 相量预算倍数 | 质量预算倍数 |
|---|---:|---:|---:|---:|---:|
| C_equal_mu0 | 0 | 0 | 0 | 0 | 0 |
| C_equal_constitutive | +3.1055600020e-4 | −2.3693542495e-9 | 0（密度相等） | 2.369 | 0 |
| C_target_mu0 | 0 | 0 | 0 | 0 | 0 |
| C_target_constitutive | −1.0868922900e-3 | +8.2923300933e-9 | −8.2724523544e-9 | 8.292 | 8.272 |

倍数分母均为运行前冻结的 **1e-9**。上述值是精确离散总账约束下的**标量预测**，不是求解器实际首步或完整64步的结果；没有构造 phi1 或 rho1。若实际推进正确复现既有离散式，这两组本构初场已预示物理预算不满足。届时仍须用保存结果正式验收，不提前记录 C 实测 FAIL，也不能因余额闭合就豁免预算。

### 2.3 小 Mach 为什么不能保证相量守恒

初始化 NS raw j=0，但构成化学势不均匀，`F=−phi G_h mu` 不为零。源码恢复速度含半步力，故

\[
u_0=F_0/(2\rho_0)\ne0.
\]

不是“已经流动了一步”才出现 S0。独立实核初场：

| 真实本构组 | max Mach | max abs(div_h u0)，格子单位 | max abs(p_h0)，格子单位 |
|---|---:|---:|---:|
| equal | 5.4762788e-7 | 3.0314866e-7 | 2.4991358e-14 |
| target | 7.9873766e-6 | 2.9904020e-6 | 7.1401759e-8 |

周期中心梯度有离散积分分部：`sum(u·G_h phi)=−sum(phi div_h u)`，原场复算亦符合。Mach 小只约束速度与声速之比，不强制离散散度严格为零。原始文献将保守对流换成 u·grad(phi) 所用的无散条件，不能由本项目的低 Mach 自动继承。[Ju 等，Eqs.6–8、17–18、26–27](https://arxiv.org/html/2311.10827v1)。本轮没有证明完整 NS/CH 的渐近等效性，也不把这些初态速度称为“已达到平衡后的伪流”。

两组 mu0 控制是人为关闭化学势与毛细力，不是原自由能的物理平衡态。equal 对照保留 NS 运动黏度端点，并未保留动力黏度；不能把两组差异解释成只有密度改变的物理实验。

## 3. 实现收支审查：哪些可以精确核，哪些只能诊断

### 3.1 相量总账

C 第 n 次碰撞读取的是保存 frame_n 的 SOURCE=B_n；刷新后的 `SOURCE_OLD=S_(n+1)`、`SOURCE=B_(n+1)` 属于下一时间层。总账必须用旧帧 B_n，而非新帧的 S 或 B。冻结 C++ `step` 与 `analyze_c.py:110–120` 的用法一致。观察/保存不额外调用会改 S_old 的耦合。

### 3.2 raw 动量与带半步力动量

令 `cut=rho[snapped(j/rho)−j/rho]`，snap 是既有小于1e-15的置零；J=sum(j)，C=sum(cut)，Fsum=sum(F)。所读 NS 平衡一阶矩及 Liang 力项给出

\[
\Delta J=Fsum_n+\sum(\omega_n cut_n),\qquad P=\sum\rho u=J+C+Fsum/2.
\]

因此

\[
\Delta P=\tfrac12(Fsum_n+Fsum_{n+1})+
\sum(\omega_n cut_n)+C_{n+1}-C_n.
\]

这两项余额的扣项、符号及时间层与冻结实现/后处理一致，见 `../src/coupled_check.cpp:159–200`、`../analyze_c.py:54–70,115–120`；NS 实际路径见本机 `OpenLB/src/dynamics/dynamics.h:331–336`、`forcing.h:228–260`、`momenta/elements.h:525–544`。这是源码矩审查，新的完整空间数据尚不存在。周期毛细净力不先验设零，P 增量也不应与单一旧力 Fsum_n 直接比较。

### 3.3 能量

冻结 Fh 使用与链接 Lh 相容的离散自由能；D=−<mu,Lh mu>/6，Wsrc 使用迁移后的源项邻点组合，Rtime=DeltaF−<mu,Delta phi>。检查 `DeltaF+D−Wsrc−Rtime` 能发现离散更新/输出的不一致；它与 CH 更新式密切相关，**不是独立的完整 NS/CH 热力学证明**。

动力学剩余、梯度黏性耗散、条件性扩散质量动能项均应按原协议描述性报告，不能强设为零或要求总能量逐步单调。本机 NS 路径没有显式读 CH 迁移率/化学势梯度作为扩散动量通量；这项源码观察不能代替完整渐近推导，也不足以断言模型所有结果错误。新结果只能先给该项的量级及误差边界。

### 3.4 未来数据覆盖

四组每步0..64保存16字段，足够重建全程宏观相量/质量、raw及半步力动量、局部CH更新和能量账本。第1步另存全部38个NS/CH分布的碰撞前三阶段，允许离线逐分布核对；其余步只保存运行时最大分布残差，不能称全程离线分布验证。64步不能证明平衡、Laplace、壁面润湿或测得K；全周期无壁面也不给 geometry_PASS。

审查未发现需要在本轮更改冻结收支公式的依据。运行后的实现合同、物理预算、安全性必须继续三栏报告，按原阈值验收。
