## 收支的物理意义

CH源项为非守恒形式，故DeltaQ=−sum(SOURCE)可能非零。检查残差闭合与检查物理Q漂移是两件事，C输出/后处理分列；插值rho的质量由phi变化，不把NS分布零阶和当真实总质量。

独立零步全场已有确定性首步预测：真实本构equal/target组DeltaQ/Q分别约−2.36935425e-9 / +8.29233009e-9，超出保留的1e-9预算；mu0组为0。这是总账代数预测，不是实际推进，不能写已测到首步FAIL。C继续作为源项/散度/力反馈诊断；不调阈值或改初值消去这项预警。完整动态结果及未来更接近平衡的初始化效果仍待分别验证。

NS raw J与报告P=sum(rho u)相差半步力和既有的微raw速度置零项。新程序记录每个分量，后处理按两套公式分别核对。周期域内力不因周期性自动相消，不把净毛细力置零或从结果中扣除。

能量用实际链接拉普拉斯对应自由能，分列真实Delta phi的化学功、链接扩散耗散、AB与源项迁移贡献、有限步余项。动能差额、梯度黏性耗散及条件性质量扩散项只作诊断；不把CH+此NS路径称为已证明热力学一致。
