## 4. 压力：未收敛，不能用于 Laplace 验收

### 4.1 读数

| step | t (s) | Δp = p_h(液内) − p_h(气) | Mach |
|---|---|---|---|
| 0 | 0 | −1.13e+02 Pa | 9.8e−06 |
| 10 | 8.68e−13 | +6.68e+05 Pa | 1.7e−05 |
| 20 | 1.74e−12 | +3.36e+06 Pa | 1.6e−05 |
| 40 | 3.47e−12 | −2.45e+05 Pa | 6.7e−06 |
| 100 | 8.68e−12 | +1.23e+06 Pa | 3.9e−06 |
| 200 | 1.74e−11 | +2.68e+06 Pa | 1.8e−06 |

### 4.2 这是振荡，不是漂移

| 判据 | 实测 | 含义 |
|---|---|---|
| 逐级上升比例 | **0.510**（102/200） | 接近 0.5 = 振荡；接近 1 才是单调漂移 |
| 最后 50 步峰峰值 | 3.24e+04 … 2.88e+06 Pa | 相对幅度 **106%** |
| 40 步窗口相对峰峰 | 214% → 244% → 242% → 237% → 220% | 缓慢衰减，远未消失 |

窗口均值：1.64 → 1.51 → 1.36 → 1.25 → 1.25（×10⁶ Pa），峰峰值同步缓慢下降
（3.50 → 3.68 → 3.29 → 2.97 → 2.74 ×10⁶ Pa）。

### 4.3 与理论值的对比

按 (1−φ) 体积积分得等效半径 R = 16.203 格 = 40.51 nm：

```
理论 2σ/R = 2 × 1.44676e−05 / 16.203 = 1.786e−06 （格子）
          = 1.481e+06 Pa
```

| 量 | 值 | 与理论之比 |
|---|---|---|
| 末步瞬时 Δp | 2.68e+06 Pa | **1.81 ×** |
| 最后窗口均值 | 1.25e+06 Pa | **0.84 ×** |

两者都不是收敛值：瞬时值在振荡的上摆，窗口均值仍随窗口下降。

### 4.4 机制：声波启动瞬态（推测，有量级支持）

初始条件是 tanh 球 + 均匀密度 + 零速度，热力学压力不平衡，会激发声波。

- 格声速 c_s = 0.5774；64 格域声波穿越 ≈ **111 步**；200 步 = **1.8 个穿越**。
- 黏性阻尼率 νk²（ν = 1/6，最低模 k = 2π/64）→ 时间常数 ≈ **622 步**；
  实测峰峰衰减时间常数 ≈ **408 步**。同量级，指向同一机制（黏性阻尼声模）。

### 4.5 可直接检验的预测

若上述机制成立，衰减到 2000 步（自 step 200 再 3 个时间常数量级）时：

- 峰峰应降到 ~0.1 MPa 量级（初始 3.5 MPa 的 ~4%）；
- 窗口均值应稳定在某个平台值，可与 1.481 MPa 比较。

**若均值平台停在 0.84× 理论值附近而不上升**，则说明存在系统性偏差（候选解释：扩散界面对
等效曲率半径的修正、CH 模型压力口径与 Korteweg 应力），需要单独排查，**不能**当作"已通过"。

### 4.6 信噪比警告（本轮新发现，需保留）

在 2.5 nm 网格下，目标信号本身很小：

| 量 | 格子单位 |
|---|---|
| 目标 Δp = 2σ/R | **1.79e−06** |
| 观测到的声学振荡幅度 | **3.20e−06** |
| 信噪比 | **≈ 0.56** |

原因：`pressureScale = ρ_ref·c² ≈ 8.29e11 Pa`，格内 1e−06 的压力扰动就对应 ~0.8 MPa。
即 **目标 Laplace 压差与格内压力噪声同量级**，单点单时刻采样不可用；必须靠长时间平均
（噪声按 1/√N 下降）或改变验证路线。这与第一篇"h=25 在 dx=5 nm 只有 5 格"的教训同类：
**分辨率不足时，信号会淹没在数值底噪里。**

### 4.7 两个压力口径的当前差异

`p_h` 与体相机械压力候选在 step 200 相差 **125 Pa**（相对 4.7e−05）。
两者在本阶段数值上一致，但这只说明两个公式在"远未平衡"的状态下给出相近数，
**不能**据此认定任一口径就是正确的 Laplace 压力。
