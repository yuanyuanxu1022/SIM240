## 第二篇的问题与结果

建议问题：液气分布和界面演化怎样改变跨槽、沿槽的有效输运能力？第一篇的全充液各向异性在部分充液/动态条件下是否仍适用？这是研究设计问题，不是已有结论。

主结果候选：Kxx、Kyy随选定动态状态的变化，A=Kyy/Kxx，以及相对同几何全充液基准的方向性响应比。接近零或液体未连通时须报告检测/数值分辨率，不能盲算发散比值。界面、气体连通性、液量和润湿用于解释K变化。

先明确使用液相通量还是两相总通量；建议液相作为主对象，但尚未冻结。两相中的系数是状态/协议相关的有效或表观响应，不能直接当作仅由几何决定的单相常数。详见 `RESISTANCE_COMPARISON.md`。

## 最小实施路线（建议，尚未冻结）

1. 核对物性、单位、液相通量定义和界面基准。既有等密度R1不覆盖真实空气密度比或压缩。
2. 在明确间隙的最小沟槽液气算例中建立成对x/y驱动测试；统一几何、初始液气状态、液量、润湿、驱动强度与边界。核对零外驱动时的毛细流动，并测试驱动线性及网格/时间步/界面厚度敏感性。
3. 研究界面演化时的方向性响应。相同时间不保证相同液气状态，须分别报告按时间和按状态比较的含义；若不存在流动响应快于界面变化的时间窗口，则报告瞬态响应，不能强行命名唯一瞬时K。
