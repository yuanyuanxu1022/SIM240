## 完全沿用的输入与定义

|项目|C04及共同设置|
|---|---|
|区域Lx、Ly|24μm、48μm|
|平均厚度及计算层厚度|均125nm，H=V_fluid/A_plan|
|物性|μ=0.001Pa·s，ρ=1000kg/m³；ρ不进入物理压力方程|
|网格|16×32×1，512单元，面内间距1.5μm，z仅一层empty|
|x压力边界|xLow为24Pa，xHigh为0Pa；物理过压Pa|
|y边界|零法向通量；对角张量用zeroGradient|
|z边界|empty，不是实际无滑移上下壁|
|驱动|G=10⁶Pa/m，沿+x；不改成y驱动或48Pa压差|
|平均与通量|U为液体体积平均速度，J=HU，phi=U·Sf|
|求解控制|二维CG/Jacobi、OF压力PCG/DIC；初始p=0，归一化残差≤1e-12，relTol=0，最多2000次|
|资源边界|每端串行1进程、300秒/2GiB预算；失败/超时即停|

二维端读取K，解div J=0、J=−(K/μ)∇p；OF端读取D，面内2×2求逆M=(μD)⁻¹，解div U=0、U=−M∇p，再输出J=HU。K单位m³，D=H K⁻¹单位m⁻²，U单位m/s，J单位m²/s，Q单位m³/s。

这里H恒定，才能把div J=0与div U=0对应。125nm平均层不是175nm包络层，不改平均分母、不额外乘孔隙率。总阻力包含原微观壁面作用，不叠加厚度剪切、Brinkman、Forchheimer或porosityForce。无体力、重力、运动边界、两相；V=0，挤压阻力F/V不适用。
