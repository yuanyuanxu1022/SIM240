## 导度—阻力接口

二维端：J=−(K/μ)∇p，div J=0。OpenFOAM端：D=H K⁻¹，M=(μD)⁻¹，U=−M∇p，div U=0，J=HU。K单位m³，D单位m⁻²，U单位m/s，J单位m²/s，phi/Q单位m³/s；逆矩阵只取面内2×2部分。

H=V_fluid/A_plan；真实沟槽的液体体积平均速度经此定义映射到125nm平均层。不改成175nm包络平均，也不另乘槽占比或孔隙率。网格没有实际沟槽或厚度速度剖面；均匀平均U不能解读为真实流体处处均匀。

K/D包含总壁面阻力，平均模型不再解上下壁剪切，不启用porosityForce、第二份Darcy源、Forchheimer或Brinkman项。无重力、体力、运动边界及两相；压头速度V=0，挤压阻力F/V不适用。当前应用是消元压力形式，不构成OpenFOAM内置DarcyForchheimer源项的验证。
