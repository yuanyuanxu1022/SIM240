# EX240 h=50/125 nm 端点网格与驱动力线性补证协议 v1（冻结）

冻结日期：2026-10-14。状态：**设计与判据冻结，尚未实施或放行任何新增计算**。本文件只覆盖固定几何、单相、全充液 EX240 的面内主方向 P（沿槽，+y）与 T（横槽，+x）。它独立于原 [`HEIGHT_SWEEP_PROTOCOL.md`](HEIGHT_SWEEP_PROTOCOL.md)：原文件中的“框架/待启动”及过时上游状态不改写。本协议也不授权自动编译、预检或启动长计算；每阶段须另行准备、审查，并由用户确认是否启动。

## 1. 科学问题、已有证据与边界

问题是：在 h=50 和 125 nm，现有 dx=2.5 nm 的 `K_P(h)`、`K_T(h)` 与各向异性变化是否大于网格不确定度，且在指定体力范围内是否保持线性？这是把三高度固定网格候选结果提升为可定量讨论的**必要补证**，不是证明真实挤压过程排液更容易。

- h75 的九点网格链已按独立[放行记录](../../reports/fine_T_C_release_20261014_v1/RELEASE.md)通过；其旧细 T `PASS=false / exit=3` 与旧 Step 3 `FAIL / INCONCLUSIVE` 不改写。
- 现有 G3-h h50/h125 × P/T 四个 dx=2.5 nm、a=1e5 m/s² 基准点经[只读审查](../../reports/transport_evidence_audit_20261012/height_audit.md)通过固定网格数值与几何门槛，**只能有条件复用**。复用须在本协议实施前逐点锁定源/程序/运行哈希、物性、几何、定义、全程诊断、场、独立 exit 与 OpenLB 版本；缺项不可事后伪造，不能仅凭数据库 CSV 复用。四点为：

## 2. 冻结的物理量与数值族

- 单胞 `Lx=Ly=P=240 nm`，mesa/groove/mesa=`60/120/60 nm`，沟槽深度 `D=100 nm`；只变 mesa 到基底间隙 `h=50/125 nm`。平面 x/y 双周期，z 向固壁为精确几何零速度 Bouzidi，解析半链接 `q=0.5`。
- `rho=1000 kg/m³`、`nu=1e-6 m²/s`、`mu=1e-3 Pa·s`、D3Q19 `<FORCE>`、ForcedBGK、`tau=1`、double、单 MPI rank、单 cuboid。每网格使用扩散标度 `dt=(tau-0.5)dx²/(3nu)`，格子体力 `a_lattice=a_phys dt²/dx`，不得保持 `a_lattice` 不变或改变流体物性以追求收敛。
- `J_i=(1/A_plan)∫_fluid u_i dV`，`A_plan=P²`；主迁移率 `K_i=mu J_i/(rho a_i)`，单位 m³，`R_J=rho a_i/J_i=mu/K_i`。周期单胞压力扰动 `p_max-p_min` 不是宏观压降。`H_ref=h+50 nm` 仅是名义体积高度；若用解析平板归一化，分母为同一 mesa 间隙的 `K0(h)=h³/12`，不能用 `H_ref³/12`。
- 单次 steady 上限 **60000 步**，1000 样本主 J 窗口。记录两面内通量、两个内部截面、K、R、质量/密度/Mach、局部场与完整日志；不得看见结果后改上限或判据。

## 3. A 阶段：端点三网格补证

每个端点和方向组成 `dx=5, 2.5, 1.25 nm` 三点，基准体力 `a=1e5 m/s²`。dx=2.5 nm 的上述四点通过独立复用审查后引用；只新增 `2 高度 × 2 方向 × 2 网格 = 8` 个 steady。若某旧基准不可复用，须创建新 run_id 补做该点，最少 8 次将相应增加，旧结果仍保留。所有新工况先各自零步预检，再由用户分批独立启动；不得从 A 自动进入 B。

每点必须同时满足以下独立门禁（旧基准按其原冻结统计与同一物理阈值审查）：

1. `geometry_PASS=true`、`q_audit_PASS=true`；实际 fluid 节点等于表中解析整数、名义体积相对差 `<=1e-10`，candidate=valid=installed，安装 `q=0.5±1e-10`，fallback/unresolved=0，材料不变。
2. 程序 `PASS=true`、收敛、所有原始诊断有限、独立 shell exit=0；全程物理流体质量相对初态最大漂移 **严格 `<1e-10`**。新补偿账本还须与独立 Σ(ρ−1) 账本全程最大差 `<=1e-13`；旧账本超限单独报告，绝不覆写历史 FAIL。
3. 最大密度偏差 `<=1e-6`，最大 Mach `<0.05`，末态两截面相对差 `<=1e-5`，跨主方向通量绝对值 `<=1e-12 m²/s`；末 1000 样本 J 相对样本标准差 `<=1e-6`、相对 span `<=5e-6`，主 J 与 K 为正。
4. `NUMERICAL_GATE`、`RESULT_PASS`、`geometry_PASS`、`q_audit_PASS` 和独立退出码分别列出；一个失败即该点不可用于正式 GCI，不得只凭末态 K 或数值单调性放行。

每个方向在三点全部通过后，按冻结的 G2 Step 3 口径取 `r=2`、`Fs=1.25`，用粗/中/细 K 计算 `p=ln| (K5-K2.5)/(K2.5-K1.25) |/ln2`，`GCI_fine=100 Fs |(K1.25-K2.5)/K1.25|/(2^p-1)`，`GCI_medium=100 Fs |(K2.5-K5)/K2.5|/(2^p-1)`。仅当两差同号且非零、p 有限且正时报告 Richardson/GCI；渐近指标 `GCI_medium/(2^p GCI_fine)` 必须在 `[0.95,1.05]`，两方向 `GCI_fine<=2%`。同时**单独**报告 `GCI_medium`，不得拿细网格 GCI 充当 dx2.5 的误差。三网格不单调、非渐近或缺一门禁时，标记 `INCONCLUSIVE/FAIL` 并停止该高度的生产网格放行，不强拟合阶数；新增网格只能另行冻结。

本协议选择 dx=2.5 nm 用于随后 B 阶段的充分条件是：两个端点 P/T 均完成上述 GCI，四个 `GCI_medium<=2%`，且各端点 `K_P/K_T` 的 dx2.5 与 dx1.25 相对变化 `<=1%`。任一条件未满足时，dx2.5 不获跨高度生产网格放行；应先人工评审采用细网格或收缩结论，**不自动实施 B**。h50 的 dx5 仅有 10 层液膜，若它不在渐近区，应诚实报告，不能提高容差挽救三点拟合。

## 4. B 阶段：端点三驱动力线性补证

仅在 A 阶段独立审查支持 dx=2.5 nm 且四个旧基准获准复用后，于每个端点 P/T 的 dx=2.5 nm 上新增 `a=5e4` 与 `2e5 m/s²`，共 **8 个** steady；现有 `a=1e5` 四点作中间点。新点逐点沿用第 3 节全部门禁、零步预检和来源绑定。若旧中间点不可复用，补做并独立标记；若最终生产网格不是 dx2.5，本阶段在该网格上的数据不足以放行选定网格的力线性，须另立/修订协议，不自动移植结论。

对每个 `(h,方向)` 的三个独立 J–a 点，普通最小二乘拟合 `J=c a+b`，计算 `R²`、三个 `K=mu J/(rho a)`、`K_spread=(max K-min K)/mean K`。冻结门槛：`R²>=0.9999`，`K_spread<=1%`，并将 `|b|/max|J|<=1%` 作为本端点方案新增的零驱动力截距检查；三点各自全部运行门禁也必须通过。报告拟合斜率、截距、原始 J/K 和残差；近零跨向分量只用绝对通量门槛，不对零附近的分量套相对误差。

## 5. 放行层级、失败处理与交付

- **A 单点/端点数值放行**：前提是每个所用 run 都有独立退出、几何/q、质量、收敛和原始输出证据；一个目录存在或 `PASS=true` 不构成完整放行。
- **端点网格结论**：四条三网格链分别给出 K、p、GCI_fine、GCI_medium、渐近指标及其有效性；选择 dx2.5 的条件按第 3 节，不把 h75 的 GCI 外推到 h50/h125。
- **端点线性结论**：只对完成三驱动力且各点门禁通过的高度/方向作出；A 不通过时，B 即使形式拟合好也不能弥补网格缺口。
- **三高度趋势/论文表述**：h50/75/125 可报告离散采样值、`K_P/K_T` 及误差界；比较相邻高度时检查差值是否超出两端不确定度范围。仅三点不能宣称普适最优高度、真实 Z 挤压载荷优势或材料物理极限。否定/非单调结果必须保留。

每个新 run 保存唯一 `run_id`、协议/源码/生成配方/程序/OpenLB 版本和库哈希、完整参数、完整 `run.log`、独立 `exit_code.txt`、`result.txt`、边界/q 审计、全程 diagnostics、截面/场 CSV 与原始场索引；后处理必须从原始数据重算，独立记录 PASS/FAIL。所有旧文件与旧 FAIL 原样保留，新增审查在独立报告中完成。本协议冻结的是**问题、矩阵和验收口径**；实施前仍需单独完成源码派生、资源预算、编译、静态 diff 与零步预检，且用户明确启动每批长计算。A、B 及任何失败后的替代路线之间均不得自动越级。
