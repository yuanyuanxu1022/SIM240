## 4 初始化缺陷修复链（本次定位，全部只动本地源码）

1. **NS 混合密度/松弛场未设**（`RHO`/`TAU_EFF` 全 0）→ `computeU` 除零 → 全场 NaN/Inf。修复：`fields::set<RHO>/<TAU_EFF>`（step6G 同款）。
2. **端盖固体格 CH 场未初始化**（材料 4 不在 defineRhoU 的 {0,1,2,3} 指示器内）→ 流体格读到垃圾 PHIWETTING。修复：指示器扩为 {0,1,2,3,4} + 全块（含 padding）先置 φ=1 有效值。
3. **深层固体格法向 {0,0,0} 触发上游抛错** → 自定义表面固体指示器只把"有流体面邻居"的格交给润湿 setter（对上游零侵入）。
4. **`ch.initialize()` 污染 PHIWETTING**（实测 PW: 1→7/6、Σf: 0→1/6，OpenLB 1.8r1 的 CH dynamics 初始化的行为；官方 contactAngle3d 与 step6G/R1 同款路径同样存在）。修复：initialize() 后重设 PW → 重跑 PreCoupling 润湿处理器 → 重算 ChemPotCalc → 再 `iniEquilibrium` 重建平衡。
   - **对 R1 的影响**：R1 的 PASS 是对其自身运行证据的判定，不改写；该污染贡献了 R1 启动瞬态的一部分（R0 诊断已将其归入"非自洽初值"类）。R2-XY 已应用修复；若后续需要，可在 R1 侧加同样的修复做对照（不改变历史判定）。

## 5 剩余阻塞项（正式 run 前必须解决）

1. **前沿接触线启动瞬态（阻塞）**：φ 过冲持续增长（step1: 1.042 → step9: 1.219，~2e-2/步）触发 φ>1.2 发散护栏。位置在斑前沿与基板/模具的接触线区（弯月面 IC 与模型离散平衡弯月面仍有残差：模型实测接触角与输入有 ~3° 偏差（R1 同款），且逐列圆弧是 2D 狭缝解析解、与 3D 离散平衡不完全一致）。候选处置：(a) 用一段"预弛豫"（低通滤波/松弛步）让接触线先成形；(b) 圆角/弯月面参数按模型离散平衡校准；(c) 前沿区用更粗的界面过渡。
2. **稳定漂移 ~4.3e-4/步（阻塞）**：前沿持续运动的 u·∇φ 源项非守恒记账（R0 E3 机制）叠加接触线区贡献；按 R1 全程口径 ≤1e-3 门槛，该速率不可接受。需与阻塞项 1 一起处置后复测；若稳态段（前沿停止后）漂移回落到 1e-8/步量级，则按协议风险 #4 口径如实报告启动段。
3. **§2.8 单位口径**：正式长算前确认 match-σ 口径（dt=2.04e-10 s、μ_eff≈2e-5 Pa·s）。
4. **中心相位**：当前默认 groove（1560 nm）；协议 §2.6（凹槽心）与 §3（足迹边界同相）互斥——groove 相位下足迹边界切半条槽（3 满 + 2 半）。已实现 `--center-phase groove|land|aligned` 三档，正式 run 前确认。
5. **12/24 进程 MPI 挂起**（§3 注）：正式 run 前验证并行规模。
