## 1 目的与范围

为**已经采样过的 19 种几何**补上横槽（T）方向的独立数值对照，使每种几何都具备两个主方向的对照值。**不新增几何**，不增加沿槽算例，不重拟合 V2。

点集见 `points.json`，登记 14 条、全部为 T 方向，其中**本包实际运行 12 条**：

运行（12）：`h50/d25`、`h50/d50`、`h50/d75`、`h50/d100`、`h75/d25`、`h75/d50`、`h75/d75`、`h75/d120`、`h125/d25`、`h125/d50`、`h125/d75`、`h125/d100`。

不运行（2）：`h25/d25_T`、`h25/d50_T`，状态 `EXCLUDED_BY_AUTHOR_DECISION`。

**范围裁定（2026-11-13，作者）**：既有"不追加 h25"的口径指**整档薄隙（h = 25 nm）**，不是仅指 h25/d100 不再加密。因此 h25 档的两个横槽点一律不补，`authorize.py` 与 `run_one.py` 在脚本层拒绝，不依赖人工记忆。此裁定同时覆盖 `excluded_from_this_package` 中的 h25/d120 两点。

> 注意区分：`h125/d25`、`h125/d50`、`h125/d75` 是**槽深** 25/50/75 而间隙 125 nm，不属于薄隙档，仍在 12 条之内。


### 1.1 科学用途（只此一条）

检查现有 5 个成对几何上观察到的现象——固定 V2 使导度绝对偏差普遍减小、但在低方向比处转为低估——**是否也出现在其余已采样几何上**。

> **不得**写成"为了算出 7/19 个低估点"。由现有 5 对推演本次 12 对只是待检验预测；新结果与之不符时如实保留，不据此重跑、不加点、不改门槛。
>
> 即使 19 对全部补齐，也只能描述这些样点上的趋势与符号分布，**不足以宣布一个连续的低方向比过度修正区间**。方向比 A 本身是待预测的输出，不能拿真实 A 的阈值反过来当作可用公式的分段输入。

### 1.2 本包不是 FVM 协议

- 不继承 FVM 的 PASS/FAIL 状态，不继承其 2%／0.40° 判据。那两条在 FVM 协议 §4 中的适用对象分别是固定六方向的单方向一致性与 h75 基准的成对结果，与本包点集不重叠。
- 本包登记的 14 点（实际运行 12 点）中**没有任何一点**存在合格 FVM 对照（唯一合格的 FVM 横槽记录是 h75/d100 T，不在本点集内）。因此不存在跨方法一致性门槛；如某点存在 OpenLB 或 v1-FEM 值，只作为差异报告，不作判据。

## 2 方程、几何与归一化

与 v1 试点完全相同，求解器 `fem_pilot.py` 与 v1 **逐字节相同**（冻结清单中记录该比对结果）。

- 单位长度 `L0 = 1 nm`。周期 `P = 240 nm`、槽宽 `w = 120 nm`、槽深 `d`、间隙 `h`、总高 `H = h + d`。区域 `0 < x < P`、`0 < z < H`，扣除固体凸台 `w < x < P`、`0 < z < d`。
- 左右两侧仅在 `d < z < H` 段周期；槽底、槽侧壁、台阶、凸台顶面与上平板为无滑移。
- `nu = 1e-6 m²/s`、`rho = 1000 kg/m³`、`a = 1e5 m/s²`，`U0 = a L0² / nu = 1e-7 m/s`，无量纲速度 `U = u / U0`。
- 横槽 T：`-ΔU + ∇π = e_x`、`div U = 0`，P2 速度／P1 压力 Taylor–Hood，稀疏直接解，压力零空间用 `∫π dA = 0` 约束，**不做 SIMPLE 外迭代**。
- 导度恢复：`K = (1e-27 / P_nm) ∫Ω U_main dA`，单位 m³。与 FVM 的 `K = nu/a · (∫u dV)/A_plan` 在上述尺度下等价。

## 3 网格与代数

每例三档均匀贴体三角网格：`dx = 5 / 2.5 / 1.25 nm`。节点对齐 `x = 0, w, P` 与 `z = 0, d, H`；固体凸台不生成流体单元。

记录每档单元数、节点数、自由度、矩阵规模、直接解相对残差、K、驱动—黏性功率差、截面通量与周期性诊断。不保存大型矩阵；场文件按档压缩保存并计算 sha256。

**网格档位是冻结的**：某档失败即记失败，不降低门槛、不自动增档、不自动换求解器。

## 4 接收依据（运行前写定，`acceptance_rule.json` 为机器可读版本）

### 4.1 作用层级

协议原文对"功率差"和"截面通量"写的是 **fine**，对相邻档变化量写的是具名档对。因此：

| 检查 | 作用档位 |
|---|---|
| 面积、独立重算 K 与求解器一致、壁面无滑移、速度周期、压力周期、压力均值、直接残差 | **每一档** |
| 功率差 ≤0.1% | **最细档** |
| 截面通量极差 ≤0.01%、截面均值与体积分通量差 ≤0.01% | **最细档** |
| coarse→mid K 变化 ≤1%、mid→fine ≤0.5% | 具名档对 |

较粗档超出最细档门槛时，作为**诊断**记录并保留在复核回执里，不删除、不改写为通过。最细档超出即该点不接受。这一层级与 FVM 协议 §4 一致（其原文亦写明 coarse/mid 只保存诊断、不施加最细层门槛）。

### 4.2 逐项门槛

| 项 | 门槛 |
|---|---|
| 输出有限 | 全部为有限值 |
| 流体面积相对误差 | ≤1e-10 |
| 独立重算 K 与求解器自报相对差 | ≤1e-9 |
| 壁面无滑移归一化最大值 | ≤1e-10 |
| 速度周期差归一化最大值 | ≤1e-10 |
| 压力周期差归一化最大值 | ≤1e-10 |
| 压力均值归一化值 | ≤1e-10 |
| 直接解相对残差（**复核器重算**，不用自报值） | ≤1e-10 |
| 最细档功率差 | ≤0.1% |
| 最细档截面通量极差、截面与体积分差 | ≤0.01% |
| coarse→mid K 变化 | ≤1% |
| mid→fine K 变化 | ≤0.5% |
| 非壁面截面数 | ≥9 |

逐点散度只作诊断：P2/P1 只保证弱不可压缩，一票否决用的是重组离散方程的代数残差。

### 4.2.1 本层补加的两项检查

v1 复核器的 `evaluate_gates` 未实现协议里的两句要求，本节在 `verify_one.py` 里补上，**不改动 `verify_results.py`**（它与 v1 逐字节相同，以保证新点与既有 22 条用的是同一套判据逻辑）：

1. **所有输出必须有限**。NaN 与 `value > 1e-10` 比较恒为假，若不显式检查会静默通过；
2. **横槽最细档非壁面截面数 ≥ 9**。v1 只检查了截面通量极差，没检查截面数。

两项的失败原因都写进复核回执的 `additive_gate_problems`，并参与 `actual_stop_reason`。

### 4.3 来源要求（与数值要求并列，不可互相替代）

1. 运行时发布清单未漂移（包内文件哈希与受控依赖版本逐项复算）；
2. 存在唯一 `run_id`；
3. 记录真实命令行、工作目录、解释器、进程号、主机名；
4. 求解进程退出码为 0；
5. 每档记录网格指纹（`p`、`t` 数组哈希）与场文件哈希；
6. 复核器重新哈希场文件，并与求解回执一致；
7. 复核器读取的求解回执摘要，在评估时仍与磁盘一致（回执未被事后编辑）；
8. 求解进程退出码写入回执本身且为 0（由求解进程在收尾时写入，复核器核对）；
9. 每档网格 JSON 的哈希在求解回执中记录，复核时仍与磁盘一致；
10. 每档方向与几何与冻结点集一致（不以结果 JSON 的自报值作准）；
11. 复核回执只写一次；重写须显式 `--replace` 并记录被替换回执的摘要。

### 4.4 分类

| 标签 | 条件 |
|---|---|
| `NOT_RUN` | 无求解回执 |
| `SOLVE_INCOMPLETE` | 有求解回执但 `state` 非 `SOLVED`，或计划档未全部完成 |
| `SOLVED_NOT_VERIFIED` | 求解已完成但无复核回执 |
| `NOT_RECONSTRUCTIBLE` | 有复核回执但 `results/` 缺失，无法从场文件重算 |
| `LOCAL_CHECKS_FAIL` | 从场文件重算后至少一项数值门槛超出（`actual_stop_reason` 写第一条实测事实） |
| `PROVENANCE_INCOMPLETE` | 数值重算通过，但至少一条来源要求不成立 |
| `REFERENCE_CANDIDATE` | 数值重算通过且来源要求全部成立 |

**标签由 `assess.py` 从原始场文件重算；复核回执自报的标签只用于交叉核对，不直接采用。**
仅有求解回执而尚未复核者标 `SOLVED_NOT_VERIFIED`，**不是** `NOT_RUN`。

**`REFERENCE_CANDIDATE` 是本包脚本能给出的最高标签，不是正式参考资格。** 正式资格须另经方法、精度与来源的独立审查并由作者与复核人签署，不由任何脚本自动授予。

**这套机制的边界必须如实表述**：它做到的是"结论可重算、代写无效"——改标签、改结论、只补回执都能被重算挡住。
它**不是"不可伪造"**：回执无签名，有写权限者若连同 `results/<case>/` 的场文件整体伪造，
本包无法分辨。因此任何"回执不可篡改"的说法都是过度声称，不得使用。

`actual_stop_reason`（实测事实）与 `post_hoc_acceptance`（依规则得出的分类）分两个字段写，避免把事后判断混入运行记录。

### 4.5 继承而来但不可触发的 FVM 分支

`verify_results.py` 的 `has_fvm_ref` 分支（最细档 K 与 FVM 差 >0.5% 记为问题项）与 v1 逐字节相同，
在本包点集上**不可触发**：其 `FVM_REF = {h75_d100_P, h75_d100_T}` 与本点集交集为空，
与 `acceptance_rule.json` 的 `cross_method_consistency.applies_to = []` 一致。
保留该分支是为了不改动与 v1 相同的复核器；它不是本包的接收门槛。

### 4.6 单点异常不得毁掉整张表

停止规则要求每个约定点都有结论。因此：

- `results/<case>` 下的元数据或场文件无法重算时（缺字段、损坏、非有限值），该点记
  `NOT_RECONSTRUCTIBLE`，并在 `assess_problems` 写明重算抛出的异常类型与信息；
- 求解回执本身不可解析时，该点记 `SOLVE_INCOMPLETE`，`assess_problems` 写 `unreadable`；
- 复核回执不可解析时按**不存在**处理（→ `SOLVED_NOT_VERIFIED`），绝不当作通过；
- 以上三种情况都只影响该行，`assess.py` 仍写出完整 14 行表。

这条是"崩溃即无表"的兜底：崩溃不会产生假候选，但会让所有点失去结论，与停止规则冲突，
故按异常记录而不是按异常退出。

## 5 记录机制：四个文件与它们各自能证明什么

| 文件 | 何时写 | 能证明 | 不能证明 |
|---|---|---|---|
| `release_manifest.json` | 首次运行前冻结 | 包内每个文件与依赖版本在冻结后未变 | 物理正确性 |
| `runs/<run_id>/SOLVE_RECEIPT.json` | 求解进程开始前写 `STARTED`，每档后原子更新 | 这次运行确实发生过：run_id、命令、退出码、逐档网格与场哈希、墙钟、峰值内存 | 数值是否合格 |
| `runs/<run_id>/VERIFY_RECEIPT.json` | 独立复核进程写 | 有人独立重算过，且重算读数与求解回执一致 | 方法本身适用于更多几何 |
| `ASSESSMENT.csv` | 汇总时写 | 约定点集逐项都有处置（含 `NOT_RUN`） | 参考资格 |

**回执只能由运行当时的进程写。** 事后构造、补填、覆盖一律视为伪造溯源，本包脚本以拒绝覆盖（`results/<case>` 已存在即拒跑）的方式防止混用两次尝试。

**测试隔离**：`tests/` 下的自检只在临时副本上进行（复制时忽略 `results`、`runs`），不写真实
`runs/`、`results/`，不改真实 `release_manifest.json`，也不创建 `authorization.json`；
`tests/test_isolation.py` 在测试前后断言真实包的 `release_sha256` 与两个输出目录的文件清单未变。

本包只证明本包的新运行。v1 那 22 条历史记录缺少逐次运行绑定，按既有的"有限采用"身份继续处理，**不因本包有回执而被追认为完整溯源，也不为本包回执之外的任何运行补造历史**。

## 7 停止规则（运行前写定）

1. 对**已授权**的点各求解一次、各独立复核一次，不重复、不跳过；
2. 出现反例（与预期趋势相反）时**限定主张，不自动加算例**；
3. 任一前置来源检查失败即停该例并记录，不继续以"先跑出来再说"；
4. 约定点集全部有处置后转入改稿，**不以凑出低估点数或全部通过为停止条件**；
5. `STOP` 文件存在时，队列跑完当前例即停。
