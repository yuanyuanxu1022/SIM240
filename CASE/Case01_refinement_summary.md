# Case01 refinement 诊断矩阵

## 目的与范围

本矩阵用于定位 Case01 中约 4.68% 的 `Jy` 解析误差。只比较基准 Case01-Bouzidi、空间加密 R2 和松弛时间变化 R3；未运行 EX240、Case01a、Case01b 或 Case02，也未修改 Frozen Protocol 和原 Case01 结果。

为了在改变 `dx` 或 `tau` 时保持相同物理运动黏度 `nu=1e-6 m2/s`，时间步由 D3Q19 converter 关系

`tau = 0.5 + 3*nu*dt/dx^2`

确定。因此 R2 使用 `dt=2.5e-12 s`，R3 使用 `dt=4.166666666666667e-12 s`。若机械保持原 `dt=1e-11 s`，则指定 tau 与物理黏度不能同时成立，不能构成受控对照。

## 误差来源诊断

### 1. 空间阶

固定 `tau=1.7`，dx 从 5 nm 减至 2.5 nm：

- `Jy` 误差比为 4.00002，对应观测阶 `p=2.00001`；
- velocity L2 误差比为 3.99999，对应观测阶 `p≈2.00000`；
- 剖面常量偏移从 `2.087499788e-6` 降至 `5.218720660e-7 m/s`，约缩小四倍。

这证明主误差为 `O(dx^2)`，不是随网格不消失的真实滑移，也不是缺失周期 wall-link。

### 2. tau 依赖

固定 `dx=5 nm`，tau 从 1.7 改为 1.0 后：

- `Jy` 误差由 4.675555% 降至 0.444441%；
- velocity L2 由 4.065283% 降至 0.202855%；
- 常量剖面偏移由 `2.087499788e-6` 降至 `1.041649886e-7 m/s`。

因此该误差强烈依赖 BGK 松弛时间，而不是单纯的几何壁面位置误差。

### 3. 与离散误差形式的吻合

三个结果均与以下离散误差形式吻合到稳态停止容差量级：

`epsilon_J = (8*tau^2 - 8*tau + 1) * (dx/H)^2`

| Case | 实测 Jy 相对误差 | 上式预测 | 差值 |
|---|---:|---:|---:|
| 基准 | 0.0467555510 | 0.0467555556 | -4.51e-9 |
| R2 | 0.0116888263 | 0.0116888889 | -6.26e-8 |
| R3 | 0.00444440865 | 0.00444444444 | -3.58e-8 |

对应的格点中心速度剖面常量偏移与

`u_offset = ay*dx^2/(24*nu) * (16*tau^2 - 16*tau + 1)`

同样吻合。`Jy` 误差还包含用格点中心离散积分连续抛物线时的 `O(dx^2)` 中点积分项。

上述公式是由当前三组结果识别并得到精确系数吻合的离散规律。用于论文前，仍应从当前 OpenLB ForcedBGK forcing 与 q=0.5 Bouzidi/halfway bounce-back 的离散方程正式推导，或用权威文献与额外独立点验证，不能仅凭三点拟合直接作为普适公式发表。

## 结论

Case01 的 4.68% 误差主因是 `ForcedBGK + 离散体力 + q=0.5 halfway wall` 组合产生的二阶、tau 相关离散偏移。周期 MATERIAL overlap 缺失是此前真实的集成错误，但在 link 完整修复后，它不再解释剩余误差。

R2 和 R3 都将解析误差降至 2% 以下，其中 R3 独立退出码为 0。不能据此直接选择 tau=1.0 作为所有后续纳米沟槽计算参数：改变 tau 会改变边界/碰撞离散误差系数，甚至可能产生误差抵消。正式方案应优先做离散方程推导，并至少增加一个网格点验证二阶收敛和外推值。
