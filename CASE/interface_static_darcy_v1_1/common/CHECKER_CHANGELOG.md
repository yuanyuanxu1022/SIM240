# 结果检查器1.1.0发布说明

日期：2026-10-30；物理协议仍为SDI-v1，未改科学门槛。

## 相对于原C01封装的修改

1. 先按Sf的最大面内分量识别主轴，用已有的10⁻¹⁰归一化几何容差识别非主浮点分量；不要求严格等于0，不更改任何原始Sf或phi。
2. 读取本次manifest的C01/C02身份，选取相应输入文件，检查manifest和输入身份一致；只接受这两个已指定的x驱动案例。
3. 输出checker_version=1.1.0，便于后续结果追溯。

原严格零值识别误拒了C01中294/1072个有效面，最大非主相对分量5.4398×10⁻¹⁴。原检查器的NOT_EVALUATED记录、报告目录的v1.1分析版本、旧封装和原始数据全部保留。完整差异见项目报告目录SDI_C02_preparation_20261030/checker_1_1_release.diff。

- 用已有C01数据复核：50个数值检查、原始输出哈希及PASS状态与前轮修正版结果完全一致；没有C01重跑。
