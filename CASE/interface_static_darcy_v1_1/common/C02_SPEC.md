## 2. 解析预期值

对本例恒系数和边界，p(x)=10⁶(24×10⁻⁶−x)Pa，U=KxxG/(μH)，J=HU，Q=J Ly。C02解析预期：

- Ux≈8.331211263609563×10⁻⁷m/s。
- Jx≈1.0414014079511954×10⁻¹³m²/s。
- Qx≈4.998726758165738×10⁻¹⁸m³/s。
- C02/C01解析流量比≈2.286886803584717。

这些是输入代入解析式的准备值，不是C02程序输出。**两例的压力曲线预期相同，因此不能只靠压力判断槽向接对；关键是流量和从计算结果恢复的K是否随主值交换。** 上述比值是本边界下的静态压力驱动流量比，不是挤压阻力比，也不证明V2比原公式准确。
