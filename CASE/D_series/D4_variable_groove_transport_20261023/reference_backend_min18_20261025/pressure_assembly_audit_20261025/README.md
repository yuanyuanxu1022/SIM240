# 9 项混合矩形方程的压力零空间与右端检查（2026-10-25）

本次仅针对原 18 项白名单中的 9 项 **P2 速度/P1 压力混合问题**。沿用上轮实际二维矩形网格、上下零速度、x 周期多点约束和原 UFL 弱式，编译并组装真正的 PETSc 矩阵 `A` 与右端 `b`。平板横槽使用无量纲单位 x 向体力；MMS 使用原符号制造源项。按原计划分别使用 8 或 12 阶积分。每项独立子进程退出码 0，详细记录在 [`evidence/assembly_all9.json`](evidence/assembly_all9.json)，独立无后端复核在 [`evidence/independent_record_review.json`](evidence/independent_record_review.json)。**没有调用线性求解器、计算速度/压力场或启动 OpenLB。**

## 关键发现及修正

上轮 `mesh_periodic_pressure_20261025/interface.py` 返回的常压候选把右侧**从属压力自由度**也设成 1。当前 MPC 组装矩阵在从属行加入单位对角项，因此它在实际组装矩阵上并非零向量。九项的旧候选 `‖A n‖₂/‖A‖F` 为 **4.1721×10⁻⁵ 至 1.3690×10⁻³**，均高于接口演示使用的 10⁻¹⁰ 检查值。原接口文件及其历史合成测试保留不改；不能把那次“压力接口已备”理解为这个候选能直接传给真实矩阵。

本目录在原候选的 MPC 从属位置清零，再正规化，得到**代数约束空间**里的常压零向量；这不改变物理压力场应在左右周期边界相等的含义。九项的 `‖A n‖₂/‖A‖F` 为 **2.1996×10⁻²¹ 至 1.7092×10⁻¹⁹**，原始 `‖A n‖₂` 最大 **3.028×10⁻¹⁷**；九项 `PETSc.NullSpace.test(A)` 均返回真。矩阵均在 10⁻¹¹ 判据下对称，组装值和右端有限。该证据验证了一个预期零模，未用谱分析证明零空间**恰好只有一个维度**。

组装并施加零固壁条件后，九项 `nᵀb/‖b‖₂=0`，压力方程对应右端自由度均为 0；移除该零空间分量前后右端差的范数为 0。这项相容性结果与此处纯速度体力和零速度壁面条件相符，**不能推广**到未检查的非零边界值、压力跳跃或沟槽。重复组装的平板最细格与 MMS N32 两对矩阵 CSR/右端字节哈希分别完全相同；12 阶积分重复项单独记录，不拿它证明精度。

最大矩阵为 `104943×104943`、`3103649` 个已用非零元。记录包含每项网格和周期映射哈希、CSR 矩阵哈希、右端哈希、矩阵范数、两个候选的残差和相容性、PETSc 内置零空间测试、退出码和源文件哈希。独立复核核了 9 项、2 对重复项、前一保护清单 4233 条路径及上一接口包 19 个文件，均无变化。`probe.py`、`run_audit.py` 只组装和作矩阵向量运算，没有 `solve()` 调用；`verify_records.py` 仅读记录与原文件。
