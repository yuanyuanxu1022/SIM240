# Offline analysis v2: preparation and software consistency specification

This version has no route for processing the actual N8 record or launching a solver. Only synthetic records carrying the explicit SYNTHETIC_EXTRACTOR_REVISION_NOT_RESULT binding and marker may enter the testable schema reader. The real N8 directory, its descendants and ancestors are rejected before payload access. The original extraction entry unconditionally rejects.

Trust anchor fixes the binding digest, acceptance certificate digest, original accepted-input-list digest, relative 48-file inventory digest, runtime code digests and specification digest. Every inventory entry must already occur in the accepted-input list. A matching newly generated inventory by itself cannot replace these anchors. The real draft additionally binds the original ONE_N8_DIAGNOSTIC_ACCEPTED certificate and its archived accepted inputs; real extraction authorization remains false.

Runtime artifact schema is contract.json, capture_manifest.json, archive/worker_completion.json, the two archive group manifests, and exact 8+17 arrays. Synthetic records use the same field structure but explicit synthetic status/kind values and a synthetic source identifier. Each array is decoded from an immutable byte snapshot whose digest has already been checked; a second scan after loading and after metric computation checks inventory and bytes again. Synthetic acceptance inputs and certificate live outside the source record and are rechecked.

The numerical definitions remain those in G4_reference_criteria_review_20261026/CRITERIA_REVISION.md. The P2/P1 numerical core is copied unchanged from v1 and remains confined to dimensionless 2x1 mixed rectangles. No physical threshold is activated.

Predeclared software comparison: pressure-test integral vs CSR residual is normalized by full nonzero RHS norm and compared with 2e-11. Reconstruction, periodic and wall max absolute discrepancies are divided by max(saved velocity amplitude, saved pressure amplitude), which must be positive, and compared with 2e-11. Periodic and wall index coverage must be complete. Postprocess quadrature normalized changes use the previously reviewed 1e-8 target. An absolute band of 64 float64 eps (about 1.42e-14) around either software limit is NEAR_THRESHOLD; this is a software decision band, not a proved error bound or uncertainty interval. Missing, nonfinite or negative normalized discrepancies are not PASS. Positive D/W/J and complete finite metrics are required for a successful synthetic analysis record. Energy, L2 and residual values are persisted without issuing a physical Gate.

Output is a unique sibling of the input tree with fixed analysis_id. No overwrite or resume. Required artifacts: input_binding.json, events.jsonl, metrics.json and checks.json on completed metric extraction, status.json, analysis.exit_code, output_manifest.json; exceptions additionally retain failure.json and traceback. Successful record is SYNTHETIC_METRICS_RECORDED, never a real result. Exit codes: 0 recorded and software-consistent; 2 input/extraction/serialization exception; 3 near-threshold/inconclusive; 4 recorded but software-inconsistent. Preflight rejection before a safe output directory exists raises instead of writing to an untrusted destination. Input and output paths must not overlap. Child CLI propagates the recorded exit; a separate shell observation checks it.

The independent nonzero error fixture uses uh=(z(1-z),0), ph=x-1 against the MMS exact fields: B=.01*(2/105+pi^2/630), velocity error squared integral B, exact norm squared 1/15+B; pressure error squared integral 2/3+.005 and exact norm squared .005. Pressure offsets and index permutations must preserve those results. This checks the existing L2 definitions, not a new PDE theory or error bound.
