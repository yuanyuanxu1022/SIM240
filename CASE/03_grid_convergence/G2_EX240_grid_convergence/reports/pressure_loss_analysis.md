# EX240 周期压力重分布分析

## 1. 分析定义

两方向均采用周期体力驱动，宏观等效压力梯度为

\[
G=\rho a=1000\times10^5=1.0\times10^8\ \mathrm{Pa/m},
\]

在一个 240 nm 周期上的等效驱动为

\[
\Delta p_{\mathrm{eq}}=GL=24\ \mathrm{Pa}.
\]

该 24 Pa 对 parallel 和 perpendicular 完全相同。VTI 中
`pressure_Pa` 是由局部密度扰动换算的周期压力修正场，用于描述几何诱导
的压力重分布；不能把 `p_max-p_min` 再加到 24 Pa 上，也不能把它直接当成
额外宏观压降。

当前 Mach 数为 `O(1e-8)`，分析采用 creeping-flow/黏性流动语言，不使用
高 Reynolds 数下的“分离损失”或“压力恢复损失”解释。

## 2. Parallel 压力场

沿槽 `+y` 方向，几何对 `y` 平移不变。`dx=1.25 nm` 最终场中：

- 全流体压力范围约 `[-1.71e-6, 0] Pa`；
- 沿 `y` 的相位平均压力为常数 `-2.59e-7 Pa`；
- 相位平均 `dp/dy` 在 Float32 VTI 精度内为零。

因此 parallel 的宏观驱动主要由均匀体力承担，没有可分辨的沿程周期压力
调制。局部微帕级变化相对于 24 Pa 等效驱动可以忽略。

## 3. Perpendicular 压力场

横槽 `+x` 方向出现显著的几何诱导压力重分布：

| 指标 | dx=1.25 nm | dx=2.5 nm |
|---|---:|---:|
| 全流体 p_min (Pa) | -12.7765 | -10.4082 |
| 全流体 p_max (Pa) | 12.7767 | 10.4082 |
| x 相位平均 p_min (Pa) | -4.83090 | -4.78532 |
| p_min 位置 (nm) | x=60.625 | x=61.25 |
| x 相位平均 p_max (Pa) | 4.83104 | 4.78528 |
| p_max 位置 (nm) | x=179.375 | x=178.75 |

两个稳定的相位平均极值分别位于中央沟槽的两侧边缘
`x≈60 nm` 和 `x≈180 nm`。这说明横槽流动需要建立与台阶几何相联系的
局部压力梯度，以在薄膜区、沟槽口和深沟槽之间重新分配动量。

中央沟槽内部的相位平均压力由负值逐渐上升为正值，代表局部
`dp/dx` 与均匀体力共同构成空间非均匀的净驱动。dx=1.25 和 2.5 nm
给出的极值位置及约 4.8 Pa 的相位平均幅值一致，支持该压力重分布模式
具有网格层面的定性稳定性。

## 4. 为什么不能把局部压力范围称为额外损失

周期体力问题不存在传统入口到出口的独立静压边界。局部压力可以在一个
周期内降低、升高并在周期接缝闭合；其作用是满足不可压缩约束及几何改变
引起的局部动量平衡。故：

- `p_max-p_min` 不是第二个宏观压降；
- 局部压力上升不是高 Re 意义的“压力恢复”；
- 不可逆阻力应由通量—驱动关系和黏性耗散评价，而不是由局部压力极差
  单独评价。

沟槽边缘的点值压力梯度对网格敏感。例如相位平均梯度的最陡负峰从
dx=2.5 nm 的约 `-6.55e8 Pa/m` 增至 dx=1.25 nm 的约
`-1.31e9 Pa/m`，没有表现出点值收敛。因此它只能定位几何突变附近的
强梯度，不能作为论文中的收敛局部损失系数。相反，相位平均压力极值位置、
幅值和全局 `Keff` 是更稳健的证据。

## 5. 机制结论

Parallel 几何沿主流方向不变，局部压力修正几乎为零；perpendicular
跨越周期台阶，需要明显的周期压力重分布来驱动速度场在薄膜与沟槽之间
调整。该压力场本身不是额外压降，但它是横向几何约束及速度重构的直接
证据，并与较低的 `Q_perpendicular` 和较高的 `R_perpendicular` 一致。

细网格 perpendicular 的质量误差略超门槛，故以上结论定位为机制解释，
不提升为该运行的完整 `RESULT_PASS`。
